# Matrix multiplication construction draft

Use the native chapter for explanations. This folder supplies its cumulative starter,
step metadata and exact input recipes. Replace only the named region's temporary
branch and nop. Each incomplete program returns safely, so partial values can be
observed at matmul_done before the caller writes completed. A provisional count is
not evidence that the product is complete. The method word selects scalar zero or
tiled one. Final free-writing checks must accept equivalent internal implementations.

Use prepare.py with an input recipe and your current cumulative source to produce a
separate observation file. It refuses overwriting either your source or an existing
output. Match the listed shape and arrays before comparing temporary registers.
Recipes contain public expected states, not instructor answer keys. Observe t-registers
at the return boundary; the supplied exit has already restored s0..s7 and fp.
