The directly edited native chapter is the composition authority. This folder contains
its cumulative starter, 34-step transcript, 68 progressive hints and 52 exact recipes.
Replace the named marked region while retaining surrounding labels and supplied code.
The first bit/table stubs have three instructions; most others have a branch and nop.
A provisional initializer returns zero, even after an intermediate table store. An
unfinished file returns its retained raw state with development status three after
closing any acquired descriptor. Neither is a completed public result.

Run prepare.py with a recipe ID, --source /path/to/current.asm and a new --output path.
The helper retains the source and refuses existing outputs. For table-update recipes
it supplies an independent 256-word table. Kernel observations stop at kernel_done
before raw_result is stored. File observations stop at file_done before the checksum
and status stores; s30 uses the second file_read visit inside the completed routine.
Working saved registers are restored when the file function returns.

For a real host file, optional --fixture-output /tmp/fixture.bin writes the recipe bytes
and embeds that absolute ASCII path in the separate source. The path must fit the
128-byte arena. Ordinary host files do not force short reads, missing paths or injected
read failures. The guided CLI checks install those controls explicitly in memory.
Do not label their numerical states as captured IDE screenshots.
