# Codec construction draft

The directly edited native chapter is the publication authority. This folder supplies
its safe cumulative starter, step transcript, progressive hints and exact input recipes.
Replace the named region's two temporary instructions. The initial decoder width gate
branches forward instead of returning, and is replaced only after the known-valid payload
loop is built. Preserve all supplied frame/status/exit excerpts and surrounding labels.

Keep default count/capacity/method lines in your cumulative source. Run prepare.py with
a recipe ID, --source /path/to/your.asm and --output /tmp/new-observation.asm. It refuses
an existing output or your source path. The recipe changes the input direction, extent
and capacity in the separate file, using unsigned byte values from inputs.json.

Most recipes pause at codec_done before caller result stores. s57-1 is an internal
completed-decoder observation at dec_terminal. Read its documented scan/commit state
before continuing to the return boundary. Saved working registers are restored on return.
An incomplete stage can write pending candidate bytes before its counters are published;
those construction states do not satisfy the final item-atomic codec contract.

Native prose is not regenerated by the structured transcript. Instructor quiz keys and
the completed reconstruction remain private. Archives, public per-step check packaging,
remote progression, enforced hint policies and actual IDE captures remain pending.
