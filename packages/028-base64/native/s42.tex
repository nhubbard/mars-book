\section{Step 42 Compare complete work boundaries}\label{base64-s42}

Measure the complete scalar and vector entries after both accept the same data. Include validation, frame handling and tail work. Keep kernel-only observations separate, and record the binary pattern and text length used for each result.

\subsection{Expected observation}
The complete decoder includes validation costs that a direct kernel measurement omits.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
What makes two instruction-work measurements comparable?

\begin{itemize}
  \item \textbf{A} Only the vector register count.
  \item \textbf{B} The same input and function boundary.
  \item \textbf{C} An identical source-line count.
\end{itemize}
