# Verified native IDE figures

Four editable native LaTeX plates use twelve original IntelliJ Light captures. Each state is reached at chunk_ready through a native conditional breakpoint. Source, signed-decimal return registers, all eight state words and input bytes are checked before and after each photograph.

Sixteen numbered explanations distinguish accepted bytes, completed scalar values, per-call consumption, pending continuations, sequence starts and detecting byte/end offsets. The examples include a split four-byte sequence, successful finality including U+0000, an impossible continuation, and an empty final call that detects truncation without reading mapped input.

A separate oracle checks all 244 data bytes before execution and at every call boundary in three fixtures, with bounded reads and exact stores including terminal refusal. Prefix feasibility is checked independently using legal scalar intervals; Python strict decoding verifies completed scalars. The capture automation belongs to the separate authoring plugin that depends on MARS. Original PNG pixels are unchanged. Color/grayscale proof review and automated tagging/font checks pass; independent accessibility review remains open.
