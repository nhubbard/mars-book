# Step 5: Load the active stream into temporaries

Load the six working state fields into t0 through t5. Copy the full input pointer into t6 and initialize the per-call accepted count in t7. No scalar or byte has been accepted by these instructions.

## Write or inspect

Append the instructions in the `load` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    lw $t0, 0($a0)
    lw $t1, 4($a0)
    lw $t2, 8($a0)
    lw $t3, 12($a0)
    lw $t4, 16($a0)
    lw $t5, 20($a0)
    move $t6, $a1
    move $t7, $zero
```
