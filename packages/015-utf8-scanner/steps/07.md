# Step 7: Select the ASCII completion path

For an idle state, compare the unsigned byte with 128. Values below it encode one complete scalar and can share the later scalar-completion code. A pending state never reaches this test, so an ASCII byte cannot silently interrupt a multibyte encoding.

## Write or inspect

Append the instructions in the `ascii` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    sltiu $t9, $t8, 128
    bne $t9, $zero, scan_ascii
    nop
```

## Expected observation

The comparison accepts every byte from hexadecimal 00 through 7f, including zero.
