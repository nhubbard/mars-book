# Step 20: Count a completed scalar

Increment the scalar count and set sequence start to minus one. ASCII reaches this block directly; a multibyte sequence reaches it only after its last continuation. Need is zero on both paths.

## Write or inspect

Append the instructions in the `complete` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    li $t5, -1
```
