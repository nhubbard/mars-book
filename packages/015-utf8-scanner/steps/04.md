# Step 4: Reject a terminal stream

Load status before accessing input. A nonzero stored status means the stream has finished or failed. Return minus three and zero immediately. This path performs no state stores and preserves the earlier status and diagnostic.

## Write or inspect

Append the instructions in the `gate` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    lw $v0, 24($a0)
    beq $v0, $zero, scan_active
    nop
    li $v0, -3
    move $v1, $zero
    jr $ra
    nop
```

## Expected observation

A previously finished state remains finished even when the new input is invalid.
