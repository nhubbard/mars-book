# Step 13: Require the f0 lower bound

Set need to three for a four-byte lead. If the lead is f0, raise the next-byte minimum to decimal 144, hexadecimal 90, and jump to byte acceptance. This prevents encodings below U+10000 from using four bytes.

## Write or inspect

Append the instructions in the `four_low` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    li $t2, 3
    li $t9, 240
    bne $t8, $t9, scan_four_high
    nop
    li $t3, 144
    beq $zero, $zero, scan_accept
    nop
```

## Expected observation

After accepting only f0, the pending range is 90 through bf in hexadecimal.
