# Step 9: Reject values below the first valid multibyte lead

Test whether the byte is below decimal 194, hexadecimal c2. ASCII has already been dispatched. The remaining smaller values are standalone continuations or c0/c1, none of which may begin a well-formed sequence. Branch to the error path.

## Write or inspect

Append the instructions in the `lead_min` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    sltiu $t9, $t8, 194
    bne $t9, $zero, scan_bad
    nop
```

## Expected observation

The branch condition rejects hexadecimal 80 through c1 as idle-state leads.
