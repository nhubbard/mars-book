# Step 8: Record a candidate sequence start

For a non-ASCII byte in an idle state, retain the current absolute total as its candidate start. Set ordinary continuation bounds 128 through 191. Later classification either refines those bounds or reports this byte as an impossible lead.

## Write or inspect

Append the instructions in the `candidate` region. Keep the scaffold labels and return stub. Intermediate register observations do not yet establish the final function contract.

```asm
    move $t5, $t0
    li $t3, 128
    li $t4, 191
```

## Expected observation

A rejected standalone continuation still has a diagnostic sequence start at its own offset.
