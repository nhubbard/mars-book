\section{Step 35 Probe an exactly full buffer privately}\label{ppm-s35}

When accumulated bytes equal capacity, request one additional byte into the supplied private probe at frame offset ninety-six. Zero proves exact-fit EOF. A positive byte proves excess input and a negative result is an I/O error. Close the descriptor on both failures without publishing metadata.

Author region \texttt{l\_probe}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{load\_eof} for the observation.

Use recipe \texttt{s35-1} with the cumulative source through this edit.

\subsection{Expected observation}
An exact fit reaches EOF; a twenty-two-byte capacity rejects the twenty-three-byte input without writing beyond the buffer.
