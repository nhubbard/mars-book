\section{Step 13 Observe a failed parser publication}\label{ppm-s13}

Repeat the trailer and unterminated-comment recipes with the completed parser. Compare the complete metadata object with its initial sentinels. A plausible width and height are not a successful result when the remaining file has the wrong extent.

Use \texttt{s11-trailer}, \texttt{s07-unterminated} for this observation.

\subsection{Expected observation}
Format failures return one with zero count and unchanged metadata.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Does a plausible width certify the file?

\begin{itemize}
  \item \textbf{A} Yes, if the destination is large.
  \item \textbf{B} No; the full declared extent must also be valid.
  \item \textbf{C} Yes, if Maxval appears anywhere later.
\end{itemize}
