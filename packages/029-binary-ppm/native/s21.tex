\section{Step 21 Inspect color words and their stored bytes}\label{ppm-s21}

Use the completed decoder to compare numerical words with their little-endian byte representation. Then use the first-sample-LF variant. That sample must survive unchanged because header scanning ended at the declared boundary.

Use \texttt{s20-1}, \texttt{s20-binary} for this observation.

\subsection{Expected observation}
Red is a numerical 0x00ff0000 word even though its stored low bytes are 00 00 ff 00.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Does little-endian storage reverse the PPM component order?

\begin{itemize}
  \item \textbf{A} No; it describes the stored word representation.
  \item \textbf{B} Only for zero samples.
  \item \textbf{C} Yes, it changes the file to BGR.
\end{itemize}
