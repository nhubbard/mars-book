\section{Step 31 Compare adjacent decimal-width boundaries}\label{ppm-s31}

Repeat the encoder with widths nine and ten. Identify the added ASCII digit and follow the first raster offset in each result. The extra header byte changes the raster position without changing the three-byte-per-pixel rule.

Use \texttt{s30-width-nine}, \texttt{s30-width-ten} for this observation.

\subsection{Expected observation}
Each output length follows nine plus both digit counts plus three times the pixel count.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
What changes when a dimension gains a decimal digit?

\begin{itemize}
  \item \textbf{A} The header gains one byte.
  \item \textbf{B} Every pixel gains one byte.
  \item \textbf{C} The pixel word changes endianness.
\end{itemize}
