\section{Step 2 Reject impossible byte counts}\label{ppm-s02}

In the parser entry, compare the full unsigned count with 12544 before loading a caller byte. Reject an over-limit count with status two, then reject counts below three with status one. Use an unsigned comparison so a high count bit cannot bypass the bound as an apparently negative value.

Author region \texttt{p\_bound}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{after\_p\_bound} for the observation.

Use recipe \texttt{s02-1} with the cumulative source through this edit.

\subsection{Expected observation}
A valid count reaches the next checkpoint without reading source; empty and high-bit counts return their declared errors.
