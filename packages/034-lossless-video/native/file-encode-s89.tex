\section{Step 89 Pass only the remaining staging window}
Fill \texttt{fe\_window}. Subtract the produced offset from the admitted staging capacity. Require at least twenty bytes before calling the record encoder, then place this remaining capacity in the private record context. Its destination is the staging base plus the produced offset. The source argument remains exactly one native image, even though the enclosing call received several images.

For the first iteration, the produced offset is twenty-four. After that iteration, the offset will depend on the actual record count returned. Passing the original total capacity at every iteration would authorize a later record to extend beyond the physical end of the staging area.

Use \texttt{s89-1} and stop before \texttt{fe\_window\_ready}.

\paragraph{Observe} The first record destination is twenty-four bytes after the staging base. Its capacity excludes those header bytes.

\Needspace{8\baselineskip}
\paragraph{Check} Which capacity belongs in the nested record context?
\begin{enumerate}[label=\Alph*.]
\item The remaining capacity after the current produced offset.
\item The source byte count for the whole file.
\item The original total staging capacity on every iteration.
\end{enumerate}
