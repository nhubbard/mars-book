\section{Step 24: Admit complete-file arguments}
A file needs a 24-byte global header. Its conservative maximum is
7\,344\,152 bytes, including 256 maximally bounded records. Admit this unsigned
64-bit interval before loading any argument window. Check directory and context
alignment with their low three address bits. The file pointer is deliberately
three bytes after its arena label in the supplied example, so byte-addressed
parsing is required.

Fill \texttt{index\_admit}. The upper limit does not fit the immediate operand
of \texttt{sltiu}; load the exclusive upper bound 7\,344\,153 into a register
and compare unsigned registers. Retain the initialized failure return on an
invalid argument. Only an admitted call enters the supplied prologue, which
copies arguments to \texttt{\$s0} through \texttt{\$s3}.

\paragraph{Observe} Prepare \texttt{s24-1} and stop before
\texttt{index\_admitted}. At \texttt{index\_admitted}, \texttt{\$a1} is 24\,795 and
the final alignment mask in \texttt{\$t0} is zero. No context or directory
byte has changed.
