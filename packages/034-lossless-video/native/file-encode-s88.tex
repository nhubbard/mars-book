\section{Step 88 Serialize the global header}
Fill \texttt{fe\_header}. Write the magic, fixed geometry, frame count, period, zero flags, duration and reserved zero field using the byte layout defined earlier. The file format is big-endian in both machine byte orders. Byte stores make this explicit and permit the staging base to be unaligned.

For the default eight-frame example, the complete header is
\texttt{4D 4C 56 31 00 40 00 40 00 00 00 08 00 04 00 00 00 00 00 28 00 00 00 00}.
The duration byte \texttt{28} is hexadecimal for forty. This header is staged output; its presence does not yet mean that all declared records have been encoded.

Use \texttt{s88-1} and stop before \texttt{fe\_header\_ready}.

\paragraph{Observe} Exactly twenty-four header bytes have been staged. Final counts in the caller context have not been published.

\Needspace{8\baselineskip}
\paragraph{Check} How is the duration forty encoded in the file?
\begin{enumerate}[label=\Alph*.]
\item As a native doubleword.
\item As four big-endian bytes 00 00 00 28.
\item As the ASCII characters 4 and 0.
\end{enumerate}
