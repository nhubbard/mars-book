\section{Step 82 Publish the selected kind, count and next sequence}
Fill \texttt{dr\_publish}. Increment sequence at context offset eight, publish delta kind one at forty, and publish payload plus sixteen at forty-eight. Return success and that same produced count. Retain every other context field, including scratch inputs and suffixes. This completes the delta path; the full branch is completed in the next step.

Use \texttt{s82-1} and stop before \texttt{dr\_published}.

\paragraph{Observe} At \texttt{dr\_published}, default outputs are next sequence two, kind one and forty bytes. Continuing the caller decodes against its saved old image and reconstructs every current source word.

\Needspace{8\baselineskip}
\paragraph{Check} Why did the caller save an old decoder image before encoding?
\begin{enumerate}[label=\Alph*.]
\item The CRC helper requires two framebuffers.
\item Encoding commits the previous image before the decoder comparison.
\item A delta can always decode against its own new image.
\end{enumerate}
