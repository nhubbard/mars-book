\section{Step 17: Read a command and require progress}
Before reading a command header, subtract the payload cursor from its
exclusive end and require at least four bytes. Read the two-byte big-endian skip
into \texttt{\$t2} and changed count into \texttt{\$t3}. Advance the byte
cursor by four and reject a zero sum. The two unsigned sixteen-bit counts can
be added safely in the working register.

Fill \texttt{record\_pair}. Progress is measured in pixels covered by either
count. A skip-only terminal command is useful for an unchanged suffix; a
zero/zero command would leave the pixel cursor unchanged. The four header bytes
may fit even when the triples do not, which is why this region cannot yet
advance to the next command.

\paragraph{Observe} Prepare \texttt{s17-1} and stop before
\texttt{record\_pair\_ready}. At the first \texttt{record\_pair\_ready}, skip is zero,
changed is one, and the byte cursor is source plus twenty. The pixel cursor
is still zero.

\paragraph{Check} Which command makes no progress?

\item[A.] Skip one, change zero.
\item[B.] Skip zero, change zero.
\item[C.] Skip zero, change one.
\end{itemize}
