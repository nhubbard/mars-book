\section{Step 61 Write kind, reserved bytes and sequence in wire order}
Fill \texttt{ef\_header}. Store full kind zero and three zero reserved bytes at offsets zero through three. Serialize \texttt{\$s4} as four big-endian bytes at offsets four through seven, using shifts and byte stores. All storage has already been admitted. Native target byte order does not change these file bytes, and the byte destination can begin at an unaligned address.

Use \texttt{s61-1} and stop before \texttt{ef\_header\_ready}.

\paragraph{Observe} At \texttt{ef\_header\_ready}, the first eight bytes are zero for default sequence zero. With sequence 255, offsets four through seven must be \texttt{00 00 00 FF}. The length and CRC bytes have not yet been written.

\paragraph{Check} Which byte sequence represents sequence 255 on the wire?
\begin{enumerate}[label=\Alph*.]
  \item FF 00 00 00.
  \item 00 00 00 FF.
  \item 00 FF 00 FF.
\end{enumerate}
