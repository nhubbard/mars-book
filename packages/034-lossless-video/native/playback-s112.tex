\section{Step 112 Advance the scheduled deadline}
Fill \texttt{vp\_deadline}. Add the admitted duration to the previous deadline using full-width unsigned arithmetic. If the sum is smaller than the previous deadline, reject the overflow before presenting the next frame. Otherwise retain the new deadline.

The default deadlines are 1040, 1080 and 1120 milliseconds, even when one interval finishes late. Adding duration to the latest actual time would accumulate decoding delays and oversleep into the schedule. Repeated addition here is equivalent to anchor plus the number of completed-or-current intervals times duration, within the checked range.

Use \texttt{s112-1} and stop before \texttt{vp\_deadline\_ready}.

\paragraph{Observe} The first deadline is 1040 under the default grading clock. The displayed image is still unchanged.
