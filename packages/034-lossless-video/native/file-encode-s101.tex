\section{Step 101 Publish the transport result}
Fill \texttt{vs\_publish}. Return the retained logical status and a zero result count on failure. On success, store the exact completed count in result-context offset zero and return the same count in \texttt{\$v1}. Retain context offset eight and its surrounding guards. Failure leaves the entire result context unchanged, although the target file may contain only the transferred prefix.

Run the example caller through encoding, indexing, seeking, storage and reload. It checks the reload count against the encoded count. The reload overwrites the shared staging area, so an earlier directory is no longer sufficient evidence for playback of those bytes. The next stage must validate the newly loaded file before using its directory to present frames.

Use \texttt{s101-1} and stop before \texttt{vs\_published}.

\paragraph{Observe} The default complete call reports status zero and 24\,795 stored bytes. The caller then reloads that exact file into its staging area.

\Needspace{8\baselineskip}
\paragraph{Check} What must playback do after the shared staging area has been reloaded?
\begin{enumerate}[label=\Alph*.]
\item Trust the old directory solely because the byte count matches.
\item Validate the newly loaded file before using a directory for playback.
\item Interpret the file as native-word pixel storage.
\end{enumerate}
