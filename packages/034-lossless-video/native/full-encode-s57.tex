\section{Step 57 Admit an exact native source image}
Fill \texttt{ef\_admit}. Require \texttt{\$a1} to equal 16\,384 as a full-width value. A count with that value only in its low word is not equal. Check four-byte source alignment and eight-byte context alignment. The entry already holds failure one and count zero; reject through \texttt{ef\_return} before allocating a frame or reading context fields. The byte destination has no extra alignment requirement.

Use \texttt{s57-1} and stop before \texttt{ef\_admitted}.

\paragraph{Observe} At \texttt{ef\_admitted}, the source count is 16\,384 and both native pointers pass their low-bit tests. No source color or context field has been read.

\paragraph{Check} Why compare the complete source count?
\begin{enumerate}[label=\Alph*.]
\item A larger value can share the same low 32 bits.
\item Every source has a variable number of pixels.
\item The destination must be sixteen-byte aligned.
\end{enumerate}
