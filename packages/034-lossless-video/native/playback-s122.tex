\section{Step 122 Publish only a complete playback result}
Fill \texttt{vp\_publish}. Store the accepted count, late-interval count, maximum lateness and scheduled logical duration in the four output fields. Logical duration is final deadline minus initial anchor; earlier overflow checks make that subtraction exact. Return status zero and the accepted count.

On a completed failure, leave the external context unchanged and return status one with the actual accepted count. Directory and scratch may have changed, and already presented pixels remain visible. These are streaming effects, not a whole-animation rollback. The supplied epilogue restores saved registers and the original stack pointer.

Use \texttt{s122-1} and stop before \texttt{vp\_published}.

\paragraph{Observe} Exact default playback publishes eight accepted frames, zero late intervals, zero maximum lateness and logical duration 320.

\Needspace{8\baselineskip}
\paragraph{Check} When do the four final context outputs change?
\begin{enumerate}[label=\Alph*.]
\item Only after every requested interval completes successfully.
\item Before validating the file.
\item Whenever a clock sample is read.
\end{enumerate}
