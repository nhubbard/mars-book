\section{Step 69 Admit the source and extended native context}
Fill \texttt{dr\_admit}. Require the full source count to equal 16\,384 and check four-byte source and eight-byte context alignment before reading context fields. Retain the initialized failure status and zero count on the early return. The extended context is still native storage; the record destination remains byte-addressed and may be unaligned.

Use \texttt{s69-1} and stop before \texttt{dr\_admitted}.

\paragraph{Observe} At \texttt{dr\_admitted}, the default source count is exact. No image, scratch or context bytes have been read by this routine.

\Needspace{8\baselineskip}
\paragraph{Check} Which pointer needs eight-byte alignment?
\begin{enumerate}[label=\Alph*.]
  \item The native context.
  \item The serialized record destination.
  \item Every RGB triple.
\end{enumerate}
