\section{Step 114 Count the picture that has become visible}
Fill \texttt{vp\_presented}. Increment the private accepted-frame count after a successful initial seek or record application. At this boundary the display contains the accepted picture. A later clock failure cannot undo the fact that these pixels have already been published.

This count is therefore returned even on a completed playback failure. It differs from a final success result in the caller context, which is published only after all requested intervals finish. Keeping those meanings separate lets a caller distinguish an initial rejection from a failure after visible progress.

Use \texttt{s114-1} and stop before \texttt{vp\_frame\_presented}.

\paragraph{Observe} The first accepted count is one and the display contains the start frame. Final caller-context results remain unchanged.

\Needspace{8\baselineskip}
\paragraph{Check} What should a later clock failure report about already accepted frames?
\begin{enumerate}[label=\Alph*.]
  \item That zero frames were accepted regardless of display changes.
  \item That the entire display was restored.
  \item The actual accepted count.
\end{enumerate}
