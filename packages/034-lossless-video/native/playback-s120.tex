\section{Step 120 Locate the next record from the validated directory}
Fill \texttt{vp\_window}. Read the current record offset from the validated directory. Its end is the next offset, except for the final record, whose end is the exact file count. Form the byte address and subtract offsets to obtain its exact record count.

The file and directory remain immutable after validation, so these relationships are already established. The single-record routine still receives only its own bounded window. A directory entry is an offset from the file base; loading it as though it were an absolute address would select unrelated memory, particularly in the high-address tests.

Use \texttt{s120-1} and stop before \texttt{vp\_window\_ready}.

\paragraph{Observe} On the second default iteration, the selected window is record one, immediately after the first full record.

\Needspace{8\baselineskip}
\paragraph{Check} How is the final record window ended?
\begin{enumerate}[label=\Alph*.]
  \item At the exact accepted file count.
  \item At the source image word count.
  \item At the next allocated memory page.
\end{enumerate}
