\section{Step 105 Admit the output and validation storage}
Fill \texttt{vp\_context}. Require at least 16\,384 bytes for the display image and for the scratch image. Check the directory pointer's eight-byte alignment, scratch pointer's four-byte alignment and a directory capacity of at least eight bytes. The indexer will later require enough directory space for the actual frame count.

These checks do not inspect the file header yet. The caller supplies separate valid storage windows; a numeric capacity is a promise about allocation. Do not use the current display as scratch for validating a replacement file.

Use \texttt{s105-1} and stop before \texttt{vp\_context\_ready}.

\paragraph{Observe} Display, directory and scratch controls have been admitted. Existing display pixels and final context fields remain unchanged.

\Needspace{8\baselineskip}
\paragraph{Check} When is the actual required directory size known?
\begin{enumerate}[label=\Alph*.]
  \item After the file header supplies an admitted frame count.
  \item Only after every frame has been displayed.
  \item From the display address.
\end{enumerate}
