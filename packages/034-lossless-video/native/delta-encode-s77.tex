\section{Step 77 Write a variable-length delta header}
Fill \texttt{dr\_header}. Store kind one, three zero reserved bytes, the input sequence as four big-endian bytes, and the measured payload length as four big-endian bytes. Do not publish the final native context yet. Header payload length, produced record count and destination capacity are three different values.

Use \texttt{s77-1} and stop before \texttt{dr\_header\_ready}.

\paragraph{Observe} At \texttt{dr\_header\_ready}, default bytes zero through eleven are \texttt{01 00 00 00 00 00 00 01 00 00 00 18}. CRC offsets twelve through fifteen are still unchanged.

\Needspace{8\baselineskip}
\paragraph{Check} Which value belongs in header offsets eight through eleven?
\begin{enumerate}[label=\Alph*.]
  \item The full output capacity.
  \item The number of changed words.
  \item The measured delta payload length.
\end{enumerate}
