\section{Step 13: Feed one byte to the checksum}
For the reflected CRC recurrence, XOR the next unsigned input byte into the
low eight bits of the accumulator. Advance the byte cursor by one. This feeds
one byte; the following region will perform its eight bit recurrences. Keeping
these actions separate makes the first byte's effect observable before shifting.

Fill \texttt{record\_crc\_byte}. Use a 64-bit address increment so this remains
correct when data is above four GiB. The supplied loop only enters this region
when the cursor is below its current exclusive end. It will reset the per-byte
bit counter to eight after the checkpoint.

\paragraph{Observe} Prepare \texttt{s13-1} and stop before
\texttt{record\_crc\_byte\_ready}. For the first header byte, kind one, \texttt{\$t2} becomes
\texttt{0x00000000fffffffe} and \texttt{\$t0} becomes source plus one at
\texttt{record\_crc\_byte\_ready}.
