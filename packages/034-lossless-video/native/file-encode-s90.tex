\section{Step 90 Accept one complete record}
Fill \texttt{fe\_record}. Call \texttt{video\_encode\_record} and preserve its distinction between completed failure one and development status four. On success, retain the actual returned byte count before using temporary registers. Check that it fits the supplied remaining capacity and the record-size bounds. Check that the private next sequence and published record count agree with this completed call.

The first record is full and occupies 12\,304 bytes. A later unchanged frame can occupy twenty bytes. Those sizes describe this format, while the free-writing contract permits equivalent valid full and delta choices. Do not substitute an assumed compact size for the result of the actual encoder.

Use \texttt{s90-1} and stop before \texttt{fe\_record\_ready}.

\paragraph{Observe} For the first record, the returned count is 12\,304 and the private next sequence is one. The outer source cursor has not advanced yet.
