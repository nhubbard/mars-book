\section{Step 18: Bound both pixel spans}
Compute the remaining pixels as 4096 minus the pixel cursor. Reject a skip
larger than that remainder, then advance the cursor by the skip. Reduce the
remainder accordingly before checking the changed count. The second comparison
uses the space after the skip, not the space at command entry.

Fill \texttt{record\_pixel\_bounds}. This region advances past skipped pixels
only. The next region advances past changed pixels after proving their triples
fit. Comparing each unsigned count against a remainder avoids constructing a
possibly invalid destination address merely to test it.

\paragraph{Observe} Prepare \texttt{s18-1} and stop before
\texttt{record\_pixels\_ready}. For the first command, the stopped state has
pixel cursor zero and \texttt{\$t4} equal to 4096. The late invalid command
in \texttt{late-skip} asks to skip 4096 after one pixel has already been covered.
