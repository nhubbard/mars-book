\section{Seek from a full frame rather than a blank image}
Validate the whole file and store the beginning offset of each record in a native
directory. Associate each target with the latest full frame at or before it. The
required period guarantees a suitable starting frame; optional full frames can move
that starting point closer to the target.

To seek to frame six in the moving fixture, load full frame four, then apply deltas
five and six. Do not XOR delta six into a cleared frame or into a previously displayed
unrelated frame. Seeking to frame three starts at full frame zero and applies three
deltas. The maximum number of intervening deltas is period minus one.

The extra-full fixture stores frame five as another full frame. It decodes to the
same pixels as the moving fixture, but a seek to six can start at five and apply only
one delta. A decoder that insists all nonperiodic frames must be deltas would reject
this permitted encoding. Check both ordinary decoding and every possible seek target.
