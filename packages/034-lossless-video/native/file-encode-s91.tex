\section{Step 91 Advance after success}
Fill \texttt{fe\_advance}. Add the successful record count to the produced byte offset, add 16\,384 to the source cursor and increment the sequence by one. These changes occur only after the nested record has completed successfully. The supplied loop then continues while the sequence differs from the declared frame count.

After the first iteration, the produced offset is 12\,328: twenty-four header bytes plus a 12\,304-byte record. The source cursor points at the second native image. Advancing by 12\,304 on the source side would enter the first image's final quarter instead. Source storage and serialized storage have different units and layouts.

Use \texttt{s91-1} and stop before \texttt{fe\_record\_advanced}.

\paragraph{Observe} Sequence is one, produced offset is 12\,328 and the source cursor has advanced exactly one 16\,384-byte image.

\Needspace{8\baselineskip}
\paragraph{Check} When may the outer sequence advance?
\begin{enumerate}[label=\Alph*.]
\item Before checking the nested result.
\item After one complete successful record.
\item Only when the record is full.
\end{enumerate}
