\section{Step 34: Publish one native offset}
The second pass resets file offset to 24 and record index to zero. Form
the destination as directory base plus eight times that index, and store the
current file-relative offset as a native doubleword. It is an offset rather
than the record pointer: the first entry is always 24 for this format, even
when the file is loaded at an address above four GiB.

Fill \texttt{index\_entry}. All records were validated before this store,
and the directory capacity was admitted before either pass. The offset can
therefore be published without a temporary public partial result on completed
failure. Keep index metadata private until every entry has been stored.

\paragraph{Observe} Prepare \texttt{s34-1} and stop before
\texttt{index\_entry\_stored}. At the first \texttt{index\_entry\_stored}, the first
doubleword eight bytes after \texttt{index\_directory} is 24. No other
directory entry or context output has changed.

  \item[B.] The frame duration.
  \item[C.] The file-relative offset 24.
\end{itemize}
