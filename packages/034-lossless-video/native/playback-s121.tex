\section{Step 121 Apply the next record to the accepted picture}
Fill \texttt{vp\_record}. Call \texttt{video\_apply\_record} with the exact window, display image and private record context. On success, the working display advances to that record's frame. A rejected record retains the previous accepted display according to the earlier routine's contract.

The complete loaded file was checked before playback. Retaining the record routine's own checks also preserves its callable behavior and makes a local construction error observable. An unchanged delta may perform no pixel stores, but it still represents the next logical frame and still receives an interval.

Use \texttt{s121-1} and stop before \texttt{vp\_record\_ready}.

\paragraph{Observe} The next complete frame has been accepted. Its numeric words match the corresponding source image, including an unchanged frame.

\Needspace{8\baselineskip}
\paragraph{Check} Does an unchanged delta receive a display interval?
\begin{enumerate}[label=\Alph*.]
  \item No, because it has no changed pixels.
  \item Yes, because it advances the logical frame sequence.
  \item Only if it is encoded as full.
\end{enumerate}
