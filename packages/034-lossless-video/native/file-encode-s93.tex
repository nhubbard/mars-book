\section{Step 93 Publish the complete file counts}
Fill \texttt{fe\_publish}. Store the exact file byte count at context offset sixty-four and the completed record count at offset seventy-two. Return status zero and the same file count in \texttt{\$v1}. Leave all input controls and the retained suffix unchanged. The supplied epilogue restores the caller's saved registers and stack pointer.

A failed call leaves these context fields unchanged, including values from a previous successful call. It may nevertheless have overwritten part of the staging area and working images. An old published count does not certify newly overwritten bytes. A caller that needs to retain a previous animation while trying a replacement must provide separate staging storage.

Use \texttt{s93-1} and stop before \texttt{fe\_published}.

\paragraph{Observe} The final context contains file count 24\,795 and record count eight. The existing reader can now validate this complete staged file.
