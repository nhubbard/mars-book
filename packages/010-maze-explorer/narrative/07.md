# Discovery claims a cell once

An open unseen neighbor is claimed by the cell currently being processed. The discovery writes its waiting state, predecessor ID, and distance before appending it to the queue. The stored distance is the current distance plus one.

Marking before the eventual dequeue matters in a cyclic graph. In the small room, both one and eight can lead to nine. If nine remained unseen while waiting, both incoming edges could enqueue it. The queue would cease to be a list of unique discovered cells, and the capacity argument would fail. The second edge should observe an already waiting state and leave the existing predecessor unchanged.

A first-discovery predecessor records an actual adjacent open cell, rather than an arbitrary cell at a plausible distance. This local relation is what allows the program to reconstruct a route later. The shortest-distance proof supplies the separate reason that the recorded route has minimum length.
