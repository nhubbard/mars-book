# Initialization establishes the search invariant

The starter reserves storage, but the search itself establishes the work-array values on every run. This is deliberate. The grader fills those arrays with unrelated bytes before execution, and a later version of the program could reuse the buffers. Correctness should not depend on a convenient old image.

After clearing, every cell is unseen, every parent and distance is unknown, the queue history is zero, and no path cell is marked. Discovering the start changes exactly the fields needed to introduce one work item: its state becomes waiting, its distance becomes zero, and the first queue entry holds its ID. It keeps the unknown-parent sentinel because no edge was used to reach it.

Head zero and tail one then define a valid nonempty queue. Result and length use minus one as word-sized unfinished values. These metadata sentinels describe progress; they are not cell IDs and should not be loaded with a byte instruction.
