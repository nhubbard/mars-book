# Change the domain before widening the program

Several extensions fit the same basic representation, but each changes a different assumption. A wider grid changes the coordinate conversion and frame stride. More than 255 cell IDs requires wider queue and predecessor entries or a different encoding. A path length beyond 254 also conflicts with the current distance sentinel.

Weighted terrain changes the selection rule more fundamentally. The next FIFO layer is a statement about equal numbers of edges, not arbitrary accumulated costs. A shortest-cost implementation needs a work policy and a correctness argument appropriate to its weights, together with checks that distinguish edge count from cost.

A second visualization could retain every minimum-distance predecessor rather than only the first. That would represent a graph of shortest choices, not one route. The path-mask contract would have to say which artifact it expects, and the caption would need to explain how multiple choices are displayed. Write those meanings down before adding stores.
