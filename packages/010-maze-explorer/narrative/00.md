# A route is a sequence of decisions

A successful search should explain how its answer can be followed. For a maze, that means a sequence of open cells in which consecutive cells share a side. Checking that the goal was encountered is insufficient: the output must connect it to the start, and this task also asks for a minimum number of moves.

The small room makes these obligations visible without a long stepping session. From zero to nine, an east-then-south route and a south-then-east route are both shortest. A check that accepts only one of them would confuse a particular implementation with the problem’s answer. We will preserve the chosen predecessor links and check their relationships instead.

Breadth-first search (BFS) keeps discovered cells in a first-in, first-out queue. The program publishes its waiting frontier, processed cells, and final route through the same 8 by 8 framebuffer used in earlier projects. Publication happens at named debugger boundaries. The maze, the search state, and the display remain separate arrays so that one representation does not have to carry every meaning.
