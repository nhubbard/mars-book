# A renderer consumes state without advancing the search

The renderer has a memory-based interface. It reads the public `walls`, `states`, and `path` arrays, writes exactly 64 frame words, and preserves the saved registers and stack pointer. Its return address comes from the caller. It changes neither the search arrays nor the progress metadata.

The classification order is part of that interface. A wall remains a wall even if other seeded flags are nonzero. For an open cell, a path flag takes precedence over the search state. Without a path flag, an unseen cell is white, a waiting cell is orange, and a processed cell is green. Final route cells are blue. The legend gives names and numeric values so the information can be understood without identifying colors alone.

A complete redraw is useful at this scale. It overwrites old colors for cells whose meanings changed and gives the independent renderer check a simple contract. It also costs instructions; the later work-count discussion will include that cost explicitly.
