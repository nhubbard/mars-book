# Failure exhausts a reachable component

If the queue empties without processing the goal, every discovered cell has had its required neighbor decisions completed. Every reachable open neighbor of those cells must therefore also have been discovered. Repeating that reasoning along any route from the start shows that no reachable cell has been missed.

The goal is either in that component or outside it. In the exhausted case it is outside, so the result is unreachable, length remains minus one, and the path mask stays empty. This conclusion is stronger than observing a wall in one direction or reaching one dead end. The search must account for every waiting branch before declaring failure.

The input contract requires valid open endpoints. Validation of malformed maps or out-of-range endpoint IDs is a separate exercise. Keeping that domain explicit lets the present chapter concentrate on traversal, queue bounds, predecessor relations, and the observable distinction between unfinished and unreachable.
