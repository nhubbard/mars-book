# Practice with changed contracts

1.  Change the fixed direction order. Predict the first three removals and the selected parent of the small-room goal, then rerun the unchanged free-writing checks.

2.  Add a report of frontier size. Define whether it is sampled before or after processing and verify the chosen interval using $`\texttt{tail}-\texttt{head}`$.

3.  Construct a reachable maze with a longer route than the corner-to-corner Manhattan distance. Explain which walls force the extra moves.

4.  Propose a rectangular-grid interface with independent width and height. Specify ID conversion, capacity, pixel stride, valid endpoint range, and sentinel bounds.

5.  Explain why changing a cell’s display color is insufficient to introduce weighted terrain. State what quantity the search would need to minimize.

Only the original 8 by 8 unit-cost contract is graded by this package. Each extension needs its own stated domain, expected artifact, and checks before it becomes an assignment.
