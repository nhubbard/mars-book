# Step 22 Report an exhausted frontier

An empty queue means every reachable cell has been processed. If no dequeued cell was the goal, the search has exhausted the entire reachable component.

## Write or inspect

Append the unreachable fragment. Retain minus one as the route length and leave every path byte zero.

```asm
    la $t0, result
    sw $zero, 0($t0)
```

## Expected observation

The row-boundary fixture with only cells seven and eight open returns result zero. The algorithm must not invent a connection between those indices.
