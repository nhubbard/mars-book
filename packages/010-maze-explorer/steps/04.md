# Step 4 Keep search state across renderer calls

The search calls a leaf renderer repeatedly. Its contract allows temporary and argument registers to change while saved registers retain the search state.

## Write or inspect

Append the base pointers and initial counters in the initialize region. Inspect which values are addresses and which are small integers.

```asm
    la $s0, walls
    la $s1, states
    la $s2, parents
    la $s3, distance
    la $s4, queue
    move $s5, $zero
    li $s6, 1
    li $s7, -1
    move $t0, $zero
    li $t1, 255
    la $t2, path
```

## Expected observation

The saved registers hold five array bases, a head counter, a tail counter, and the current cell. The buffers have not yet been initialized.
