# Step 18 Publish one completed processing step

After a dequeue and all its discoveries, metadata and the frame describe one consistent boundary. The goal case skips neighbor discovery but uses the same publication.

## Write or inspect

Append the phase-one publication and the next search decision. Run through the small room.

```asm
    la $t0, head
    sw $s5, 0($t0)
    la $t0, tail
    sw $s6, 0($t0)
    la $t0, current
    sw $s7, 0($t0)
    li $t1, 1
    la $t0, phase
    sw $t1, 0($t0)
    jal render
    nop
    la $t0, goal
    lw $t1, 0($t0)
    beq $s7, $t1, found
    nop
    j search
    nop
```

## Expected observation

The dequeue order is zero, one, eight, nine in this reference. Result and length remain unfinished until the success or failure fragments are added.
