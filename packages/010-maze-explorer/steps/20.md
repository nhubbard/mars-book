# Step 20 Record a reachable result

When the dequeued cell is the goal, its stored distance is the shortest edge count. The result word distinguishes success from the unfinished state and from an exhausted search.

## Write or inspect

Append the success fragment. Prepare to walk backward from the goal using parent bytes.

```asm
    la $t0, result
    li $t1, 1
    sw $t1, 0($t0)
    daddu $t0, $s3, $s7
    lbu $t1, 0($t0)
    la $t0, length
    sw $t1, 0($t0)
    move $t0, $s7
    la $t1, path
    la $t2, start
    lw $t2, 0($t2)
    li $t3, 1
```

## Expected observation

For the small room, result is one and length is two. The path mask is still empty until the predecessor walk is implemented.

What does length count?

- **A** The number of bytes in parents.

- **B** Edges from start to goal.

- **C** All discovered cells.
