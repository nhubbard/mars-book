# Step 9 Redraw the entire frame

A frontier cell can later become processed or part of a route. Leaving old pixels unchanged would confuse persistent memory with current search state.

## Write or inspect

Append the pointer increments and loop branch. Advance the frame pointer by four bytes and each classification pointer by one byte.

```asm
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 1
    daddiu $t2, $t2, 1
    daddiu $t3, $t3, 1
    addiu $t4, $t4, -1
    bne $t4, $zero, render_cell
    nop
```

## Expected observation

All 64 cells now match the initial metadata. Walls are dark, unseen open cells are white, and the start is orange.
