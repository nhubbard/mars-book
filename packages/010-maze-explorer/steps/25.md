# Step 25 Accept a different shortest route

The assignment specifies FIFO discovery and checkpoint meaning, but does not prescribe the order of the four directions. A valid implementation can therefore choose different parents.

## Write or inspect

Make a copy of your completed program. In the guided version, change the direction tables to dx values minus one, zero, one, zero and dy values zero, one, zero, minus one. Run the public checks against both copies, and compare their chosen routes.

## Expected observation

One small-room route is zero, one, nine; the other is zero, eight, nine. Both have length two and satisfy adjacency and predecessor distances.
