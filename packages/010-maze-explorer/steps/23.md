# Step 23 Publish the final route or failure

The final snapshot has a phase distinct from per-cell processing. This allows the debugger and grader to distinguish search progress from the finished artifact.

## Write or inspect

```asm
    la $t0, current
    sw $s7, 0($t0)

    la $t0, phase
    sw $t1, 0($t0)
    jal render

```
