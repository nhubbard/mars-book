# Step 11 Interpret the queue as a moving interval

This queue uses monotonically increasing counters. Entries before head are retained history; entries from head through tail minus one are waiting work.

## Write or inspect

At each checkpoint, calculate the number of waiting cells as tail minus head. Do not use head equals zero as an empty test.

## Expected observation

The queue is empty exactly when head equals tail. Capacity is sufficient because each of the 64 cells can be discovered only once.

## Check your understanding

What does head equal tail mean?

- **A** Every maze cell is a wall.

- **B** No discovered cell remains waiting.

- **C** The goal must be reachable.
