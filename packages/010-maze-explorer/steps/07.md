# Step 7 Publish the initial state

An animation checkpoint must expose a complete logical state. The search stores its register counters into metadata and asks the renderer to write the entire frame.

## Write or inspect

Append the initial publication in the initial region. Set a breakpoint at `maze_ready`.

```asm
    la $t0, head
    sw $s5, 0($t0)
    la $t0, tail
    sw $s6, 0($t0)
    la $t0, current
    sw $s7, 0($t0)
    li $t1, 0
    la $t0, phase
    sw $t1, 0($t0)
    jal render
    nop
```

## Expected observation

Phase zero has head zero, tail one, and current minus one. At this stage the renderer stub returns without drawing; the state is initialized but the image is unfinished.
