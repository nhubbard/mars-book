# Step 10 Check the renderer on its own

The renderer reads the public arrays and writes the frame. It does not discover cells, change counters, or choose a path.

## Write or inspect

Run the renderer checks independently, with a return address targeting `done`. Inspect cases that combine wall, state, and path flags.

## Expected observation

The caller can seed the arrays and preserved registers without running main. A full redraw erases a poisoned old frame, and the renderer leaves its input arrays and metadata unchanged.
