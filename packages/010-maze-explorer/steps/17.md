# Step 17 Examine all four directions

Processing one ordinary cell includes examining every permitted direction. Early invalid candidates do not end its neighbor loop.

## Write or inspect

Append the direction-loop continuation. In this reference the order is north, east, south, west.

```asm
    addiu $a0, $a0, 1
    sltiu $t0, $a0, 4
    bne $t0, $zero, neighbor
    nop
```

## Expected observation

Processing zero discovers one and eight. The active queue becomes one, eight after the already processed zero. Other fixed direction orders are allowed by the assignment.

## Check your understanding

Should an invalid north neighbor end processing of the cell?

- **A** Yes; a boundary blocks every direction.

- **B** No; the remaining directions still need examination.

- **C** Only when the start is zero.
