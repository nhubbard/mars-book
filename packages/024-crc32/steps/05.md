# Mix one octet and start eight bit steps

Load an unsigned octet, XOR it into the low byte of the raw state, and initialize the bit counter. These three operations prepare one byte; they do not yet advance the source. The first default byte is hexadecimal 31, so the mixed state is `ffffffce`.

## Write and inspect

Replace the marked temporary region `b_byte`, retaining surrounding labels.

```asm
    lbu $t0, 0($a0)
    xor $v0, $v0, $t0
    li $t1, 8
```

## Expected observation

The first check byte leaves `v0`=`ffffffce` and `t1`=8.
