# Map a mixed low byte to a full table address

XOR the source octet with the state, retain only its low byte, scale the index by four, and add it to the full table base. Then load the selected word without sign extension. These operations keep the logical byte index, byte offset, address and loaded value distinct even though the temporary register is reused.

## Write and inspect

Replace the marked temporary region `t_lookup`, retaining surrounding labels.

```asm
    lbu $t0, 0($a0)
    xor $t0, $t0, $v0
    andi $t0, $t0, 255
    dsll $t0, $t0, 2
    daddu $t0, $a3, $t0
    lwu $t1, 0($t0)
```

## Expected observation

The default first index is 206. A zero seed and input 80 select entry 128, yielding unsigned `edb88320`.
