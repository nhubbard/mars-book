# Finish all eight steps for this byte

Decrease the bit counter after each completed transition and repeat while it is nonzero. The loop returns to the feedback decision rather than loading the byte again. When it stops, the state represents one complete octet, but the outer pointer and byte count still refer to that octet.

## Write and inspect

Replace the marked temporary region `b_bits`, retaining surrounding labels.

```asm
    addiu $t1, $t1, -1
    bne $t1, $zero, bit_next_bit
    nop
```
