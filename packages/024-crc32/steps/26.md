# Distinguish errors, EOF and positive data

Check negative results before testing EOF. An error follows the supplied close-and-error path. Zero selects finalization, while a positive count falls through toward an update. Finalization is still temporary at this stage, so an EOF observation returns development status three until the success block is written.

## Write and inspect

Replace the marked temporary region `f_classify`, retaining surrounding labels.

```asm
    bltz $v0, file_read_error
    nop
    beq $v0, $zero, file_finish
    nop
```

## Expected observation

An immediate injected error returns zero/status two and closes the descriptor; positive reads have not yet changed the raw state.
