# Apply feedback from the old low bit

Retain the old low bit in `t2`, shift the state right with zero fill, then apply feedback only when that retained bit is one. The branch targets the common path after feedback. Testing the shifted low bit instead would change which polynomial terms are cancelled.

## Write and inspect

Replace the marked temporary region `b_step`, retaining surrounding labels.

```asm
    andi $t2, $v0, 1
    dsrl $v0, $v0, 1
    beq $t2, $zero, bit_no_feedback
    nop
    xor $v0, $v0, $t3
```

## Expected observation

The first default step gives `7fffffe7`. A zero seed with byte 01 instead gives `edb88320` after one step.
