# Retain the incoming state and feedback mask

Keep the raw state in `v0` and load the reflected feedback mask in `t3`. The constant must represent a nonnegative 32-bit value in this 64-bit register. Loading it once outside the byte loop avoids repeating constant construction for every byte.

## Write and inspect

Replace the marked temporary region `b_setup`, retaining surrounding labels.

```asm
    move $v0, $a2
    dli $t3, 0xedb88320
```

## Expected observation

The default raw state is `ffffffff`; `t3` is the zero-extended `edb88320`.
