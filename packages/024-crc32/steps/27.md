# Pass the returned byte count to the selected kernel

Move the actual positive result into the length argument, pass the scratch address and retained raw state, and call the selected routine. The table argument is meaningful to the table method and harmless to the bit method. Retain the returned raw state in `s5` before another syscall overwrites `v0`.

## Write and inspect

Replace the marked temporary region `f_update`, retaining surrounding labels.

```asm
    move $a1, $v0
    move $a0, $s1
    move $a2, $s5
    dla $a3, crc_table
    jalr $s6
    nop
    move $s5, $v0
```

## Expected observation

A three-byte first read of the check message updates the raw state to `77b79c2d` before temporary cleanup.
