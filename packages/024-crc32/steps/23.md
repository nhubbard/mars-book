# Open the path and retain a valid descriptor

Open read-only and branch to the supplied open-error result when the descriptor is negative. Retain a successful descriptor in `s4` and start this file state at `ffffffff`. Until later regions exist, the supplied temporary cleanup closes that descriptor and returns development status three.

## Write and inspect

Replace the marked temporary region `f_open`, retaining surrounding labels.

```asm
    li $a1, 0
    li $v0, 13
    syscall
    bltz $v0, file_open_error
    nop
    move $s4, $v0
    dli $s5, 0xffffffff
```

## Expected observation

A present fixture is opened and then closed by temporary cleanup; a missing fixture returns checksum zero/status one without a close.
