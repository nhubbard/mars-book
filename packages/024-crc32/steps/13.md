# Complete the entry before storing it

Repeat the entry transition eight times before advancing to the store. This loop changes `t0` and `t1` while retaining the destination walker and entry index. An incomplete entry must not become the starting state for a later entry.

## Write and inspect

Replace the marked temporary region `i_bits`, retaining surrounding labels.

```asm
    addiu $t1, $t1, -1
    bne $t1, $zero, init_bit
    nop
```

## Expected observation

Entry zero reaches its store path with `t0`=0 and `t1`=0.
