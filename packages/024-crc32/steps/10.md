# Start a table walker and an entry index

Retain the full destination in `t4`, begin with index zero in `t5`, and load the same feedback mask used by the bit update. The walker addresses words; the index identifies the byte value whose eight-step effect will be stored. Keeping both roles explicit prevents a byte index from being mistaken for an address.

## Write and inspect

Replace the marked temporary region `i_setup`, retaining surrounding labels.

```asm
    move $t4, $a0
    move $t5, $zero
    dli $t3, 0xedb88320
```

## Expected observation

No table word changes yet; `t4` points to the selected table and `t5`=0.
