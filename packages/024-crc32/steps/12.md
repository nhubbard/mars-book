# Use the reflected transition for table construction

Apply the same bit transition to the entry remainder in `t0`. This is the operation being precomputed, so its polynomial and shift direction must agree with the byte kernel. A separately specified table oracle will check the initializer rather than trusting agreement between two student routines.

## Write and inspect

```asm
    dsrl $t0, $t0, 1
    beq $t2, $zero, init_no_feedback
    nop
    xor $t0, $t0, $t3
```

## Expected observation

Entry zero remains zero after this first transition.
