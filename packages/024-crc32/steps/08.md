# Advance the byte interval and complete the update

After eight steps, advance the full source address and reduce the remaining byte count. The next outer guard decides whether another byte exists. Together, the two loops now consume every supplied byte exactly once and return the raw state without finalizing it.

## Write and inspect

Replace the marked temporary region `b_bytes`, retaining surrounding labels.

```asm
    daddiu $a0, $a0, 1
    addiu $a1, $a1, -1
    beq $zero, $zero, bit_next_byte
    nop
```

## Expected observation

The nine-byte default returns `340bc6d9`; the remaining count is zero and the pointer is at its exclusive end.
