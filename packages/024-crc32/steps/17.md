# Begin the table update with the caller state

The table routine uses the same raw-state convention as the bit routine. Copy the incoming state into `v0`; do not initialize or complement it here. This makes either routine usable for any segment of the same message.

## Write and inspect

Replace the marked temporary region `t_setup`, retaining surrounding labels.

```asm
    move $v0, $a2
```

## Expected observation

The default incoming state is retained without reading data.
