# Check open and read failures separately

Run a missing-file fixture, then an existing file with a read failure after four bytes. A valid descriptor exists only in the second case. The read-error result discards the partial checksum as a public result while still releasing the descriptor.

## Expected observation

Missing input returns status one with no read/close; an error after a valid prefix returns status two and closes the opened handle.

## Check your understanding

May a partial raw state be reported as a successful file checksum?

- **A** No; a read failure has its own status and zero checksum.
- **B** Yes, if at least one byte was read.
- **C** Only when the buffer is full.
