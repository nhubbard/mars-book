# Build each entry from its index

Copy the current index into the temporary remainder and reset the bit counter. The previous entry remainder is not an input to the next entry. Each of the 256 words must be computed independently from the corresponding value zero through 255.

## Write and inspect

Replace the marked temporary region `i_entry`, retaining surrounding labels.

```asm
    move $t0, $t5
    li $t1, 8
```

## Expected observation

The initial entry starts from `t0`=0 with eight steps remaining.
