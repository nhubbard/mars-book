# Select a kernel and prepare the table once

Choose the bit routine for method zero. For method one, construct the table before selecting the table routine. Retain the selected entry address in saved register `s6`, since reads reuse caller-saved argument and result registers. Table construction belongs outside the repeated read loop.

## Write and inspect

Replace the marked temporary region `f_select`, retaining surrounding labels.

```asm
    beq $s3, $zero, file_bit_method
    nop
    dla $a0, crc_table
    jal crc32_table_init
    nop
    dla $s6, crc32_table_update
    beq $zero, $zero, file_read
    nop
file_bit_method:
    dla $s6, crc32_bit_update
```

## Expected observation

Table mode initializes exactly 1024 workspace bytes before any read; bit mode leaves the table alone. Both provisional paths close the file.
