\section{Step 13 Complete the entry before storing it}\label{crc-s13}

Repeat the entry transition eight times before advancing to the store. This loop changes \texttt{t0} and \texttt{t1} while retaining the destination walker and entry index. An incomplete entry must not become the starting state for a later entry.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the marked temporary instructions in \texttt{i\_bits}. Retain surrounding labels and markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t1, $t1, -1
    bne $t1, $zero, init_bit
    nop
\end{minted}

Use \texttt{s13-1}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
Entry zero reaches its store path with \texttt{t0}=0 and \texttt{t1}=0.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
When is a table word ready to store?

\begin{itemize}
\item \textbf{A} After the first outgoing one bit.
\item \textbf{B} After eight transitions from its index.
\item \textbf{C} After the source file closes.
\end{itemize}
