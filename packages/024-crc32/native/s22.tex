\section{Step 22 Carry an actual returned state across methods}\label{crc-s22}

Process a prefix with one method, retain its actual returned raw state, and continue the suffix with the other. Test every split of the nine check bytes, including empty prefix and empty suffix. Follow with a new message initialized independently to expose hidden state.

Use \texttt{s22-1}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
Every split completes at raw \texttt{340bc6d9}; a new message does not inherit that state.
