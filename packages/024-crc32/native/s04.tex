\section{Step 4 Return before loading an empty interval}\label{crc-s04}

At the byte-loop boundary, test the remaining length before using the source pointer. Zero length is a valid identity update: the incoming state is already the result. This guard also becomes the loop exit after the final byte has been consumed.

\subsection{Expected observation}
An empty update preserves its arbitrary seed and reads no caller input.
