\section{Step 10 Start a table walker and an entry index}\label{crc-s10}

Retain the full destination in \texttt{t4}, begin with index zero in \texttt{t5}, and load the same feedback mask used by the bit update. The walker addresses words; the index identifies the byte value whose eight-step effect will be stored. Keeping both roles explicit prevents a byte index from being mistaken for an address.
