\section{Step 2 Inspect the caller and safe temporary exits}\label{crc-s02}

The starter selects a bit update, table construction, table update, or complete file operation. Marked regions initially branch to temporary exits. The first bit/table stubs copy the incoming raw state before returning; the initializer returns provisional zero. The file frame supplies a descriptor marker and a temporary cleanup path so an unfinished file step still closes any successfully opened handle.

\subsection{Expected observation}
The default starter returns the incoming state without processing data. File provisional returns use status three, which is a construction marker outside the completed file contract.
