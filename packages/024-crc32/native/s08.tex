\section{Step 8 Advance the byte interval and complete the update}\label{crc-s08}

After eight steps, advance the full source address and reduce the remaining byte count. The next outer guard decides whether another byte exists. Together, the two loops now consume every supplied byte exactly once and return the raw state without finalizing it.

\Needspace{11\baselineskip}
\subsection{Write and inspect}
Replace the marked temporary instructions in \texttt{b\_bytes}. Retain surrounding labels and markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    daddiu $a0, $a0, 1
    addiu $a1, $a1, -1
    beq $zero, $zero, bit_next_byte
    nop
\end{minted}

Use \texttt{s08-1}, \texttt{s08-2}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
The nine-byte default returns \texttt{340bc6d9}; the remaining count is zero and the pointer is at its exclusive end.
