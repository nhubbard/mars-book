\section{Step 17 Begin the table update with the caller state}\label{crc-s17}

The table routine uses the same raw-state convention as the bit routine. Copy the incoming state into \texttt{v0}; do not initialize or complement it here. This makes either routine usable for any segment of the same message.

\Needspace{8\baselineskip}
\subsection{Write and inspect}
Replace the marked temporary instructions in \texttt{t\_setup}. Retain surrounding labels and markers.

Use \texttt{s17-1}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
The default incoming state is retained without reading data.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Must every table update begin at \texttt{ffffffff}?

\begin{itemize}
\item \textbf{A} Yes, including suffix calls.
\item \textbf{B} Only when the source is aligned.
\item \textbf{C} No; a suffix continues its explicit incoming state.
\end{itemize}
