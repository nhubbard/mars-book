\section{Step 23 Open the path and retain a valid descriptor}\label{crc-s23}

Open read-only and branch to the supplied open-error result when the descriptor is negative. Retain a successful descriptor in \texttt{s4} and start this file state at \texttt{ffffffff}. Until later regions exist, the supplied temporary cleanup closes that descriptor and returns development status three.

\Needspace{14\baselineskip}
\subsection{Write and inspect}
Replace the marked temporary instructions in \texttt{f\_open}. Retain surrounding labels and markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $a1, 0
    li $v0, 13
    syscall
    bltz $v0, file_open_error
    nop
    move $s4, $v0
    dli $s5, 0xffffffff
\end{minted}

Use \texttt{s23-1}, \texttt{s23-2}. The CLI checks install explicit in-memory files and read/error controls. Ordinary IDE files do not force these short-read or failure conditions.

\subsection{Expected observation}
A present fixture is opened and then closed by temporary cleanup; a missing fixture returns checksum zero/status one without a close.

\subsection{Check your understanding}
What may be closed after an unsuccessful open?

\begin{itemize}
\item \textbf{A} The negative result.
\item \textbf{B} Descriptor zero.
\item \textbf{C} No descriptor was acquired.
\end{itemize}
