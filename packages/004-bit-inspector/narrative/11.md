# Use boundary cases to test the interpretation

Zero and one establish the simple representations and padding. Negative one
separates sign extension from zero extension. The maximum signed word separates
word arithmetic from doubleword arithmetic. The minimum signed word checks the
opposite signed boundary.

Walking-one and walking-zero patterns exercise every bit position. Additional
mixed words test cases that do not resemble one-hot masks or endpoint constants.
These fixtures help find implementation mistakes. They are not an exhaustive
execution of every one of the 2^32 input patterns.

The general explanation remains important. The load rules define each extension;
the arithmetic rules define each result width; the format services define the
word report. Together they account for inputs beyond those used in the tests.
