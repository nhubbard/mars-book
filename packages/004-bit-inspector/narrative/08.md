# Numeral order is different from byte-address order

The hexadecimal report places the most significant digit on the left, and the
binary report places bit 31 on the left. Those are conventions for writing a
number. A memory view ordered by increasing byte addresses follows a different
convention.

For the word 12345678, little-endian memory contains bytes 78, 56, 34, and 12
in increasing address order. The hexadecimal report still prints 0x12345678.
There is no contradiction: the first representation describes addresses and the
second describes place values in a numeral.

Reversing the printed digits to match an address view would produce another
number. Keep the memory layout and the numerical notation explicit whenever
a trace uses both. The previous sprite chapter's bit reversal was also a
deliberate transformation of a pattern, not a formatting change.
