# An address is separate from its contents

The address load identifies the word that is the input to this run. The
following word loads read its contents. Treating an address as an integer value
is mechanically possible, but it would answer a different question from the
assignment: it would describe where the word lives rather than the word itself.

The input and outputs also have different sizes. The input occupies four bytes.
Each result field occupies eight bytes because it must preserve an entire
64-bit register value. The labels identify those objects independently of the
registers used to compute them.

Keeping the input unchanged makes repeated observations comparable. The program
may load it more than once, and the grader checks that the stored word is still
the supplied pattern after execution. A change of interpretation needs no write
to that input.
