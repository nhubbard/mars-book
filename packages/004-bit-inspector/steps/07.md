# Step 7 Store a complete signed result

The result fields are doublewords: each occupies eight bytes. sd stores one complete 64-bit general-purpose register. The .align 3 directive in the supplied data section establishes eight-byte alignment for the initial layout.

## Write or inspect

Load the result-block address and store the first value.

```asm
    la $t1, results
    sd $s0, 0($t1)
```

## Expected observation

signed_value now contains all eight bytes of the sign-extended result. For -1, every one of those bytes is ff.

How many bytes does this sd write?

- **A** Four because the original input was a word.
- **B** One because the input initializer was -1.
- **C** Eight.
