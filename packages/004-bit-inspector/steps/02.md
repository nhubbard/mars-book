# Step 2 Load the sample address

The program first needs the address of the input word. la supplies that address in a register; it does not load the word itself. The result fields and messages are separate objects in the same data section.

## Write or inspect

Append the address load in the program region.

```asm
    la $t0, sample
```

## Expected observation

`$t0` identifies sample. The sample bytes and all output fields are unchanged.

What does this instruction put in `$t0`?

- **A** The unsigned value 4294967295.
- **B** The address of sample.
- **C** The signed value -1.
