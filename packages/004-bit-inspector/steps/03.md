# Step 3 Load and sign-extend the word

lw reads a 32-bit word and sign-extends it into the 64-bit destination. It copies word bit 31 into every upper-register bit. For the all-one input, the full register is ffffffffffffffff, representing -1 as a signed 64-bit integer.

## Write or inspect

Append the word load and its following checkpoint label.

```asm
    lw $s0, 0($t0)
signed_loaded:
```

## Expected observation

`$s0` is 0xffffffffffffffff for the default sample. The next instruction has not yet loaded the unsigned version.
