# Step 4 Load and zero-extend the same word

lwu reads the same four bytes but fills the upper 32 register bits with zeroes. The default becomes 00000000ffffffff, representing positive 4294967295. The low words of the two load results are identical.

## Write or inspect

Append the unsigned word load.

```asm
    lwu $s1, 0($t0)
unsigned_loaded:
```

## Expected observation

`$s0` is -1 and `$s1` is 4294967295, yet both have low word ffffffff. No input bytes changed.

When do these load results differ?

- **A** For every possible source word.
- **B** Only when the source address is odd.
- **C** When source bit 31 is one.
