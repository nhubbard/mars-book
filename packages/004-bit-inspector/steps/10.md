# Step 10 Print unsigned decimal

Service 36 treats that same low word as an unsigned integer. It does not need a separate positive 64-bit argument to print the unsigned word interpretation. The format service supplies the interpretation.

## Write or inspect

Append the unsigned line.

```asm
    la $a0, unsigned_msg
    li $v0, 4
    syscall
    move $a0, $s0
    li $v0, 36
    syscall
    la $a0, newline
    li $v0, 4
    syscall
unsigned_printed:
```

## Expected observation

The second line is unsigned: 4294967295 for the same default bits that printed as signed -1.
