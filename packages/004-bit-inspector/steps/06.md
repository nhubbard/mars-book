# Step 6 Add one at doubleword width

daddiu adds at the 64-bit register width. Its input here is the sign-extended original word. All allowed input values plus one fit in a signed doubleword, so this task reaches no 64-bit overflow boundary.

## Write or inspect

Append the doubleword addition.

```asm
    daddiu $s3, $s0, 1
wide_added:
```

## Expected observation

For the maximum signed word, `$s3` is 0x0000000080000000, or 2147483648. That differs from the word-width result.
