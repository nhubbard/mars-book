# Bit inspector starter

Open this folder with MARS enabled. The input is the stored word at sample; this
program does not read console input. Use the default little-endian environment.
The grader may replace sample and poison the output fields before running the program.

Preserve the supplied data labels and add instructions inside the program region.
The exit sequence is already supplied. Each required code segment can be assembled
and run with that exit. Optional alternative code replaces the corresponding operation
in a separate completed copy; it is not appended to the baseline.
