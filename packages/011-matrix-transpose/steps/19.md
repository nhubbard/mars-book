# Step 19 Finish the current clipped tile

The inner column test uses the clipped column end, not the entire matrix width. After those columns, increment the current row and compare it with the clipped row end. Reentering `next_tiled_row` recomputes the two starting pointers for that row.

## Write or inspect

Append the column and row back edges. Run the partial program to the return boundary. Identify which output positions remain untouched.

```asm
    addiu $t5, $t5, 1
    sltu $t9, $t5, $t3
    bne $t9, $zero, next_tiled_column
    nop
    addiu $t4, $t4, 1
    sltu $t9, $t4, $t2
    bne $t9, $zero, next_tiled_row
    nop
```

## Expected observation

The first tile copies the twelve source cells in rows zero through two and columns zero through three. The source values four, nine, and fourteen have not been copied; they belong to the remaining tile.
