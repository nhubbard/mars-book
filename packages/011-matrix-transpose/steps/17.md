# Step 17 Form the corresponding destination address

The destination starts at output coordinate (tile first column, current input row). Its linear word index is the tile’s first column times the input row count, plus the current row. Initialize the inner column counter from the tile’s first column as well.

## Write or inspect

Append the destination pointer and column-counter initialization. Predict both pointers for the second tile at origin (0,4).

```asm
    mul $t7, $t1, $a2
    addu $t7, $t7, $t4
    sll $t7, $t7, 2
    daddu $t7, $a1, $t7
    move $t5, $t1
```

## Expected observation

That tile begins at input byte offset sixteen and output byte offset forty-eight for three by five. Neither pointer should restart at its allocation base.
