# Step 5 Establish row starts and strides

Keep the source row start in `$t2` and the first destination of that row in `$t4`. The source row stride is four times the input width. The destination stride inside a row is four times the output width, which equals the input row count. Copy those starts to inner pointers at `naive_row`; the inner loop will advance only the copies.

## Write or inspect

Append the strides, row counter, and inner initialization. Distinguish `t0`, a row index, from `t2`, a full address.

```asm
    sll $t6, $a2, 2
    sll $t7, $a3, 2
    move $t0, $zero
    move $t2, $a0
    move $t4, $a1
naive_row:
    move $t1, $zero
    move $t3, $t2
    move $t5, $t4
```

## Expected observation

For three by five, `t6` is twelve and `t7` is twenty. The inner source pointer names the first input word and the inner destination pointer names the first output word.
