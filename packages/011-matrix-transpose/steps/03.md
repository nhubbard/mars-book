# Step 3 Stop before and after a call

The supplied caller chooses a function address in `$t9`, then calls through that address at `transpose_begin`. It places the two full pointers in the first two argument registers and the dimensions in the next two. The continuation at `transpose_done` records the count only after the function returns. This separates the function measurement from the caller’s store.

## Write or inspect

Set source breakpoints at `transpose_begin` and `transpose_done`. Inspect `a0` through `a3` at entry. The stubs return immediately; do not interpret their output as a completed transpose.

## Expected observation

The default entry arguments name the two matrix bases and dimensions three and five. The first breakpoint precedes the call, and the second precedes the result store.
