# Step 24 Measure the larger square at the return boundary

The default small example is for tracing correctness. A sixteen-by-sixteen input exceeds the cache capacity and exposes reuse differences. Change both dimensions to sixteen, keep the source data and layout fixed, and start each measurement cold. Record function-only counters before the caller stores its count.

## Write or inspect

Compare ordinary and tiled results under fully associative LRU. Record completed instructions and data accesses separately from misses.

## Expected observation

The measured reference performs 512 data accesses in either method. Ordinary has 320 misses and 2204 completed instructions; tiled has 128 misses and 3117 instructions. Equivalent implementations can have different whole-function counts.
