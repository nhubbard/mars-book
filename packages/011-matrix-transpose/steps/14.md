# Step 14 Clip the tile row end

Let `$t0` hold the tile’s first row and `$t1` its first column. The exclusive row end begins at the first row plus four. Replace it with the matrix row count when the matrix ends sooner. The end is exclusive, so a loop visits rows strictly below it.

## Write or inspect

Append the outer tile-row label, column reset, and clipped row-end calculation. Inspect `t2` for the default three-row input.

```asm
next_tile_row:
    move $t1, $zero
next_tile:
    addiu $t2, $t0, 4
    sltu $t9, $a2, $t2
    beq $t9, $zero, row_end_ready
    nop
    move $t2, $a2
row_end_ready:
```

## Expected observation

The candidate end is four, but the clipped end is three. Row index three is never a valid source row in this fixture.
