# Step 15 Clip the column end and select the first tile row

Apply the same clipping rule to columns. The current row inside the tile is a separate counter: initialize it from the tile origin rather than zero. Reusing zero would work for the first tile row and repeat earlier rows for later ones.

## Write or inspect

Append the clipped column end and the current-row initialization. For the first tile in the three-by-five matrix, compare `t2` and `t3`.

```asm
    addiu $t3, $t1, 4
    sltu $t9, $a3, $t3
    beq $t9, $zero, column_end_ready
    nop
    move $t3, $a3
column_end_ready:
    move $t4, $t0
```

## Expected observation

The exclusive row end is three and the exclusive column end is four. The tile contains twelve cells, not sixteen.
