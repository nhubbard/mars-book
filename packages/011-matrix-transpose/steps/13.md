# Step 13 Give the tiled function the same empty-case behavior

The tiled function has a different traversal but the same interface and result. Start it with the same count and early returns. Its destination stride remains four times the input row count. Use `$v1` for that stride and keep `$v0` available as the return value.

## Write or inspect

Append this entry fragment in the `tiled` region. Set `METHOD` to one for the remaining guided tiled steps.

```asm
    mul $v0, $a2, $a3
    beq $a2, $zero, tiled_return
    nop
    beq $a3, $zero, tiled_return
    nop
    sll $v1, $a2, 2
    move $t0, $zero
```

## Expected observation

Zero dimensions return zero without matrix traffic. With three by five, the incomplete tiled function returns fifteen and has not copied any words.
