# Step 20 Advance tile origins in steps of four

After completing a tile, advance its first column by four. If another tile column begins inside the matrix, calculate its clipped ends and process it. At the end of a tile row, advance the tile’s first row by four and reset the first column through `next_tile_row`. Cell counters advance by one; tile origins advance by four.

## Write or inspect

Append the outer tile loops. Run to the return boundary with three by five, then five by three and five by nine.

```asm
    addiu $t1, $t1, 4
    sltu $t9, $t1, $a3
    bne $t9, $zero, next_tile
    nop
    addiu $t0, $t0, 4
    sltu $t9, $t0, $a2
    bne $t9, $zero, next_tile_row
    nop
```

## Expected observation

The default second tile copies four, nine, and fourteen. Both functions now produce the same five-by-three output while following different access orders.
