# Step 8 Advance to the next source row

The inner source pointer is now past the completed row, but the program still keeps its row starts separately. Advance the source row start by the full source stride. Advance the first destination by four bytes so that the next input row fills the next column of every output row. Reenter the row initialization to reset the column index and inner pointers.

## Write or inspect

Append the outer loop. This completes the ordinary function. Run the three-by-five example to the return boundary and read the output as five rows of three.

```asm
    daddu $t2, $t2, $t7
    daddiu $t4, $t4, 4
    addiu $t0, $t0, 1
    sltu $t9, $t0, $a2
    bne $t9, $zero, naive_row
    nop
```

## Expected observation

The output is zero, five, ten; one, six, eleven; two, seven, twelve; three, eight, thirteen; four, nine, fourteen. The returned count is fifteen.
