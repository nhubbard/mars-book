# Start one complete eight-tap window

Clear t0 for the exact sum, copy the outer input address into t1 and the coefficient address into t2, then set the tap count in t3 to eight. The outer input address identifies this output window. Its private walker will traverse eight samples while the outer address stays in place until the output is stored. Coefficients restart from their base for every scalar output.

## Write and inspect

Replace the temporary branch and nop in `scalar_window`. Keep surrounding labels and region markers.

```asm
    move $t0, $zero
    move $t1, $a0
    move $t2, $a1
    li $t3, 8
```

Use the `s05-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

Before the first tap, t0=0 and t3=8. The two walkers identify the selected input and coefficient starts.
