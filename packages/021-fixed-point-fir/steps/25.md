# Inspect the provided vector quantizer before switching

The vector path already contains the rounding, bounds, endpoint replacement, counting and byte stores just developed in the scalar path. Compare its fir labels with their scalar counterparts. The final vector sum must arrive in t0; v0 retains the original count and v1 accumulates clipped outputs. Reusing the established rule avoids introducing a different quantizer while changing the dot product.
