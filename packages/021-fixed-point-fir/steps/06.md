# Load the oldest sample in this window

Use two unsigned byte loads from t1. The first tap sees the oldest history sample, not the first current sample at window position seven. Arbitrary byte alignment makes byte loads a direct way to respect the two-byte sample boundary. t4 and t5 still hold separate byte values; their combination and sign interpretation follow in separate edits.

## Write and inspect

Replace the temporary branch and nop in `sample_load`. Keep surrounding labels and region markers.

```asm
    lbu $t4, 0($t1)
    lbu $t5, 1($t1)
```

Use the `s06-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

For sample -1000, t4=24 and t5=252, the stored hexadecimal bytes 18 fc.
