# Build the coefficient sign-extension mask

Compare each signed halfword in w1 with zero. clti_s.h produces ffff where a coefficient is negative and zero otherwise. These bits will supply the high half of each word. A sign mask is a representation tool here; it does not count negative coefficients or change their scale.

## Write and inspect

Replace the temporary branch and nop in `coefficient_mask`. Keep surrounding labels and region markers.

```asm
    clti_s.h $w2, $w1, 0
```

Use the `s28-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

For the mixed-sign recipe, mask lanes are ffff,0000,ffff,0000,ffff,0000,0000,0000.
