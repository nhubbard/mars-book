# Load the matching Q15 coefficient

Read two bytes from t2 into t5 and t6. Reusing t5 is safe because the complete signed sample is retained in t4. This first coefficient multiplies the oldest sample. Its stored code supplies a weight only after the binary scale is applied to the complete dot product; the two loaded bytes are not separate weights.

## Write and inspect

Replace the temporary branch and nop in `coefficient_load`. Keep surrounding labels and region markers.

```asm
    lbu $t5, 0($t2)
    lbu $t6, 1($t2)
```
