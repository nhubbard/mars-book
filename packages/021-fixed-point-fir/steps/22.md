# Write the first output byte only

Store the result’s low byte at a2 with sb. A halfword result occupies exactly two permitted bytes, even at an odd address. This first store publishes one byte and leaves the second poisoned byte untouched. Input and coefficients are immutable under this FIR contract, so no in-place assumption from the mixer may justify storing into either source.

## Write and inspect

Replace the temporary branch and nop in `store_low`. Keep surrounding labels and region markers.

```asm
    sb $t0, 0($a2)
```

Use the `s22-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

Positive saturation writes ff as its first byte; negative saturation writes 00. The second byte remains a5.
