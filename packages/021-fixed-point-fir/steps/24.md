# Advance the outer input by one sample

Advance a0 and a2 by two, consume one output and repeat scalar_window while count remains. The new input window overlaps seven samples of the previous window. Its private walkers and accumulator restart, while v1 keeps the call’s accumulated clipping count. The scalar path now implements every supported count, including asymmetric impulse responses and maximum sums.

## Write and inspect

Replace the temporary branch and nop in `next_window`. Keep surrounding labels and region markers.

```asm
    daddiu $a0, $a0, 2
    daddiu $a2, $a2, 2
    addiu $a3, $a3, -1
    bne $a3, $zero, scalar_window
    nop
```

Use the `s24-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

The default sixteen-output impulse returns eight samples of 2000 then zeros. The asymmetric two-output fixture yields 4096 then 3584. Sixty-four maximum positive sums return sixty-four clipping events.
