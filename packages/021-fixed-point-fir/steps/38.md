# Transfer the first doubleword partial sum

Copy w7[0] into t0 with copy_s.d. This is a complete sixty-four-bit integer transfer. A word-sized copy would lose the extreme fixture’s 4294967296. The transfer neither scales the value nor adds the second lane; the common rounding block must not run yet.
