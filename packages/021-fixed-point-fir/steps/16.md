# Use an arithmetic shift for floor division

Shift t0 right arithmetically by fifteen with dsra. Together with the bias, this implements floor((S+16384)/32768). A negative biased value must round downward under the division, so truncation toward zero would be wrong. A logical shift would replace the sign with zeros and produce a large positive value.

## Write and inspect

Replace the temporary branch and nop in `round_scale`. Keep surrounding labels and region markers.

```asm
    dsra $t0, $t0, 15
```

Use the `s16-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

The three tie-adjacent recipes produce rounded codes one, zero and -1. The maximum eight-product sum produces 262144 before saturation.
