# Predict an asymmetric impulse response

First use the default impulse 16000 with all coefficients 4096: eight outputs are 2000 and later outputs zero. Then use impulse 16384 and unequal coefficients 1024,2048,3072,4096,5120,6144,7168,8192. The impulse enters at the current end and moves toward the oldest end in successive windows, exposing the stored coefficient order.

## Expected observation

The unequal-coefficient response is 4096,3584,3072,2560,2048,1536,1024,512, then zeros.

- **B** The first coefficient, position zero.
