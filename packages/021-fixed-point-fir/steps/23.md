# Complete the low-byte-first halfword

Shift the result right by eight into t1 and store that register’s low byte at a2+1. For a negative result, a logical shift is sufficient here because sb selects just the original bits fifteen through eight. This differs from the arithmetic shift used for signed rounding. The input/output window advance is still a separate operation.

## Write and inspect

Replace the temporary branch and nop in `store_high`. Keep surrounding labels and region markers.

```asm
    dsrl $t1, $t0, 8
    sb $t1, 1($a2)
```

Use the `s23-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

Positive saturation stores ff 7f; negative saturation stores 00 80. Each overflow contributes one event.

## Check your understanding

Why can this byte-extraction shift be logical?

- **A** It replaces the earlier rounding operation.
- **B** Only the next selected byte is stored.
- **C** Negative output codes have no high bits.
