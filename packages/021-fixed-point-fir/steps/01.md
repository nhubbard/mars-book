# Identify the current sample in the supplied input

Read the input as seven chronological history samples followed by the new samples. a0 addresses the oldest history value. At the first output, array position seven is current; at the next output, the base slides one halfword and the current value is original position eight. Coefficients stay in oldest-first order, so the last stored coefficient multiplies the current sample.

## Expected observation

One output requires eight input halfwords, two output bytes and the same sixteen coefficient bytes used by every output.
