# Load the coefficient window once

Load all sixteen coefficient bytes into w1 before the output loop. Each nonempty output uses the same eight weights, so this setup is outside fir_window. The zero guard has already excluded empty calls. Byte loading does not require a halfword-aligned coefficient address in the pinned implementation.

## Write and inspect

Replace the temporary branch and nop in `vector_coefficients`. Keep surrounding labels and region markers.

```asm
    ld.b $w1, 0($a1)
```

Use the `s27-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

w1 contains all eight coefficient codes in stored oldest-first order.
