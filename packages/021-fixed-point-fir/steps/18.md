# Keep rounded in-range values on the store path

Test whether the rounded result is smaller than -32768. Branch to scalar_low when it is; otherwise transfer directly to scalar_store. This bypasses both endpoint replacement and the clipping increment. An accumulator representing -32768.5 rounds to -32768 under this contract, so its clipping decision must use that rounded value.

## Write and inspect

Replace the temporary branch and nop in `lower_bound`. Keep surrounding labels and region markers.

```asm
    li $t8, -32768
    slt $t9, $t0, $t8
    bne $t9, $zero, scalar_low
    nop
    beq $zero, $zero, scalar_store
    nop
```

Use the `s18-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

Rounded -262136 takes the low path. Rounded -32768 and zero go to storage without increasing the count.
