# Give the coefficient its signed value

Sign-extend the coefficient halfword with seh. Code c000 represents -16384, a weight of negative one half. Multiplying the same sample by a positive or negative weight must change the contribution’s sign as ordinary signed arithmetic requires. Keep the code as an integer; do not shift it down to an integral weight before multiplication.
