# Test the rounded upper endpoint strictly

Compare rounded t0 with 32767 using a strict signed test. The filter’s clipping count concerns the rounded result, not the raw accumulator. Equality is representable and must pass to the lower test. A result larger than the endpoint goes to scalar_high, whose replacement is still unfinished.

## Write and inspect

Replace the temporary branch and nop in `upper_bound`. Keep surrounding labels and region markers.

```asm
    li $t8, 32767
    slt $t9, $t8, $t0
    bne $t9, $zero, scalar_high
    nop
```
