# Extend the sample before multiplication

Use seh so the halfword sign bit determines the complete signed register value. The pattern fc18 must become -1000 rather than positive 64536. A correct coefficient cannot repair an unsigned interpretation of the sample. This representation step precedes every product, including products in later windows.

## Write and inspect

Replace the temporary branch and nop in `sample_sign`. Keep surrounding labels and region markers.

```asm
    seh $t4, $t4
```

Use the `s08-*` input recipes in [the observation guide](../fixtures/guided-inputs.md). Start a fresh Debug execution and pause at filter_ready.

## Expected observation

t4 is -1000 for the negative recipe and 32767 for the positive boundary recipe.

## Check your understanding

Which bit supplies the extension?

- **A** Bit fifteen of the reconstructed sample.
- **B** The sign bit of the input address.
- **C** Bit seven of the low byte.
