# Grade behavior separately from the illustrated temporaries

Construction observations name registers so this particular sequence can be explained and checked. Final grading instead checks the fir_q15 interface, exact rounded/saturated outputs, state preservation and every caller-data access. An alternative may use different helpers, registers or coefficient caching. A vectorization objective additionally needs review of strategy; output alone does not prove which instructions were used.

## Expected observation

Both a scalar implementation and the widened-vector implementation satisfy the same final contract. Correct argument-register changes after last use are accepted.
