# Consume exactly eight matched pairs

Advance both private walkers by two, decrement t3 and repeat scalar_tap while a pair remains. The outer a0 window base stays unchanged. On the last pair, fall through to scalar_round. This completes an exact dot product; output storage is still unfinished. The coefficient walker must not keep its end position for the next output.
