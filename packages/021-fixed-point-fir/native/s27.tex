\section{Step 27 Load the coefficient window once}\label{fir-s27}

Load all sixteen coefficient bytes into \texttt{w1} before the output loop. Each nonempty output uses the same eight weights, so this setup is outside \texttt{fir\_window}. The zero guard has already excluded empty calls. Byte loading does not require a halfword-aligned coefficient address in the pinned implementation.
