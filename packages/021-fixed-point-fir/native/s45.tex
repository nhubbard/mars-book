\section{Step 45 Compare the stored input and filtered audio}\label{fir-s45}

Use the low, high and mixed listening scenes with their explicit periodic histories. The high component repeats four samples; every eight-tap average contains two complete periods and produces zero. The mixed filtered file matches the low filtered file, which still differs in shape and delay from the original low input. Listening is optional because the stored values and native plot establish these properties numerically.

\subsection{Expected observation}
Both implementations produce identical six-file audio sets. High-only output is zero PCM; the filtered mixed and low files are byte-identical.
