\section{Step 51 Emit the readings array head}\label{cbor-s51}
Write key two followed by the preferred array head for the selected sample count. Retain the number of readings and a pointer to the first local signed halfword for the following loop. The trace emits \texttt{02 8a}, bringing the cursor to eighteen before the reading items. The array argument counts readings, not their combined encoded bytes.

Author region \texttt{e\_array}. Use \texttt{s51-1} and stop before \texttt{after\_e\_array}.

\paragraph{Observe} The array head is 8a for ten readings.

\paragraph{Check} What does the output array argument ten count?
\begin{itemize}
\item[A.] Encoded payload bytes.
\item[B.] Two-byte local storage slots in the whole capacity.
\item[C.] Reading items.
\end{itemize}
