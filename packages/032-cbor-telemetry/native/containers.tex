\section{Count array elements and map pairs separately}
A definite array's argument counts its child items. A map's argument counts pairs,
with one key followed by one value for each pair. The worked outer map has argument
four, so it contains eight immediate child items. The sizes of those children vary;
one cannot reach the next pair by advancing a fixed number of bytes.

The readings array contains ten integers. Its input head is \texttt{98 0a}, and its
preferred output head is \texttt{8a}. Its preferred sample encodings occupy nineteen
bytes, while the ten local signed sixteen-bit slots occupy twenty. An array count is
therefore neither a byte length nor a promise of the local element width.

Maintain a remaining-item or remaining-pair count for the current container. Establish
the permitted count before doubling a map pair count or allocating state for children.
This profile limits arrays to sixty-four elements and maps to eight pairs. A wire
argument with its top bit set must fail those limits as a large unsigned value; it
must not become a negative loop count that appears already finished.
