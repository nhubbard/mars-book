\section{Step 34 Choose a following-argument width}\label{cbor-s34}
For a non-inline argument, choose one, two, four or eight following bytes according to the unsigned argument's highest nonzero byte. Add one for the initial byte. The threshold method may compare shifts against zero; it must handle a set high bit as an eight-byte unsigned argument rather than a negative short value.

Author region \texttt{z\_width}. Use \texttt{s34-1} and stop before \texttt{after\_z\_width}. 

\paragraph{Observe} Argument twenty-four needs two head bytes.

\paragraph{Check} How wide is the complete head for argument twenty-four?
\begin{itemize}
\item[A.] Two bytes.
\item[B.] One byte.
\item[C.] Twenty-five bytes.
\end{itemize}
