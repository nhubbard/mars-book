\section{Step 22 Read each root key once}\label{cbor-s22}
Finish when the retained pair count reaches zero. Otherwise consume one key head, require unsigned type and a value no greater than seven, and reject duplicate decoded keys in the root mask. Retain the current key for dispatch. On the trace, the first key is optional key three, which sets bit eight before its value is visited.

Author region \texttt{d\_key}. Use \texttt{s22-1} and stop before \texttt{after\_d\_key}.

\paragraph{Observe} The first root key is three and the root mask is eight.

\paragraph{Check} Which bit represents root key three?
\begin{itemize}
  \item[A.] The bit with value eight.
  \item[B.] The bit with value three.
  \item[C.] The bit with value four.
\end{itemize}
