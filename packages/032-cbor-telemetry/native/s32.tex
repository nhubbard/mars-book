\section{Step 32 Publish active payloads and return}\label{cbor-s32}
Copy the accepted identifier bytes and the accepted two-byte sample slots from private storage to the caller's active fields. Retain every unused caller tail byte. Return status zero and the complete original input count, then restore the supplied decoder frame. The trace now produces a complete local record while its unselected storage remains unchanged.

Author region \texttt{d\_payload}. Use \texttt{s32-1} and stop before \texttt{after\_d\_payload}.

\paragraph{Observe} Decode returns zero and fifty-two; only the prefix and active fields changed.

\paragraph{Check} What should the successful decoder return in v1?
\begin{itemize}
\item[A.] The size of the local record.
\item[B.] The deterministic encoded output size.
\item[C.] The complete selected input count.
\end{itemize}
