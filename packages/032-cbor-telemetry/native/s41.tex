\section{Step 41 Retain the type while sizing its argument}\label{cbor-s41}
The private \texttt{write\_head} helper receives major type, argument and destination in \texttt{a0} through \texttt{a2}. Retain the type before passing the argument to \texttt{head\_size}, and propagate an unfinished helper result. Its internal caller has already selected a valid type and sufficient destination extent. Test type zero and argument twenty-four.

Author region \texttt{w\_fields}. Use \texttt{s41-1} and stop before \texttt{after\_w\_fields}. 

\paragraph{Observe} The selected complete head width is two; no output byte is needed yet.

\paragraph{Check} Why retain the major type across the size call?
\begin{itemize}
\item[A.] The type is part of the argument's numeric value.
\item[B.] The size helper uses a0 for the argument.
\item[C.] The destination stores the type for later retrieval.
\end{itemize}
