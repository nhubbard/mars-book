\section{Step 54 Run the connected memory pipeline}\label{cbor-s54}
Select the pipeline recipe and stop at each supplied return label before continuing to the next routine. Head reading returns two, generic skipping and complete decoding each return fifty-two, and sizing and encoding each return thirty-seven. The caller stops on any nonzero status. Observe the local record after decode, then the output after encode, rather than attributing every count to the same unit.

Use \texttt{s54-1} and stop before \texttt{results\_ready}.

\paragraph{Observe} The pipeline reaches results\_ready with zero status and count thirty-seven.

\paragraph{Check} Why are the head and decoder counts different?
\begin{itemize}
\item[A.] They measure different declared extents.
\item[B.] One routine has lost input bytes.
\item[C.] The pipeline has changed its source between calls.
\end{itemize}
