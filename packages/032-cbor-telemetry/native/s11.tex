\section{Step 11 Distinguish immediate completion from payload work}\label{cbor-s11}
Unsigned and negative integers finish after their heads. A byte string needs a checked payload advance. Arrays and maps need container-depth and count checks before child traversal. Test the primitive item \texttt{17} and stop at \texttt{skip\_done}; this path must not open a container or treat the argument as a payload length.

Author region \texttt{k\_kind}. Use \texttt{s11-1} and stop before \texttt{skip\_done}.

\paragraph{Observe} The primitive cursor has advanced by one and reaches skip\_done without a child call.

\paragraph{Check} Which item completes immediately after its head?
\begin{itemize}
  \item[A.] A nonempty byte string.
  \item[B.] A nonempty array.
  \item[C.] A supported integer.
\end{itemize}
