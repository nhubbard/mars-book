\section{Step 6 Accumulate the big-endian argument}\label{cbor-s06}
Start a sixty-four-bit accumulator at zero. For each argument byte, shift the existing value left by eight and insert the newly loaded unsigned byte. Keep the argument-byte loop count separate from the returned complete head width. Retain all bits when the last byte sets the accumulator's high bit; the result is an unsigned bit pattern.

Author region \texttt{h\_bytes}. Use \texttt{s06-1} and stop before \texttt{after\_h\_bytes}.

\paragraph{Observe} The root argument is four and the complete head width is two.

\paragraph{Check} Why use a sixty-four-bit shift here?
\begin{itemize}
\item[A.] Every map contains sixty-four fields.
\item[B.] An argument may need all eight bytes.
\item[C.] The byte pointer must be aligned to eight.
\end{itemize}
