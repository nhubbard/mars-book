\section{Step 16 Start fresh state for one map}\label{cbor-s16}
Require at most eight map pairs and initialize this map's seen-key mask to zero. Each loop iteration consumes one unsigned key and one complete value. Retain the container kind so the common loop knows whether a key must be read first. The fixture \texttt{a1 00 00} has one pair whose key and value are both zero.

Author region \texttt{k\_map}. Use \texttt{s16-1} and stop before \texttt{after\_k\_map}.

\paragraph{Observe} The map begins with one pair and an empty seen-key mask.

\paragraph{Check} Where does a map's duplicate-key mask belong?
\begin{itemize}
\item[A.] In one shared mask for the whole input.
\item[B.] In the caller's telemetry record.
\item[C.] In that map invocation's retained state.
\end{itemize}
