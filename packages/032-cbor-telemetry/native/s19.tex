\section{Step 19 Require a complete-record extent}\label{cbor-s19}
Before reading either input or destination, reject an unsigned count above 1024 with two and a count below seven with one. Seven is the smallest complete required-field record in this profile. Unlike the generic skipper, this entry is responsible for the complete selected input. The worked trace passes the count checks without publishing any candidate field.

Author region \texttt{d\_count}. Use \texttt{s19-1} and stop before \texttt{after\_d\_count}.

\paragraph{Observe} Count fifty-two passes; all 176 destination bytes remain sentinels.

\paragraph{Check} Why reject a count below seven before input access?
\begin{itemize}
\item[A.] A CBOR head always needs seven bytes.
\item[B.] No complete required-field record can fit.
\item[C.] The local record is seven bytes long.
\end{itemize}
