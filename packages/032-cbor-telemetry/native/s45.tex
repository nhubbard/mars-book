\section{Step 45 Return the written head extent}\label{cbor-s45}
Complete the internal writer's zero-status return and keep its complete width in \texttt{v1}. Restore its own return address and stack frame before returning to the encoder. Test the two-byte unsigned-twenty-four head again. This helper writes a head only; a byte-string payload and a container's children still belong to its caller.

Author region \texttt{w\_finish}. Use \texttt{s45-1} and stop before \texttt{after\_w\_finish}. 

\paragraph{Observe} The helper returns zero and two for 18 18.

\paragraph{Check} Does writing a byte-string head also write its payload?
\begin{itemize}
\item[A.] Yes; its argument contains every payload byte.
\item[B.] Only when its length is below twenty-four.
\item[C.] No; the caller handles the payload.
\end{itemize}
