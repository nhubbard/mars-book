\section{Step 39 Measure each sample's encoded argument}\label{cbor-s39}
Load only the selected signed sixteen-bit sample slots. For a nonnegative sample, size its own value; for a negative one, size minus one minus that value. Add each complete head width to the running result. The trace's ten readings contribute nineteen bytes. Do not read identifier contents or unused sample slots while computing this bound.

Author region \texttt{b\_samples}. Use \texttt{s39-1} and stop before \texttt{after\_b\_samples}.

\paragraph{Observe} The trace's running size reaches thirty-seven.

\paragraph{Check} Why does bound not read identifier contents?
\begin{itemize}
\item[A.] Identifiers are always ASCII.
\item[B.] Their byte count alone determines their encoded extent.
\item[C.] Zero bytes are omitted during encoding.
\end{itemize}
