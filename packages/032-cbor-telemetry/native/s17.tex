\section{Step 17 Check key identity before its value}\label{cbor-s17}
At the common loop, finish an exhausted container. For a map, read a key head, require unsigned type zero and a value from zero through seven, then test its bit in this map's seen mask. Reject a set bit; otherwise set it and consume the key head. Compare decoded values, so \texttt{00} and \texttt{18 00} identify the same key.

Author region \texttt{k\_key}. Use \texttt{s17-1} and stop before \texttt{after\_k\_key}.

\paragraph{Observe} For a1 00 00, key zero sets mask bit one and the value remains unread.

\paragraph{Check} Which pair of encodings duplicates a key?
\begin{itemize}
  \item[A.] 00 and 01.
  \item[B.] 00 and 18 00.
  \item[C.] 18 00 and 18 01.
\end{itemize}
