\section{Step 40 Return the exact size}\label{cbor-s40}
Return zero status and the accumulated preferred output length, preserving the original caller state. The trace returns thirty-seven, an empty record seven and the maximum required-field record 241. These are exact values for their records; requiring the maximum for every encode would reject a valid smaller destination unnecessarily.

Author region \texttt{b\_finish}. Use \texttt{s40-1} and stop before \texttt{after\_b\_finish}.

\paragraph{Observe} The trace returns exact output size thirty-seven.

\paragraph{Check} Must a destination for the trace hold 241 bytes?
\begin{itemize}
\item[A.] Yes; every record reserves the maximum.
\item[B.] No; thirty-seven is sufficient.
\item[C.] Only when its identifier begins with zero.
\end{itemize}
