\section{Step 28 Establish the readings count}\label{cbor-s28}
Require array type and an unsigned argument no greater than sixty-four. Store this element count in the private prefix and begin a separate sample index at zero. The ten-element trace array has twenty encoded payload bytes, but the count to retain is ten. Each local reading will occupy two bytes regardless of its encoded width.

Author region \texttt{d\_array}. Use \texttt{s28-1} and stop before \texttt{after\_d\_array}.

\paragraph{Observe} The candidate reading count is ten and the first encoded reading begins at offset fifteen.

\paragraph{Check} Which count belongs in the local prefix?
\begin{itemize}
\item[A.] Twenty encoded bytes.
\item[B.] Ten readings.
\item[C.] One hundred twenty-eight reserved bytes.
\end{itemize}
