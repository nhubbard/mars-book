\section{Step 18 Resume a parent after one complete value}\label{cbor-s18}
Call the walker on the selected child with the retained open depth. Propagate unfinished status four while developing, and reject a completed child failure. Advance by the returned prefix, subtract it from the remaining bytes and decrement this parent's child or pair count once. A key does not decrement a map's pair count separately.

Author region \texttt{k\_child}. Use \texttt{s18-1} and stop before \texttt{after\_k\_child}.

\paragraph{Observe} The value zero completes the map's one pair; its counter becomes zero.

\paragraph{Check} When should a map pair counter decrease?
\begin{itemize}
\item[A.] After the key head alone succeeds.
\item[B.] After every byte in the value.
\item[C.] After the complete associated value succeeds.
\end{itemize}
