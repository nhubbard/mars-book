\section{Step 52 Convert each signed sample to a head argument}\label{cbor-s52}
Load each selected signed halfword. Use major type zero and its value when nonnegative; otherwise use type one and minus one minus the signed value. Call the head writer, advance by its result and continue until the selected count is exhausted. The trace's ten reading items add nineteen bytes; local unused slots are never read.

Author region \texttt{e\_samples}. Use \texttt{s52-1} and stop before \texttt{after\_e\_samples}.

\paragraph{Observe} The final trace output extent reaches thirty-seven bytes.

\paragraph{Check} Which argument encodes sample minus twenty-five?
\begin{itemize}
  \item[A.] Twenty-five with negative-integer type.
  \item[B.] Twenty-four with negative-integer type.
  \item[C.] The halfword bit pattern 65511 with unsigned type.
\end{itemize}
