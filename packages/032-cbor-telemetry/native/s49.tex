\section{Step 49 Write the identifier key and count}\label{cbor-s49}
Write key one and a byte-string head for the accepted identifier length. This head is derived from the local length, not copied from the wider incoming head. For the trace, emit \texttt{01 43}, making thirteen output bytes so far. Do not append the identifier's unused local tail or a terminator.

Author region \texttt{e\_identifier\_head}. Use \texttt{s49-1} and stop before \texttt{after\_e\_identifier\_head}.

\paragraph{Observe} Output offsets eleven and twelve hold 01 43.

\paragraph{Check} Why does the output use 43 rather than 58 03?
\begin{itemize}
\item[A.] The identifier has changed its type.
\item[B.] A zero in the identifier terminates the output head.
\item[C.] The writer selects the shortest head for length three.
\end{itemize}
