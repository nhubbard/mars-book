\section{Step 47 Compare capacity as an unsigned count}\label{cbor-s47}
Compare the caller's unsigned capacity with the exact bound. Return two and a zero count on shortage, preserving every destination byte. A high-bit-set capacity is a large permitted capacity, not a negative error. Only after this check may the encoder read active identifier bytes or begin output stores.

Author region \texttt{e\_capacity}. Use \texttt{s47-1} and stop before \texttt{after\_e\_capacity}.

\paragraph{Observe} Capacity thirty-seven passes; thirty-six returns two with no output writes.

\paragraph{Check} How should a capacity with its top bit set be interpreted?
\begin{itemize}
\item[A.] As an automatic format failure.
\item[B.] As a negative request for truncation.
\item[C.] As a large unsigned capacity.
\end{itemize}
