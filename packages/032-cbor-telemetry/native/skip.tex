\section{Resume a parent after consuming one child}
Keep a cursor and an end for the selected byte interval. After accepting a head, a
primitive integer is complete. A byte string adds its checked payload length. An array
visits its declared number of children; a map alternates checked keys and supported
values for its declared pair count. At each boundary, compare the requested extent
with the remaining interval before advancing an address.

The optional map in the trace occupies bytes three through eleven, so a skipper
starting at offset three returns nine. A skipper starting at the root returns fifty-two.
If one additional integer byte follows that root, it still returns fifty-two: its job
is one item, not the entire selected interval. The telemetry decoder has the separate
responsibility of rejecting that trailing byte.

Retain inherited depth before calling the head reader. The skipper receives depth in
\texttt{a2}, but the head reader returns major type in that register. Reusing the altered
\texttt{a2} as the parent's depth can turn a type code into a nesting allowance. Saved
registers or a private frame must keep the caller's meaning across the nested call.
