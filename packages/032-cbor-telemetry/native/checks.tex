\section{Check widths, structure and publication independently}
Exercise argument boundaries at twenty-three/twenty-four, 255/256, 65535/65536 and
$2^{32}-1$/$2^{32}$. Include counters with their high bit set and the all-ones pattern.
Give the head reader every truncated width, unsupported major types and reserved
additional-information values. For supported values, compare the returned type,
unsigned argument bits and head length separately.

For the walker, test empty containers, byte strings containing apparent item tokens,
every permitted depth, a ninth container, duplicate keys at different head widths and
fresh masks in sibling maps. Test a complete item followed by more bytes: the skipper
returns its prefix length, while the telemetry decoder rejects an inexact complete
record. Oversized length arguments must fail before narrowed arithmetic can advance
the cursor or multiply a pair count.

For record processing, vary required-key order, optional fields, empty payloads and
both signed endpoints. Check failed publication, untouched unused tails, exact-size
output capacity and full-width saved registers. Two complete private prototypes now pass these finite entry checks, using candidate
storage and checked input slices. The cumulative sequence now has checked checkpoint states and continuations at both
address layouts. Public feedback now covers both the declared interfaces and these illustrated
checkpoints. Separate distributions retain instructor keys and full implementations
privately.
