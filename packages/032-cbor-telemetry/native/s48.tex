\section{Step 48 Emit the map and complete counter}\label{cbor-s48}
Write the three-pair map head and key zero, then ask the completed writer for the unsigned counter head. Retain all sixty-four counter bits from the flat record. Advance the destination cursor by the helper's complete width, propagating an unfinished result during development. The trace's nine-byte counter head follows two fixed initial bytes.

Author region \texttt{e\_counter}. Use \texttt{s48-1} and stop before \texttt{after\_e\_counter}.

\paragraph{Observe} The first eleven output bytes are a3 00 1b followed by counter bytes 01 through 08.
