# Verified native expression figures

Four native LaTeX plates combine twelve original IntelliJ Light captures at expression_ready: successful precedence, missing group close, decimal-literal overflow before unary negation, and a zero denominator after a complete group. Sixteen explanations distinguish status-dependent return values, byte offsets, eager diagnostic priority, logical input boundaries and caller result publication.

An independent Pratt parser with unbounded arithmetic checks the outcomes. Every one of 224 data bytes is verified initially, at call entry, at return and after exit. The evaluator leaves caller data unchanged; all its input reads fit the supplied slice, and only the caller writes the two result words after return. Native mutation tests reject same-value input writes and suffix overreads.

The capture driver is the separate authoring plugin that depends on MARS. Its unchanged source, build and installed JAR are bound to the 68-test and paired API-verification evidence; this chapter's graphical batch is independently verified. Original PNG pixels are unchanged in the PDF. All four color/grayscale proofs are reviewed, and coordinate, font and tagging checks pass. Independent accessibility review remains open.
