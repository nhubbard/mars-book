# 38. Return the accumulated expression value

When this level has no next operator, reload its accumulator and restore the frame. Consuming only the part owned by this rule is essential: a expression can finish before the whole byte slice does. The outermost wrapper alone decides whether complete input consumption has been achieved.

## Write or inspect

Replace the temporary return in the `expr_value` region. Preserve its surrounding labels and frame scaffolding.

```asm
    ld $v0, 0($sp)
```

## Expected observation

All parser regions are now complete. The default expression returns twenty-four with cursor seventeen; the public wrapper reports success.
