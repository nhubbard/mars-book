# 7. Skip a run without reading past its end

Increment the cursor once and branch back to the bound check. A whitespace byte at the final position therefore advances to the length and returns before another load. Keep the update inside this loop; branching back without it would repeatedly classify the same byte.

## Write or inspect

Replace the temporary return in the `space_advance` region. Preserve its surrounding labels and frame scaffolding.

```asm
    addiu $s1, $s1, 1
    beq $zero, $zero, skip_space
    nop
```

## Expected observation

The slice space, tab, carriage return, line feed, 7 leaves the cursor at four. An empty slice causes no input load.

- **A** At the length check.
