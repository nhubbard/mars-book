# 21. Retain the offending literal-digit position

Set overflow status, copy the current cursor into the diagnostic offset, clear the private value, and return through the balanced primary exit. The cursor has not advanced past the digit that exceeded the bound. Unary minus outside this literal cannot turn an already rejected token into a valid operand.

## Write or inspect

Replace the temporary return in the `primary_overflow` region. Preserve its surrounding labels and frame scaffolding.

```asm
    li $s3, -2
    move $s4, $s1
    move $v0, $zero
    beq $zero, $zero, primary_return
    nop
```

## Expected observation

2147483648 reports status minus two, offset nine, with cursor nine.
