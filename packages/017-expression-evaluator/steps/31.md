# 31. Accumulate term operations from left to right

Store the successful result back into the same accumulator slot and return to the operator probe. The next multiplication or division therefore uses the previous result as its left operand. This loop establishes left association; it must not recursively absorb an entire same-precedence right expression first.

## Write or inspect

Replace the temporary return in the `term_repeat` region. Preserve its surrounding labels and frame scaffolding.

```asm
    sd $v0, 0($sp)
    beq $zero, $zero, term_loop
    nop
```

## Expected observation

For 3*4/2, successive operations produce twelve and then six.
