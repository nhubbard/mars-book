# 18. Return the completed literal

Copy the bounded accumulator into the private value result and leave through the primary frame restore. A successful number need not consume the whole input. In 12+3, the primary returns twelve and leaves the cursor at the plus byte; the expression routine will decide what that byte means.

## Write or inspect

```asm
    beq $zero, $zero, primary_return

```
