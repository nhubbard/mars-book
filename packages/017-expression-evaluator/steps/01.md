# 1. Read status before interpreting the second result

The same second result register represents a signed expression value on success and a byte offset on failure. The supplied default input is seventeen bytes long and evaluates to twenty-four. Read `v0` first; a negative value there is a status, not an arithmetic result.

## Expected observation

At expression_ready for the complete program, `v0` is zero and `v1` is twenty-four.
