# 30. Apply the pending term operation

Move the right value into `a1`, reload the left value into `a0`, and recover the operator and its position into `a2` and `a3`. Call the checked arithmetic helper. A new arithmetic failure returns immediately; a successful value is ready to become the next accumulator.

## Write or inspect

Replace the temporary return in the `term_apply` region. Preserve its surrounding labels and frame scaffolding.

```asm
    move $a1, $v0
    ld $a0, 0($sp)
    ld $a2, 8($sp)
    ld $a3, 16($sp)
    jal apply_binary
    nop
    bne $s3, $zero, term_return
    nop
```

## Expected observation

For 3*4, the checked operation now returns twelve.
