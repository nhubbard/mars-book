# 35. Save the pending expression operation

Save both the operator byte and its cursor position before advancing. Then call the term routine for the right operand. The right call may recurse, skip whitespace, or fail. If it fails, return that diagnostic before attempting this pending binary operation.

## Write or inspect

Replace the temporary return in the `expr_operator` region. Preserve its surrounding labels and frame scaffolding.

```asm
    sd $t0, 8($sp)
    sd $s1, 16($sp)
    addiu $s1, $s1, 1
    jal parse_term
    nop
    bne $s3, $zero, expr_return
    nop
```

## Expected observation

For 1+2*3, the right operand returns six; the left value and operator remain in the frame.

Why retain the operator position before the right call?

- **A** The position is always zero.
