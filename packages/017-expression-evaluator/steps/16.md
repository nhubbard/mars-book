# 16. Accumulate and check one decimal digit

Multiply the accepted prefix by ten in doubleword width, then add the digit value. Compare with 2147483647 before advancing the cursor. Because the previous accepted prefix was bounded, this candidate fits in a doubleword even when it is too large for the literal domain.

## Write or inspect

Replace the temporary return in the `primary_digit` region. Preserve its surrounding labels and frame scaffolding.

```asm
    li $t4, 10
    dmul $t3, $t3, $t4
    daddu $t3, $t3, $t1
    li $t4, 2147483647
    slt $t5, $t4, $t3
    bne $t5, $zero, primary_overflow
    nop
```

## Expected observation

With first digit 7, the accumulator becomes seven while the cursor still identifies that digit.
