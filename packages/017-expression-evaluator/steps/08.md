# 8. Select a binary arithmetic operation

The private arithmetic helper receives the left value in `a0`, right value in `a1`, operator byte in `a2`, and operator offset in `a3`. Compare against ASCII plus, minus, and asterisk. The remaining valid operator is slash; only the parser calls this helper, so it supplies one of those four bytes.

## Write or inspect

Replace the temporary return in the `apply_dispatch` region. Preserve its surrounding labels and frame scaffolding.

```asm
    li $t0, 43
    beq $a2, $t0, apply_add
    nop
    li $t0, 45
    beq $a2, $t0, apply_subtract
    nop
    li $t0, 42
    beq $a2, $t0, apply_multiply
    nop
```

## Expected observation

The plus byte, decimal 43, selects apply_add. Arithmetic regions that are still unfinished return provisional zero.
