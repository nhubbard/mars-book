# 19. Enter a parenthesized expression

Consume the opening parenthesis and call the expression routine. Each primary invocation has already preserved its return address in its own stack frame. If the nested call establishes an error, leave immediately instead of replacing that diagnostic while looking for a closing parenthesis. The expression routine is still a temporary stub at this stage.

## Write or inspect

Replace the temporary return in the `primary_group_call` region. Preserve its surrounding labels and frame scaffolding.

```asm
    addiu $s1, $s1, 1
    jal parse_expr
    nop
    bne $s3, $zero, primary_return
    nop
```

## Expected observation

For an opening-parenthesis-only slice, the temporary nested call returns zero with cursor one. This is an intermediate scaffold observation, not a successful complete expression.
