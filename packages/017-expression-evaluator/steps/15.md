# 15. Distinguish a group from a decimal literal

Skip permitted whitespace, reject end of input as a missing primary, and inspect the next byte. An opening parenthesis selects the group path. Otherwise subtract ASCII zero and use an unsigned comparison with ten. Values below ASCII zero become large unsigned values after subtraction, so they fail this digit test. Initialize the literal accumulator only after the first digit is established.

## Write or inspect

Replace the temporary return in the `primary_entry` region. Preserve its surrounding labels and frame scaffolding.

```asm
    jal skip_space
    nop
    beq $s1, $s2, primary_syntax
    nop
    daddu $t0, $s0, $s1
    lbu $t0, 0($t0)
    li $t1, 40
    beq $t0, $t1, primary_group
    nop
    addiu $t1, $t0, -48
    sltiu $t2, $t1, 10
    beq $t2, $zero, primary_syntax
    nop
    move $t3, $zero
```

## Expected observation

For 7, `t1` is digit value seven, `t2` is one, `t3` is zero, and the cursor is still zero.

## Check your understanding

Why does the unsigned digit comparison reject a slash?

- **A** Slash becomes digit nine.
- **B** The slash is a whitespace byte.
- **C** Subtracting ASCII zero gives a negative value, which is outside unsigned zero through nine.
