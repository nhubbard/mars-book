# 32. Return the accumulated term value

When this level has no next operator, reload its accumulator and restore the frame. Consuming only the part owned by this rule is essential: a term can finish before the whole byte slice does. The outermost wrapper alone decides whether complete input consumption has been achieved.

## Write or inspect

Replace the temporary return in the `term_value` region. Preserve its surrounding labels and frame scaffolding.

```asm
    ld $v0, 0($sp)
```

## Expected observation

For 7+2, term returns seven and leaves the plus at cursor one.
