# 37. Accumulate expression operations from left to right

Store the successful result back into the same accumulator slot and return to the operator probe. The next addition or subtraction therefore uses the previous result as its left operand. This loop establishes left association; it must not recursively absorb an entire same-precedence right expression first.

## Write or inspect

Replace the temporary return in the `expr_repeat` region. Preserve its surrounding labels and frame scaffolding.

```asm
    sd $v0, 0($sp)
    beq $zero, $zero, expr_loop
    nop
```

## Expected observation

For 1+2*3-4, successive outer operations produce seven and then three.
