# 23. Recognize a sign before selecting a primary

Skip whitespace, then distinguish plus and minus from the primary path. A sign transfers to the recursive sign path. A non-sign delegates to primary; end of input also delegates so that the primary reports the required missing-operand error. This helper does not silently create a value for an isolated sign.

## Write or inspect

Replace the temporary return in the `unary_entry` region. Preserve its surrounding labels and frame scaffolding.

```asm
    jal skip_space
    nop
    beq $s1, $s2, unary_primary
    nop
    daddu $t0, $s0, $s1
    lbu $t0, 0($t0)
    li $t1, 43
    beq $t0, $t1, unary_sign
    nop
    li $t1, 45
    beq $t0, $t1, unary_sign
    nop
```

## Expected observation

For -7, the inspected operator byte is decimal 45 and the cursor is still zero.
