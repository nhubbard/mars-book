# Count neighbors from one immutable phase

For a cell pointer p in the current padded board, the three positions above are at
p−11, p−10, and p−9. The same-row neighbors are p−1 and p+1. The lower row uses p+9,
p+10, and p+11. There is no load at offset zero in the count because the center is
not its own neighbor.

All loaded bytes are binary, so their sum is between zero and eight. The reference
spells out the eight load/add pairs. This makes the geometry of each access visible
and removes a small loop's pointer, counter, branch, and delay-slot work.

A table of signed offsets is an equivalent way to describe those positions. The
alternative walks that table and loads each source byte through its computed address.
Both methods must read the same current generation, keep its allocation unchanged,
and write results only into the separate destination interior.
