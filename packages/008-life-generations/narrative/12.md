# Compare instruction work after verifying the same evolution

For the default two-step oscillator, the unrolled/Boolean reference completes 7,007
simulated instructions and the offset-loop/branching alternative 14,197. Both counts
include seed initialization, three full renders, two complete sweeps, and normal exit.
The difference is measured after both programs satisfy the same generation contract.

The unrolled count body trades repeated source lines for less loop-control work.
The Boolean rule also has a fixed instruction path, while the alternative's branch
path depends on neighbor counts. This is a concrete opportunity to discuss instruction
work without replacing correctness checks with a speed score.

The totals are not physical CPU cycles or host-runtime measurements. MARS tool observers,
backstep recording, JIT compilation, and UI activity can contribute to elapsed time.
The chapter records its fixture and metric so a smaller instruction total does not
silently become an unsupported wall-time claim. Larger boards, packed bit states,
vector kernels, or another boundary model need separate contracts and measurements.
