# Step 4 Load current and destination pointers

The reference begins with `board_a` as current and `board_b` as destination. It loads the requested evolution count and initializes the working generation number to zero.

## Write or inspect

Append the pointer and count setup.

```asm
    la $s0, board_a
    la $s1, board_b
    la $t0, generations
    lw $s2, 0($t0)
    move $s3, $zero
```

## Expected observation

`$s0` identifies `board_a`, `$s1` `board_b`, `$s2` is the requested count, and `$s3` is zero.
