# Step 20 Render and publish the newly current board

The back-edge returns to the renderer. After rendering, the same ready label is reached with the new generation. The boundary test then decides whether another sweep is required.

## Write or inspect

Append the loop back-edge.

```asm
    beq $zero, $zero, render
    nop
```

## Expected observation

The complete default program publishes generation zero, one, and two before exiting.
