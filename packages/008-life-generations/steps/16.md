# Step 16 Store the next state into the other board

The destination pointer identifies the same cell in the next generation. `sb` writes one binary state and leaves the source intact.

## Write or inspect

Append the destination store.

```asm
    sb $t4, 0($t7)
cell_written:
```

## Expected observation

The first next-state cell is complete; the rest of the destination may still contain old data.

## Check your understanding

Is this partial destination ready to render as a generation?

- **A** Yes, because one cell is correct.
- **B** No; all 64 next-state cells must be complete first.
- **C** Only if the first cell is dead.
