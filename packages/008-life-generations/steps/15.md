# Step 15 Evaluate birth or survival with Boolean values

XOR with a constant yields zero exactly on equality. `sltiu` value,value,1 converts that zero test into a binary flag. Combine count==3 with current_alive AND count==2 to implement the rule.

## Write or inspect

Append the rule expression.

```asm
    xori $t4, $t3, 3
    sltiu $t4, $t4, 1
    xori $t5, $t3, 2
    sltiu $t5, $t5, 1
    lbu $t6, 0($s7)
    and $t5, $t5, $t6
    or $t4, $t4, $t5
rule_decided:
```

## Expected observation

`$t4` is exactly zero or one, the state to write into the destination.
