# Step 6 Copy one binary byte

`lbu` reads one unsigned seed byte. `sb` stores it into the working interior. Advancing both byte cursors by one prepares the next column without changing the input allocation.

## Write or inspect

Append the per-cell copy body.

```asm
    lbu $t4, 0($t0)
    sb $t4, 0($t1)
    daddiu $t0, $t0, 1
    daddiu $t1, $t1, 1
```

## Expected observation

Only the first interior byte has been copied at this partial stage.

## Check your understanding

Does `lbu` create a live link to the seed byte?

- **A** Yes, later stores update the register automatically.
- **B** Only if the byte is one.
- **C** No; it copies the current byte value into a register.
