# Step 17 Complete all rows before changing roles

Advance the interior column through eight, then the row through eight. Every destination cell is computed from the same current board. No halo cell is part of the write sweep.

## Write or inspect

Append the sweep-loop control.

```asm
    addiu $s5, $s5, 1
    slti $t0, $s5, 9
    bne $t0, $zero, cell_loop
    nop
    addiu $s4, $s4, 1
    slti $t0, $s4, 9
    bne $t0, $zero, cell_row
    nop
generation_computed:
```

## Expected observation

At `generation_computed`, the destination is complete and the current board is still the old generation.
