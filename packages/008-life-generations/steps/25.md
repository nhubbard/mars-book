# Step 25 Check zero steps and buffer parity

Generation zero is in `board_a`. Each swap changes which allocation is current, so even generations return to `board_a` and odd generations use `board_b`. The other board retains the previous complete generation after the first step.

## Write or inspect

Predict the current board for requested counts zero through four.

## Expected observation

Counts 0,2,4 use `board_a`; counts 1,3 use `board_b`.

## Check your understanding

What should the unused destination contain at generation zero?

- **A** It must already be generation one.
- **B** Its interior is scratch and may still be arbitrary; its halo remains zero.
- **C** It must be an alias of the seed.
