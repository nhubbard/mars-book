# Step 19 Exchange roles without copying the board

Three moves exchange current and destination base pointers. Increment the working generation count once. No board bytes move during this exchange.

## Write or inspect

Append the pointer swap and count update.

```asm
    move $t0, $s0
    move $s0, $s1
    move $s1, $t0
    addiu $s3, $s3, 1
buffers_swapped:
```

## Expected observation

After the first swap, `board_b` is current, `board_a` is the next destination, and `$s3` is one.
