# Allow a single-byte value without a minimality test

At `dec_terminal`, compare candidate length with one. A one-byte zero payload is valid and can proceed directly to inverse mapping. Longer candidates must prove their terminal payload is nonzero.

## Write and inspect

```asm
    li $t6, 1
    beq $t3, $t6, dec_unmap
    nop
```

## Expected observation

Byte 00 represents one complete zero value; the default two-byte candidate proceeds toward the minimality check.
