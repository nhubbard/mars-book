# Subtract the committed predecessor in full width

Use `dsubu` to compute the current reading minus `s4`. At the first value `s4` is zero. Later iterations update it only after a candidate has been fully written. This subtraction must retain endpoint jumps wider than a word.

## Write and inspect

Replace the temporary branch and nop in `e_difference`, retaining labels and markers.

```asm
    dsubu $t1, $t0, $s4
```

## Expected observation

The first default delta is `t1`=1000; an initial minimum reading gives -2147483648.
