# Finish an empty encoder before checking capacity

At `enc_next`, compare the committed reading count `s5` with the input count `s1`. Return immediately when they are equal. This makes empty input successful even when capacity is zero, and also recognizes a completed nonempty sequence on the next loop visit.

## Write and inspect

Replace the temporary branch and nop in `e_end`, retaining labels and markers.

```asm
    beq $s5, $s1, enc_return
    nop
```

## Expected observation

Empty input returns `v0`=0,`v1`=0,`a3`=0 without input or output access.

Which test comes first at encoder entry?

- **A** Whether five bytes remain.

- **C** Whether a continuation bit is set.
