# Turn mapped parity into an inverse sign mask

At `dec_unmap`, isolate the unsigned accumulator low bit and negate it in a doubleword. The result is zero for even mapped values and all ones for odd values. Keep the full unsigned accumulator `t1` available for the magnitude shift.

## Write and inspect

Replace the temporary branch and nop in `d_inverse_mask`, retaining labels and markers.

```asm
    andi $t5, $t1, 1
    dsubu $t5, $zero, $t5
```

## Expected observation

The default even mapped value produces inverse mask zero; mapped one produces -1.
