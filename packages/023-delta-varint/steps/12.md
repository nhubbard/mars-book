# Count groups without destroying the mapped value

Copy `t2` into `t3` and start the candidate byte count `t4` at one. The length loop consumes only this copy. Keeping the count at one initially ensures mapped zero still reserves its required terminating byte.

## Write and inspect

Replace the temporary branch and nop in `e_length_setup`, retaining labels and markers.

```asm
    move $t3, $t2
    li $t4, 1
```

## Expected observation

The default copy is 2000 and its initial candidate length is one.
