# Load the current signed reading through its full address

Multiply the committed reading index by four and add it to the full source base. Load the word into `t0` with `lw`. Keep the current reading while the byte-group logic uses other temporaries; it later becomes the next predecessor.

## Write and inspect

Replace the temporary branch and nop in `e_load`, retaining labels and markers.

```asm
    dsll $t0, $s5, 2
    daddu $t0, $s0, $t0
    lw $t0, 0($t0)
```

## Expected observation

The default first current reading is `t0`=1000.
