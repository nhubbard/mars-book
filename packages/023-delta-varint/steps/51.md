# Reject a reconstructed value below the signed minimum

Load the full signed minimum into `t7` and compare `t6` with it. Use `dec_range` when the candidate is smaller. The canonical 33-bit mapped maximum decodes to a delta too negative for any allowed predecessor and is a useful test of this distinction.

## Write and inspect

Replace the temporary branch and nop in `d_minimum`, retaining labels and markers.

```asm
    dli $t7, -2147483648
    slt $t9, $t6, $t7
    bne $t9, $zero, dec_range
    nop
```
