# Stop length counting when no higher group remains

If the shifted copy is zero, branch to `enc_check_capacity`. Otherwise another byte is required. This gate is also what makes a mapped zero finish with candidate length one.

## Write and inspect

Replace the temporary branch and nop in `e_length_end`, retaining labels and markers.

```asm
    beq $t3, $zero, enc_check_capacity
    nop
```

## Expected observation

The zero-value recipe reaches capacity preflight with a one-byte candidate.
