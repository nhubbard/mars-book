# Recognize a terminating raw byte

Mask bit seven of `t4` into `t6`. If it is clear, branch to `dec_terminal`. Otherwise another group is required. This condition does not inspect the reconstructed reading sign; framing belongs to the raw byte.

## Write and inspect

Replace the temporary branch and nop in `d_continuation`, retaining labels and markers.

```asm
    andi $t6, $t4, 128
    beq $t6, $zero, dec_terminal
    nop
```

## Expected observation

The first default byte has continuation set; the second will terminate.
