# Double the exact signed delta

Shift `t1` left by one in a doubleword and place that intermediate bit pattern in `t2`. For a negative delta this intermediate is not yet the final unsigned mapped value. The sign-mask XOR follows in a separate edit.

## Write and inspect

Replace the temporary branch and nop in `e_double`, retaining labels and markers.

```asm
    dsll $t2, $t1, 1
```

## Expected observation

For the default positive delta, `t2`=2000 before the mask.
