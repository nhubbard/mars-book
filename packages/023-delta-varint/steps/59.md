# Compose the real functions in one session

Encode a complete sequence, inspect the bytes actually produced, then pass those bytes to the decoder in the same stopped execution session. Follow with zero-capacity and empty calls, then a different sequence. Both functions reset their predecessor and preserve caller state every time. Independent model checks remain necessary because paired mistakes can cancel.

## Expected observation

Actual encoder bytes decode to the original readings; failed and empty calls do not leak state into the next call.
