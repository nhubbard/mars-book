# Reject continuation on the fifth byte

Test bit seven at the fifth-byte path and use `dec_bad` if it is set. A sixth byte cannot repair this width violation. The rejected candidate does not advance committed input or output, even though its private scan reached byte five.

## Write and inspect

Replace the temporary branch and nop in `d_fifth_continuation`, retaining labels and markers.

```asm
    andi $t6, $t4, 128
    bne $t6, $zero, dec_bad
    nop
```

## Expected observation

A five-byte continued prefix returns malformed status two with zero committed counts.
