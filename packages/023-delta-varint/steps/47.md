# Reject a redundant terminal zero group

For a multibyte candidate, branch to `dec_bad` when the terminal payload `t5` is zero. Earlier zero payloads are allowed because they can hold low positions below a later nonzero group. This check establishes the shortest representation before inverse mapping.

## Write and inspect

Replace the temporary branch and nop in `d_minimal`, retaining labels and markers.

```asm
    beq $t5, $zero, dec_bad
    nop
```

## Expected observation

Input 80 00 returns malformed status two with no committed value or output store.
