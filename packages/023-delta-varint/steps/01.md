# Keep the units beside both result counters

The same register interface serves two directions, but the units change. Encoding consumes word readings and produces bytes; decoding consumes bytes and produces readings. Status in `a3` is separate from both counts. Use the format table before interpreting a stopped register value.

## Expected observation

A decoder result of four consumed bytes and three readings refers to a different pair of units than an encoder result of four readings and five bytes.
