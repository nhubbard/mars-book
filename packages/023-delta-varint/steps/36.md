# Load one byte at the full scan address

Add the private byte index to the full source base and load through that address with `lbu` into `t4`. Unlike word readings, these bytes may start at any alignment. Keep the raw byte until both payload and continuation have been interpreted.

## Write and inspect

Replace the temporary branch and nop in `d_load`, retaining labels and markers.

```asm
    daddu $t4, $s0, $t0
    lbu $t4, 0($t4)
```

## Expected observation

The default first raw byte is decimal 208, hexadecimal d0.
