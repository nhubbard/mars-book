# Choose the terminal-byte path

Branch to `enc_last_byte` when the remaining value is zero. That path stores the unflagged payload. Otherwise continue toward a flagged continuation byte.

## Write and inspect

Replace the temporary branch and nop in `e_terminal`, retaining labels and markers.

```asm
    beq $t2, $zero, enc_last_byte
    nop
```

## Expected observation

Mapped zero takes the terminal path with payload zero.
