# Reject a candidate that cannot fit completely

Compare remaining bytes with `t4` and branch to `enc_full` only when the remainder is smaller. Equality permits the complete candidate. This test precedes all candidate stores, so a rejected value cannot leave a partial prefix in output.

## Write and inspect

```asm
    sltu $t5, $t5, $t4
    bne $t5, $zero, enc_full
    nop
```

Capacity one cannot hold the first two-byte value; capacity two permits it.
