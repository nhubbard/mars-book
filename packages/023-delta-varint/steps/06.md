# Stop a full encoder before reading another word

Compare committed output bytes `s6` with byte capacity `s3`. If equal, use the supplied `enc_full` path, which returns capacity status one. Do not load a new reading when no byte can fit, because even zero needs one byte.

## Write and inspect

Replace the temporary branch and nop in `e_capacity`, retaining labels and markers.

```asm
    beq $s6, $s3, enc_full
    nop
```

## Expected observation

A nonempty zero-capacity call returns zero counts and status one without a source read.

## Check your understanding

Can mapped source memory be read when output capacity is zero?

- **A** Only if the first value is zero.
- **B** Only if it is word aligned.
- **C** No; this interface requires the capacity stop before that read.
