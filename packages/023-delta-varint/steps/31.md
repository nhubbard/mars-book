# Reserve an output slot before inspecting a candidate

Compare output-reading count `s6` with capacity `s3`. Use `dec_full` when they are equal. This gives capacity priority over malformed data that belongs to the next unstarted candidate. A nonempty zero-capacity input must remain unread.

## Write and inspect

Replace the temporary branch and nop in `d_capacity`, retaining labels and markers.

```asm
    beq $s6, $s3, dec_full
    nop
```

## Expected observation

Malformed input 80 00 at zero capacity returns status one, not malformed status two.
