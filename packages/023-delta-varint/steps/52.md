# Reject a reconstructed value above the signed maximum

Load the signed maximum into `t8` and test whether it is below the exact candidate `t6`. Equality is representable and must succeed. Keeping this addition full-width prevents an excessive positive value from wrapping into a plausible negative reading.

## Write and inspect

Replace the temporary branch and nop in `d_maximum`, retaining labels and markers.

```asm
    li $t8, 2147483647
    slt $t9, $t8, $t6
    bne $t9, $zero, dec_range
    nop
```

## Expected observation

An initial mapped value 4294967296 reconstructs 2147483648 and returns range status three.
