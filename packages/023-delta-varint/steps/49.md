# Recover the exact signed delta

Shift `t1` logically right by one and XOR with the inverse mask. This implements both parity branches without narrowing the candidate. A five-byte mapped value may need bits above a word before this transformation is complete.

## Write and inspect

Replace the temporary branch and nop in `d_inverse`, retaining labels and markers.

```asm
    dsrl $t6, $t1, 1
    xor $t6, $t6, $t5
```

## Expected observation

The default candidate gives delta 1000; mapped one gives -1.
