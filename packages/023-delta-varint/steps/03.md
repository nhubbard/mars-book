# Mark the default stream value boundaries

Predict the mapped default values 2000,4,1,0,37998 and their byte groups. The stream d0 0f 04 01 00 ee a8 02 has five values in eight bytes. The first and last values each need more than one byte.

## Expected observation

The first reading ends after two bytes; the last occupies byte positions five through seven.

## Check your understanding

What does the continuation bit indicate?

- **A** A negative reading.
- **B** An output word boundary every four bytes.
- **C** Another payload group of this value follows.
