# Shift a payload to its group position

At `dec_accumulate`, use `dsllv` to shift `t5` by the private bit position `t2`. The first payload uses shift zero. A later fifth payload may contribute bits above the word boundary, so keep this operation in a doubleword.

```asm
    dsllv $t6, $t5, $t2
```
