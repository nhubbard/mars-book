# Reset payload shift and candidate byte count

Clear `t2` for the payload bit position and `t3` for bytes scanned in this candidate. The first payload contributes at shift zero; later groups move seven bits upward. The byte count supports separate fifth-byte and minimal-length checks.

## Write and inspect

```asm

    move $t3, $zero
```

## Expected observation

Both the initial payload shift and candidate byte count are zero.
