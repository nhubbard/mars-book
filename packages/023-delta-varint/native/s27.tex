\section{Step 27 Publish the byte count and repeat the complete encoder}\label{delta-s27}

Add the candidate length \texttt{t4} into committed bytes \texttt{s6} and return to \texttt{enc\_next}. The whole encoder now processes each value atomically: preflight, complete byte emission, both counts, then the next candidate. Validate the completed entry with all capacity boundaries before starting the decoder.
