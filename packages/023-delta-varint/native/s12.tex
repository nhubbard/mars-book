\section{Step 12 Count groups without destroying the mapped value}\label{delta-s12}

Copy \texttt{t2} into \texttt{t3} and start the candidate byte count \texttt{t4} at one. The length loop consumes only this copy. Keeping the count at one initially ensures mapped zero still reserves its required terminating byte.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the supplied temporary branch and nop in \texttt{e\_length\_setup}. Keep surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}

    move $t3, $t2
    li $t4, 1
\end{minted}
Use \texttt{s12-1} from the companion construction inputs. Pause at \texttt{codec\_done} before caller result storage.

\subsection{Expected observation}
The default copy is 2000 and its initial candidate length is one.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why not initialize length to zero?

\begin{itemize}
\item \textbf{A} Every encoding includes at least one byte, including zero.
\item \textbf{B} The first byte is a file header.
\item \textbf{C} All values have two payload groups.
\end{itemize}
