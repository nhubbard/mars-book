# Verified RSA arithmetic IDE figures

Four figures use sixteen actual IntelliJ Light screenshots captured automatically
by the separate MARS book authoring plugin. Each folder contains unchanged original
PNGs, native capture receipts, a preview rendered from the annotated LaTeX proof,
and its reviewed composition receipt. The directly editable native book source is
authoritative; the student snapshot relocates only capture asset paths.

The figures distinguish a 64-bit product accumulator from its stored low limb,
the 129th sum bit from the stored four-limb sum, private reduction from publication,
and complete modular-power output from later frame restoration. Captions and numbered
explanations identify byte order, private-value boundaries and untouched output bytes.

Independent unbounded integer calculations check the values. Complete caller images,
exact caller/workspace access histories, declared private arithmetic values, protected
workspace and restored registers are checked separately. Active unused stack padding
and saved return-address bytes are not claimed to form a fully expected stack image.
Original screenshot pixels, native annotation coordinates, embedded fonts, tagged
figure descriptions and full-image layout bounds pass automated checks; color and
grayscale proofs were reviewed. Finite tests do not certify cryptographic security,
constant-time execution or independent PDF/UA conformance. Later substantive editing
and independent accessibility review remain open.
