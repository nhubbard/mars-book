# Trace a stopped starter

Open the cumulative starter and locate the seven entry points and their marked regions. The default caller selects the gcd example. Missing regions return development status three; the gcd also uses `v1` to distinguish this from a numerical answer. Run to the caller's return before interpreting output. The result objects begin with sentinels.

## Expected observation

An unfinished return is observable without claiming a completed arithmetic value.
