\section{Step 1 Trace a stopped starter}\label{rsa-s01}

Open the cumulative starter and locate the seven entry points and their marked regions. The default caller selects the gcd example. Missing regions return development status three; the gcd also uses \texttt{v1} to distinguish this from a numerical answer. Run to the caller's return before interpreting output. The result objects begin with sentinels.

\subsection{Expected observation}
An unfinished return is observable without claiming a completed arithmetic value.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Does development status three certify an arithmetic answer?

\begin{itemize}
  \item \textbf{A} Only for a zero exponent.
  \item \textbf{B} No; it marks unfinished work.
  \item \textbf{C} Yes, if the low byte happens to match.
\end{itemize}
