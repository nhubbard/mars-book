\section{Step 29 Guard the public modular multiplier}\label{rsa-s29}

Test the complete modulus before reading either operand or touching the output. A valid request reaches the supplied frame, while the zero case returns an error directly. This public entry accepts arbitrary 128-bit operands; residue bounds will be established internally.

Replace only the body of region \texttt{modproduct\_guard}, retaining its BEGIN and END comments.
