\section{Step 9 Store exactly one scalar result}\label{rsa-s09}

Publish the low word only after the loop has finished. The scalar product was wider than this store because the remainder needed its high bits. A successful residue itself fits the interface's output word. Return status zero without changing bytes surrounding that word.

Replace only the body of region \texttt{word\_publish}, retaining its BEGIN and END comments.

Use recipe \texttt{s09-1} with the cumulative source through this edit. Stop at \texttt{function\_return} before continuing to the temporary or normal return. With the supplied caller, use \texttt{pow32\_return} as that return breakpoint.

Exactly four output bytes encode 2790; the remaining sentinel bytes are intact.
