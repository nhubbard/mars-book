\section{Step 25 Double the prefix and extract a bit}\label{rsa-s25}

Call modular addition with the private remainder twice, updating that same object. Check the nested status before using its result. Convert the current bit index to a word byte offset and an in-word shift, then mask the selected bit. A word index is not yet a byte offset.

Replace only the body of region \texttt{reduce\_bit}, retaining its BEGIN and END comments.

\Needspace{21\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
reduce_bit:
    move $a0, $sp
    move $a1, $sp
    move $a2, $s1
    move $a3, $sp
    jal rsa_addmod128
    nop
    bnez $v0, reduce_development
    nop
    dsrl $t0, $s3, 5
    dsll $t0, $t0, 2
    daddu $t0, $s0, $t0
    lwu $t1, 0($t0)
    andi $t2, $s3, 31
    dsrlv $t1, $t1, $t2
    andi $t1, $t1, 1
\end{minted}

Use recipe \texttt{s25-1} with the cumulative source through this edit. Stop at \texttt{after\_reduce\_bit} before continuing to the temporary or normal return.

\subsection{Expected observation}
For \(2^{127}\) plus 13, the first extracted bit is one and the doubled initial remainder is still zero.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
How is a bit index converted to its containing word's byte offset?

\begin{itemize}
  \item \textbf{A} Use the original bit index as an address.
  \item \textbf{B} Divide by 32, then multiply by four.
  \item \textbf{C} Multiply directly by 32.
\end{itemize}
