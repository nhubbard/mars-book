\section{Step 1 Trace a rectangular product before writing loops}\label{matmul-s01}

Use the two-by-three left input and the three-by-two right input from the worked example. Keep the output row and column fixed while listing the three reduction pairs. This gives a value to check before any register allocation or traversal change. Record the flattened output in row-major order, with an eight-byte slot for each result.

\subsection{Expected observation}
The four exact output values are 58, 64, 139 and 154.

\Needspace{10\baselineskip}
\subsection{Check your understanding}
Which values determine output row one, column zero?

\begin{itemize}
\item \textbf{A} The second left row and first right column.
\item \textbf{B} The second row of both inputs.
\item \textbf{C} Only the diagonal of each input.
\end{itemize}
