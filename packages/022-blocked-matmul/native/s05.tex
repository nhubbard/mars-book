\section{Step 5 Guard empty scalar output and start row zero}\label{matmul-s05}

Test the two output dimensions before any matrix operation. A zero row or column count means there are no destination cells. K may still be nonzero, but that does not authorize an input load. For a nonempty output, initialize the row index \texttt{t0} to zero. Keep the descriptor loads and frame supplied by the starter.
