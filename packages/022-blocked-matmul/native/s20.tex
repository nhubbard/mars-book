\section{Step 20 Select the tiled function without changing the contract}\label{matmul-s20}

Use the tiled input recipes to select method one in a separate observation file. Keep the cumulative source method word at its default zero so prepare.py can apply either method reproducibly. Function grading can invoke either entry directly; the selector is a convenience for the program caller. Keep the baseline as a checked comparison. Both functions take the same pointer descriptor and return the same cell count.

\subsection{Expected observation}
Switching the selector changes which function runs; it does not change the matrix representation.
