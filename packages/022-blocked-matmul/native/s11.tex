\section{Step 11 Load one signed left value}\label{matmul-s11}

At \texttt{naive\_dot}, use \texttt{lw} to load the signed word through \texttt{t4}. The input domain is signed sixteen-bit, but each stored element occupies a complete word. The load sign-extends that stored signed value into the full register. Keep the right operand separate in the next edit.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the temporary branch and nop in \texttt{n\_load\_left}. Keep its surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lw $t7, 0($t4)
\end{minted}
Use \texttt{s11-1}, \texttt{s11-2} from the companion construction inputs. Pause at \texttt{matmul\_done} before the caller stores the returned count.

\subsection{Expected observation}
The default first left operand is 1. A minimum operand remains -32768 in the full register.

\subsection{Check your understanding}
How should stored -32768 be interpreted?

\begin{itemize}

\item \textbf{B} As the address -32768.
\item \textbf{C} As signed -32768.
\end{itemize}
