# Give each index one job

An output row chooses a left row, an output column chooses a right column, and k selects matching reduction positions. For A=[[1,2,3],[4,5,6]] and B=[[7,8],[9,10],[11,12]], the result is [[58,64],[139,154]]. Rectangular shapes expose swapped strides.

The full directly edited composition is in `native/product.tex`.
