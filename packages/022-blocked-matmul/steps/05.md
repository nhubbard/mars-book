# Guard empty scalar output and start row zero

Test the two output dimensions before any matrix operation. A zero row or column count means there are no destination cells. K may still be nonzero, but that does not authorize an input load. For a nonempty output, initialize the row index `t0` to zero. Keep the descriptor loads and frame supplied by the starter.

## Write and inspect

Replace the temporary branch and nop in `n_empty`. Keep surrounding labels and region markers.

```asm
    beq $s0, $zero, naive_return
    nop
    beq $s2, $zero, naive_return
    nop
    move $t0, $zero
```

Use the `s05-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

Default construction returns with `t0`=0 and unchanged output. Empty M or N performs no matrix access.
