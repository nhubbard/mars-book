# Return a zero reduction or start the first row tile

After zeroing, return immediately when K is zero. For a nonzero reduction, initialize the row-tile start `s7` to zero. This start is private working state and will be restored to the caller value by the supplied exit; do not confuse the returned saved register with the internal tile start.

## Write and inspect

Replace the temporary branch and nop in `t_reduction_gate`. Keep surrounding labels and region markers.

```asm
    beq $s1, $zero, tiled_return
    nop
    move $s7, $zero
```

Use the `s25-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

K=0 produces a complete zero matrix without either input read.
