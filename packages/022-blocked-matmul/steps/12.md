# Load the matching signed right value

Load the right word through `t5` into `t8`. Both walkers refer to the same reduction position: one row value in A and one column value in B. Do not advance either walker between these two loads. The multiplication that follows consumes this pair.

## Write and inspect

Replace the temporary branch and nop in `n_load_right`. Keep surrounding labels and region markers.

```asm
    lw $t8, 0($t5)
```

Use the `s12-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

For the first default pair, `t7`=1 and `t8`=7.

## Check your understanding

Which pair belongs to reduction position zero?

- **A** A[0,0] and B[0,0] for the first output.
- **B** A[0,0] and B[1,0].
- **C** A[0,1] and B[0,0].
