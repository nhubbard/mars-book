# Clip the reduction-tile exclusive end

At `block_reduction`, form L+T in `a2` and clip it against K. This endpoint controls the number of products contributed in the current tile. A complete last tile is allowed; a shorter last tile must stop before reading an absent input pair.

## Write and inspect

Replace the temporary branch and nop in `t_reduction_bound`. Keep surrounding labels and region markers.

```asm
    addu $a2, $t0, $s3
    sltu $t9, $s1, $a2
    beq $t9, $zero, reduction_bound
    nop
    move $a2, $s1
```

Use the `s30-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

The first default reduction tile ends at two. For K=1,T=3, `a2` clips to one.
