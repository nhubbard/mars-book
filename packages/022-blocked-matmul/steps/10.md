# Skip the scalar reduction when K is zero

Test K before entering `naive_dot`. A zero reduction has a valid zero sum and still needs output stores for every selected cell. Branch to `naive_store`, retaining the cleared accumulator. The input walkers may have been computed, but computing an address is not a memory access.

## Write and inspect

Replace the temporary branch and nop in `n_zero_k`. Keep surrounding labels and region markers.

```asm
    beq $s1, $zero, naive_store
    nop
```

Use the `s10-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

With K=0, the provisional sum is zero and neither matrix is read.
