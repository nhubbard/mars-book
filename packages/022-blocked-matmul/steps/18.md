# Advance the scalar column and restart its reduction

Increment `t1` and branch to `naive_column` while another column remains. That target resets both the reduction index and the accumulator, then reconstructs both input walkers for the new column. A completed row ends with `t1`=N.

## Write and inspect

Replace the temporary branch and nop in `n_next_column`. Keep surrounding labels and region markers.

```asm
    addiu $t1, $t1, 1
    bne $t1, $s2, naive_column
    nop
```

Use the `s18-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

The first default output row is now 58,64; the second row is still sentinel.
