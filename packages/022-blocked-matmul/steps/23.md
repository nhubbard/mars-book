# Initialize one full output cell

At `zero_product`, write a doubleword zero. This establishes the first partial sum without reading the previous output. The next edit will repeat it for every selected cell. All eight bytes matter because a later `ld` consumes the full partial sum.

## Write and inspect

Replace the temporary branch and nop in `t_zero_store`. Keep surrounding labels and region markers.

```asm
    sd $zero, 0($t1)
```

Use the `s23-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

Only the first default output cell is zero; the rest remain sentinel.
