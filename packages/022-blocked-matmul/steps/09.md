# Form the right-column address and row stride

The first pair in column j is B[0,j], so multiply `t1` by four and add it to the right base. Keep the resulting walker in `t5`. Compute 4N in `t6` once for this dot product; that stride moves from one right-input row to the next without changing the selected column.

## Write and inspect

Replace the temporary branch and nop in `n_right`. Keep surrounding labels and region markers.

```asm
    dsll $t5, $t1, 2
    daddu $t5, $s5, $t5
    dsll $t6, $s2, 2
```

Use the `s09-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

The first right walker addresses right[0], and `t6` is eight bytes for N=2.
