# Form the full left-row address

Multiply the row index by K to count left-input elements before this row, then multiply that offset by four. Add the byte offset to the full base with `daddu`. The bounded index arithmetic does not permit narrowing the base pointer. Retain this walker in `t4`.

## Write and inspect

Replace the temporary branch and nop in `n_left`. Keep surrounding labels and region markers.

```asm
    mul $t4, $t0, $s1
    dsll $t4, $t4, 2
    daddu $t4, $s4, $t4
```

Use the `s08-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

For the first output, `t4` addresses the first left element.
