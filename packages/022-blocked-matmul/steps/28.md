# Clip the column-tile exclusive end

At `block_column`, form J+T in `a1` and clip it against N. The output and right input share this column bound. Their element widths differ, but neither width changes the index comparison. Keep the full output pointer in `s6`.

## Write and inspect

Replace the temporary branch and nop in `t_column_bound`. Keep surrounding labels and region markers.

```asm
    addu $a1, $fp, $s3
    sltu $t9, $s2, $a1
    beq $t9, $zero, column_bound
    nop
    move $a1, $s2
```

Use the `s28-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

For N=2,T=2, `a1`=2. A single-column matrix clips to one even when T=3.
