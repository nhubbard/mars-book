# Inspect the supplied frame and safe exits

The starter supplies both function frames and exits. Each frame saves all nine required full registers, retains the three input pointers, and loads M, K, N and T into working registers. An unfinished region branches to its own restoring exit. These exits calculate the cell count, restore caller registers and return through `ra`. Select the scalar path first; a provisional return is evidence about construction, not a completed matrix product.

## Expected observation

The untouched starter returns four for the default shape while leaving the output sentinel unchanged.
