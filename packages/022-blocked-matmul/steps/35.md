# Address the left input at the reduction-tile start

Compute i*K+L, scale by four, and add the A base. This walker begins at the current reduction tile rather than at zero. It must be reconstructed for every output cell because the previous dot segment advanced its own walker.

## Write and inspect

Replace the temporary branch and nop in `t_left_address`. Keep surrounding labels and region markers.

```asm
    mul $t5, $t1, $s1
    addu $t5, $t5, $t0
    dsll $t5, $t5, 2
    daddu $t5, $s4, $t5
```

Use the `s35-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

For the first default reduction tile, `t5` addresses the first left word.
