# Count the product cells to initialize

Compute M*N in `t0` and copy the full output base to `t1`. This count is a number of doublewords, not bytes. The output pointer will advance by eight for each zeroed cell. Prior output contents may come from another call and cannot serve as initial sums.

## Write and inspect

Replace the temporary branch and nop in `t_zero_setup`. Keep surrounding labels and region markers.

```asm
    mul $t0, $s0, $s2
    move $t1, $s6
```

Use the `s22-*` recipes with your cumulative source. Pause at `matmul_done` before the caller stores the count.

## Expected observation

The default zeroing count is four and `t1` addresses the supplied product.
