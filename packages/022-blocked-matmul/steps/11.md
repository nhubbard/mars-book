# Load one signed left value

At `naive_dot`, use `lw` to load the signed word through `t4`. The input domain is signed sixteen-bit, but each stored element occupies a complete word. The load sign-extends that stored signed value into the full register. Keep the right operand separate in the next edit.

## Write and inspect
