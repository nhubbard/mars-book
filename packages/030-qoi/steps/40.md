# Read a cache candidate without replacing it yet

Author e_hash to calculate the current pixel’s weighted slot, form its entry address in t8 and load the old cached word into t9. Do not store the new pixel before comparing it with the old entry. Doing so would make every lookup appear to match, including colors the decoder has never cached.

Observe: For the first opaque-black pixel, t8 selects slot fifty-three and t9 is still transparent black.

Use observation s40-1. Native prose and typeset quizzes are in native/s40.tex.

Check: Why must the old cache word be read before replacement?

**A** It determines the image width.
**B** It is the next input pixel.
**C** It determines whether INDEX is valid.

Hint 1: Hash equality is weaker than complete pixel equality.
Hint 2: Retain the entry address and its previous word so the later comparison can inspect all four components.
