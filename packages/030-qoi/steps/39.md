# Load one complete input word

Author e_pixel to load the current four-byte pixel with a consistent unsigned word representation, advance the input pointer by four and reduce the remaining pixel count. The count now describes pixels after the one currently held in t0. Do not advance the output yet: repeat, cache and difference decisions determine how many bytes this pixel will need.

Observe: t0 is opaque black, the input cursor advanced four bytes and seven pixels remain after the loaded pixel.

Use observation s39-1. Native prose and typeset quizzes are in native/s39.tex.

Check: What does the reduced remaining count exclude?

**A** The pixel already loaded into t0.
**B** Only pixels that have explicit RGBA chunks.
**C** The header and marker.

Hint 1: Loading a pixel and emitting its representation are separate events.
Hint 2: Use a four-byte word load, full-width pointer increment and one-pixel count decrement.
