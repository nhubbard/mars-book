# Form signed representatives of byte differences

Author e_delta to compute red, green and blue changes from the predictor, reducing each to a signed representative in minus 128 through 127. The red change from zero to 255 can then be minus one. Keep these numerical changes in t1, t2 and t3 for the range tests; they are not already biased fields.

Observe: The first red pixel’s changes are minus one, zero and zero. No color command has been written for it yet.

Use observation s47-1. Native prose and typeset quizzes are in native/s47.tex.

Check: Why is minus one useful for zero-to 255 red?

**A** It changes the byte order.
**B** It describes the same modulo 256 change in a smaller field.
**C** It instructs the decoder to clamp red.

Hint 1: QOI additions wrap independently within each channel.
Hint 2: Normalize each difference modulo 256 into a signed-byte range before testing DIFF or LUMA.
