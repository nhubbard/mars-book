# Insert the reconstructed color into its cache slot

Author w_hash to extract the previous color’s four components, form their weighted sum and select the low six bits. Convert that slot to a byte offset only when addressing its four-byte entry. Store the complete RGBA word. This common stage must run for repeated pixels too, so the first opaque-black run establishes a cache value that did not exist initially.

Observe: Cache slot fifty-three contains opaque black. The other entries remain transparent black; the caller’s metadata and framebuffer are untouched.
