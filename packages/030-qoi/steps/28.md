# Validate through a private decoder descriptor

Author d_call to retain the four decoder arguments and call qoi_validate with private metadata at frame offset eighty. The supplied nonzero-status guard propagates both completed errors and development status. Reading private dimensions before a successful return would use an unaccepted header. The output framebuffer remains untouched during this call.

Observe: The private descriptor is valid, v0 is zero and v1 is eight. The public framebuffer remains sentinels.

Use observation s28-1. Native prose and typeset quizzes are in native/s28.tex.
