# Validate before truncating an existing file

Author sv_validate to retain path, bytes and selected count and call qoi_validate into private metadata at frame offset eighty. The supplied status guard returns on any nonzero result before open. Validation needs no caller metadata publication here. A malformed stream must leave an existing destination intact rather than opening first and discovering the error afterward.

Observe: Validation succeeds in private metadata while the output file still contains its old bytes. No writable descriptor has been opened.

Use observation s60-1. Native prose and typeset quizzes are in native/s60.tex.
