# Retain encoder metadata and locate its private cache

Author e_state to retain the four accepted fields in private frame words and set the cache base to frame offset 112. Initialize the clear-loop pointer and store count without advancing that retained base. Keeping header fields private lets later work use temporary registers without losing the values that must be serialized in the header.

Observe: The private fields remain eight, one, four and zero; the clear pointer names the start of a256-byte cache.
