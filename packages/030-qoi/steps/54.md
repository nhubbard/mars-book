# Bound a file buffer before opening its path

Author l_bound to accept unsigned byte capacities from one through 20502. A zero, over-limit or high-bit capacity returns status two before pointer access or a file operation. The supplied frame is entered only after this guard. The buffer’s capacity concerns complete input bytes, not pixel count or private marker storage.

Observe: The prepared capacity reaches the checkpoint without reading a path or opening a descriptor.

Use observation s54-1. Native prose and typeset quizzes are in native/s54.tex.

Check: Which capacity is valid for the loader?

**A** Thirty-eight bytes for this thirty-eight-byte file.
**B** Zero bytes because EOF can be probed privately.
**C** An unsigned value above 20502.

Hint 1: The private EOF probe does not enlarge the caller’s declared buffer.
Hint 2: Reject zero and unsigned values above 20502 before the supplied load frame.
