# Validate the encoder descriptor before pixels

Author e_descriptor to load four unsigned words from the descriptor and validate dimensions, channels and colorspace. The supplied frame retains the pixel pointer and destination cursor. Do not read the pixel pointer or store a header while checking these fields. A bad descriptor takes the supplied status-one path even if its byte capacity is also too small.

Observe: The accepted fields are eight, one, four and zero in t4..t7. Both caller pixel input and destination remain unchanged.

Use observation s33-1. Native prose and typeset quizzes are in native/s33.tex.

Check: Which error takes priority over capacity?

**A** An invalid descriptor field.
**B** The first pixel’s color.
**C** A pending run of zero.

Hint 1: The descriptor defines what input pixels and output header would mean.
Hint 2: Validate widths/heights in 1..64, channels in 3..4 and colorspace in 0..1 before using pixel data.
