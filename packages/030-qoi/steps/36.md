# Clear the encoder cache for this invocation

Author e_clear to zero every private cache entry while retaining the accepted header values. A stale word that happens to equal the first input pixel could otherwise cause an INDEX whose decoder entry is still empty. This requirement is about the meaning of emitted bytes, not just tidying memory. The cache must be ready before any pixel lookup.

Observe: The complete cache is zero. Header fields and the destination cursor retain their accepted values.

Use observation s36-1. Native prose and typeset quizzes are in native/s36.tex.

Check: What can an uncleared matching cache word cause?

**A** An INDEX that reconstructs the wrong pixel.
**B** A harmless extra header byte.
**C** Automatic initialization in every external decoder.

Hint 1: The decoder starts with a zero cache for every image.
Hint 2: Clear 256 bytes using a separate loop pointer; preserve t4..t7 for the header construction.
