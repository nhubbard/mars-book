# Return both decoder dimensions in full

Author d_return to read the accepted private dimensions and form height in the upper thirty-two bits and width in the lower thirty-two. Return that packed value with status zero through the supplied restore. A word-sized store in the caller’s result field would lose the height, so the supplied count/result slot is a doubleword.

Observe: v1 is 0x 0000000100000008, and all saved registers and the stack pointer are restored.

Use observation s31-1. Native prose and typeset quizzes are in native/s31.tex.

Check: What would truncating this result to a word lose?

**A** The low width bits only.
**B** The first pixel’s alpha.
**C** Height.

Hint 1: This result is a pair of dimensions, not a byte count.
Hint 2: Zero-extend width, shift height left by 32 and combine them before the full-width return.
