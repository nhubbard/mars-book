# Validate flags and retain private metadata

Author w_flags to accept channels three or four and colorspace zero or one. Store the four accepted numerical fields in the private descriptor at frame offsets eighty-eight through one hundred. Each occupies a word. These are preliminary values for the current invocation; publishing them to the caller now would falsely certify a stream whose commands have not been checked.

Observe: The private descriptor contains eight, one, four and zero. The caller’s metadata remains its original sentinel bytes.

Use observation s08-1. Native prose and typeset quizzes are in native/s08.tex.

Check: Where should these accepted header fields go first?
