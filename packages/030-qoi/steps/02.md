# Separate the two packed dimensions

Author b_unpack to recover width from the low thirty-two bits of a0 and height from the high thirty-two. Retain both as unsigned numerical fields. An arithmetic right shift would copy a sign bit into the height result. A word-sized shift cannot preserve both halves of the original argument. Put width in t1 and height in t2 for the following bound checks.

Observe: For packed 0x0000000100000008, t1 is eight and t2 is one. No caller memory has been accessed.

Use observation s02-1. Native prose and typeset quizzes are in native/s02.tex.

Check: Which operation should recover the upper field?

**A** A word-sized left shift by thirty-two.
**B** A logical sixty-four-bit right shift by thirty-two.
**C** A signed byte load.

Hint 1: Both fields are unsigned even though the host register API represents raw bits as a signed Long.
Hint 2: Use full-width shifts; isolate the low half without retaining any original high bits.
