# Finish a working uniform-image subset

Author e_marker to append seven zero bytes and a final one after the last represented pixel. Return the byte cursor minus its original destination, not the conservative bound. This creates a complete one-pixel file even while other color paths remain unfinished. That limited success is useful evidence for framing and run handling, not proof that the entire encoder is complete.

Observe: The one-pixel black file has twenty-three bytes and status zero. The destination after the returned interval remains unchanged.
