# Close before validating loaded bytes

Author l_finish to close the input descriptor at EOF, validate the accepted bytes into caller metadata and return the loaded byte count only on success. The validator’s successful v1 is pixels, so replace it with the retained byte count for the loader interface. A nonzero validator result propagates after the file is already closed.

Observe: The loader returns status zero and thirty-eight bytes. Metadata contains 8,1,4,0 and no fixture descriptor remains open.

Use observation s58-1. Native prose and typeset quizzes are in native/s58.tex.

Check: Why replace the validator’s successful count?

**A** The open call returned an unreliable descriptor.
**B** The decoder has already produced the framebuffer.
**C** The loader returns bytes, while validation returns pixels.

Hint 1: Nested interfaces can use the same return register for different units.
Hint 2: Close first, call validation with s4 accepted bytes and return s4 after a zero status.
