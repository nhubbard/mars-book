# Assemble and bound big-endian dimensions

Author w_dimensions to combine bytes four through seven into width and bytes eight through eleven into height. Shift the first byte of each field by twenty-four bits, the next by sixteen and the next by eight before combining the final byte. Validate both fields in the local one-through-sixty-four domain. Retain accepted width in t4 and height in t5.

Observe: The numerical fields are eight and one. The input cursor has not yet become a command cursor.

Use observation s07-1. Native prose and typeset quizzes are in native/s07.tex.

Check: What would a little-endian native load of 00 00 00 08 produce?

**A** Eight.
**B** The address of the first pixel.
**C** 0x08000000.

Hint 1: Byte order belongs to the file field, not to the simulator’s configured word storage.
Hint 2: Use unsigned loads and explicitly positioned shifts, then apply the dimension checks before multiplication.
