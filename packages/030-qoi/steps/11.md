# Load one bounded tag

Author w_next to distinguish completion from another command. If no pixels remain, transfer to the marker stage. Otherwise require the command cursor to be before the payload end, load one unsigned tag and advance the cursor by one. A missing command must become a format error rather than borrowing a byte from the reserved marker.

Observe: The first tag is c0 in t0. The cursor is at offset fifteen and eight pixels remain.

Use observation s11-1. Native prose and typeset quizzes are in native/s11.tex.

Check: What proves that a tag byte is available?

**A** The remaining output capacity is nonzero.
**B** The cursor is strictly before the payload end.
**C** The arena has mapped padding.

Hint 1: The logical payload limit excludes all eight marker bytes.
Hint 2: Test remaining pixels first, then compare the full-width cursor with the payload end before loading.
