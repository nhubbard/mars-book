# Return a conservative byte bound

Author b_size to form n = width times height, multiply n by five and add twenty-two. That total accounts for the fixed header and marker plus a worst-case RGBA chunk for every pixel. Return status zero and the complete bound in v1 through the supplied return. This helper neither reads pixel data nor predicts how well a particular image compresses.

Observe: The eight-pixel bound is sixty-two bytes. All saved registers and the stack pointer retain their incoming values.

Use observation s04-1. Native prose and typeset quizzes are in native/s04.tex.

Check: What does the returned sixty-two describe?

**A** The actual worked file length.
**B** The decoded framebuffer byte count.
**C** Required conservative capacity.

Hint 1: Count fixed framing and per-pixel maximum separately.
Hint 2: Five times eight plus twenty-two is sixty-two; keep the result in a full-width register.
