# Flush the biased run field

Use the one-pixel opaque-black recipe so the first loaded pixel is also the last. Author e_flush to encode pending count minus one under the RUN class bits, write one byte and clear the pending count. Advancing the output by one is independent of how many pixels the tag describes. The common per-pixel finish remains unfinished for now.

Observe: The header is followed by c0, s2 points to offset fifteen and pending count is zero. The temporary function result is still development status four.
