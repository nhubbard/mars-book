# Emit a fitting DIFF command

Author e_diff to test whether all three changes fit minus two through plus one. Add two only when constructing the unsigned fields, position them and combine the class bits. The worked red pixel fits with fields 01,10,10 and emits 5a. A non-fitting triple must continue to LUMA rather than truncating fields that cannot represent it.

Observe: The prefix is the fourteen-byte header followed by c0 and 5a. The output cursor is sixteen.

Use observation s48-1. Native prose and typeset quizzes are in native/s48.tex.

Check: What happens to a change of plus two?

**A** It fails the DIFF range test.
**B** It is stored as field 00.
**C** It is always clamped to plus one.

Hint 1: A field must be proven representable before masking or placement.
Hint 2: Test each change plus two as unsigned less-than four; then place the three two-bit fields.
