# Accumulate a run until a flush is required

Author e_run to increment the pending count. Flush when it reaches sixty-two or when the loaded pixel was the last one. Otherwise retain it and proceed to the common per-pixel finish. The first black pixel leaves one pending repetition because seven later pixels remain. No run tag has to be written at that point.

Observe: The pending count is one and the byte cursor remains at the end of the header.

Use observation s42-1. Native prose and typeset quizzes are in native/s42.tex.

Check: When must a pending run be emitted?

**A** At length sixty-two or the final pixel.
**B** Only when the entire input is black.
**C** After every accepted repeated pixel.

Hint 1: The format limits one run chunk to sixty-two pixels.
Hint 2: Check both the pending count and the already reduced remaining-pixel count.
