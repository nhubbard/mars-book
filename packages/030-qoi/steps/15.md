# Make public stores conditional on publication mode

Author w_emit to store the current word and advance the output pointer only when the supplied publication flag is enabled. In this validation call fp is zero, so no caller pixel is written. Both branches must reach the supplied checkpoint and remaining-count stage. The same code will later serve the decoder’s accepted second pass without changing its cursor units.

Observe: The validation-mode output pointer has not advanced and the framebuffer remains sentinels. The accepted repetition still needs to reduce the remaining count.
