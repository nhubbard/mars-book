# Initialize a predictor and an empty pending run

Author e_previous to establish the encoder’s initial opaque-black predictor and zero pending repetitions. Keep that predictor numerically consistent with the unsigned words loaded from the input. The first pixel of the worked image is already opaque black, so the earliest compressed command can be a run rather than an explicit color.

Observe: The predictor is 0xff 000000 and the pending-run count is zero. The destination still contains only the header.

Use observation s38-1. Native prose and typeset quizzes are in native/s38.tex.
