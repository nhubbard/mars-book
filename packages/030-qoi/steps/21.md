# Apply three biased two-bit changes

Author w_diff to split the tag’s three fields, subtract two from each and add them to the previous components. Mask each updated component to eight bits before packing. For tag 7f after opaque black, every stored field is three, so each actual change is plus one. Alpha is retained, and this command has no payload bytes after its tag.

Observe: The unpacked components are one, one, one and 255. The input cursor is twenty-two.

Use observation s21-1. Native prose and typeset quizzes are in native/s21.tex.

Check: What operation follows each component addition?

**A** Reduction modulo 256.
**B** Saturation to the range 0..255.
**C** Multiplication by alpha.

Hint 1: QOI changes wrap; they do not clamp.
Hint 2: Extract fields at shifts 4,2 and 0, subtract the bias and mask the resulting components with 255.
