# Inspect stored alpha separately from displayed RGB

Inspect the completed framebuffer and its little-endian bytes before changing the encoder. The seventh pixel has numerical word 0x 80070605 and stored bytes 05 06 07 80. The final pixel is 0xff 010101. Connect this buffer to the RGB display when the capture runner is available, but use the stored high bytes to establish alpha correctness; the current display does not blend them.

Observe: The penultimate alpha is 128 and the final alpha is 255. Both can be established from memory even when their RGB display appearance is similar.

Use observation s32-1. Native prose and typeset quizzes are in native/s32.tex.
