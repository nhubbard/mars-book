# Probe EOF outside an exactly full caller buffer

Use capacity thirty-eight to make the worked file fill the caller buffer exactly. Author l_probe to request one more byte into the supplied private probe at frame offset 96. Zero confirms EOF; a positive result means excess input and status two; a negative result is an I/O error. None of these results authorizes a thirty-ninth caller-buffer store.

Observe: The exact file reaches load_eof after a zero-byte probe. The caller buffer has thirty-eight bytes, metadata is untouched and the descriptor is still live.
