# Separate repetition from a new-color decision

Author e_repeat to route a pixel equal to the predictor to run accumulation. For a different pixel, emit any already pending run before making the new color’s cache decision. The first worked pixel takes the repeated-color branch immediately. Its cache candidate differs from it because a newly initialized cache contains transparent black, but repetition depends on the predictor instead.

Observe: Execution reaches encode_run with current and previous opaque black, seven later pixels and no emitted payload byte.

Use observation s41-1. Native prose and typeset quizzes are in native/s41.tex.
