\section{Vary one state transition at a time}
\begin{MARSExercise}{Replace a cache entry}
Find a second RGBA color that hashes to the same slot as opaque red. Construct a legal
stream that emits red, emits the colliding color, then fetches that slot. Predict the
third pixel and explain why an encoder cannot use the old red value without first
reestablishing it. Confirm the prediction with exact component bytes.
\end{MARSExercise}

\begin{MARSExercise}{Cross a row with a run}
Make a small rectangular image whose first run ends in the middle of its second row.
Trace the input offset and output address before and after that run. Then lengthen the
run to exceed the total image by one pixel. State which caller objects must remain
unchanged when the completed decoder rejects it.
\end{MARSExercise}

\begin{MARSExercise}{Preserve an invisible difference}
Give two pixels identical RGB values and different alpha values. Decode, display and
encode them. Explain which observations can establish alpha preservation and why the
RGB display alone cannot establish it. Repeat with colorspace one and inspect the
encoder's descriptive header field as well as its samples.
\end{MARSExercise}

\begin{MARSExercise}{Accept another valid encoding}
Replace one explicit RGB or RGBA command with another legal sequence that produces the
same pixel values. Check both files independently. Compare their lengths without
requiring equal bytes. Then test the uniform-image size promise separately, so accepting
equivalent encodings does not remove the run-compression objective.
\end{MARSExercise}
