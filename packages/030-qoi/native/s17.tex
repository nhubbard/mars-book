\section{Step 17 Observe the first run before adding RGB}\label{qoi-s17}
Run the current validator to \texttt{walk\_rgb}. The shared stages now accept the first run and fetch the following RGB tag, but its body is unfinished. Inspect the cache and predictor before implementing that handler. A later index fetch of slot fifty-three must recover opaque black, not the transparent black that occupied every slot before the first command.

Use \texttt{s17-1} for this observation.

\paragraph{Observe} At \texttt{walk\_rgb}, the command cursor is at offset sixteen, seven pixels remain and slot fifty-three is opaque black.

\paragraph{Check} Why does slot fifty-three now differ from its initial value?
\begin{itemize}
\item[A.] The RGB handler has already changed it.
\item[B.] The first reconstructed run pixel was inserted.
\item[C.] Every cache entry was initialized opaque.
\end{itemize}
