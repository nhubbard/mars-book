\section{Step 6 Check every magic byte}\label{qoi-s06}
Author \texttt{w\_magic} in the shared walker. Compare four unsigned source bytes with the ASCII codes for qoif, branching to the supplied walker error path on any mismatch. Do not use a native word comparison that silently assumes a byte order. The walker has saved the metadata destination and its publication flag, but it has not accepted dimensions yet.

Work in \texttt{w\_magic}; use \texttt{s06-1} and stop at \texttt{after\_w\_magic}.

\paragraph{Observe} The four literal comparisons pass for the fixture. No public metadata or pixel byte has changed.

\paragraph{Check} Why use byte comparisons here?
\begin{itemize}
  \item[A.] The file’s literal byte order stays explicit.
  \item[B.] The magic has a signed numerical meaning.
  \item[C.] A byte pointer must be four-byte aligned.
\end{itemize}
