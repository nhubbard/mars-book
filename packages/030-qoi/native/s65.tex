\section{Step 65 Reuse the pipeline for the earlier sprite}\label{qoi-s65}
Prepare the sprite fixture and repeat the complete pipeline. The image is now eight by eight, so decoded word memory spans 256 bytes and the metadata height must change. Compare the reconstructed cells with the original eight row bytes from chapter three, not with an image generated by the candidate encoder. Exact samples establish orientation and component order independently of a recognizable display.

Use \texttt{s65-1} for this observation.

\paragraph{Observe} The valid sprite file occupies sixty-one bytes, the framebuffer contains sixty-four opaque pixels and metadata describes 8,8,4,0.

\paragraph{Check} What supplies an independent expected sprite image?
\begin{itemize}
\item[A.] The previous eight-pixel trace’s dimensions.
\item[B.] The original eight row-byte decisions.
\item[C.] The candidate encoder’s own output alone.
\end{itemize}
