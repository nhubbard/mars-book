\section{Step 64 Connect loading, reconstruction, encoding and saving}\label{qoi-s64}
Select the connected caller and run to \texttt{results\_ready}. It loads the original thirty-eight-byte file, decodes eight words, passes accepted metadata to the encoder and saves the encoder’s returned byte count. Check each boundary independently as well as the final round trip. The compact output must preserve header flags and alpha even though its bytes differ from the input.

Use \texttt{s64-1} for this observation.

\paragraph{Observe} The caller returns status zero and thirty-five saved bytes, with eight correct framebuffer words and no open descriptors.

\paragraph{Check} Which length should the caller pass from encoder to saver?
\begin{itemize}
\item[A.] The original loaded length.
\item[B.] The conservative capacity bound.
\item[C.] The encoder’s complete returned byte count.
\end{itemize}
