\section{Step 12 Dispatch full-byte tags before classes}\label{qoi-s12}
Author \texttt{w\_dispatch} to recognize fe and ff before inspecting the high two tag bits. The other classes select index, difference, luma or run handling. Retain the previous-index marker only for an INDEX comparison; any other chunk ends adjacency with an earlier INDEX. For c0, the selected path reaches the run handler without loading another source byte.

Work in \texttt{w\_dispatch}; use \texttt{s12-1} and stop at \texttt{after\_w\_dispatch}.

\paragraph{Observe} The first tag selects RUN. Previous color is still opaque black; the source cursor remains at offset fifteen.

\paragraph{Check} What goes wrong if fe is first treated as class 11?
\begin{itemize}
  \item[A.] It is mistaken for a run of sixty-three pixels.
  \item[B.] It becomes a one-byte RGB command.
  \item[C.] It automatically supplies opaque alpha.
\end{itemize}
