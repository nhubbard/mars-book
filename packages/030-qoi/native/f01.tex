    \begin{enumerate}
      \setlength{\itemsep}{0pt}
            \setlength{\parsep}{0pt}
      \item At \texttt{validate\_return}, validation has returned. The selected caller branch and saved-result stores have not executed.
      \item \texttt{v0 = 0} reports success. \texttt{v1 = 8} counts pixels, eight times one; it is neither a byte length nor packed dimensions.
      \item The descriptor stores width eight, height one, channels four and colorspace zero as four four-byte little-endian fields.
      \item The source begins ASCII \texttt{qoif} and uses big-endian dimensions. Its thirty-eight logical bytes end with the eight-byte marker; the later \texttt{a5} suffix is outside the file.
      \item The untouched framebuffer contains \texttt{a5}. Validation checked the complete chunk stream without publishing decoded pixel words.
      \item Both saved result fields remain $-1$; the caller has not yet stored pixel count eight.
    \end{enumerate}
