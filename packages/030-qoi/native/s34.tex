\section{Step 34 Preflight the conservative encoder capacity}\label{qoi-s34}
Author \texttt{e\_capacity} to calculate the accepted pixel count and the bound twenty-two plus five times that count. Compare this bound with unsigned \texttt{a3} before reading any pixel or writing the destination. A capacity below the bound returns status two even if a particular encoding could fit. Keep the remaining pixel count independently of the byte cursor.

Work in \texttt{e\_capacity}; use \texttt{s34-1} and stop at \texttt{after\_e\_capacity}.

\paragraph{Observe} The eight-pixel bound is sixty-two; the prepared capacity accepts it. No header byte has been stored.

\paragraph{Check} Why can capacity thirty-five still be rejected for this image?
\begin{itemize}
  \item[A.] A QOI stream must have a multiple-of-four length.
  \item[B.] The encoder always writes sixty-two bytes.
  \item[C.] The interface requires the conservative sixty-two-byte bound.
\end{itemize}
