\section{Step 25 Require the exact eight-byte marker}\label{qoi-s25}
Author \texttt{w\_marker} to require that the command cursor equals the reserved payload end. Then compare seven zero bytes and the final one byte. Do not scan forward to find a plausible marker after unconsumed commands. A wrong byte or trailing payload must take the format-error path while caller metadata is still untouched.

Work in \texttt{w\_marker}; use \texttt{s25-1} and stop at \texttt{after\_w\_marker}.

\paragraph{Observe} Cursor thirty equals payload end thirty, and all eight marker bytes pass. Metadata publication is the next unfinished body.

\paragraph{Check} Why reject a cursor short of the payload end?
\begin{itemize}
  \item[A.] It necessarily identifies a smaller valid image.
  \item[B.] Zero bytes automatically terminate QOI data.
  \item[C.] It leaves unconsumed payload bytes.
\end{itemize}
