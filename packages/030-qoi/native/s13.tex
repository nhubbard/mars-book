\section{Step 13 Decode a run and prove its output extent}\label{qoi-s13}
Author \texttt{w\_run} to extract the low six bits, add one and compare that length with remaining pixels. The c0 command means one repetition of the current predictor. Keep the repetition count in \texttt{t3} for the common update loop. Branch to the supplied format return for an overlong run before any cache or output update for that command.

Work in \texttt{w\_run}; use \texttt{s13-1} and stop at \texttt{after\_w\_run}.

\paragraph{Observe} The first command has repetition count one, while eight output pixels remain. Its accepted color is still opaque black.

\paragraph{Check} Why add one to the stored field?
\begin{itemize}
\item[A.] Every run includes an extra marker pixel.
\item[B.] The cache uses one-based indices.
\item[C.] The field stores run length minus one.
\end{itemize}
