\section{Step 11 Load one bounded tag}\label{qoi-s11}
Author \texttt{w\_next} to distinguish completion from another command. If no pixels remain, transfer to the marker stage. Otherwise require the command cursor to be before the payload end, load one unsigned tag and advance the cursor by one. A missing command must become a format error rather than borrowing a byte from the reserved marker.

Work in \texttt{w\_next}; use \texttt{s11-1} and stop at \texttt{after\_w\_next}.

\paragraph{Observe} The first tag is c0 in \texttt{t0}. The cursor is at offset fifteen and eight pixels remain.

\paragraph{Check} What proves that a tag byte is available?
\begin{itemize}
  \item[A.] The remaining output capacity is nonzero.
  \item[B.] The cursor is strictly before the payload end.
  \item[C.] The arena has mapped padding.
\end{itemize}
