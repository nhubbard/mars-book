\section{Step 55 Open input and retain the actual descriptor}\label{qoi-s55}
Author \texttt{l\_open} to retain the caller buffer, capacity and metadata destination, then open the supplied path for reading. Keep the actual nonnegative result in \texttt{s3} and initialize accepted bytes to zero. An open failure takes the supplied I/O-error return. The guided fixture deliberately returns descriptor nineteen, so a constant descriptor three will fail.

Work in \texttt{l\_open}; use \texttt{s55-1} and stop at \texttt{after\_l\_open}.

\paragraph{Observe} At the checkpoint \texttt{s3} is nineteen and \texttt{s4} is zero. The supplied development exit closes that live descriptor when the next body is unfinished.

\paragraph{Check} Which descriptor should the next read use?
\begin{itemize}
  \item[A.] Three by convention.
  \item[B.] The file byte count.
  \item[C.] The value returned by open.
\end{itemize}
