\section{Step 1 Locate the first command before running it}\label{qoi-s01}
The source arena contains the thirty-eight-byte worked file. Inspect its first fourteen bytes before changing a routine. Read the width as four big-endian bytes, then locate the first command at offset fourteen. The initial caller selects the bound helper, so its first argument is packed dimensions rather than a pointer to this arena. Keep the file description and the current call arguments distinct.

Use \texttt{s01-1} for this observation.

\paragraph{Observe} The source begins with qoif, width eight, height one, channels four and colorspace zero. Byte fourteen is c0. The caller has not executed a QOI routine yet.

\paragraph{Check} What does the first bound call receive?
\begin{itemize}
\item[A.] The address of the first command.
\item[B.] An already decoded color.
\item[C.] Packed dimensions.
\end{itemize}
