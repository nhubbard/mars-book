\section{Step 4 Return a conservative byte bound}\label{qoi-s04}
Author \texttt{b\_size} to form n = width times height, multiply n by five and add twenty-two. That total accounts for the fixed header and marker plus a worst-case RGBA chunk for every pixel. Return status zero and the complete bound in \texttt{v1} through the supplied return. This helper neither reads pixel data nor predicts how well a particular image compresses.

Work in \texttt{b\_size}; use \texttt{s04-1} and stop at \texttt{function\_return}.

\paragraph{Observe} The eight-pixel bound is sixty-two bytes. All saved registers and the stack pointer retain their incoming values.

\paragraph{Check} What does the returned sixty-two describe?
\begin{itemize}
  \item[A.] The actual worked file length.
  \item[B.] The decoded framebuffer byte count.
  \item[C.] Required conservative capacity.
\end{itemize}
