\section{Step 47 Form signed representatives of byte differences}\label{qoi-s47}
Author \texttt{e\_delta} to compute red, green and blue changes from the predictor, reducing each to a signed representative in minus 128 through 127. The red change from zero to 255 can then be minus one. Keep these numerical changes in \texttt{t1}, \texttt{t2} and \texttt{t3} for the range tests; they are not already biased fields.

Work in \texttt{e\_delta}; use \texttt{s47-1} and stop at \texttt{after\_e\_delta}.

\paragraph{Observe} The first red pixel’s changes are minus one, zero and zero. No color command has been written for it yet.

\paragraph{Check} Why is minus one useful for zero-to 255 red?
\begin{itemize}
\item[A.] It changes the byte order.
\item[B.] It describes the same modulo 256 change in a smaller field.
\item[C.] It instructs the decoder to clamp red.
\end{itemize}
