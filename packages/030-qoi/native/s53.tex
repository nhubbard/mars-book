\section{Step 53 Verify an equivalent stream independently}\label{qoi-s53}
Compare the thirty-five-byte result with the thirty-eight-byte worked input by decoding both. The reference policy replaced explicit red with 5a, but the recovered pixels and flags must agree. Inspect the returned interval only; unused destination capacity is not part of the file. Repeat this check with another valid encoding rather than making byte identity an acceptance rule.

Use \texttt{s53-1} for this observation.

\paragraph{Observe} The two file lengths differ by three, but their decoded eight RGBA pixels and descriptive flags match.

\paragraph{Check} Which comparison is the completed encoder’s primary content check?
\begin{itemize}
\item[A.] Only a smaller file length.
\item[B.] Exact decoded pixels and metadata.
\item[C.] Identical bytes to the worked file.
\end{itemize}
