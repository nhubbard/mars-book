\section{Step 33 Validate the encoder descriptor before pixels}\label{qoi-s33}
Author \texttt{e\_descriptor} to load four unsigned words from the descriptor and validate dimensions, channels and colorspace. The supplied frame retains the pixel pointer and destination cursor. Do not read the pixel pointer or store a header while checking these fields. A bad descriptor takes the supplied status-one path even if its byte capacity is also too small.

Work in \texttt{e\_descriptor}; use \texttt{s33-1} and stop at \texttt{after\_e\_descriptor}.

\paragraph{Observe} The accepted fields are eight, one, four and zero in \texttt{t4}..\texttt{t7}. Both caller pixel input and destination remain unchanged.

\paragraph{Check} Which error takes priority over capacity?
\begin{itemize}
\item[A.] An invalid descriptor field.
\item[B.] The first pixel’s color.
\item[C.] A pending run of zero.
\end{itemize}
