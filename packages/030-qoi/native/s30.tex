\section{Step 30 Run the accepted publishing pass}\label{qoi-s30}
Author \texttt{d\_walk} to pass the retained bytes and count, private metadata destination and framebuffer pointer to the shared walker. Set its explicit publication flag to one. It resets reconstruction state for this second pass; it must not inherit the validator’s final predictor or cache. The supplied guard retains any nonzero return before the decoder constructs its own result.

Work in \texttt{d\_walk}; use \texttt{s30-1} and stop at \texttt{after\_d\_walk}.

\paragraph{Observe} Thirty-two framebuffer bytes contain the eight exact RGBA words. The walker returns eight pixels, but the decoder’s final result body is still unfinished.

\paragraph{Check} Which state must be reinitialized for the second pass?
\begin{itemize}
\item[A.] Predictor, cache and cursors.
\item[B.] Only the display’s repaint state.
\item[C.] Only the remaining output capacity.
\end{itemize}
