\section{Step 43 Flush the biased run field}\label{qoi-s43}
Use the one-pixel opaque-black recipe so the first loaded pixel is also the last. Author \texttt{e\_flush} to encode pending count minus one under the RUN class bits, write one byte and clear the pending count. Advancing the output by one is independent of how many pixels the tag describes. The common per-pixel finish remains unfinished for now.

Work in \texttt{e\_flush}; use \texttt{s43-1} and stop at \texttt{after\_e\_flush}.

\paragraph{Observe} The header is followed by c0, \texttt{s2} points to offset fifteen and pending count is zero. The temporary function result is still development status four.
