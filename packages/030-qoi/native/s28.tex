\section{Step 28 Validate through a private decoder descriptor}\label{qoi-s28}
Author \texttt{d\_call} to retain the four decoder arguments and call \texttt{qoi\_validate} with private metadata at frame offset eighty. The supplied nonzero-status guard propagates both completed errors and development status. Reading private dimensions before a successful return would use an unaccepted header. The output framebuffer remains untouched during this call.

Work in \texttt{d\_call}; use \texttt{s28-1} and stop at \texttt{after\_d\_call}.

\paragraph{Observe} The private descriptor is valid, \texttt{v0} is zero and \texttt{v1} is eight. The public framebuffer remains sentinels.

\paragraph{Check} Why pass a private metadata destination?
\begin{itemize}
  \item[A.] The validator requires a global scratch object.
  \item[B.] It changes the file’s channel count.
  \item[C.] The decoder has no public metadata output argument.
\end{itemize}
