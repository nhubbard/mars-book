Return to the eight-pixel recipe. Author \texttt{e\_lookup} to select INDEX for a complete cached-word match. Otherwise compare alpha with the predictor and route a changed alpha to RGBA. Only unchanged alpha reaches difference calculations. The first red pixel misses the cache and has unchanged alpha; the preceding pending black run has already been flushed.

Work in \texttt{e\_lookup}; use \texttt{s46-1} and stop at \texttt{after\_e\_lookup}.

\paragraph{Observe} The byte cursor is fifteen after the black run. Current red and previous black have equal alpha, and the old red-slot entry is not a match.
