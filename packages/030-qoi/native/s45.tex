\section{Step 45 Finish a working uniform-image subset}\label{qoi-s45}
Author \texttt{e\_marker} to append seven zero bytes and a final one after the last represented pixel. Return the byte cursor minus its original destination, not the conservative bound. This creates a complete one-pixel file even while other color paths remain unfinished. That limited success is useful evidence for framing and run handling, not proof that the entire encoder is complete.

Work in \texttt{e\_marker}; use \texttt{s45-1} and stop at \texttt{function\_return}.

\paragraph{Observe} The one-pixel black file has twenty-three bytes and status zero. The destination after the returned interval remains unchanged.

\paragraph{Check} Which length belongs in the successful return?
\begin{itemize}
  \item[A.] The actual emitted byte count.
  \item[B.] The conservative twenty-seven-byte capacity bound.
  \item[C.] One pixel.
\end{itemize}
