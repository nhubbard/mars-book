\section{Step 8 Validate flags and retain private metadata}\label{qoi-s08}
Author \texttt{w\_flags} to accept channels three or four and colorspace zero or one. Store the four accepted numerical fields in the private descriptor at frame offsets eighty-eight through one hundred. Each occupies a word. These are preliminary values for the current invocation; publishing them to the caller now would falsely certify a stream whose commands have not been checked.

Work in \texttt{w\_flags}; use \texttt{s08-1} and stop at \texttt{after\_w\_flags}.

\paragraph{Observe} The private descriptor contains eight, one, four and zero. The caller’s metadata remains its original sentinel bytes.

\paragraph{Check} Where should these accepted header fields go first?
\begin{itemize}
\item[A.] Into the first four framebuffer pixels.
\item[B.] Into the private descriptor.
\item[C.] Directly into caller metadata.
\end{itemize}
