\section{Step 23 Replace all four components for RGBA}\label{qoi-s23}
Author \texttt{w\_rgba} to require four payload bytes and load every component, including alpha, as an unsigned value. Advance across those four bytes before entering the packer. The worked command keeps RGB at seven, six and five while changing alpha to 128. The already implemented final INDEX then restores an earlier complete pixel, including its opaque alpha.

Work in \texttt{w\_rgba}; use \texttt{s23-1} and stop at \texttt{after\_w\_rgba}.

\paragraph{Observe} The loaded components are seven, six, five and 128. The cursor is twenty-nine before the final index tag.

\paragraph{Check} Which component is explicitly replaced here but retained by RGB?
\begin{itemize}
\item[A.] The dimensions.
\item[B.] Alpha.
\item[C.] Blue.
\end{itemize}
