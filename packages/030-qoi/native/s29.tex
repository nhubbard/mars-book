\section{Step 29 Compare capacity in pixels with unsigned arithmetic}\label{qoi-s29}
Author \texttt{d\_capacity} to compare the retained pixel capacity with the validated pixel count. A short capacity returns status two without a framebuffer store. This decision follows complete validation, so malformed input still takes priority. Treat capacity as a full unsigned value; a high-bit capacity is large, not negative.

Work in \texttt{d\_capacity}; use \texttt{s29-1} and stop at \texttt{after\_d\_capacity}.

\paragraph{Observe} Capacity 4096 accepts eight pixels. No framebuffer word has been stored yet.

\paragraph{Check} Which unit belongs in this comparison?
\begin{itemize}
\item[A.] Four-byte words plus header bytes.
\item[B.] Pixels.
\item[C.] Compressed bytes.
\end{itemize}
