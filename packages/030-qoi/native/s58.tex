\section{Step 58 Close before validating loaded bytes}\label{qoi-s58}
Author \texttt{l\_finish} to close the input descriptor at EOF, validate the accepted bytes into caller metadata and return the loaded byte count only on success. The validator’s successful \texttt{v1} is pixels, so replace it with the retained byte count for the loader interface. A nonzero validator result propagates after the file is already closed.

Work in \texttt{l\_finish}; use \texttt{s58-1} and stop at \texttt{function\_return}.

\paragraph{Observe} The loader returns status zero and thirty-eight bytes. Metadata contains 8,1,4,0 and no fixture descriptor remains open.

\paragraph{Check} Why replace the validator’s successful count?
\begin{itemize}
\item[A.] The open call returned an unreliable descriptor.
\item[B.] The decoder has already produced the framebuffer.
\item[C.] The loader returns bytes, while validation returns pixels.
\end{itemize}
