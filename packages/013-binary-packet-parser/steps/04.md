# Step 4: Check both magic bytes

Select the bad-magic status, load each identifier byte unsigned, and compare it with its constant. Either mismatch returns the same status. Keep the input address in a0; the small immediate offsets select bytes without moving it.

## Write or inspect

Append the following code in the `magic` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    li $v0, -2
    lbu $t7, 0($a0)
    li $t9, 0x4d
    bne $t7, $t9, packet_return
    nop
    lbu $t7, 1($a0)
    li $t9, 0x50
    bne $t7, $t9, packet_return
    nop
```

## Expected observation

With eight bytes available, changing either first byte reports -2. A short prefix still reports -1.
