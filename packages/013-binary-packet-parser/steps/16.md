# Step 16: Commit the decoded record

Mask the payload-only sum to its low byte and write the four accepted fields through a2. Every error branch bypasses these stores. The word-aligned output address is a caller guarantee, unlike the potentially unaligned input pointer.

## Write or inspect

Append the following code in the `commit` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    andi $t4, $t4, 255
    sw $t1, 0($a2)
    sw $t2, 4($a2)
    sw $t0, 8($a2)
    sw $t4, 12($a2)
```

## Expected observation

The default record becomes 1, 4660, 3, 254 at offsets zero, four, eight, and twelve.
