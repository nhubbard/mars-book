# Step 5: Require the supported version

Only after the identifier passes, test the version byte at offset two. This function supports version one. Returning a distinct error lets a caller distinguish recognizable data in an unsupported format from an unrelated identifier.

## Write or inspect

Append the following code in the `version` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    li $v0, -3
    lbu $t7, 2($a0)
    li $t9, 1
    bne $t7, $t9, packet_return
    nop
```

## Expected observation

Changing byte two to two reports -3 after a complete fixed header is available.
