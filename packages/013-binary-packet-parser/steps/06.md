# Step 6: Reject reserved flag bits

Load the flags into t1 so the accepted value survives until record publication. Mask with hexadecimal fe, which retains bits one through seven and clears the permitted bit zero. Any nonzero residue reports bad flags.

## Write or inspect

Append the following code in the `flags` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    li $v0, -4
    lbu $t1, 3($a0)
    andi $t9, $t1, 0xfe
    bne $t9, $zero, packet_return
    nop
```

## Expected observation

Flags zero and one pass; two, three, and 255 fail. The record is still untouched at this stage.
