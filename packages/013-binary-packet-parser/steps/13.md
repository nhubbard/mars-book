# Step 13: Handle an empty payload before its loop

Initialize the separate payload sum and copy the validated length into the loop counter. When it is zero, branch directly to trailer_sum. Without this initial check, a body-first countdown loop would read a byte for an empty payload and underflow its counter.

## Write or inspect

Append the following code in the `payload_init` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    move $t4, $zero
    move $t6, $t0
    beq $t6, $zero, trailer_sum
    nop
```

## Expected observation

For length zero, the next input byte read is the checksum at offset eight. There are no payload bytes to visit.
