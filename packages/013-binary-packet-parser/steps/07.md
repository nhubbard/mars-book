# Step 7: Assemble the unsigned length

Load the high length byte from offset four, shift it left eight positions, then combine the low byte from offset five with OR. Both loads use zero extension. These values are numbers, so word operations suffice; no address is narrowed.

## Write or inspect

Append the following code in the `length` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    lbu $t0, 4($a0)
    sll $t0, $t0, 8
    lbu $t7, 5($a0)
    or $t0, $t0, $t7
```

## Expected observation

Bytes 00 03 produce three. Bytes 01 00 produce 256 and will fail the next semantic check.
