# Step 11: Prepare a bounded header scan

Clear the full-packet sum, copy the input pointer to t5, and set an eight-byte counter. These registers belong to the parser. The original a0 remains available for constructing the returned payload address.

## Write or inspect

Append the following code in the `header_init` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    move $t3, $zero
    move $t5, $a0
    li $t6, 8
```

## Expected observation

The cursor starts at header offset zero and the remaining count is eight.

Which register here is an address?

- **A** t5.
- **B** The checksum in t3.
