# Step 10: Decode the sequence number

Combine the two sequence bytes using the same high-byte shift and low-byte OR. Keep the result separate from the checksum. The checksum adds the original bytes, not the decoded integer. Sequence numbers span the full unsigned 16-bit range.

## Write or inspect

Append the following code in the `sequence` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    lbu $t2, 6($a0)
    sll $t2, $t2, 8
    lbu $t7, 7($a0)
    or $t2, $t2, $t7
```
