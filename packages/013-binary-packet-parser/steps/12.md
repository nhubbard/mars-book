# Step 12: Sum exactly eight header bytes

Load one unsigned byte, add it to the checksum, advance the cursor with a full-width increment, and reduce the count. The retained conditional branch has a nop following it. After eight iterations, the cursor already points to payload offset eight.

## Write or inspect

Append the following code in the `header_loop` region, between its BEGIN and END comments. Retain all scaffold labels and the supplied return stub.

```asm
    lbu $t7, 0($t5)
    addu $t3, $t3, $t7
    daddiu $t5, $t5, 1
    addiu $t6, $t6, -1
    bne $t6, $zero, header_sum
    nop
```

## Expected observation

For the default fixture the header accumulator is 232 and the cursor equals input plus eight.
