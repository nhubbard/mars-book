# Verified native IDE figures

Three editable native LaTeX plates use twelve original IntelliJ Light captures. Each state replays the unchanged reference program to a conditional breakpoint at operation_ready. Source, native signed-decimal return values, descriptor, ring and output views are checked before capture.

The figures explain independent cursor wrap, an exact-fit full queue and a short-destination failure. Five numbered explanations per figure identify the logical record order, stale free bytes, explicit occupancy, full buffer pointer and preserved output. A separate core oracle verifies all 472 data bytes at initialization and all fourteen publications, exact per-call writes and bounded reads. Print annotations do not alter the original PNGs.

The automation runs in the separate MARS Book Authoring plugin, which depends on MARS. Color and grayscale proof review and automated tagging/font checks are complete; independent accessibility review remains open.
