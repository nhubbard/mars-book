# Step 5: Compare required and free space

Load occupied bytes, subtract them from capacity, and form the encoded size as payload length plus one. Return full if the free count is smaller. Equality is an accepted exact fit. Select the full status only after the earlier record-size check passes.

## Write or inspect

Append these instructions in the `push_space` region. Keep all scaffold labels and both return stubs.

```asm
    lw $t2, 8($a0)
    subu $t9, $t3, $t2
    addiu $t5, $a2, 1
    li $v0, -1
    sltu $t9, $t9, $t5
    bne $t9, $zero, push_return
    nop
```

## Expected observation

An eight-byte ring with three used bytes can accept a four-byte encoded record and retain one free byte.
