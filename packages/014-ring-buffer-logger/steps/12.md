# Step 12: Publish the successful push

Add the encoded size to used, store the completed tail and used words, and return zero with encoded size as the auxiliary result. Head and configuration remain unchanged. This completes the push function.

## Write or inspect

Append these instructions in the `push_publish` region. Keep all scaffold labels and both return stubs.

```asm
    addu $t2, $t2, $t5
    sw $t1, 4($a0)
    sw $t2, 8($a0)
    move $v1, $t5
    move $v0, $zero
```

## Expected observation

The first default push changes state from 0/0/0 to head zero, tail four, used four.
