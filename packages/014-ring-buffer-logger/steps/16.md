# Step 16: Reject a destination that is too small

Select the short-destination status and report the required payload length in v1. Compare destination capacity with that length. If it is too small, return before copying or changing queue state. Equality succeeds.

## Write or inspect

Append these instructions in the `pop_fit` region. Keep all scaffold labels and both return stubs.

```asm
    li $v0, -2
    move $v1, $t5
    sltu $t9, $a2, $t5
    bne $t9, $zero, pop_return
    nop
```

## Expected observation

A seven-byte payload and capacity six return -2 and seven; a retry with capacity seven can still pop that record.
