# Step 6: Write the prefix through the supplied buffer

Load tail and the descriptor buffer pointer. Form the full effective address from base plus tail, then store the payload length as one byte. All failure conditions have already been decided. The caller source has no prefix to copy.

## Write or inspect

Append these instructions in the `push_prefix` region. Keep all scaffold labels and both return stubs.

```asm
    lw $t1, 4($a0)
    ld $t4, 16($a0)
    daddu $t6, $t4, $t1
    sb $a2, 0($t6)
```

## Expected observation

For a three-byte payload beginning at tail seven, ring byte seven becomes three.
