# Step 18: Prepare the destination copy

Copy the destination pointer to a full-width cursor and the decoded length to the remaining count. Skip the loop when the length is zero. A zero-capacity destination is sufficient for an empty record and must receive no writes.

## Write or inspect

Append these instructions in the `pop_init` region. Keep all scaffold labels and both return stubs.

```asm
    move $t6, $a1
    move $t7, $t5
    beq $t7, $zero, pop_commit
    nop
```

## Expected observation

An empty record succeeds with status zero and eventually consumes one queue byte.
