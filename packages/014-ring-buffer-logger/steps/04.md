# Step 4: Reject a record that can never fit

Initialize the failure auxiliary value to zero. Load capacity and compare payload length with it using an unsigned comparison. Since the prefix needs one additional byte, a payload length equal to capacity is already too large.

## Write or inspect

Append these instructions in the `push_fit` region. Keep all scaffold labels and both return stubs.

```asm
    li $v0, -2
    move $v1, $zero
    lw $t3, 12($a0)
    sltu $t9, $a2, $t3
    beq $t9, $zero, push_return
    nop
```

## Expected observation

With capacity eight, payload length eight reports -2 before inspecting current free space.
