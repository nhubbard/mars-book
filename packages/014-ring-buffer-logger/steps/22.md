# Step 22: Publish the successful pop

Form encoded size as decoded length plus one, subtract it from used, and store the completed head and used. Return payload length in v0 and encoded size in v1. Tail, capacity, pointer, and ring bytes remain unchanged.

## Write or inspect

Append these instructions in the `pop_publish` region. Keep all scaffold labels and both return stubs.

```asm
    addiu $v1, $t5, 1
    subu $t2, $t2, $v1
    sw $t0, 0($a0)
    sw $t2, 8($a0)
    move $v0, $t5
```

## Expected observation

Popping the first three-byte record changes 0/7/7 to head four, tail seven, used three.
