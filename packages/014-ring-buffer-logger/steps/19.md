# Step 19: Copy a payload byte out

Form the full address from the buffer base and current head index. Load one byte and store it through the linear destination cursor, then advance that cursor at full width. Leave ring storage unchanged.

## Write or inspect

Append these instructions in the `pop_bytes` region. Keep all scaffold labels and both return stubs.

```asm
    daddu $t9, $t4, $t0
    lbu $t8, 0($t9)
    sb $t8, 0($t6)
    daddiu $t6, $t6, 1
```

## Expected observation

The destination receives the oldest record bytes in their original order.

## Check your understanding

Must pop erase a byte after reading it?

- **A** Yes, to make it free.
- **B** No; occupancy changes through descriptor state.
- **C** Only when its value is zero.
