# Project contract

Implement `push_record` and `pop_record` for a bounded byte ring. Each stored record consists of one length byte followed by that many payload bytes. Payloads contain zero through 31 arbitrary bytes, including zeros. A descriptor supplies the ring’s head, tail, occupied-byte count, capacity, and full buffer address. Capacity is one through 32 bytes and need not be a power of two. The caller supplies a well-formed queue; detecting corrupted metadata is outside this exercise.

Both calls receive the descriptor address in `a0`. Push receives the source pointer in `a1` and payload length in `a2`. Pop receives the destination pointer in `a1` and destination capacity in `a2`. Those counts range from zero through 31, with enough physical source or destination storage provided. Source, destination, descriptors, and rings do not overlap. The data pointers can be byte unaligned; each descriptor is eight-byte aligned. Preserve full saved registers and `sp`, return through the supplied `ra`, and produce no console output.

A failed call makes no caller-data writes, even writes subsequently restored. Successful push writes only its new circular record and the descriptor’s first three state words. Successful pop writes only its returned payload bytes and those state words; it leaves all ring bytes unchanged. Capacity and buffer address are read-only configuration. The state-word store order and payload-copy order may vary, but the complete queue must agree with the interface at return. This is a sequential queue contract, with no concurrent-reader or interrupt-safety guarantee.
