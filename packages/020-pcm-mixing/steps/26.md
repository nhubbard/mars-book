# Turn equality into a clipping mask

Use nor.v with the equality vector as both operands. This computes its bitwise complement, changing unclipped lanes to zero and clipped lanes to ffff. The operation is whole-register logic, but it preserves the established halfword boundaries because it complements each bit independently. A comparison alone had the opposite meaning from the count we need.

## Write and inspect

Replace the temporary branch and nop in `vector_invert`. Keep surrounding labels and markers.

```asm
    nor.v $w4, $w4, $w4
```

Use the `s26-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

The default clipping mask is 0000, 0000, 0000, ffff, ffff, 0000, 0000 and ffff: three clipped lanes.

## Check your understanding

Which lanes are now all ones?

- **A** The clipped lanes.
- **B** The exact endpoint lanes.
- **C** Every negative input lane.
