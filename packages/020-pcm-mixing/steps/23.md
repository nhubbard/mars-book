# Compute the ordinary lane sums for comparison

Apply addv.h to obtain the low sixteen bits of each lane sum in w2. This is the deliberately wrapping result, not the required output. It is kept because comparing it with a saturated sum reveals exactly which lanes needed clipping. Neighboring samples do not contribute to one another’s carry.

## Write and inspect

Replace the temporary branch and nop in `vector_wrap`. Keep surrounding labels and markers.

```asm
    addv.h $w2, $w0, $w1
```

Use the `s23-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

The first group’s wrapped sums are 0, 3000, -3000, -25536, 25536, 32767, -32768 and -25536.
