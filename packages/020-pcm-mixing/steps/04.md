# Test the logical sample count before loading

The entry has already retained the original count in v0 and cleared v1. The provisional vector gate goes directly to mix_tail. Test a3 before entering the scalar body: the arena size says where storage exists, while a3 says which samples belong to this call. An empty slice permits no input or output access. Keep the supplied return so ra remains the caller’s continuation.

## Write and inspect

Replace the temporary branch and nop in `scalar_bound`. Keep surrounding labels and markers.

```asm
    beq $a3, $zero, mix_return
    nop
```
