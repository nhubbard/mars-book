# Store only the low output byte

Write t0’s low byte at output offset zero with sb. This publishes just one byte; the high byte remains unchanged until the next edit. Both inputs have already been fully loaded, so exact in-place output is safe for the current sample. A word store would write beyond the two-byte sample and can damage a neighbor or a guard even when later stores repair it.

## Write and inspect

Replace the temporary branch and nop in `store_low`. Keep surrounding labels and markers.

```asm
    sb $t0, 0($a2)
```

Use the `s17-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

Clamped +32767 writes low byte ff; clamped -32768 writes 00. The second output byte still has its poison value.
