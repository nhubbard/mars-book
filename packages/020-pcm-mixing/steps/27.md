# Count mask bits in two doublewords

Use pcnt.d to count one bits separately in each sixty-four-bit half of the register. Four halfword masks fit each doubleword. The default low half has one clipped lane, contributing sixteen bits; the high half has two, contributing thirty-two. These are bit counts rather than sample counts. pcnt.h would leave eight separate counts and would require a different reduction.

## Write and inspect

Replace the temporary branch and nop in `vector_popcount`. Keep surrounding labels and markers.

```asm
    pcnt.d $w4, $w4
```

Use the `s27-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

w4’s doublewords hold 16 and 32.
