# Replace a negative overflow with the endpoint

The low path loads -32768. It falls directly into the shared clipping-count region. The two overflow signs therefore choose different stored values but share one increment. In-range control flow already bypasses this label, so merely storing -32768 does not prove that the count was increased.

## Write and inspect

Replace the temporary branch and nop in `lower_value`. Keep surrounding labels and markers.

```asm
    li $t0, -32768
```

Use the `s15-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

The negative-overflow fixture now has t0=-32768 with v1 still zero.
