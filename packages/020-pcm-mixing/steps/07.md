# Extend A from its halfword sign bit

Apply seh to the reconstructed halfword. It copies bit fifteen into the higher register bits, making the numerical signed value agree with the sixteen-bit sample. For the worked negative sample the register changes from positive 64536 to -1000. The stored input bytes do not change. The instruction is needed even though both loads used lbu.

## Write and inspect

Replace the temporary branch and nop in `sign_a`. Keep surrounding labels and markers.

```asm
    seh $t0, $t0
```

Use the `s07-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

t0 now holds -1000. The same operation preserves a positive halfword.

## Check your understanding

Which bit determines the extension?

- **A** Bit fifteen of the reconstructed sample.
- **B** Bit seven of its low byte.
- **C** Bit sixty-three of its address.
