# Detect sums strictly above the positive endpoint

Load 32767 and ask whether that endpoint is less than the exact sum. Branch to mix_high only when slt produces one. Equality is allowed: 30000+2767 is representable and must not increase the clipping count. The branch’s following nop is retained as explicit source padding; this Release 6 lesson does not depend on a delay slot.

## Write and inspect

Replace the temporary branch and nop in `upper_test`. Keep surrounding labels and markers.

```asm
    li $t1, 32767
    slt $t2, $t1, $t0
    bne $t2, $zero, mix_high
    nop
```

Use the `s12-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

Sum 40000 takes the high path with t2=1. Sum 32767 leaves t2=0 and continues toward the lower test.

## Check your understanding

Should exact sum 32767 count as clipped?

- **A** Yes, because the stored result is an endpoint.
- **B** Only when A is positive.
- **C** No, because it is representable.
