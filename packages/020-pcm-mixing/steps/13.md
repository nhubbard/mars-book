# Keep in-range sums out of the clipping path

Test whether the exact sum is less than -32768. On success branch to mix_low. Otherwise transfer directly to mix_store, bypassing both endpoint replacement and count increment. This second test uses the opposite comparison order from the positive bound. A negative input does not itself imply clipping; only the exact sum matters.

## Write and inspect

Replace the temporary branch and nop in `lower_test`. Keep surrounding labels and markers.

```asm
    li $t1, -32768
    slt $t2, $t0, $t1
    bne $t2, $zero, mix_low
    nop
    beq $zero, $zero, mix_store
    nop
```

Use the `s13-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

Sum -40000 takes mix_low. Sums -32768, 0 and 32767 go to storage without increasing v1.
