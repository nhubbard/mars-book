# Retain both complete input groups

Load sixteen bytes from each source into w0 and w1 before writing the output. Byte loads impose no halfword alignment requirement in this pinned MARS implementation. Subsequent halfword arithmetic interprets adjacent low/high bytes as signed sixteen-bit lanes in little-endian order. Loading both groups first extends the scalar alias argument to eight samples.

## Write and inspect

Replace the temporary branch and nop in `vector_load`. Keep surrounding labels and markers.

```asm
    ld.b $w0, 0($a0)
    ld.b $w1, 0($a1)
```

Use the `s22-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

The first eight default samples appear in w0 and w1 as their raw halfword bit patterns.
