# Interpret B as a signed halfword

Sign-extend B just as for A. Correctly decoding only one input would make the result depend on which side supplied a negative sample, violating the symmetric arithmetic contract. The next addition can now treat both registers as signed values in the range -32768 through 32767.

## Write and inspect

Replace the temporary branch and nop in `sign_b`. Keep surrounding labels and markers.

```asm
    seh $t1, $t1
```

Use the `s10-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

With A=1000 and B=-2000, the registers contain 1000 and -2000.

## Check your understanding

Can sign extension be omitted because A was already extended?

- **A** No; B has its own independent sign bit.
- **B** Yes; one extension affects both registers.
- **C** Only if output aliases A.
