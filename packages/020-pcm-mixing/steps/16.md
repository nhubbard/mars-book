# Count each out-of-range sample once

Increment v1 at the shared mix_clipped label. Either overflow path reaches this label exactly once per sample, while the in-range path reaches mix_store directly. Initialize v1 only at function entry: clearing it here would lose earlier clipping events. The count measures samples that needed replacement, not the number of changed output bytes.

## Write and inspect

Replace the temporary branch and nop in `count_clip`. Keep surrounding labels and markers.

```asm
    addiu $v1, $v1, 1
```

Use the `s16-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

Positive and negative overflow each produce v1=1 for one sample. Exact endpoint sums keep v1=0.
