# Separate endpoint equality from overflow

Run fresh one-sample calls for 30000+2767, 32767+1, -30000+-2768 and -32768+-1. The first and second store the same positive endpoint but return clipping counts zero and one. The third and fourth do the same at the negative endpoint. Changing the input data is part of each fresh call; continuing an already completed call would not repeat the entry initialization.

## Expected observation

The four clipping results are zero, one, zero and one. Every call returns v0=1.

## Check your understanding

Which pair actually clips?

- **A** 32767+1.
- **B** 30000+2767.
- **C** -30000+-2768.
