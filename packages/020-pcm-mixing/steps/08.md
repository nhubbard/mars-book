# Read B before making any output store

Load B’s two bytes at offsets zero and one from a1 into t1 and t2. Reusing t1 is safe because A’s combined signed value is already in t0. Both complete inputs must be retained before output is stored: when output is exactly input B, an early store could otherwise replace a byte that this same sample still needs.

## Write and inspect

Replace the temporary branch and nop in `load_b`. Keep surrounding labels and markers.

```asm
    lbu $t1, 0($a1)
    lbu $t2, 1($a1)
```

Use the `s08-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

For A=-1000 and B=2000, t0 stays -1000 while t1=208 and t2=7.

## Check your understanding

What must survive reuse of t1?

- **A** The previous high-byte temporary forever.
- **B** A’s complete signed value in t0.
- **C** The last output sample in a0.
