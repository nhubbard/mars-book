# Read the sample-level interface

The function receives two full input addresses, a full output address and a sample count. One sample consumes two bytes from each source and produces two output bytes. v0 returns how many samples were requested; v1 counts exact sums outside the signed halfword range. Byte counts, sample counts and clipping counts have different units even when held in ordinary integer registers.

## Expected observation

For count sixteen, each selected slice has thirty-two bytes. The output has sixteen samples, not thirty-two samples.
