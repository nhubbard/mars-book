# Copy the low population count to a scalar register

Use copy_s.d to transfer w4[0] into t2. It copies the numerical doubleword count; it does not count again or move the vector’s bytes in memory. Although the operation uses signed transfer, this count is in 0..64, so its interpretation is unambiguous. The second count remains in w4[1].

## Write and inspect

Replace the temporary branch and nop in `vector_low_count`. Keep surrounding labels and markers.

```asm
    copy_s.d $t2, $w4[0]
```

Use the `s28-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

t2 contains 16 for the default group.
