# Finish the little-endian output sample

Shift the result logically right by eight into t1, then store its low byte at output offset one. For a negative result, the shifted register has other set bits; sb selects precisely bits fifteen through eight of the original halfword. The output is now complete in the requested byte order, but the pointers and remaining count still describe this sample.

## Write and inspect
