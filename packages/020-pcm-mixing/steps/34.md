# Repeat complete groups and retain the scalar tail

Advance all three full pointers by sixteen, consume eight samples and repeat only when another complete group remains. Otherwise fall through to mix_tail, which returns immediately at zero or processes the final one through seven samples. The scalar tail adds into the same v1. Neither path resets v0. The completed routine now covers short calls, exact blocks and mixed calls under one interface.

## Write and inspect

Replace the temporary branch and nop in `vector_next`. Keep surrounding labels and markers.

```asm
    daddiu $a0, $a0, 16
    daddiu $a1, $a1, 16
    daddiu $a2, $a2, 16
    addiu $a3, $a3, -8
    sltiu $t0, $a3, 8
    beq $t0, $zero, mix_block
    nop
```

Use the `s34-*` input recipes from [the observation guide](../fixtures/guided-inputs.md). Begin a fresh Debug execution and pause at mix_ready.

## Expected observation

Eight default samples return three clips; nine return four; sixteen return six. A sixty-four-sample call exercises repeated groups without a scalar tail.
