# Compute signed saturated lane sums

Apply adds_s.h to the original inputs and retain the result in w3. Its signed halfword operation replaces positive and negative overflow with the corresponding endpoints, independently for each lane. w2 is still available for the comparison. The register does not carry a permanent halfword type; the instruction’s h suffix selects the lane interpretation.

## Write and inspect
