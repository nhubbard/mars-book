\section{Step 2 Trace the default sums before writing code}\label{pcm-s02}

Use the supplied sixteen-sample inputs. Trace indices three, five and nine: 30000+10000 clips to 32767; 32767+0 reaches that endpoint without clipping; 32767+1 clips to the same stored endpoint. This distinguishes what memory can show from what the routine must report. The default outputs contain six clipping events.

\subsection{Expected observation}
The required saturated outputs are 0, 3000, -3000, 32767, -32768, 32767, -32768, 32767, -32768, 32767, -32768, 0, 0, 0, 0 and 32767.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Can scanning only endpoint outputs recover the clipping count?

\begin{itemize}
  \item \textbf{A} No; representable sums can also equal an endpoint.
  \item \textbf{B} Yes; every endpoint is clipped.
  \item \textbf{C} Only when count is even.
\end{itemize}
