\section{Step 38 Compare stored audio and numerical waveforms}\label{pcm-s38}

Use the three supplied listening scenes. Each track is a separate mono stream; a and b are inputs, saturated and wrapped are output rules. The renderer writes samples actually produced by MARS and checks them independently. Listening is optional: the numerical examples, plot and sample formula convey the same clipping distinction. Do not infer clip counts solely from perceived loudness.

\subsection{Expected observation}
Quiet saturated and wrapping files are identical. Both louder scenes have 11000 clipped samples but different waveforms. The files have two seconds of audio at 16000 mono frames per second.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Do the two input streams make each file stereo?

\begin{itemize}
  \item \textbf{A} Yes, because two values are added.
  \item \textbf{B} Only in the phase-offset scene.
  \item \textbf{C} No; each stored output frame contains one mixed sample.
\end{itemize}
