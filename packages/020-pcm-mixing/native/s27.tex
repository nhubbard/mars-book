\section{Step 27 Count mask bits in two doublewords}\label{pcm-s27}

Use \texttt{pcnt.d} to count one bits separately in each sixty-four-bit half of the register. Four halfword masks fit each doubleword. The default low half has one clipped lane, contributing sixteen bits; the high half has two, contributing thirty-two. These are bit counts rather than sample counts. pcnt.h would leave eight separate counts and would require a different reduction.
