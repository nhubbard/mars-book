# Step 17 Prepare the newline string

The declaration newline contains a newline byte followed by a zero terminator. Loading its address prepares the same print-string interface used earlier.

## Write or inspect

Append the address load.

```asm
    la $a0, newline
```

## Expected observation

$a0 now contains a string address rather than the numeric answer. $t0 still retains that answer.

## Check your understanding

Does la change the contents of the newline string?

- **A** Yes; it replaces the newline with its address.
- **B** Yes; it immediately appends the string to the console.
- **C** No; it loads its address into a register.
