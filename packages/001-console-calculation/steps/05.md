# Step 5 Select string output

li means load immediate: an immediate is a constant written in the source. MARS uses $v0 to choose a syscall service. Service 4 prints a zero-terminated string whose address is in $a0. Selecting the service and requesting it are separate operations.

## Write or inspect

Append the instruction after the address load.

```asm
    li $v0, 4
```

## Expected observation

$v0 contains the service selector 4. The string has not been printed yet.

## Check your understanding

Does loading 4 into $v0 print the string?

- **A** Yes; every write to $v0 prints a string.
- **B** Yes; la already printed it.
- **C** No; syscall must request the selected service.
