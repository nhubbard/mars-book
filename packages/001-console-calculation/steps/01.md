# Step 1 Open the starter

An assembly source file describes data and instructions. MARS assembles the text into executable machine instructions before running it. This first program is a standalone source file; it does not need a build framework.

## Write or inspect

Open starter/main.asm. Identify the two marked regions and the supplied exit sequence. Run the unchanged file once.

## Expected observation

The template should terminate without printing anything. If Run is unavailable, check that the MARS plugin is enabled and the file has the .asm extension.

- **A** The assembler translates source into machine instructions.
- **B** The processor executes the comments as instructions.
- **C** The console converts every source line to an input value.
