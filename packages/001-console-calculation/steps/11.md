# Step 11 Prepare the answer message

The input syscall left a number in $v0; the upcoming output syscalls need service selectors there. $t0 keeps the arithmetic result while $a0 and $v0 prepare the next requests.

## Write or inspect

Append the address load for the answer message.

```asm
report:
    la $a0, answer
```

## Expected observation

$a0 now identifies the answer prefix. $t0 still contains the arithmetic result.

## Check your understanding

Why keep the arithmetic result in $t0 here?

- **A** $t0 is the only register that can hold integers.
- **B** String output reads every register automatically.
- **C** Subsequent syscall setup will overwrite $v0.
