# Step 22 Write an equivalent solution

The free-writing contract describes behavior. An implementation can compute the same result with a different scratch register or sequence of additions. Teaching observations can name a register for a guided exercise without making that register part of the final program interface.

## Write or inspect

Copy the starter into a new folder and implement the same contract with a different correct arithmetic sequence. Test both input-domain endpoints as well as the public examples. Explain why the transformation preserves 2 × x + 1.

## Expected observation

The public checks should accept the alternative. Instruction count and source spelling may differ; output and termination must agree.
