# Step 21 Trace before trusting the result

A breakpoint pauses before its instruction executes. Step Over follows source-level execution; pseudo-instructions may expand into multiple machine instructions. The two arithmetic lines here are basic instructions and give direct state observations.

## Write or inspect

Set a breakpoint on addu below calculate. Debug with input 20. Inspect $v0 before the addition, then $t0 after each of the two arithmetic steps. Resume to termination.

## Expected observation

Before addu: $v0 = 20. After addu: $t0 = 40. After addiu: $t0 = 41. In hexadecimal these are 0x14, 0x28, and 0x29.
