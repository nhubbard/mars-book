# Step 14 Pass the numeric result

move copies a register value without changing the source. For integer output, $a0 holds the number itself. Contrast that with string output, where $a0 holds an address. The service contract determines how the bits are interpreted.

## Write or inspect

Append the move into the output argument register.

```asm
    move $a0, $t0
```

## Expected observation

For input 20, $a0 and $t0 both contain 41. This instruction alone produces no output.

What does $a0 represent for integer output?

- **A** Always a string address, regardless of service.
- **B** An instruction count.
- **C** The integer value to print.
