# Step 12 Select string output again

The service selector must be set for each request. After reading input, $v0 contains the input value, so relying on its previous role would select the wrong service.

## Write or inspect

Append the string-output selector.

```asm
    li $v0, 4
```

## Expected observation

$v0 contains 4 and $a0 still identifies the answer prefix.

## Check your understanding

Why explicitly load 4 again?

- **A** All registers are cleared after each instruction.
- **B** The read service returned its result in $v0.
- **C** The string text has changed itself.
