# Step 2 Declare the messages

The .data directive selects the data section. A label gives an address a name. The .asciiz directive emits the text bytes followed by a zero byte; the string-printing service uses that zero to find the end. The colon belongs after the label name.

## Write or inspect

Add these declarations inside the student data region. Preserve spaces at the ends of the two prompts.

```asm
prompt:  .asciiz "Enter a small integer: "
answer:  .asciiz "Twice your number plus one is: "
newline: .asciiz "\n"
```

## Expected observation

The file should still assemble and exit silently. Declaring data does not print it.
