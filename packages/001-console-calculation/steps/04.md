# Step 4 Put the prompt address in an argument register

la means load address. The print-string service needs the location of the string, not its first character. $a0 is the argument register for that service. la is a pseudo-instruction: the assembler may expand it into more than one machine instruction.

## Write or inspect

Insert this instruction at the beginning of the student program region.

```asm
    la $a0, prompt
```

## Expected observation

$a0 now identifies the prompt bytes. Nothing has been printed yet.

What should $a0 contain before printing a string?

- **A** The address of its zero-terminated bytes.
- **B** The first character only.
