# Step 3 Read the entry and exit scaffold

The .text directive selects the instruction section. The .globl main directive exports main; main: names the entry in this starter. li puts a constant into a register. With service number 10 in $v0, syscall requests normal termination from MARS. Registers beginning with $ are processor storage locations.

## Write or inspect

Read the scaffold, including the two exit instructions. Add all subsequent instruction fragments above done, in the listed order. Leave the exit sequence at the end.

```asm
done:
    li $v0, 10
    syscall
```

## Expected observation

The supplied exit makes the first partial versions safe to run. A label names a location and does not execute an operation.
