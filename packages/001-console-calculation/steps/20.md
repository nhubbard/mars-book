# Step 20 Check the output contract

Testing several values catches mistakes that one positive input can hide. Zero distinguishes 2 × x + 1 from 2 × x; a negative input checks the signed result. The public grader compares the output produced by the program, not terminal echo.

## Write or inspect

Run with 20, 0, and -3. Then run the public checks using the repository instructions.

## Expected observation

Expected results are 41, 1, and -5 with exact prompts and one trailing newline. A wrong answer and a formatting mismatch are different failures to investigate.
