# Step 8 Read the input

The input syscall waits until a complete input is available. In the default console mode, type a number and press Enter. Reading replaces the service number in $v0 with the input value.

## Write or inspect

Append syscall. Run and enter 20; then try -3.

```asm
    syscall
```

## Expected observation

The partial program prompts, accepts input, and exits. In Debug, $v0 is 20 after reading 20, or -3 after reading -3.

## Check your understanding

After reading 20, what does $v0 contain?

- **A** 5, because service selectors can never change.
- **B** 40, because input automatically doubles the number.
- **C** 20, the returned input.
