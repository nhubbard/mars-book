# Step 10 Add the final one

addiu adds an immediate to a source register and writes a word result. Using $t0 as both destination and source replaces its previous value. The u means signed overflow does not trap; a word result is still sign-extended. For this input domain the result is the ordinary integer 2 × x + 1.

## Write or inspect

Append this instruction and calculate the expected intermediate values for 0, 20, and -3.

```asm
    addiu $t0, $t0, 1
```

## Expected observation

The final result is 1 for 0, 41 for 20, and -5 for -3. Keep it in $t0 while preparing output.
