# Step 7 Select integer input

Service 5 reads a signed decimal integer and returns it in $v0. That register is reused: it holds the service number before the request and the input afterward.

## Write or inspect

Append the selector after the prompt syscall.

```asm
    li $v0, 5
```

## Expected observation

$v0 contains 5 before the next syscall. Merely selecting service 5 does not wait for input.
