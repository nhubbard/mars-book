# Step 15 Select integer output

Service 1 prints the signed integer supplied in $a0. Setting $v0 does not change the argument in $a0, so the result remains available for the request.

## Write or inspect

Append the integer-output selector.

```asm
    li $v0, 1
```

## Expected observation

$v0 is 1 and $a0 contains the answer. These registers now have different roles in one request.
