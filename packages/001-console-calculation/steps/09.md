# Step 9 Double the value

The first operand of addu is its destination. The next two operands are source registers. Reading $v0 twice adds x to itself and writes 2 × x into $t0. addu performs word arithmetic and sign-extends the 32-bit result into the 64-bit register. It does not trap on signed overflow; our input bounds keep the demonstrated sums in range.

## Write or inspect

Append the addition. This is the first arithmetic instruction.

```asm
calculate:
    addu $t0, $v0, $v0
```

## Expected observation

Immediately after this instruction, input 20 gives $t0 = 40. Input -3 gives $t0 = -6.

## Check your understanding

For input -3, what is $t0 after this addition?

- **A** 6, because the u forces a positive result.
- **B** -6.
- **C** -3, because a source cannot appear twice.
