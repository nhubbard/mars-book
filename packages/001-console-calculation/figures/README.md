# Reviewed lesson figures

The five figures in ../captures/plan.json retain actual IntelliJ Light captures,
resolved native callout bounds and reviewed native LaTeX annotations. The starter,
completed Run and three arithmetic Debug stops are captured automatically through
the separate MARS Book Authoring plugin. The original PNGs remain unchanged.

Color previews are rendered from the native compositions; the matching grayscale
proofs are retained in the private publication evidence. Captions, alternatives and
numbered explanations are editable LaTeX in the book. The native export changes only
image-path prefixes and refuses to overwrite edited exported compositions. See the
repository capture workflow for reproduction and review requirements.
