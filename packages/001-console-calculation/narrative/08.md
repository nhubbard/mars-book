# Read a state at a defined boundary

A state observation needs a precise boundary. “At the input operation” could
mean before the request, while it waits, or after it returns. Those moments have
different values in `$v0`.

For input 20, the state immediately after the input syscall has `$v0 = 20`.
The following arithmetic instruction has not executed yet. A breakpoint on that
arithmetic line gives the debugger a clear place to stop and display the returned
input.

Use decimal when checking the calculation and hexadecimal when inspecting the
underlying pattern. Decimal 20 is hexadecimal `0x14`; a 64-bit display may add
leading zeroes. The display format changes how the value is written, not the
stored bits.
