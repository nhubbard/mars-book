# An immediate is part of the instruction

The last operand of `addiu $t0, $t0, 1` is an immediate constant. The value
one comes from the instruction, while the other input comes from a register.
The destination and register source happen to be the same location. Execution
reads the existing value and replaces it with the result.

For input 20, the old `$t0` is 40 and the new `$t0` is 41. For input −3, the
old value is −6 and the new value is −5. Writing these pairs makes the operation
checkable without depending on the console output.

The instruction operates on a 32-bit word and sign-extends the result to the
64-bit register width. A register's storage width alone does not determine the
arithmetic width; the selected instruction does.
