# Explain an equivalent implementation

The alternative calculation `(x + 1) + x` also gives `2 × x + 1`. Within the
published input range, both its intermediate sum and final result fit in a signed
word. This establishes a valid alternative for the task, even if its temporary
register differs from the book's trace.

The guided trace uses `$t0` to make its observations easy to compare. The final
input/output contract does not require that scratch register. Free-writing
checks therefore compare behavior and termination rather than reference-source
spelling or a private label arrangement.

An optimization must preserve the contract for all specified inputs. Later
projects will add contracts for memory effects, procedure interfaces, and
arithmetic boundaries before comparing execution costs.
