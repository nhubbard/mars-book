# Termination completes the contract

After the last output request, execution reaches `done` and selects the exit
service. No branch is required to reach the following instruction. The label
provides a name for that position in the source and assembled program.

Normal termination is part of the task. Producing the expected text and then
continuing indefinitely would leave the caller without a completed result.
The grader's instruction limit bounds such execution during a check; it does
not repair a missing exit.

This straight-line program separates input, arithmetic, output, and termination
into visible sections. Later programs will use branches and calls to choose
which instruction executes next.
