# Argument preparation and service selection

At this point, `$a0` contains the numeric answer while `$v0` selects integer
output. The two registers describe different parts of one request. A trace
should show them together immediately before `syscall`.

Changing the selector does not by itself request output. This repeats the same
interface pattern used for the prompt, with a different selector and argument
interpretation. Recognizing that pattern is more useful than memorizing a single
three-line sequence without its preconditions.

For input 20, the required pair is `$v0 = 1` and `$a0 = 41`. The answer must be
in the argument register before the request executes.
