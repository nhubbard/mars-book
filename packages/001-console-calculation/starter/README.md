# Console calculation starter

Open this folder as an IntelliJ project with the MARS plugin enabled.
Open main.asm and use its MARS Run or Debug action. No Gradle project is needed
for the assembly program itself. The unmodified template exits without output.

Follow the lesson in ../assignment.md and ../steps. Add data and instructions
inside the marked regions. The exit sequence is supplied so early checkpoints
can terminate normally. Those comments are editing landmarks, not security boundaries.

Use a separate copy for free-writing practice. The final contract constrains input,
output, and termination; it does not prescribe scratch registers or arithmetic spelling.
