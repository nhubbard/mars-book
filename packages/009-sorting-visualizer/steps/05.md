# Step 5 Prepare the leaf renderer

The function uses its argument pointer and length, not main's saved-register values. Start at the frame base with row and column zero. The public return stub already provides `jr` `ra` and its delay slot.

## Write or inspect

Append this fragment inside render.

```asm
    la $t0, frame
    move $t1, $zero
render_row:
    move $t2, $zero
render_cell:
```

## Expected observation

No frame word has been written at this partial stage.
