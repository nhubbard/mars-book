# Step 4 Initialize inputs and publish the initial call

Load the array base, length, and algorithm selector into persistent working registers. Initialize the output metadata, pass `a0` and `a1`, and call render. `jal` saves the return location; its `nop` delay slot still executes.

## Write or inspect

Insert this fragment in setup.

```asm
    la $s0, values
    la $t0, count
    lw $s1, 0($t0)
    la $t0, algorithm
    lw $s7, 0($t0)
    move $s6, $zero
    la $t0, swap_count
    sw $zero, 0($t0)
    la $t0, phase
    sw $zero, 0($t0)
    move $a0, $s0
    move $a1, $s1
    jal render
    nop
```
