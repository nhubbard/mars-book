# Step 9 Dispatch to the selected algorithm

Zero chooses insertion sort; one takes the selection path. The algorithm selector is input, so read it but do not overwrite it to simplify a branch.

## Write or inspect

Insert this fragment in dispatch.

```asm
    beq $s7, $zero, insertion_sort
    nop
    beq $zero, $zero, selection_sort
    nop
```

## Expected observation

Each valid selector enters its own loop setup.
