# Step 13 Advance the insertion boundary

Once the new item reaches its position, increase the outer index and revisit the prefix test. Inner movement and outer progress use different indices.

## Write or inspect

```asm
    addiu $s2, $s2, 1
    beq $zero, $zero, insertion_outer
    nop
```

## Expected observation

Insertion sort now handles the active prefix completely.
