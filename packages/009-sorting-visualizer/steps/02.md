# Step 2 Decode the bar representation

The signed value is converted to a positive visible height by adding five. Values −4 through 3 map to heights one through eight. Screen y increases downward, so a bar fills rows at or below its top.

## Write or inspect

Use the height table to predict two columns.

## Expected observation

Value −4 lights only row seven; value three lights all eight rows.

## Check your understanding

How tall is the bar for value zero?

- **A** Zero cells.
- **B** Five cells.
- **C** Eight cells.
