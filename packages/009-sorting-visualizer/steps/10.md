# Step 10 Start an insertion sorted prefix

A prefix of length one is already ordered. Start the outer index at one; if it is outside count, the input needs no insertion work. Set the inner index to the new item.

## Write or inspect

Insert this fragment in insertion_init.

```asm
    li $s2, 1
insertion_outer:
    slt $t0, $s2, $s1
    beq $t0, $zero, sort_end
    nop
    move $s3, $s2
```

## Expected observation

Empty and singleton inputs exit without loading a pair.
