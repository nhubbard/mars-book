# Step 14 Relate adjacent exchanges to inversions

An inversion is an earlier value greater than a later one. Exchanging an inverted adjacent pair removes exactly one inversion without changing other pair orders.

## Write or inspect

Count inversions in the default and reversed fixtures.

## Expected observation

The default has seventeen inversions; eight distinct reversed values have twenty-eight.
