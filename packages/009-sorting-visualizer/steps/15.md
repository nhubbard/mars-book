# Step 15 Initialize a selection suffix scan

The sorted prefix starts empty. If fewer than two positions remain, finish. Otherwise begin with the suffix's first index as the minimum and scan from the next index.

## Write or inspect

Insert this fragment in selection_init.

```asm
    move $s2, $zero
selection_outer:
    addiu $t0, $s1, -1
    slt $t0, $s2, $t0
    beq $t0, $zero, sort_end
    nop
    move $s4, $s2
    addiu $s3, $s2, 1
```

## Expected observation

For the default input, the initial candidate minimum is value two at index zero.
