# Step 24 Read branch totals with their definition

Branch counts use the core's taken/not-taken decisions. An always-taken `beq` counts as a branch; `jal` and `jr` are jumps and do not. Delay-slot nops count as instructions, not branch decisions.

## Write or inspect

Compare taken, not-taken, and total branch counts.
