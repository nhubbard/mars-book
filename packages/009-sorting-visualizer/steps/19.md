# Step 19 Publish completion separately

Set phase two and call the same renderer once more. The final swap count is unchanged. Even an input requiring no exchanges has distinct initial and completion observations.

## Write or inspect

Insert this fragment in final.

```asm
    li $t0, 2
    la $t1, phase
    sw $t0, 0($t1)
    move $a0, $s0
    move $a1, $s1
    jal render
    nop
```

## Expected observation

Both algorithms now meet the full initial/exchange/final publication protocol.
