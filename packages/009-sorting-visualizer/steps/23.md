# Step 23 Measure whole-run and selected code work

The whole counter includes setup, rendering, sorting, and exit. The range counter counts PCs from `sort_begin` through just before `sort_end`, excluding the renderer body. Caller argument setup, call instructions, and their delay slots inside the range still count.

## Write or inspect

Read the measured sorted/reversed/shuffled table.

## Expected observation

A large whole-run difference can be dominated by how many frames were rendered.
