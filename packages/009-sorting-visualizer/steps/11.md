# Step 11 Compare an adjacent pair safely

Stop when the inner index reaches zero. Otherwise load the left and right words and use signed `slt` to ask whether right is strictly smaller. Equality stops the movement.

## Write or inspect

Append this fragment in insertion_inner.

```asm
    beq $s3, $zero, insertion_next
    nop
    sll $t0, $s3, 2
    daddu $t0, $s0, $t0
    lw $t1, -4($t0)
    lw $t2, 0($t0)
    slt $t3, $t2, $t1
    beq $t3, $zero, insertion_next
    nop
```

## Expected observation

For the default first pair, −2 is smaller than 2, so an exchange is required.
