# Offset encoding of signed values

| Value | Height v+5 | First white row 3−v |
| --- | --- | --- |
| −4 | 1 | 7 |
| −3 | 2 | 6 |
| −2 | 3 | 5 |
| −1 | 4 | 4 |
| 0 | 5 | 3 |
| 1 | 6 | 2 |
| 2 | 7 | 1 |
| 3 | 8 | 0 |

Row zero is at the top. Inactive columns are entirely black. The full frame always
contains 64 words, independent of active length.
