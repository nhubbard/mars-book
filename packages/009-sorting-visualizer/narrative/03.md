# A call links to a continuation, not to the next source line

For a retained delayed `jal` at machine address P, the return address is P+8. The instruction
at P+4 is its delay slot and executes before entry to the target. The reference places
`nop` there. A pseudo-instruction elsewhere may expand into several machine instructions,
so addresses belong to the assembled program rather than to source-line numbers.

Inside the renderer, `sort_ready` names the boundary after every frame word is stored.
The following `jr` `ra` transfers to the caller's continuation after its own explicit `nop`
delay slot. The jump does not restore registers automatically. The preservation rules
hold because the renderer avoids changing the saved registers and stack pointer.

The independent function check enters render without running main. It supplies an actual
label-resolved data address and return continuation, changes the argument length, and
fills saved registers with unrelated 64-bit values. This exposes a hidden dependence on
main's pointer register or on the global values symbol instead of the declared argument.
