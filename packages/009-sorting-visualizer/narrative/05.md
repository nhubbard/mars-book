# Insertion extends an ordered prefix

Before an outer insertion step, the items to the left of its new index are already
ordered. The new item moves left by exchanging with its neighbor whenever it is strictly
smaller. Reaching index zero or a neighbor no greater than the item ends that insertion.
The outer index then advances to extend the ordered prefix by one.

The signed comparison matters because negative values are active inputs. The reference
uses `slt` on loaded words. It tests the index before loading the left neighbor so an item
at position zero never causes a read before the array.

An exchange first loads both old words, then stores them in opposite positions. During
those two stores the memory array can briefly contain a duplicate, but the next publication
occurs only after both are complete. The renderer therefore observes a permutation rather
than a half-exchange. Its call can overwrite temporaries because the indices and array
base needed afterward are in preserved registers.
