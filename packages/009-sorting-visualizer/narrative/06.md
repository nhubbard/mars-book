# Inversions explain insertion work and termination

An inversion is a pair of positions whose earlier value is greater than its later value.
If an inverted adjacent pair is exchanged, that pair becomes ordered. Any other item's
relation to the two values contributes the same total before and after the exchange,
so the inversion count decreases by exactly one.

The count is nonnegative, which bounds the number of such exchanges. Eight distinct
values have at most 8×7/2 = 28 inversions, attained by reverse order. The default shuffled
array has seventeen. The insertion variant performs exactly that many adjacent exchanges
before reaching an array with no inversions.

Its loop indices also give local progress: the inner index decreases after an exchange,
and the outer index increases when an insertion finishes. Equal values do not exchange,
which avoids unnecessary work and preserves their relative order in this adjacent policy.
Stability of arbitrary records needs identities in the representation, not just equal numbers.
