# Give the renderer an explicit register contract

The renderer's arguments are an array pointer in `a0` and a length in `a1`. It writes the
fixed frame, reaches the public ready label, and returns through `ra`. It preserves the
saved-register group `s0` through `s7` and the stack pointer. Its temporary and argument
registers are caller-owned scratch under this exercise's contract.

Main keeps algorithm state in the preserved group. It can therefore call the renderer
in the middle of a loop without rebuilding its indices from memory afterward. The caller
still reloads arguments before each call and does not rely on temporary values surviving.

This is a small explicit interface rather than a complete description of every MIPS ABI.
The guide's renderer is a leaf: it calls no other function and uses no saved registers,
so it needs no stack frame. Introducing a nested call would require preserving the incoming
return address before another `jal` overwrites it. A larger calling convention will need
its own stack, alignment, and register rules.
