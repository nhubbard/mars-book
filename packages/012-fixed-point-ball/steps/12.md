# Step 12 Draw the point through the full pointer

Scale the word index by four to obtain a byte displacement. Add that small displacement to the full destination pointer with a doubleword address operation. Store the white RGB word. The supplied return instruction then returns the ID already in the result register.

## Write or inspect

Append the address calculation and store. Call the completed renderer with either frame pointer and verify all 64 words, not only the white cell.

```asm
    sll $t4, $v0, 2
    daddu $t4, $a0, $t4
    li $t5, 0x00ffffff
    sw $t5, 0($t4)
```

## Expected observation

Exactly one destination word is white and every other word is black. The returned ID agrees with the white word. The other arena, guards, and saved registers remain unchanged.
