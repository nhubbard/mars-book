# Step 27 Compute the exact wider raw sum

Add the correctly sign-extended operands with a doubleword operation. The exact sum of two signed 32-bit integers fits in a signed 64-bit integer. The scale remains 256; widening the operation does not move the binary point.

## Write or inspect

Append the wider addition. Compare the two result registers before the supplied return continuation overwrites the word result to request exit.

```asm
    daddu $v1, $a0, $a1
```

## Expected observation

The wider result is positive 2147483904, while the wrapped word result is negative 2147483392. Both use the same raw scale.
