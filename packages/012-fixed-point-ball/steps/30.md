# Step 30 Submit a checked equivalent and plan a variation

The final checks assess the public numeric and publication contracts. They allow different scratch registers, branch arrangements, and rendering strategies. A larger velocity range, changed scale, trail, or different marker protocol is a new experiment with a changed contract, not an unnoticed submission variation.

## Write or inspect

## Expected observation

The reference and alternative both pass despite different work counts. Inputs, guards, caller-owned data, saved registers where required, and every published state satisfy the declared contract.
