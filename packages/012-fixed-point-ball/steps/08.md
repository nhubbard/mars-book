# Step 8 Use the velocity bound in the proof

One reflection is sufficient because the maximum step is four pixels and the two walls are seven pixels apart. The tentative interval and the two reflected intervals can be bounded with integer arithmetic. Enlarging the velocity domain changes that argument.

## Write or inspect

Derive the minimum and maximum trial positions from the input bounds. Then bound the result of each reflection formula. Do not extend a test beyond the contract and assume the same algorithm still applies.

## Expected observation

Trials lie between minus 1024 and 2816. Reflected outputs remain inside zero through 1792. Negating the bounded velocity is representable in a word.
