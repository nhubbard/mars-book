# Step 16 Distinguish remaining steps from the current tick

The remaining-step counter starts at the requested count. The tick number starts at zero because the initial state is published before an update. Keep the selected rounding mode independently of both. A zero request still needs its initial frame.

## Write or inspect

Append the request, mode, and initial tick setup. Predict those three saved-register values for the default request and for a request of zero.

```asm
    dla $t0, steps
    lw $s4, 0($t0)
    dla $t0, round_mode
    lw $s6, 0($t0)
    move $s5, $zero
```

## Expected observation

The default has eight remaining steps, floor mode, and tick zero. A zero request has zero remaining steps and the same initial tick; it does not mean zero publications.
