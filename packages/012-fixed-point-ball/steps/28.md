# Step 28 Run the separate overflow demonstration

The supplied `DEMO` constant selects the numeric experiment before normal animation initialization. This keeps the larger-domain arithmetic example separate from the ball’s valid motion inputs. Stop before the result registers are reused for exit.

## Write or inspect

Set `DEMO` to one, assemble, and stop at `overflow_ready`. Inspect both signed values and their hexadecimal register views. Restore `DEMO` to zero afterward for normal animation and submission checks.

## Expected observation

The wrapped register view is ffffffff80000100; the wider positive sum is 0000000080000100. The ordinary ball state has not been advanced in this mode.
