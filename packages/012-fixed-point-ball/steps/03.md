# Step 3 Identify the three function contracts

The project separates a one-axis state update, a renderer, and a wide-domain arithmetic probe. Keeping those interfaces separate lets the grader supply independent arguments and lets the debugger inspect one concern at a time. The initial caller and the return stubs are already present.

## Write or inspect

Inspect `advance_axis`, `render_ball`, and `add_fixed_probe`. Find the edit regions and their supplied return instructions. Read the input/output table before choosing scratch registers.

## Expected observation

The axis updater returns position and velocity. The renderer returns a pixel ID. The probe returns a wrapped word and an exact wider sum. Each function must preserve saved registers and the stack pointer.
