# Step 9 Clear a complete destination frame

The frame shows the current point rather than its trail. Start the renderer by writing black to all 64 destination words. Use the full pointer argument, not the main frame’s global label. Another valid implementation can classify every cell in one pass later.

## Write or inspect

Append the clear loop in the `render` region. Test with a poisoned frame and a destination pointing at `spare_frame`. This partial renderer returns without drawing the point yet.

```asm
    move $t0, $a0
    li $t1, 64
clear_pixel:
    sw $zero, 0($t0)
    daddiu $t0, $t0, 4
    addiu $t1, $t1, -1
    bne $t1, $zero, clear_pixel
    nop
```

## Expected observation

All 64 destination words are zero. The other frame and all guards are unchanged. The returned pixel ID has not been implemented.
