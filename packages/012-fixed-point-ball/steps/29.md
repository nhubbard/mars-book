# Step 29 Distinguish a trapped addition from a wrapped result

The trapping word instruction is a different experiment. With the same overflowing operands, it reports an arithmetic-overflow error rather than returning the wrapped word. A simulator fault is an observable outcome that must be distinguished from a normal return containing an unexpected value.

## Write or inspect

In the separate demo only, temporarily replace the probe’s word `addu` with `add`. Observe the arithmetic-overflow error. Restore `addu` and `DEMO=0` immediately afterward; the submitted probe must return both specified results.

## Expected observation

The intentional trapping experiment stops with an arithmetic-overflow report. Restoring the nontrapping word operation restores the two normal probe results.
