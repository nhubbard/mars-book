# Step 7 Check contacts that an image can hide

A point on a wall can have the correct position and the wrong velocity. The next step reveals the mistake, but checking both return values identifies it immediately. Zero velocity at either wall remains zero.

## Write or inspect

Test lower and upper exact contacts, lower and upper overshoots, a stationary interior position, and zero velocity on a wall. Keep each position and velocity inside its stated domain.

## Expected observation

Every new position is in zero through 1792, and the speed magnitude is unchanged. Nonzero velocity points inward at an exact returned wall position.
