# Step 10 Apply the selected rounding adjustment

Copy the raw coordinates to temporary registers. Floor needs no adjustment. For nearest rounding in this nonnegative domain, add half a pixel before discarding the fractional bits. The argument coordinates remain raw inputs and are not replaced by display cells.

## Write or inspect

Append the mode test and the two optional half-pixel additions. Compare mode zero and mode one at the same position. The next increment will perform the shifts.

```asm
    move $t2, $a1
    move $t3, $a2
    beq $a3, $zero, quantize
    nop
    addiu $t2, $t2, 128
    addiu $t3, $t3, 128
quantize:
```

## Expected observation

Mode zero leaves the coordinate copies unchanged. Mode one adds 128 to each. The destination is still all black in this incomplete version.
