# Step 21 Advance y without mixing velocity components

The same axis routine can update y because the raw scale and wall bounds are identical. Supply the vertical component, then save its two results separately. A horizontal reflection must not reverse vertical velocity, or vice versa.

## Write or inspect

Append the vertical call. Inspect the live state after both calls with the default seed. The fallback still exits without publishing the updated state.

```asm
    move $a0, $s1
    move $a1, $s3
    jal advance_axis
    nop
    move $s1, $v0
    move $s3, $v1
```

## Expected observation

The first live updated position is raw (512,768), with unchanged velocities (192,320). Published tick-zero words still retain (320,448).
