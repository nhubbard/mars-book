\section{Step 6 Reject impossible extents before reading pointers}\label{pcm-wav-s06}
Use the unsigned complete count in \texttt{a1} to reject counts above 266240 with status two and counts below forty-four with status one. Perform these comparisons before reading either input or metadata. A caller can therefore supply unusable pointers with an already invalid count and still receive the specified result. The supplied invocation frame is entered only after these early checks pass.
