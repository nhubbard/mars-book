\section{Step 62 Close and return the selected count}\label{pcm-wav-s62}
After the written count reaches the selected complete count, close the descriptor once and set its marker to minus one. Return status zero and the selected count. Keep I/O failure paths separate: a partial output is not rolled back, but every acquired descriptor still requires cleanup. The supplied restore sequence retains full saved-register values for either outcome.

Author region \texttt{sv\_finish}. Use \texttt{s62-1} and stop at \texttt{after\_sv\_finish}.

\paragraph{Observe} The trace save returns eighty-two bytes and leaves no live output descriptor.

\paragraph{Check} Does a later write failure restore an old truncated file?
\begin{itemize}
  \item[A.] Only when the status is three.
  \item[B.] No; the contract permits the accepted output prefix.
  \item[C.] Yes; close rolls back truncation.
\end{itemize}
