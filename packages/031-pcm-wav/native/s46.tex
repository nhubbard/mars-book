\section{Step 46 Write the canonical format identity}\label{pcm-wav-s46}
Place the fmt identifier at offset twelve and payload length sixteen at sixteen. Write PCM tag one and channel count at twenty and twenty-two. This writer always uses the sixteen-byte base format even when its input description came from an eighteen-byte format. Canonical output preserves supported audio, not the original container's optional extension or unknown chunks.

Author region \texttt{e\_fmt}. Use \texttt{s46-1} and stop at \texttt{after\_e\_fmt}.

\paragraph{Observe} The format payload starts at twenty and declares PCM with two channels.

\paragraph{Check} How long is the canonical format payload?
\begin{itemize}
  \item[A.] Eighteen bytes whenever the input used eighteen.
  \item[B.] Forty-four bytes.
  \item[C.] Sixteen bytes.
\end{itemize}
