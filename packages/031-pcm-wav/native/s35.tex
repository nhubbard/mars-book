\section{Step 35 Accumulate clipping events in a wide count}\label{pcm-wav-s35}
Add the kernel's clipped-result count from \texttt{v1} to \texttt{s7} with sixty-four-bit arithmetic. The total covers all blocks and channels. It counts results that needed saturation, not frames with any saturation and not the sum of clipped magnitudes. The largest supported stereo file can produce 131072 clipping events, so a sixteen-bit total is insufficient.

Author region \texttt{f\_accumulate}. Use \texttt{s35-1} and stop at \texttt{after\_f\_accumulate}.

\paragraph{Observe} The averaging coefficients produce zero clips for this first block; the accumulated total remains zero.

\paragraph{Check} What is the maximum number of sample results in a supported stereo file?
\begin{itemize}
  \item[A.] 32768.
  \item[B.] 131072.
  \item[C.] 65536.
\end{itemize}
