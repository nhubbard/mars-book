\section{Step 45 Write the outer canonical header}\label{pcm-wav-s45}
Write RIFF at destination offsets zero through three, the little-endian size \texttt{s4-8} at four through seven, and WAVE at eight through eleven. Use byte stores for the unaligned output contract. The size describes the complete file minus eight bytes; it does not include the readable syscall guard beyond the file.

Author region \texttt{e\_riff}. Use \texttt{s45-1} and stop at \texttt{after\_e\_riff}.

\paragraph{Observe} The trace header begins RIFF, size fifty-two, WAVE. Only its first twelve bytes have been authored so far.

\paragraph{Check} Which RIFF size belongs to a sixty-byte canonical file?
\begin{itemize}
\item[A.] Fifty-two.
\item[B.] Sixty.
\item[C.] Sixteen.
\end{itemize}
