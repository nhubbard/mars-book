\section{Step 57 Close before parsing the complete file}\label{pcm-wav-s57}
Close the acquired descriptor exactly once and set \texttt{s3} to minus one. Then call \texttt{wav\_parse} with buffer base, actual accepted count and caller metadata. Propagate a failed parse status and zero result. On success return the accepted complete byte count, not the parser's frame count. If the parser is unfinished during construction, the close marker prevents development cleanup from closing the same handle again.

Author region \texttt{l\_finish}. Use \texttt{s57-1} and stop at \texttt{after\_l\_finish}.

\paragraph{Observe} The successful trace load returns eighty-two bytes and the parsed descriptor, with no live file descriptor.

\paragraph{Check} What count does a successful load return?
\begin{itemize}
\item[A.] Complete file bytes accepted.
\item[B.] Frames returned by the nested parser.
\item[C.] Unused buffer capacity.
\end{itemize}
