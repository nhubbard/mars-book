\section{Step 5 Return the canonical file extent}\label{pcm-wav-s05}
Compute twice the channel count times the frame count with sixty-four-bit arithmetic, then add forty-four header bytes. Return status zero and that total in \texttt{v1}. For two channels and four frames, sixteen PCM bytes produce a sixty-byte canonical file. This result is smaller than the worked input because the canonical writer omits its JUNK and note chunks.

Author region \texttt{b\_size}. Use \texttt{s05-1} and stop at \texttt{after\_b\_size}.

\paragraph{Observe} The completed helper returns status zero and sixty bytes. A valid zero-frame prefix returns forty-four bytes.

\paragraph{Check} What accounts for the difference between eighty-two and sixty bytes?
\begin{itemize}
  \item[A.] Stereo becomes mono.
  \item[B.] The canonical result omits ancillary chunks.
  \item[C.] Filtering removes six frames.
\end{itemize}
