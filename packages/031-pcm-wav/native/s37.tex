\section{Step 37 Locate the retained input suffix}\label{pcm-wav-s37}
Compute the address of the final seven halfwords of the current input window. The full window has seven old samples plus \texttt{fp} new samples, so its last-seven suffix begins \texttt{2*fp} bytes after the window base. Keep that source address in a temporary register. It refers to input history, not to the kernel's output buffer.

Author region \texttt{f\_history\_base}. Use \texttt{s37-1} and stop at \texttt{after\_f\_history\_base}.

\paragraph{Observe} For a four-sample block, the retained suffix begins eight bytes into the window: three zeros followed by the four new input samples.

\paragraph{Check} Which buffer supplies the next history?
\begin{itemize}
\item[A.] The filtered output buffer.
\item[B.] The coefficient array.
\item[C.] The chronological input window.
\end{itemize}
