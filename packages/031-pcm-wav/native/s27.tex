\section{Step 27 Reject a malformed trailer without publication}\label{pcm-wav-s27}
Use the missing-pad recipe, which removes the note pad and adjusts the outer size to the new complete count. The outer extent is therefore consistent. Run the parser to its caller return and inspect the descriptor sentinel. This isolates the chunk-padding check from the earlier outer-size check; merely deleting a byte without updating RIFF would exercise a different failure.

Use \texttt{s27-1} and stop at \texttt{parse\_return}.

\paragraph{Observe} The missing final pad produces status one and zero count; all descriptor bytes remain unchanged.

\paragraph{Check} Why adjust RIFF size in this malformed example?

  \item[B.] To make the file valid.
  \item[C.] To change the channel count.
\end{itemize}
