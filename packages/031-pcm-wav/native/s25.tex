\section{Step 25 Check completion and the overhead budget}\label{pcm-wav-s25}
Require both format and data to have been accepted. Compute complete count minus PCM byte length and require that outside-data overhead be at most 4096. The chunk walk has already proved the selected slice lies within the file, so this subtraction has a bounded nonnegative meaning. A file can fit the overall byte limit yet exceed the separate overhead allowance.

Author region \texttt{p\_finish}. Use \texttt{s25-1} and stop at \texttt{after\_p\_finish}.

\paragraph{Observe} The trace has sixty-six overhead bytes, within the 4096-byte allowance.

\paragraph{Check} Which bytes count toward outside-data overhead?
\begin{itemize}
  \item[A.] Only unknown chunk payloads.
  \item[B.] Only the first forty-four bytes.
  \item[C.] Every complete-file byte outside the selected PCM payload.
\end{itemize}
