\section{Step 30 Initialize per-call progress}\label{pcm-wav-s30}
Load validated frame count into \texttt{s1} and channel count into \texttt{s2}. Initialize current channel \texttt{s5} and total clips \texttt{s7} to zero. The supplied zero-frame route then goes directly to \texttt{filter\_done}. It must avoid all input, coefficient and output accesses, while still validating the prefix. A new invocation starts with fresh progress even when the same session filtered an earlier file.

Author region \texttt{f\_state}. Use \texttt{s30-1} and stop at \texttt{after\_f\_state}.

\paragraph{Observe} The trace starts with four frames, two channels, channel index zero and zero clips.

\paragraph{Check} Which input may be read for a valid zero-frame filter?
\begin{itemize}
  \item[A.] The description prefix only.
  \item[B.] All sixteen coefficient bytes.
  \item[C.] One PCM sample to detect silence.
\end{itemize}
