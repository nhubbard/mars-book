\section{Step 32 Choose a bounded group of new samples}\label{pcm-wav-s32}
Set block count \texttt{fp} to the smaller of remaining frames and sixty-four. The seven-sample history occupies the front of the window; the new samples follow it. A sixty-four-sample block therefore needs seventy-one input halfwords, not sixty-four. Keep the block count across the nested kernel call in a saved register.

Author region \texttt{f\_block}. Use \texttt{s32-1} and stop at \texttt{after\_f\_block}.

\paragraph{Observe} The four-frame trace selects a block of four new samples for the current channel.

\paragraph{Check} How many halfwords does a full input window contain?
\begin{itemize}
\item[A.] Sixty-eight.
\item[B.] Seventy-one.
\item[C.] Sixty-four.
\end{itemize}
