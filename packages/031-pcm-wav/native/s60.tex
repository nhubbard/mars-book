\section{Step 60 Acquire output only after validation}\label{pcm-wav-s60}
Open the retained path for writing in truncate mode and retain the actual descriptor in \texttt{s3}. Set written count \texttt{s4} to zero. An open failure returns status three without entering the write loop. The caller must provide a readable byte immediately after the selected file extent because the current educational write syscall reads its request plus one guard byte.

Author region \texttt{sv\_open}. Use \texttt{s60-1} and stop at \texttt{after\_sv\_open}.

\paragraph{Observe} The permitted output is now open with zero bytes written; the guard remains outside the selected count.

\paragraph{Check} Is the readable guard part of the saved file?
\begin{itemize}
  \item[A.] No; it lies outside the exact file extent.
  \item[B.] Yes; every saved WAV ends with a guard byte.
  \item[C.] Only after an odd-sized chunk.
\end{itemize}
