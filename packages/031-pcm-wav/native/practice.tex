\section{Change one observation at a time}
\subsection*{Exercise: Move an ancillary chunk}
Move the worked note chunk before fmt, updating only the outer extent and resulting
offsets as required. The recovered format and PCM samples must remain the same.
Repeat with an even-sized unknown payload and explain why its stride has no pad.

\subsection*{Exercise: Distinguish signed values from stored codes}
Select a negative right-channel input and show its two stored bytes, its unsigned
sixteen-bit value and its signed sample value. Trace the different FIR result produced
by incorrectly using the unsigned interpretation. Do not judge the error from duration.

\subsection*{Exercise: Split inside a short history}
Process the four-frame trace as four one-frame blocks, then as a three-frame block
followed by one frame. Write the seven history values retained at each boundary.
Explain why a history assembled from filtered output is a different recurrence.

\subsection*{Exercise: Preserve the empty case}
Construct an accepted zero-frame mono file, parse it, filter it without touching a
PCM or coefficient pointer, and encode it. Record which calls return zero in
\texttt{v1}, which return forty-four, and why all can still return success.
