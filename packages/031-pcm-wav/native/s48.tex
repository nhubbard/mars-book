\section{Step 48 Write the frame width and sample width}\label{pcm-wav-s48}
Store block alignment \texttt{2*C} at offset thirty-two and bits per sample sixteen at thirty-four, each as a little-endian two-byte field. These are different widths: one counts bytes per frame, the other bits per sample. For mono the first value changes to two while the second remains sixteen.

Author region \texttt{e\_frame\_format}. Use \texttt{s48-1} and stop at \texttt{after\_e\_frame\_format}.

\paragraph{Observe} The stereo header contains block alignment four and sample width sixteen.

\paragraph{Check} Which field remains sixteen when converting this description to mono?
\begin{itemize}
  \item[A.] Bits per sample.
  \item[B.] Block alignment.
  \item[C.] Channel count.
\end{itemize}
