\section{Step 12 Accept only the two format payload sizes}\label{pcm-wav-s12}
Use bit zero of \texttt{s4} to reject a second format chunk. Require its payload length to be sixteen or eighteen. The sixteen-byte path can branch directly to \texttt{parse\_format\_size}; the eighteen-byte path must retain its size for the later extension check. This rejects undersized base descriptions and unimplemented extensions before their individual fields are read.

Author region \texttt{p\_fmt\_size}. Use \texttt{s12-1} and stop at \texttt{parse\_format\_size}.

\paragraph{Observe} The worked sixteen-byte format reaches parse\_format\_size. Its format-seen flag remains clear until all fields pass.

\paragraph{Check} When should the format-seen flag be committed?
\begin{itemize}
  \item[A.] After all supported format fields pass.
  \item[B.] As soon as the identifier matches.
  \item[C.] Before checking for a duplicate.
\end{itemize}
