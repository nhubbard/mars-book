\section{Step 1 Distinguish the file from its description}\label{pcm-wav-s01}
Open a working copy of the starter and inspect \texttt{source}, \texttt{metadata} and \texttt{mode} before running it. The source contains the complete eighty-two-byte worked file; metadata initially supplies only the sixteen-byte rate, channel and frame prefix. The bound caller passes that prefix's address. It does not ask the helper to parse source. Stop at \texttt{bound\_call} and follow the address in \texttt{a0} to the three fields it describes.

Use \texttt{s01-1} and stop at \texttt{bound\_call}.

\paragraph{Observe} At the call, a0 points to metadata: rate 16000, channels two and four frames. The eighty-two-byte source remains a separate object.

\paragraph{Check} What must the bound helper inspect?
\begin{itemize}
\item[A.] The first forty-four source bytes.
\item[B.] The file named by input\_path.
\item[C.] The description prefix addressed by a0.
\end{itemize}
