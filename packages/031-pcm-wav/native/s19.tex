\section{Step 19 Check the optional empty extension}\label{pcm-wav-s19}
A sixteen-byte format needs no extension read. For an eighteen-byte payload, require the final two-byte extension count to be zero. Use the trace18 observation so execution reaches this region's after-label rather than taking the short-format branch. Its inserted two zero bytes shift the data payload from offset fifty-six to fifty-eight; the parser must discover that offset from chunks.

Author region \texttt{p\_extension}. Use \texttt{s19-1} and stop at \texttt{after\_p\_extension}.

\paragraph{Observe} The eighteen-byte format has a zero extension count and an eighty-four-byte complete file. The later PCM offset will be fifty-eight.

\paragraph{Check} What changes when the empty extension adds two bytes?
\begin{itemize}
\item[A.] The number of audio frames.
\item[B.] The filter coefficients.
\item[C.] The later chunk and PCM offsets.
\end{itemize}
