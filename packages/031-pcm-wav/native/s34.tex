\section{Step 34 Call the kernel with a chronological window}\label{pcm-wav-s34}
Pass the private window, coefficient pointer, private output at stack offset 256 and positive block count to \texttt{fir\_q15}. The supplied return guard requires the raw processed count to equal \texttt{fp}. An imported routine that is still missing returns minus one and reaches the development exit. Do not interpret a valid processed count of four as WAV development status four.

Author region \texttt{f\_kernel}. Use \texttt{s34-1} and stop at \texttt{after\_f\_kernel}.

\paragraph{Observe} The first left-channel call processes four outputs and returns zero clips. Its private outputs are 1500, 1500, 500 and 4596.

\paragraph{Check} Which condition confirms completion of the kernel block?
\begin{itemize}
  \item[A.] Its v0 equals WAV status zero.
  \item[B.] Its v1 equals the byte length.
  \item[C.] Its processed count equals the requested block count.
\end{itemize}
