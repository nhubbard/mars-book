# Publish three RGB component bytes

Store the expanded red, green and blue values at consecutive offsets zero, one and two. These are packed RGB888 bytes, not a display word. The destination is exactly three times the pixel count; a word store here could change a fourth byte that belongs to the next pixel or lies outside the slice.

## Write or inspect

Replace the temporary branch and nop in `unpack_store`. Preserve surrounding labels and the provided entry and return.

```asm
    sb $t1, 0($a1)
    sb $t2, 1($a1)
    sb $t3, 2($a1)
```

Use the `s17-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

The worked packed value writes bytes 123, 44 and 66.
