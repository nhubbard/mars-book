# Expand red through two nonoverlapping parts

Retain a copy shifted right by two, shift red left by three, then OR those parts. Eight red fields now become eight full eight-bit code values in halfwords. The high bytes remain zero, which will matter when the later packing operation selects even byte positions.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_red`. Preserve surrounding labels and the provided entry and return.

```asm
    srli.h $w4, $w1, 2
    slli.h $w1, $w1, 3
    or.v $w1, $w1, $w4
```

Use the `s34-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Each w1 halfword equals the scalar red expansion for that pixel.
