# Gather eight zero-extended channel values

Shuffle from w0 as the right source and w1 as the left source, using the prepared destination controls. The alternating component and zero selectors make eight halfwords per channel. The next arithmetic uses halfword lanes, so a zero high byte is part of the representation invariant rather than cosmetic padding.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_shuffle`. Preserve surrounding labels and the provided entry and return.

```asm
    vshf.b $w4, $w1, $w0
    vshf.b $w5, $w1, $w0
    vshf.b $w6, $w1, $w0
```

Use the `s23-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

The low halfwords of w4, w5 and w6 are the eight unsigned red, green and blue component values in pixel order.
