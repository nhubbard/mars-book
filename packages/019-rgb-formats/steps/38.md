# Alternate the red and green bytes

Interleave the right, low halves of the compacted registers with red as the right source and green as the left. The sixteen-byte result alternates red and green in pixel order. The final shuffle can combine that sequence with the separate blue halfwords to construct complete RGB triples.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_interleave`. Preserve surrounding labels and the provided entry and return.

```asm
    ilvr.b $w4, $w2, $w1
```

Use the `s38-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

w4 bytes are R0,G0,R1,G1 through R7,G7.
