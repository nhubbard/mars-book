# Guard the expansion input before loading

The unpack entry retains the original count, then its current vector placeholder transfers to the scalar tail. Test remaining count before entering the body. A zero-length conversion must not read even the first input byte, regardless of how much mapped memory follows it.

## Write or inspect

Replace the temporary branch and nop in `unpack_bound`. Preserve surrounding labels and the provided entry and return.

```asm
    beq $a2, $zero, unpack_return
    nop
```

Use the `s12-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

A zero-count expansion returns zero with no caller-data access.

## Check your understanding

Does a mapped byte beyond an empty slice permit a load?

- **A** Yes, if the allocation is large.
- **B** Only when its value is zero.
- **C** No.
