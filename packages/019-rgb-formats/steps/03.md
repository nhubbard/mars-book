# Inspect the supplied leaf entries and returns

Each entry copies the incoming count to v0 before a0, a1 and a2 become working pointers and remaining count. The functions are leaves, so their incoming ra remains live. No saved register or native stack slot is needed by this guided design; equivalent nonleaf implementations must preserve their own return and frame correctly.

## Expected observation

The provided exits return through ra. Temporary vector gates initially choose the scalar path; other unfinished regions choose their function return.
