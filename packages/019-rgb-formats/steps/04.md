# Return before reading an empty slice

The initial vector placeholder transfers directly to the scalar tail. Test the remaining pixel count before loading any input byte. At zero, use the supplied return; at positive count, enter the pixel body. The original count is already retained in v0, so this guard must not replace it with another value.

## Write or inspect

Replace the temporary branch and nop in `pack_bound`. Preserve surrounding labels and the provided entry and return.

```asm
    beq $a2, $zero, pack_return
    nop
```

Use the `s04-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

A zero-count pack returns zero without a caller-data read or write. A positive call still stops at the next unfinished region.
