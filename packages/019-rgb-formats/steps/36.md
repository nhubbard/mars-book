# Expand blue without losing its source

Use the five-bit expansion shifts for blue, keeping the shifted copy in the reusable temporary vector w4. Its prior red or green temporary value is no longer live. All three component vectors now contain eight expanded values, each in a zero-extended halfword.

## Write or inspect

```asm

    slli.h $w3, $w3, 3
    or.v $w3, $w3, $w4
```
