# Load three unsigned component bytes

Load the red, green and blue bytes at offsets zero, one and two from the current full source pointer. Use unsigned byte loads. The input is packed RGB, so these are three components of one pixel, not three little-endian pieces of a display word. No pointer advances in this edit.

## Write or inspect

Replace the temporary branch and nop in `pack_load`. Preserve surrounding labels and the provided entry and return.

```asm
    lbu $t0, 0($a0)
    lbu $t1, 1($a0)
    lbu $t2, 2($a0)
```

Use the `s05-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Input bytes 123, 45 and 67 leave those unsigned values in t0, t1 and t2.
