# Read eight packed halfwords as bytes

Load the sixteen-byte packed group into w0. Its bytes are low then high for each pixel, so the same register bits form eight RGB565 halfword lanes in the pinned little-endian environment. The load width is sixteen bytes even though the instruction suffix is b.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_load`. Preserve surrounding labels and the provided entry and return.

```asm
    ld.b $w0, 0($a0)
```

Use the `s32-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

The eight w0 halfwords equal the input packed values in pixel order.
