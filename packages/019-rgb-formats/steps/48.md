# Explain the measured block boundaries

Compare complete scalar and vector calls for short counts, exact blocks and blocks with tails. In these implementations, thirty-one pixels need three full groups and seven scalar pixels, while thirty-two need four full groups. Also inspect byte-access counts: overlapping windows add reads or writes even when native work falls.

## Expected observation

Packing thirty-two pixels uses 120 MSA-path instructions versus 581 scalar; expansion uses 148 versus 805. These are simulator work counts, not elapsed-time claims.
