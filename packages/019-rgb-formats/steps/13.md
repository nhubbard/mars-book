# Reconstruct the little-endian halfword

Load the low and high bytes unsigned. Shift the high byte left by eight and OR it into the low byte. This reconstructs a zero-extended value from zero through 65535 without requiring a halfword-aligned source. Each of its component fields can now be extracted from the same numerical value.

## Write or inspect

Replace the temporary branch and nop in `unpack_load`. Preserve surrounding labels and the provided entry and return.

```asm
    lbu $t0, 0($a0)
    lbu $t1, 1($a0)
    sll $t1, $t1, 8
    or $t0, $t0, $t1
```

Use the `s13-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Bytes 68 79 reconstruct decimal 31080 in t0.
