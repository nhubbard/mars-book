# Advance by each format size

Advance the full source pointer by three and the destination pointer by two. Decrement the pixel count once, then repeat the pixel body while a pixel remains. The loop body is now complete for every count; the vector gate is still a direct transfer to this scalar path.

## Write or inspect

Replace the temporary branch and nop in `pack_next`. Preserve surrounding labels and the provided entry and return.

```asm
    daddiu $a0, $a0, 3
    daddiu $a1, $a1, 2
    addiu $a2, $a2, -1
    bne $a2, $zero, pack_pixel
    nop
```

Use the `s11-1`, `s11-2` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Two RGB pixels produce four packed bytes. The remaining count becomes zero while v0 still contains two.
