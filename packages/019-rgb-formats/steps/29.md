# Repeat full groups and hand off the tail

Advance input by twenty-four bytes, output by sixteen and remaining count by eight pixels. Test eligibility again; repeat a full block when possible, otherwise fall through to the existing scalar bound check. A count exactly divisible by eight reaches that check with zero and performs no tail access.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_next`. Preserve surrounding labels and the provided entry and return.

```asm
    daddiu $a0, $a0, 24
    daddiu $a1, $a1, 16
    addiu $a2, $a2, -8
    sltiu $t0, $a2, 8
    beq $t0, $zero, pack_block
    nop
```

Use the `s29-1`, `s29-2`, `s29-3` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Eight, nine and sixteen pixels all pack correctly. The nine-pixel call executes one full group and one scalar pixel.
