# Prepare fresh controls for this block

Copy the preserved controls into w4, w5 and w6. These working registers will supply controls to vshf and then receive its output. Copying each iteration prevents a prior block's component values from becoming the next block's selectors. A move copies all 128 bits; it does not shuffle them.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_copy`. Preserve surrounding labels and the provided entry and return.

```asm
    move.v $w4, $w16
    move.v $w5, $w17
    move.v $w6, $w18
```

Use the `s22-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

The working registers now equal their corresponding preserved control vectors.
