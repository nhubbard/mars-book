# Position red in eight halfwords

Apply the same red quantizer and positioning shifts to all eight halfwords. The byte shuffle established values no larger than 255; right shift three leaves five bits and left shift eleven positions them. A whole-register shift would mix neighboring lanes and implement a different operation.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_red`. Preserve surrounding labels and the provided entry and return.

```asm
    srli.h $w4, $w4, 3
    slli.h $w4, $w4, 11
```

Use the `s24-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Each w4 halfword contains only its pixel's red contribution.
