# Keep the low blue fields in lane order

Shift blue halfwords right by three. Their retained values already belong at bit zero, so no positioning shift follows. All three component vectors now have matching pixel indices and nonoverlapping field positions, allowing two vector OR operations to assemble the eight packed results.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_blue`. Preserve surrounding labels and the provided entry and return.

```asm
    srli.h $w6, $w6, 3
```

Use the `s26-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Each w6 halfword is the corresponding blue value divided by eight.
