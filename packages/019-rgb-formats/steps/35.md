# Expand all green values

Repeat the green high bits using right shift four, left shift two and OR. The result fills one byte in each halfword and reaches 255 for the maximum six-bit input. Reusing the five-bit expansion shifts would produce the wrong scale and repeated bits.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_green`. Preserve surrounding labels and the provided entry and return.

```asm
    srli.h $w4, $w2, 4
    slli.h $w2, $w2, 2
    or.v $w2, $w2, $w4
```

Use the `s35-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Each w2 halfword equals the scalar green expansion.
