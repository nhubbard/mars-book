# Finish the group loop and scalar tail

Advance packed input by sixteen bytes, RGB output by twenty-four and count by eight pixels. Repeat while another full group remains, then fall through to the scalar tail. Both public functions now implement every legal count with vector groups and byte-safe tails. Their original count remains in v0.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_next`. Preserve surrounding labels and the provided entry and return.

```asm
    daddiu $a0, $a0, 16
    daddiu $a1, $a1, 24
    addiu $a2, $a2, -8
    sltiu $t0, $a2, 8
    beq $t0, $zero, unpack_block
    nop
```

Use the `s42-1`, `s42-2`, `s42-3` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

Eight, nine and sixteen packed pixels expand correctly; the nine-pixel input needs one scalar tail pixel.
