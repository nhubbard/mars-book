# Load the complete group without overreading

Load sixteen bytes at source offset zero and another sixteen at offset eight. The two loads overlap but stay inside the twenty-four-byte group. Keep the actual register contents in mind: w1 begins at input byte eight, so a selector for its lane is not generally the original input offset.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_load`. Preserve surrounding labels and the provided entry and return.

```asm
    ld.b $w0, 0($a0)
    ld.b $w1, 8($a0)
```

Use the `s21-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

w0 contains source bytes zero through fifteen; w1 contains eight through twenty-three.
