# Load reusable channel selector vectors

Load the supplied red, green and blue control tables into w16, w17 and w18. Each table has sixteen bytes: a component selector followed by selector 64 for the zero high byte of each halfword. The controls are immutable constants; retain them while working destinations are overwritten each block.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_controls`. Preserve surrounding labels and the provided entry and return.

```asm
    dla $t0, gather_red
    ld.b $w16, 0($t0)
    dla $t0, gather_green
    ld.b $w17, 0($t0)
    dla $t0, gather_blue
    ld.b $w18, 0($t0)
```

Use the `s20-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

The three preserved registers hold the selector rows derived in the gathering fixture.

## Check your understanding

What does selector 64 request in these controls?

- **A** Input byte sixty-four.
- **B** A zero result byte.
- **C** The next packed halfword.
