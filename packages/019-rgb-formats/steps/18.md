# Complete the scalar expansion loop

Advance the full input pointer by two and output pointer by three, then consume one pixel. Repeat until the remaining count is zero. Both conversion functions now work through their scalar paths. Preserve this behavior while adding complete vector groups, and keep these bodies as the short tail.

## Write or inspect

Replace the temporary branch and nop in `unpack_next`. Preserve surrounding labels and the provided entry and return.

```asm
    daddiu $a0, $a0, 2
    daddiu $a1, $a1, 3
    addiu $a2, $a2, -1
    bne $a2, $zero, unpack_pixel
    nop
```

Use the `s18-1`, `s18-2` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

A two-pixel input expands to six bytes and returns count two.
