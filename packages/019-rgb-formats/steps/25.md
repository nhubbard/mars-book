# Position green with its own width

Shift all green halfwords right by two, then left by five. Green retains six bits per pixel, so the red shift count is not interchangeable. The separate red and green vectors now occupy disjoint fields in each lane. Blue remains available for its final quantization.

## Write or inspect

Replace the temporary branch and nop in `vector_pack_green`. Preserve surrounding labels and the provided entry and return.

```asm
    srli.h $w5, $w5, 2
    slli.h $w5, $w5, 5
```

## Expected observation

Each w5 halfword contains its pixel's six-bit green contribution at bit five.
