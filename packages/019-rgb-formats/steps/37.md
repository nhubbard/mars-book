# Collect the even component bytes

Pack even bytes from each red and green register using that register as both sources. The low eight bytes become the eight component values in order, and the high eight repeat them. Blue remains in halfwords for the final shuffle. This changes layout while preserving the component values.

## Write or inspect

Replace the temporary branch and nop in `vector_unpack_compact`. Preserve surrounding labels and the provided entry and return.

```asm
    pckev.b $w1, $w1, $w1
    pckev.b $w2, $w2, $w2
```

Use the `s37-1` scenes in [the guided input recipes](../fixtures/guided-inputs.md). Set the listed source bytes and count, then run the supplied caller to its named checkpoint.

## Expected observation

w1 and w2 each contain their eight expanded component bytes twice.
