# Serialize every bit of the saved length

Write the most significant length byte first, using doubleword logical variable shifts with counts fifty-six down to zero. Store the low byte of each shifted result. Word-sized variable shifts would wrap the shift count modulo thirty-two and lose the intended high half. After this loop the final block is complete, but has not yet been compressed.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_length` and `# END fin_length`, retaining markers and surrounding labels.

```asm
    li $t0, 56
    daddiu $t1, $s0, 104
final_length_byte:
    dsrlv $t2, $s3, $t0
    sb $t2, 0($t1)
    daddiu $t1, $t1, 1
    addiu $t0, $t0, -8
    bgez $t0, final_length_byte
    nop
```

Use `s34-1`, `s34-2`. Prepare each recipe in a separate image from the cumulative source through this step.
