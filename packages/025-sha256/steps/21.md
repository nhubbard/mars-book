# Install the initial eight-word state

Walk the fixed initial-state constants and the supplied context together, copying eight numeric words. This code initializes meaningful state without clearing every workspace byte. The context pointer supplied in a0 remains available after the temporary walker has advanced. No source message is consumed by initialization.

## Write and inspect

Replace the temporary instructions between `# BEGIN init_copy` and `# END init_copy`, retaining markers and surrounding labels.

```asm
    dla $t0, sha_iv
    move $t1, $a0
    li $t2, 8
init_word:
    lw $t3, 0($t0)
    sw $t3, 0($t1)
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 4
    addiu $t2, $t2, -1
    bne $t2, $zero, init_word
    nop
```

Use `s21-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

Context words zero through seven equal the standard initial state; the count fields have not yet been reset by this edit.
