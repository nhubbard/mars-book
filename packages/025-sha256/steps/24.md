# Guard the source before copying a byte

Check remaining input before loading through the source pointer. For a nonempty interval, load one unsigned byte, add the current used count to the context base and store at buffer offset forty-eight. This edit copies one byte but does not yet advance either count. For zero length, the branch reaches the supplied normal update exit without touching source memory.

## Write and inspect

Replace the temporary instructions between `# BEGIN upd_copy` and `# END upd_copy`, retaining markers and surrounding labels.

```asm
    beq $s2, $zero, update_done
    nop
    lbu $t0, 0($s1)
    daddu $t1, $s0, $s3
    sb $t0, 48($t1)
```

Use `s24-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The first selected input byte is copied at the old used position; an empty call performs no source read.
