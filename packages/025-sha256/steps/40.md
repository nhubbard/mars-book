# Request a bounded scratch prefix

Pass the retained descriptor, scratch address and positive capacity to the read syscall. Inspect its returned count before deciding how to use the scratch bytes. At this construction stage the temporary exit still closes the descriptor after this one read, so a provisional return is not a successful hash of the file.

## Write and inspect

Replace the temporary instructions between `# BEGIN file_read` and `# END file_read`, retaining markers and surrounding labels.

```asm
    move $a0, $s4
    move $a1, $s1
    move $a2, $s2
    li $v0, 14
    syscall
```

Use `s40-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The first read writes only its returned prefix; an injected short read can return fewer bytes than the capacity.

## Check your understanding

Which bytes in scratch are new input?

- **A** Every byte up to the capacity.
- **B** Only the number reported by the positive result.
- **C** Every byte that happens to be nonzero.

Use `checks/construction/s40.kts` to check this illustrated stage. Its allocation-specific observations differ from the completed free-writing contract.

The full native reading is in `native/s40.tex`. It remains directly editable and is not regenerated from these descriptors.
