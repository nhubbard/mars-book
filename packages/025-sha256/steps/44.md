# Publish only after successful EOF and close

Finalize the private context into the caller's output, select success status zero and branch to the common close path. Error branches already select their own status and preserve output. The close path then restores the caller's full saved values and returns. The complete wrapper now has a single publication event at successful EOF.

## Write and inspect

Replace the temporary instructions between `# BEGIN file_final` and `# END file_final`, retaining markers and surrounding labels.

```asm
    move $a0, $s0
    move $a1, $s3
    jal sha256_final
    nop
    move $s5, $zero
    b file_close
    nop
```

Use `s44-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

Status is zero and all thirty-two digest bytes match the complete file; missing and failed reads leave output unchanged.
