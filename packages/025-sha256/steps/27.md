# Begin a fresh buffer after compression

Set the working used count to zero and return to the source guard. Any remaining bytes now start at buffer position zero. When input is exhausted, the common exit stores the final used count before restoring the frame. This completes update for both partial and complete source blocks, including a final incomplete tail.
