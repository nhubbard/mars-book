# Hash exactly the returned read count

Move the positive read result into the update length argument before another call can replace v0. Pass the private context and scratch pointer, then call the completed update routine. The original file capacity remains retained separately; it controls requests, not the length of valid data returned by a particular read.

## Write and inspect

Replace the temporary instructions between `# BEGIN file_update` and `# END file_update`, retaining markers and surrounding labels.

```asm
    move $a2, $v0
    move $a0, $s0
    move $a1, $s1
    jal sha256_update
    nop
```

Use `s42-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The private byte total includes the first returned prefix; no digest output has been written.
