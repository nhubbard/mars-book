# Count the supplied message bytes once

Load the original byte count, add the incoming update length using doubleword arithmetic and store the full count. This addition belongs before the copy loop. Adding the complete length during every loop iteration would overcount, and adding padding later would change the encoded message length. The provided frame already retains the source, length and current used count.

## Write and inspect

Replace the temporary instructions between `# BEGIN upd_count` and `# END upd_count`, retaining markers and surrounding labels.

```asm
    ld $t0, 32($s0)
    daddu $t0, $t0, $s2
    sd $t0, 32($s0)
```

Use `s23-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

For a fresh context and three input bytes, the total becomes three before any buffer byte is written.
