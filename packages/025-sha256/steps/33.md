# Leave exactly eight bytes for the length

Fill buffer positions from the working used count through fifty-five with zeros. The used count may begin after a short message and its marker, or at zero after the extra-block path. Both cases reach final_write_length with the same destination layout: eight remaining bytes at positions fifty-six through sixty-three.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_zero_last` and `# END fin_zero_last`, retaining markers and surrounding labels.

```asm
    sltiu $t0, $s2, 56
    beq $t0, $zero, final_write_length
    nop
    daddu $t0, $s0, $s2
    sb $zero, 48($t0)
    addiu $s2, $s2, 1
    b final_zero_to_length
    nop
```

Use `s33-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The final eight buffer positions are reserved for the bit length; all padding positions before them are zero.
