# Copy the incoming state into working registers

Load the eight state words into s0 through s7, representing a through h. Keep the incoming state in memory for feed-forward at the end of the block. The supplied frame will restore these preserved registers on every return; while the function runs, they are its working storage. A signed word load preserves the low-word pattern required by word operations.
