# Publish thirty-two big-endian digest bytes

For each state word, extract its high byte first, then the next two bytes and its low byte. Byte stores support an unaligned output pointer. Advance by one word and four output bytes until all eight words are written. Clear the consumed context's used field, then let the supplied epilogue return status zero.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_output` and `# END fin_output`, retaining markers and surrounding labels.

```asm
    move $t0, $s0
    li $t1, 8
final_output_word:
    lwu $t2, 0($t0)
    dsrl $t3, $t2, 24
    sb $t3, 0($s1)
    dsrl $t3, $t2, 16
    sb $t3, 1($s1)
    dsrl $t3, $t2, 8
    sb $t3, 2($s1)
    sb $t2, 3($s1)
    daddiu $t0, $t0, 4
    daddiu $s1, $s1, 4
    addiu $t1, $t1, -1
    bne $t1, $zero, final_output_word
    nop
    sw $zero, 40($s0)
```

Use `s36-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The output contains exactly thirty-two digest bytes, matching the host result for the selected message.
