# Reset the original length and incomplete-buffer count

Clear the eight-byte original byte count and the four-byte used count. Use sd for the former so an earlier long message cannot leave stale high bits. With an empty buffer prefix, old buffer contents have no meaning. Initialization now returns zero and can start a fresh message in a previously used context.

## Write and inspect

Replace the temporary instructions between `# BEGIN init_counts` and `# END init_counts`, retaining markers and surrounding labels.

```asm
    sd $zero, 32($a0)
    sw $zero, 40($a0)
```

Use `s22-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The initialized context has the initial state, total zero and used zero.
