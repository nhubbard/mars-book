# Finish a block that has no room for the length

Fill the remainder of the current buffer with zero bytes until the working used count reaches sixty-four. Branch before writing when the buffer is already full. This path is selected only when the marker left too little room for the length, so the length field will go in a separate block.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_zero_first` and `# END fin_zero_first`, retaining markers and surrounding labels.

```asm
    sltiu $t0, $s2, 64
    beq $t0, $zero, final_first_compress
    nop
    daddu $t0, $s0, $s2
    sb $zero, 48($t0)
    addiu $s2, $s2, 1
    b final_zero_first
    nop
```

Use `s31-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The first padding block contains the original tail, one 80 byte and zeros through its final byte.
