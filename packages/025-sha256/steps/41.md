# Separate read errors, EOF and positive input

A negative read result branches to status two and cleanup. Zero branches to finalization. Positive results continue to update. The order matters: passing a negative result as an update length would convert an error into an invalid memory request. The EOF branch remains unfinished until the finalization region is authored.

## Write and inspect

Replace the temporary instructions between `# BEGIN file_result` and `# END file_result`, retaining markers and surrounding labels.

```asm
    bltz $v0, file_read_error
    nop
    beq $v0, $zero, file_finish
    nop
```

Use `s41-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

Positive input reaches the update boundary; a failed read closes the descriptor and preserves the output.
