# Form capital sigma one of old e

Apply the three word rotations to s4, which still holds the old e value. XOR the results into t0. The working vector must remain unchanged until both round temporaries are ready. This capital-sigma function has no logical-shift term; it differs from the schedule's small-sigma-one function.

## Write and inspect

Replace the temporary instructions between `# BEGIN comp_sigma1` and `# END comp_sigma1`, retaining markers and surrounding labels.

```asm
    rotr $t0, $s4, 6
    rotr $t2, $s4, 11
    xor $t0, $t0, $t2
    rotr $t2, $s4, 25
    xor $t0, $t0, $t2
```

Use `s13-1`. Prepare each recipe in a separate image from the cumulative source through this step.
