# Recognize when the buffer becomes full

Advance the full source pointer, reduce remaining input, and increase the used count. If the buffer has fewer than sixty-four bytes, continue at update_byte. Reaching sixty-four must leave the copy loop and enter compression before another store occurs. Otherwise the next byte would overwrite the schedule area following the buffer.

## Write and inspect

Replace the temporary instructions between `# BEGIN upd_walk` and `# END upd_walk`, retaining markers and surrounding labels.

```asm
    daddiu $s1, $s1, 1
    daddiu $s2, $s2, -1
    addiu $s3, $s3, 1
    li $t0, 64
    bne $s3, $t0, update_byte
    nop
```

Use `s25-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

For a 64-byte update to an empty context, the buffer is full, remaining input is zero and used is sixty-four at the compression boundary.
