# Keep a schedule destination and decode count

Copy the destination address to t0 and set t1 to sixteen. The source pointer remains in a0. These registers describe the two arrays we are walking: each source group contains four bytes, and each destination element occupies four bytes. Keeping separate walkers lets the routine accept a block at an unaligned address while retaining aligned schedule stores.

## Write and inspect

Replace the temporary instructions between `# BEGIN sch_setup` and `# END sch_setup`, retaining markers and surrounding labels.

```asm
    move $t0, $a1
    li $t1, 16
```

Use `s03-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

t0 points to the first schedule word and t1 is sixteen; no schedule word has been written.
