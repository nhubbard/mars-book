# Compute small sigma zero from its predecessor

The current destination is W16. Load W1 from byte offset minus sixty, then form its two rotations and logical shift. XOR combines their bit patterns; it is not an arithmetic sum. The result remains in t3 for the next region. A pointer-relative predecessor uses a byte displacement, even though the equation names word indices.

## Write and inspect

Replace the temporary instructions between `# BEGIN sch_sigma0` and `# END sch_sigma0`, retaining markers and surrounding labels.

```asm
    lw $t2, -60($t0)
    rotr $t3, $t2, 7
    rotr $t4, $t2, 18
    xor $t3, $t3, $t4
    srl $t4, $t2, 3
    xor $t3, $t3, $t4
```

Use `s07-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation
