# Advance constants and schedule entries together

Increment each word pointer by four and decrement the round count. Repeat at compress_round while the count is nonzero. Both pointers must advance once per round, since Kt and Wt refer to the same round index. After sixty-four rounds the working vector is ready for feed-forward; it has not yet replaced the running state.

## Write and inspect

Replace the temporary instructions between `# BEGIN comp_walk` and `# END comp_walk`, retaining markers and surrounding labels.

```asm
    daddiu $t6, $t6, 4
    daddiu $t7, $t7, 4
    addiu $t8, $t8, -1
    bne $t8, $zero, compress_round
    nop
```

Use `s18-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The two pointers have advanced by 256 bytes and t8 is zero; caller state remains unchanged before feed-forward.
