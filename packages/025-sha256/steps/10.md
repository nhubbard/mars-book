# Check the entire schedule before calling compression

Use both padded abc and a binary block containing high-bit bytes. Compare all sixty-four schedule words, not only the first and last. This separates decoding and recurrence errors from the compression loop that will consume the schedule. A correct complete schedule is also a useful debugger observation for later blocks.

Use `s10-1`, `s10-2`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

All sixty-four words agree with the independent model on aligned and offset inputs.
