# Call the schedule builder without losing the caller

The supplied frame has saved the state and workspace pointers as well as ra. Pass the block and workspace to the completed schedule routine. After that call, reload the state and workspace pointers, select the fixed constant table and set the round count to sixty-four. Reloading is necessary because the schedule builder may change temporary registers and argument registers.

## Write and inspect

Replace the temporary instructions between `# BEGIN comp_prepare` and `# END comp_prepare`, retaining markers and surrounding labels.

```asm
    move $a0, $a1
    move $a1, $a2
    jal sha256_schedule
    nop
    ld $t9, 72($sp)
    ld $t6, 80($sp)
    dla $t7, sha_k
    li $t8, 64
```

Use `s11-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The workspace contains the full schedule; t9 points to state, t6 to W0, t7 to K0 and t8 is sixty-four.
