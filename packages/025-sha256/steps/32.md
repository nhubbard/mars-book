# Compress the first padding block and restart its count

Call compression on the now-complete buffer, then clear the working used count. Keep the saved original bit length in s3 across the call. The same physical buffer will hold the final block next; it is its logical occupancy that has become zero. Its old bytes still need to be overwritten where the final block requires zeros.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_first` and `# END fin_first`, retaining markers and surrounding labels.

```asm
    move $a0, $s0
    daddiu $a1, $s0, 48
    daddiu $a2, $s0, 112
    jal sha256_compress
    nop
    move $s2, $zero
```

Use `s32-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

The state includes the first padding block and s2 is zero before the final-block fill loop.
