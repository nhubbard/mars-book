# Record the bit length and append the marker

Read the original byte total and shift it left by three with dsll. Keep that full bit count in s3 while writing the marker at the next free buffer position. Advance the working used count after the store. The context's original-byte total remains unchanged: the marker belongs to padding rather than the message.

## Write and inspect

Replace the temporary instructions between `# BEGIN fin_marker` and `# END fin_marker`, retaining markers and surrounding labels.

```asm
    ld $s3, 32($s0)
    dsll $s3, $s3, 3
    daddu $t0, $s0, $s2
    li $t1, 128
    sb $t1, 48($t0)
    addiu $s2, $s2, 1
```

Use `s29-1`. Prepare each recipe in a separate image from the cumulative source through this step.

## Expected observation

For abc, s3 is twenty-four, the marker occupies buffer index three and the working used count is four.
