\section{Step 24 Guard the source before copying a byte}\label{sha-s24}

Check remaining input before loading through the source pointer. For a nonempty interval, load one unsigned byte, add the current used count to the context base and store at buffer offset forty-eight. This edit copies one byte but does not yet advance either count. For zero length, the branch reaches the supplied normal update exit without touching source memory.

\subsection{Write and inspect}
Replace only the temporary instructions between \texttt{\# BEGIN upd\_copy} and \texttt{\# END upd\_copy}. Keep the supplied labels outside that region.
