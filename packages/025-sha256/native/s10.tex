\section{Step 10 Check the entire schedule before calling compression}\label{sha-s10}

Use both padded abc and a binary block containing high-bit bytes. Compare all sixty-four schedule words, not only the first and last. This separates decoding and recurrence errors from the compression loop that will consume the schedule. A correct complete schedule is also a useful debugger observation for later blocks.

\subsection{Observe and compare}
Use recipes \texttt{s10-1}, \texttt{s10-2}. Prepare each in a separate source image from the current cumulative program. An internal checkpoint is inspected before its temporary or normal return; otherwise pause at \texttt{main\_done}.

Use the completed entries available at this point; keep their inputs and observation boundary explicit. The surrounding explanation identifies the state being compared.
