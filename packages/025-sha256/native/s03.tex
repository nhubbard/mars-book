\section{Step 3 Keep a schedule destination and decode count}\label{sha-s03}

Copy the destination address to \texttt{t0} and set \texttt{t1} to sixteen. The source pointer remains in \texttt{a0}. These registers describe the two arrays we are walking: each source group contains four bytes, and each destination element occupies four bytes. Keeping separate walkers lets the routine accept a block at an unaligned address while retaining aligned schedule stores.

\subsection{Write and inspect}
Replace only the temporary instructions between \texttt{\# BEGIN sch\_setup} and \texttt{\# END sch\_setup}. Keep the supplied labels outside that region.

\Needspace{6\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t0, $a1
    li $t1, 16
\end{minted}

Use recipe \texttt{s03-1} with the cumulative program through this edit. The exact recipe names the entry, prepared input and checkpoint. Observe the checkpoint before continuing to its temporary or normal return.

\subsection{Expected observation}
\texttt{t0} points to the first schedule word and \texttt{t1} is sixteen; no schedule word has been written.
