\section{Step 36 Publish thirty-two big-endian digest bytes}\label{sha-s36}

For each state word, extract its high byte first, then the next two bytes and its low byte. Byte stores support an unaligned output pointer. Advance by one word and four output bytes until all eight words are written. Clear the consumed context's used field, then let the supplied epilogue return status zero.

\subsection{Write and inspect}
Replace only the temporary instructions between \texttt{\# BEGIN fin\_output} and \texttt{\# END fin\_output}. Keep the supplied labels outside that region.
