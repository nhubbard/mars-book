# Describe a window with a half-open interval

Let f be the starting index and n be the requested count. The selected entries
are the half-open interval from f through f + n, with the end excluded. The
bounds `0 ≤ f ≤ 16` and `0 ≤ n ≤ 16 − f` ensure that every selected index
is between zero and fifteen.

An empty interval has n = 0. It selects no entry, including when f equals
sixteen. Forming a pointer to that exclusive end is different from loading a
byte there. The reference tests the count before its first table access.

For f = 14 and n = 2, the selected indices are fourteen and fifteen. The pointer
after the final iteration is table base + 16. The code reaches that pointer as
a boundary and does not use it for another lookup.
