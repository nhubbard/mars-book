# Lookup turns an index into a pattern

The table maps each hexadecimal index to one byte of segment decisions.
Because an entry occupies one byte, index ten lies ten bytes after the table
base. Scaling by four, as in a framebuffer word array, would select another
location and eventually leave the table.

`lbu` brings the pattern into a register as a value from zero through 255.
The store then uses its low byte. The default masks have their decimal point
clear, so they are all below 128. A custom mask can use the high bit without
changing the table's element size or the port width.

The table is input to this assignment. It may be replaced by an instructor's
fixture. Hard-coding the familiar sixteen masks in the program body would fail
to honor that interface even if the default picture looked right.
