# Use the transaction width required by the device

The right display is a byte port. Its next three byte addresses control other
state. A word store beginning at the right port would cover all four, potentially
changing the left display, keypad selection, and timer control as well.

The contract therefore requires byte transactions at one address. This is an
interface requirement rather than an arbitrary demand for the reference source.
Other register allocations and loop structures are allowed; a different memory
transaction that touches adjacent ports is not equivalent under this contract.

The new grader trace keeps wider overlapping stores in its history instead of
silently ignoring them. A program cannot pass the byte-port check by using a
word store that happens to leave the right port with the expected low byte.
