# Memory-mapped I/O belongs to the simulated platform

A memory-mapped peripheral associates an address with device behavior. The
program uses a store instruction, but the destination is a device register rather
than an ordinary array element. A new write to the right-display port replaces
its segment mask; it does not append another digit somewhere else.

The port map and segment wiring are properties of MARS Digital Lab, not
universal addresses required by the MIPS instruction set. In the Default memory
layout, the MMIO base is 0xffff0000 and the right display is sixteen bytes above
it. Other MIPS platforms can have different peripheral maps.

These addresses belong to the simulated machine. The source-header comment
connects the MARS tool to the execution so the writes can be shown. The comment
itself neither stores a byte nor changes the instruction semantics.
