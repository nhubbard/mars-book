# Step 12 Repeat while entries remain

`bne` returns to the table load if the remaining count is nonzero. Its `nop` delay slot has no state update. After the last iteration, the count is zero and execution falls through to the supplied exit.

## Write or inspect

Append the loop branch and slot.

```asm
    bne $s3, $zero, display_loop
    nop
```

## Expected observation

The default sequence has sixteen byte transactions and ends with mask 71. It does not include a seventeenth write or an automatic blanking write.
