# Step 14 Test a short and an empty range

The final two entries are E and F. An end window with count zero has no selected entry at all. These cases separate loop bounds from the default whole-table example.

## Write or inspect

Use separate copies or the public checks to test `first_digit` = 14 with `digit_count` = 2, and `first_digit` = 16 with `digit_count` = 0.

## Expected observation

The short range emits 79, then 71. The empty range emits no port writes. Neither case changes its inputs or table.
