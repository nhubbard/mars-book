# Step 6 Apply the starting byte index

The table has one byte per glyph. Adding `first_digit` to its base therefore reaches the first selected entry without multiplying the index by four. `daddu` performs a full-width address addition.

## Write or inspect

Append the pointer adjustment.

```asm
    daddu $s1, $s1, $s2
```

## Expected observation

For a window starting at fourteen, the cursor is fourteen bytes beyond glyphs. For the empty end window it can equal the one-past-table address without being dereferenced.

Why is no scale-by-four operation needed?

- **A** The display uses four-byte glyph codes.
