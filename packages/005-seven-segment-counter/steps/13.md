# Step 13 Observe a single transaction in Debug

A fast Run can complete before every glyph is repainted. A breakpoint gives the program a stable state while the tool refreshes. The labels distinguish the just-written value from the updated loop counters.

## Write or inspect

Set a breakpoint on the first executable line below `displayed`. Debug the default fixture and inspect the right glyph and raw mask. Resume to later hits, or stop below `iteration_done` to inspect the updated counters.

## Expected observation

After the first store the right mask is 3f. At the eleventh `displayed` hit it is 77 for A. At done it is 71 for F, and the left unit remains blank.
