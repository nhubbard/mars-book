# Step 9 Write one byte to the port

`sb` transfers the low byte of the glyph register to the fixed device address. A word store would affect adjacent byte ports and violate this interface, even when the right display happened to look correct.

## Write or inspect

Append the store and its following checkpoint label.

```asm
    sb $t1, 0($s0)
displayed:
```

## Expected observation

The first program transaction is a byte write of 3f at 0xffff0010. At `displayed`, index and remaining count have not yet been updated.

## Check your understanding

Why does transaction width matter?

- **A** The display reads only an instruction mnemonic, not memory.
- **B** Adjacent addresses control other parts of the peripheral.
- **C** A byte store is merely a faster spelling of every word store.
