# Step 10 Advance the table cursor only

The next glyph is one byte later in the table. The device address stays unchanged because every new mask replaces the same right-display register. This differs from the framebuffer lesson, where successive destination addresses named different cells.

## Write or inspect

Append the cursor update.

```asm
    daddiu $s1, $s1, 1
```

## Expected observation

The cursor moves to the next table entry. `$s0` still identifies the right port; it must not move to the left or control ports.
