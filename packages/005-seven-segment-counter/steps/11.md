# Step 11 Update the logical index and remaining count

The index records the next entry and the count records how many are still required. After these updates, the state is ready for another loop test. `iteration_done` names that boundary.

## Write or inspect

Append the two word-sized updates.

```asm
    addiu $s2, $s2, 1
    addiu $s3, $s3, -1
iteration_done:
```

## Expected observation

After the first default transaction, the next index is one and the remaining count is fifteen. Immediately after the store but before these updates, they were zero and sixteen.

## Check your understanding

Which observation boundary has remaining count fifteen after the first output?

- **A** `displayed`, before the updates.
- **B** The initial state before any table load.
- **C** `iteration_done`, after the updates.
