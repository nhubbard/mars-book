# Step 4 Locate the table and input words

The glyphs are a byte array. The starting index and count are word-sized inputs. Separate pointers identify these objects so that table traversal does not move the fixed device address.

## Write or inspect

Append the two data-address loads.

```asm
    la $s1, glyphs
    la $t0, first_digit
```

## Expected observation

`$s1` identifies table byte zero and `$t0` identifies the first input word. The device pointer remains fixed.
