# Step 7 Handle an empty window before the loop

A zero count requests no transactions. The pre-test branches directly to the existing exit. `beq` is a retained delayed branch, so its following `nop` executes whether the branch is taken or not.

## Write or inspect

Append the zero-count test and its explicit delay slot.

```asm
    beq $s3, $zero, done
    nop
```

## Expected observation

The empty window exits before the table load and port store. A nonempty window continues to the loop body.

Why test the count before the first store?

- **A** An empty window must produce no I/O writes.
