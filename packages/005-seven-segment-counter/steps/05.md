# Step 5 Read the requested window

The `first_digit` word is the starting table index, and the following word is the number of entries to emit. The supplied objects are adjacent, so `digit_count` is four bytes beyond `first_digit` in this starter.

## Write or inspect

Append the input loads.

```asm
    lw $s2, 0($t0)
    lw $s3, 4($t0)
```

## Expected observation

For the default fixture, the index is zero and the remaining count is sixteen. All valid inputs are small nonnegative values.

What does `digit_count` = 16 mean here?

- **A** Emit only the entry whose index is sixteen.
- **B** Wait sixteen seconds between stores.
- **C** Emit sixteen table entries.
