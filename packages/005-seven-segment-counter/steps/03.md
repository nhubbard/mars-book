# Step 3 Load the complete device address

`dli` is a pseudo-instruction for a doubleword constant. The supplied literal makes the intended 64-bit pointer explicit, with zeroes in its high half. Loading the address does not yet write the device.

## Write or inspect

Append the device-address load.

```asm
    dli $s0, RIGHT_DISPLAY
```

## Expected observation

`$s0` is 0x00000000ffff0010. The device has received no program store.

Which part of the program changes the device?

- **A** The label `RIGHT_DISPLAY` executes as a store.
- **B** The later store to its port, not this constant load.
- **C** Every load into `$s0` changes the device automatically.
