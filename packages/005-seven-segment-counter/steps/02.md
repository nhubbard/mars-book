# Step 2 Connect the model and locate its port

The source-header comment configures the plugin tool. The .eqv declaration gives a source-level constant a name; it reserves no memory. `RIGHT_DISPLAY` is the simulated device address used by the program.

## Write or inspect

Inspect the supplied header, constant, table, and input words. Keep the Default layout and little-endian setting for this lesson.

## Expected observation

Digital Lab Sim should be connected for this execution. Its right port is 0xffff0010; its neighboring control ports are not part of this counter.

## Check your understanding

Does .eqv `RIGHT_DISPLAY` allocate a byte for the display?

- **A** Yes; it creates the peripheral in ordinary data memory.
- **B** Yes; it also writes the first glyph.
- **C** No; it names a constant used during assembly.
