# Step 8 Load one glyph byte

`lbu` reads the selected table byte as an unsigned value from zero through 255. The `display_loop` label names the start of one iteration. The `port_write` label gives a debugger stop before the transaction.

## Write or inspect

Append the table lookup.

```asm
display_loop:
    lbu $t1, 0($s1)
port_write:
```

## Expected observation

For default index zero, `$t1` contains 0x3f. The table cursor is an address; the loaded value is the segment mask.

## Check your understanding

What is loaded into `$t1`?

- **A** The address of the right display.
- **B** An automatically generated ASCII digit.
- **C** The selected mask byte, not the index itself.
