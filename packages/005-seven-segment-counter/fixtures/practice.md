# Change the glyph without changing the port

1. Set the middle-segment bit in the zero mask. Predict the resulting shape and byte.
2. Add the decimal point to the zero mask and express the new byte as a signed source
   initializer within the assembler's accepted byte range.
3. Derive the output for `first_digit` = 10 and `digit_count` = 3.
4. Explain why the device pointer must stay fixed while the table cursor advances.
5. Write an exclusive-end-pointer implementation and check the empty end window.
6. Explain which additional observations would be needed to grade a required delay
   between successive device writes.

Use separate copies for glyph-design experiments. Preserve the assignment's
transaction and protected-data contracts in the submitted baseline.
