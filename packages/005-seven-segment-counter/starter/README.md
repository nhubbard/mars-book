# Seven-segment counter starter

Open this folder in IntelliJ with MARS enabled. Use the Default memory layout and
little-endian byte order. The supplied header connects Digital Lab Sim. The program
has no console input or output; its inputs are the glyph table and two words in data.

Keep the supplied data labels and add code in the program region before the exit.
The template exits without writing a display. Every required code segment can be
assembled and run with the exit already present. Normal Run is fast; use the guide's
Debug checkpoints to observe intermediate glyphs. There is no required display delay.
