# Step 7 Compute horizontal and signed vertical differences

`subu` computes a word difference without an overflow exception. Here all coordinates are zero through seven, so each difference is small and exact. The ordered horizontal difference cannot be negative.

## Write or inspect

Append the difference calculations.

```asm
    subu $s4, $s2, $s0
    subu $s5, $s3, $s1
```

## Expected observation

The default horizontal difference is five and signed vertical difference is three.

## Check your understanding

Can the ordered horizontal difference be negative?

- **A** No, because endpoint ordering made x0 no greater than x1.
- **B** Yes, for every steep line.
- **C** Only for a white color.
