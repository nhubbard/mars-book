# Step 3 Load the four endpoint coordinates

`la` obtains the endpoint-block address. The four `lw` instructions read consecutive four-byte fields into working registers. Keep the source words unchanged when reordering the working endpoints.

## Write or inspect

Append the endpoint loads.

```asm
    la $t0, endpoints
    lw $s0, 0($t0)
    lw $s1, 4($t0)
    lw $s2, 8($t0)
    lw $s3, 12($t0)
inputs_loaded:
```

## Expected observation

`$s0`, `$s1` hold the first point; `$s2`, `$s3` hold the second. The default is 1,1,6,4.
