# Step 17 Return to address calculation

An unconditional `beq` with equal zero operands returns to `line_loop`. Its `nop` delay slot performs no extra write or coordinate change. Endpoint equality is checked after each store, so the loop does not plot beyond the endpoint.

## Write or inspect

Append the loop back-edge.

```asm
    beq $zero, $zero, line_loop
    nop
```

## Expected observation

The default final image contains six white cells, with every off-line word preserved.
