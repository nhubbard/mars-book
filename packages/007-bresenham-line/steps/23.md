# Step 23 Explain the integer error relation

Let i be x displacement from the ordered start and j be signed y displacement along sy. The state relation is err = dx − D − D×i + dx×j. An x step subtracts D; a y step adds dx. The fixed relation connects the update instructions to the line geometry.
