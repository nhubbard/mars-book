# Step 16 Apply the independent y decision

The condition for stepping y is e2 ≤ dx. `slt` computes dx < e2, and a true result skips the update. Otherwise add dx to err and add the signed direction to y. This is a second independent decision, not an else branch.

## Write or inspect

Append the y decision and its join label.

```asm
    slt $t3, $s4, $t2
    bne $t3, $zero, skip_y
    nop
    addu $s7, $s7, $s4
    addu $s1, $s1, $s6
skip_y:
```

## Expected observation

The first update finishes at (2,2), err four, with the original e2 still four.
