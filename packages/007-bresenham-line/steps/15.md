# Step 15 Apply the independent x decision

The condition for stepping x is e2 ≥ dy. `slt` computes the opposite strict comparison, e2 < dy; `bne` skips the update only when that opposite is true. An x step adds the negative vertical difference to err and increments x by one.

## Write or inspect

Append the x decision and its join label.

```asm
    slt $t3, $t2, $s5
    bne $t3, $zero, skip_x
    nop
    addu $s7, $s7, $s5
    addiu $s0, $s0, 1
skip_x:
```

## Expected observation

For the first default update, x becomes two and err becomes −1; the saved e2 is still four.
