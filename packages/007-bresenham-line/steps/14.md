# Step 14 Save twice the old error

Both coordinate decisions must use the same error value from the start of this update. `sll` copies its double into a separate register before either decision changes the running error. The small declared domain makes this word shift exact.

## Write or inspect

Append the saved doubled error.

```asm
    sll $t2, $s7, 1
```

## Expected observation

`$t2` is four on the first default update and remains four through both coordinate decisions.

## Check your understanding

Why save this value separately?

- **A** The color instruction needs it as an address.
- **B** The first update can change err before the second decision.
- **C** MIPS forbids comparing the same register twice.
