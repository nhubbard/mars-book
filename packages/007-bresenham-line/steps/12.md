# Step 12 Paint the current point

`sw` writes the complete color word. `pixel_written` marks the boundary after that store, before any endpoint test or coordinate update.

## Write or inspect

Append the store and checkpoint.

```asm
    sw $t9, 0($t0)
pixel_written:
```

## Expected observation

The first default cell is white; the other 63 words keep their previous values.
