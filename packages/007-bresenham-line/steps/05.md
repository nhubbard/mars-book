# Step 5 Order the working endpoints

`slt` tests whether the second x is smaller. A taken branch selects the swap. If x differs and no swap is needed, `bne` skips the equal-x comparison. For equal x, a second `slt` compares y. Each three-move group exchanges one coordinate using a temporary register.

## Write or inspect

Append the complete comparison and swap block.

```asm
    slt $t1, $s2, $s0
    bne $t1, $zero, swap_endpoints
    nop
    bne $s0, $s2, ordered
    nop
    slt $t1, $s3, $s1
    beq $t1, $zero, ordered
    nop
swap_endpoints:
    move $t1, $s0
    move $s0, $s2
    move $s2, $t1
    move $t1, $s1
    move $s1, $s3
    move $s3, $t1
ordered:
```

## Expected observation

At `ordered`, x0 is no greater than x1. When x is equal, y0 is no greater than y1. Source memory is unchanged.
