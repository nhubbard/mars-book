# Step 13 Test the endpoint after painting

The line includes the current point even when it is already the endpoint. If x differs, continue to advance. If x agrees, compare y too and exit only when both coordinates agree. `advance` labels the unfinished path.

## Write or inspect

Append the endpoint test.

```asm
    bne $s0, $s2, advance
    nop
    beq $s1, $s3, done
    nop
advance:
```

## Expected observation

Coincident endpoints paint one cell and exit without a coordinate update.
