# Step 9 Initialize the signed decision state

Negate the vertical magnitude to obtain dy = −D. Then initialize err = dx + dy. The negative convention makes an x step add dy and a y step add dx. This value is a scaled decision state, not a memory address or a displayed distance.

## Write or inspect

Append the signed difference and error initialization.

```asm
    subu $s5, $zero, $s5
    addu $s7, $s4, $s5
```

## Expected observation

For dx=5 and D=3, dy is −3 and err is two.
