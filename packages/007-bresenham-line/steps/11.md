# Step 11 Compute the row-major cell address

Multiplying y by eight gives its row offset in cells. Adding x selects a cell within that row. Shifting by two converts the cell index to a byte offset; `daddu` then adds the full-width base pointer.

## Write or inspect

Append the address calculation.

```asm
    sll $t0, $s1, 3
    addu $t0, $t0, $s0
    sll $t0, $t0, 2
    daddu $t0, $t8, $t0
```

## Expected observation

For (1,1), the cell index is nine and the address is 0x10010024.

## Check your understanding

Why shift the cell index left by two?

- **A** To double the error for a branch.
- **B** Each framebuffer cell occupies four bytes.
- **C** The board has two rows.
