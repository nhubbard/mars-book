# Step 2 Read the frame and input contract

The endpoint block stores four coordinates, not four addresses. The frame is a separate row-major word array, and its existing off-line cells must survive.

## Write or inspect

Locate the frame, guards, endpoint block, and color word.

## Expected observation

An 8 by 8 frame uses 64 words, or 256 bytes.

## Check your understanding

What should happen to a cell outside the selected line?

- **A** It must always become black.
- **B** It must keep its complete original word.
- **C** Only its red byte must survive.
