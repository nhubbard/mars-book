# Step 10 Load the fixed frame base and color

The frame base and color are invariant across the line. `line_loop` names the boundary before a cell address is calculated. It will become the loop-back target after the coordinate-update logic is complete.

## Write or inspect

Append the invariant loads and loop label.

```asm
    la $t8, frame
    la $t0, color
    lw $t9, 0($t0)
line_loop:
```

## Expected observation

`$t8` is 0x10010000 and `$t9` is the default white word 0x00ffffff.
