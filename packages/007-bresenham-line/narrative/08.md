# Translate inclusive comparisons with strict tests

The reference uses `slt` and delayed branches to implement two inclusive inequalities.
For e2 ≥ dy, it tests the opposite, e2 < dy, and skips when that opposite is true.
For e2 ≤ dx, it tests dx < e2 and skips when true. Equality belongs to the update
path in both cases, which implements the published halfway convention.

Every shown retained branch has an explicit `nop` delay slot. The slot executes whether
the branch is taken or not. Moving a coordinate update into a slot would change more
than scheduling: it could make an update occur on a path that was intended to skip it.

The unconditional back-edge uses `beq` with two zero operands. Its `nop` performs no
hidden store. These choices make the instructional trace easier to verify. They are
not a requirement that an equivalent submission use exactly these branch mnemonics.
