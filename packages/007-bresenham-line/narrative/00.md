# From visiting coordinates to choosing them

The MarsBot program used feedback to reach specified corners. A framebuffer line
requires a different decision: which integer cells should represent the continuous
segment between two endpoints? A shallow segment crosses several columns between
successive rows. A steep one crosses several rows between successive columns. Treating
every line as a diagonal would choose the wrong cells.

This chapter builds a rasterizer, a program that converts geometry into discrete
image samples. It uses an integer decision state so that the next cell can be chosen
with additions, comparisons, and branches. The line is overlaid on an existing image;
its off-line words must survive. That requirement keeps address errors visible and
makes the result usable as a drawing operation rather than a whole-screen demo.

Bresenham described an integer decision method for digital plotters in his 1965
paper, [Algorithm for computer control of a digital plotter](https://janmr.com/files/papers/bresenham65.pdf).
The chapter uses a two-test formulation and an explicit endpoint-ordering convention.
Its exact halfway rule is part of this assignment's interface, not a claim that every
line rasterizer uses the same convention.
