# Read a complete error trace

The default errors at painted cells are 2, 4, 1, 3, 0, 2. Their changing signs and
magnitudes encode the balance between horizontal and vertical contributions. They
need not move steadily toward zero, and zero is not the termination condition.

At (2, 2), e2 is eight. The x condition succeeds, but the y condition fails because
eight is greater than dx = 5. The next point is (3, 2). At (5, 3), e2 is zero, so
both coordinate conditions succeed and the final point becomes (6, 4).

The endpoint is then painted before the equality test exits. There is no additional
update or out-of-range store. The trace table gives register and coordinate evidence
for each step; the grid diagram shows the corresponding image without requiring a
reader to infer cells from color alone.
