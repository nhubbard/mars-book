# Extend the same decisions to the remaining cases

For a steep line, the y condition can succeed while the x condition fails. For a
falling line, sy is negative, so successful y decisions move upward on the screen.
Canonicalization handles originally leftward input by using the same internally
rightward set of samples; the task grades the final image rather than plot order.

Horizontal and vertical lines do not need separate painting routines. A zero vertical
magnitude prevents y changes on a nontrivial horizontal line. A zero horizontal
difference prevents x changes on a nontrivial vertical line. The point case exits
before either decision is needed.

All coordinates in this task are already inside the canvas. The program is not a
clipping routine for out-of-bounds endpoints. A larger renderer would have to define
clipping, coordinate width, and line-joining rules before these assumptions could be
extended to arbitrary geometric input.
