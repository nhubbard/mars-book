# Build a decision state from integer contributions

Write D for the nonnegative vertical magnitude. The implementation stores its
negative, dy = −D, and starts err at dx − D. Each x step then adds dy, subtracting
D from the error. Each y step adds dx. A y step changes the coordinate by sy, so its
contribution is positive in the direction of travel even for a falling line.

Let i = x − Ax and j = sy × (y − Ay), measured from the ordered start A. The running
state obeys err = dx − D − D × i + dx × j. This relation is preserved by the two
updates. It is a scaled decision expression, not a perpendicular distance measured
in pixels and not a value intended for display.

The coordinate domain is deliberately small. Differences, doubled errors, cell offsets,
and the rational alternative's products all fit comfortably in signed word arithmetic.
Generalizing to arbitrary 64-bit coordinates would require a new overflow analysis;
using a 64-bit register file alone does not make word instructions unbounded.
