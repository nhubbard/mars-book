# Indices, full addresses and pending values

Multiply an operand index by four, then add the byte displacement to the full stack base with daddu. The older of the top pair is left; the top is right. The common binary path retains the left-slot address in t7 and wide candidate in t3. After the check succeeds, the handler sets proposed next PC in t8. It changes depth and publishes a result only after representability succeeds. The inactive right cell is workspace within capacity, not a promised zero.

A guest target is an unsigned byte offset. The next fetch adds it to the unchanged full code base. A self-branch still retires and consumes budget.
