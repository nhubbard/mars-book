# Share the arithmetic operand path

Route all four arithmetic opcodes to vm_binary. That common path will enforce two live operands and locate the left and right values. A later inner dispatch selects the actual arithmetic operation while retaining the original opcode.

## Write or inspect

Replace the temporary branch in `dispatch_arithmetic`. Preserve surrounding labels and the provided frame and exits.

```asm

    beq $t9, $t1, vm_binary
    nop
    li $t1, 17
    beq $t9, $t1, vm_binary
    nop
    li $t1, 18
    beq $t9, $t1, vm_binary
    nop
    li $t1, 19
    beq $t9, $t1, vm_binary
    nop
```

An ADD byte selects vm_binary; its stack handling remains unfinished.
