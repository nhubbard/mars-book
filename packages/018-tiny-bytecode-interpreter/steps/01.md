# Separate the program from the interpreter

The MIPS source implements a second, smaller instruction set. Its code_a bytes are data to MARS and instructions to run_vm. A native debugger step executes one MIPS instruction; one guest retirement can require many of those steps. Use byte offsets for guest PC and full addresses for native loads.

## Expected observation

The completed default call retires thirty-three guest instructions and returns one live value, six.
