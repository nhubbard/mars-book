# Recognize a wide constant or reject the opcode

Select size five only for PUSH32. If no legal opcode matched any earlier group, select invalid-opcode status and use the provided image-error return. That return records the failing decode offset and resets the output PC to zero because execution has not begun.

## Write or inspect

Replace the temporary branch in `format_wide`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t1, 5
    li $t2, 2
    beq $t9, $t2, format_size
    nop
    li $v0, -1
    beq $zero, $zero, image_error
    nop
```

## Expected observation

PUSH32 selects size five. Byte ff in opcode position reports minus one at that instruction start.
