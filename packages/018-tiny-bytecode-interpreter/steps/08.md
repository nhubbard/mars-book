# Recognize the two-byte records

Select size two for PUSH8, JMP and JZ. Their second byte is payload. A branch payload will later be interpreted as an unsigned offset, while a short push payload is a signed value. Both interpretations share the same structural requirement that one operand byte exists.

## Write or inspect

Replace the temporary branch in `format_short`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t1, 2
    li $t2, 1
    beq $t9, $t2, format_size
    nop
    li $t2, 48
    beq $t9, $t2, format_size
    nop
    li $t2, 49
    beq $t9, $t2, format_size
    nop
```

## Expected observation

PUSH8 followed by seven selects encoded size two.
