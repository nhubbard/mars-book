# Complete ordinary guest retirement

Install the next PC from t8, increment retired count, consume one budget unit, and return to the budget-before-fetch loop. Later handlers join this path only after success. With halt and short push implemented, ordinary guest sequences can now execute complete prefixes.

## Write or inspect

Replace the temporary branch in `retire`. Preserve surrounding labels and the provided frame and exits.

```asm
    move $s6, $t8
    addiu $v1, $v1, 1
    addiu $a3, $a3, -1
    beq $zero, $zero, vm_loop
    nop
```

## Expected observation

PUSH8 seven followed by halt now returns status one, retired count two, PC three and live value seven.
