# Walk complete records through the whole image

Advance by encoded size and return to the bound-before-fetch entry. This skips payload bytes as part of their owning instruction. The supplied targets_begin label resets the cursor before the second pass. At this stage that pass still takes a temporary return, so inspect the completed bitmap rather than treating the call as executed bytecode.

## Write or inspect

Replace the temporary branch in `format_advance`. Preserve surrounding labels and the provided frame and exits.

```asm
    addu $s6, $s6, $t1
    beq $zero, $zero, format_loop
    nop
```

## Expected observation

The default image marks thirteen starts. Sixty-four halt bytes set all sixty-four bitmap bits, including bit sixty-three.
