# Check budget before the next guest fetch

Test remaining guest budget first. With positive budget, require PC below length before loading an opcode. The validated control flow can reach a beginning or the image end; the latter produces the end-fetch fault when an instruction is actually attempted. The input address still requires full-width addition.

## Write or inspect

Replace the temporary branch in `execute_guard`. Preserve surrounding labels and the provided frame and exits.

```asm
    beq $a3, $zero, vm_commit
    nop
    sltu $t0, $s6, $s1
    beq $t0, $zero, end_fault
    nop
    daddu $t0, $s0, $s6
    lbu $t9, 0($t0)
```

## Expected observation

An empty image with zero budget returns status zero; with budget one it reports minus four at zero.
