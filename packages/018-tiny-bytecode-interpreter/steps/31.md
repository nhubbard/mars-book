# Check a duplicate source before checking room

Require one live value before testing capacity. Then choose source index depth minus one and transfer to the shared copy. The copy is still unfinished, so this stage establishes the index rather than claiming a new live value. Empty capacity zero reports underflow because no source exists.

## Write or inspect

Replace the temporary branch in `dup`. Preserve surrounding labels and the provided frame and exits.

```asm
    sltiu $t1, $s7, 1
    bne $t1, $zero, underflow_stack
    nop
    sltu $t1, $s7, $s4
    beq $t1, $zero, overflow_stack
    nop
    addiu $t1, $s7, -1
    beq $zero, $zero, vm_copy
    nop
```

## Expected observation

After pushing seven, DUP selects source index zero. Empty DUP reports minus five, including at capacity zero.
