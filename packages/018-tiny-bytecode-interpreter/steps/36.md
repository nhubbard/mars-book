# Locate left and right without popping them

Require two live values and address index depth minus two. Load the older word as left and the top word as right. Keep depth unchanged while computing a candidate. A failure must return the original live prefix, so consuming operands before checks would publish incorrect state.

## Write or inspect

Replace the temporary branch in `binary_operands`. Preserve surrounding labels and the provided frame and exits.

```asm
    sltiu $t1, $s7, 2
    bne $t1, $zero, underflow_stack
    nop
    addiu $t7, $s7, -2
    sll $t7, $t7, 2
    daddu $t7, $s3, $t7
    lw $t1, 0($t7)
    lw $t2, 4($t7)
```

## Expected observation

After pushes seven and twelve, the common entry loads left seven and right twelve.
