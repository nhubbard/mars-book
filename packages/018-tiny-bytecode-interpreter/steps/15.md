# Select both branch forms for validation

Route JMP and JZ to the same target check. Nonbranch one-byte records advance without a target test. A conditional branch is validated here regardless of what value execution might eventually test; no runtime stack value determines whether its encoded target is legal.

## Write or inspect

Replace the temporary branch in `targets_branches`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t2, 48
    beq $t9, $t2, target_check
    nop
    li $t2, 49
    bne $t9, $t2, target_advance
    nop
```

## Expected observation

The JMP zero image reaches the target-check region before any guest instruction executes.
