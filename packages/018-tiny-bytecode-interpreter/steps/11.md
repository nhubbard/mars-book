# Record an instruction beginning in full width

Create one full-width bit at the current byte offset and combine it with the bitmap. The cursor is below length and length is at most sixty-four, so the shift position is zero through sixty-three. Operand positions receive no mark. The next edit will advance past the complete record.

## Write or inspect

Replace the temporary branch in `format_mark`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t2, 1
    dsllv $t2, $t2, $s6
    or $s5, $s5, $t2
```

## Expected observation

For halt at byte zero, s5 becomes one while the decode cursor remains zero.

## Check your understanding

What does one set bit mean?

- **A** A decoded instruction begins at that offset.
- **B** The byte value equals one.
- **C** A guest instruction retired there.
