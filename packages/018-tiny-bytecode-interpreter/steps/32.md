# Select the second value from the top

Require two live values, then require room for one more. Select source index depth minus two and fall through to the copy. This copies a value without removing either existing operand; it is not a swap or a pop.

## Write or inspect

Replace the temporary branch in `over`. Preserve surrounding labels and the provided frame and exits.

```asm
    sltiu $t1, $s7, 2
    bne $t1, $zero, underflow_stack
    nop
    sltu $t1, $s7, $s4
    beq $t1, $zero, overflow_stack
    nop
    addiu $t1, $s7, -2
```

## Expected observation

After pushes seven and twelve, OVER selects source index zero while the shared copy is still unfinished.
