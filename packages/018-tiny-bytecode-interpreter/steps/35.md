# Exchange two live words without changing depth

Require two values and address the older of the top pair. Load both words before storing either, then write them in the opposite order. Preserve depth and select the next byte. Reusing one loaded value for both stores would lose an operand.

## Write or inspect

Replace the temporary branch in `swap`. Preserve surrounding labels and the provided frame and exits.

```asm
    sltiu $t1, $s7, 2
    bne $t1, $zero, underflow_stack
    nop
    addiu $t1, $s7, -2
    sll $t1, $t1, 2
    daddu $t1, $s3, $t1
    lw $t2, 0($t1)
    lw $t3, 4($t1)
    sw $t3, 0($t1)
    sw $t2, 4($t1)
    addiu $t8, $s6, 1
    beq $zero, $zero, vm_retire
    nop
```

## Expected observation

Seven, twelve, SWAP leaves twelve below seven.
