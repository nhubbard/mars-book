# Require a decoded beginning at the target

Form a bit only after the range test succeeds and intersect it with the completed start bitmap. Zero intersection means that the target points into payload. The image is still rejected before execution, with the branch location in the fault field and output PC zero.

## Write or inspect

Replace the temporary branch in `target_bit`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t4, 1
    dsllv $t4, $t4, $t3
    and $t4, $t4, $s5
    beq $t4, $zero, bad_target
    nop
```

## Expected observation

JMP one in its own two-byte record reports invalid target: byte one is its payload.
