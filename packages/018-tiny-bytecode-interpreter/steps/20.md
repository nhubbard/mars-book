# Complete target validation before execution

Advance by the selected size and repeat. When all records pass, execute_begin resets the shared cursor to guest PC zero. The still-unfinished execution region then returns provisionally. An invalid branch anywhere in the image instead reaches the image-error return before any guest retirement.

The default image completes both validation passes with zero retirements. Changing its conditional target to six reports fault five and PC zero.
