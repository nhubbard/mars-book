# Pop the test value on both branch outcomes

Require one value and load the top word. Reduce depth regardless of the test result. Select PC plus two for a nonzero value and the validated target for zero, then retire. This final handler completes the interpreter: the countdown can now loop through its conditional cleanup.

## Write or inspect

```asm

    bne $t1, $zero, underflow_stack
    nop
    addiu $t1, $s7, -1
    sll $t1, $t1, 2
    daddu $t1, $s3, $t1
    lw $t2, 0($t1)
    addiu $s7, $s7, -1
    addiu $t8, $s6, 2
    bne $t2, $zero, vm_retire
    nop
    lbu $t8, 1($t0)
```
