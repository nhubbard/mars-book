# Assemble an unaligned little-endian constant

Check push capacity first, then load four unsigned payload bytes. Shift the higher bytes into place and combine them. The word shift of the high byte supplies the signed-word representation when bit thirty-one is set. Byte loads keep this path valid for unaligned image addresses. Storage and retirement remain in the next edit.

## Write or inspect

Replace the temporary branch in `push32_decode`. Preserve surrounding labels and the provided frame and exits.

```asm
    sltu $t1, $s7, $s4
    beq $t1, $zero, overflow_stack
    nop
    lbu $t2, 1($t0)
    lbu $t3, 2($t0)
    sll $t3, $t3, 8
    or $t2, $t2, $t3
    lbu $t3, 3($t0)
    sll $t3, $t3, 16
    or $t2, $t2, $t3
    lbu $t3, 4($t0)
    sll $t3, $t3, 24
    or $t2, $t2, $t3
```

## Expected observation

Payload 00 00 00 80 produces the signed value minus 2147483648 in t2 without yet increasing depth.
