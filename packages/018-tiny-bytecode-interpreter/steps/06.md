# Recognize the arithmetic opcode family

Compare against decimal 16 through 19, the four one-byte arithmetic opcodes. A match transfers to the common size check with size one. These comparisons only recognize records; they do not read guest operands or perform arithmetic. Later execution will enforce stack and result requirements.

## Write or inspect

Replace the temporary branch in `format_arithmetic`. Preserve surrounding labels and the provided frame and exits.

```asm
    li $t2, 16
    beq $t9, $t2, format_size
    nop
    li $t2, 17
    beq $t9, $t2, format_size
    nop
    li $t2, 18
    beq $t9, $t2, format_size
    nop
    li $t2, 19
    beq $t9, $t2, format_size
    nop
```

## Expected observation

An ADD byte selects size one without attempting to pop an empty operand stack.
