# Use the common publication and restore path

The supplied validation exits record a fault offset before resetting the output PC. Runtime exits retain their current PC. All paths reach vm_commit, which writes five output words, restores the saved registers and releases the frame. Temporary regions also branch there so incomplete programs return cleanly.
