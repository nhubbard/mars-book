# Retire a branch to its validated target

Load the unsigned target byte as the next PC and join common retirement. Range and boundary membership were established before execution, so this path performs no stack operation. A branch to its own address still retires and consumes budget.

## Write or inspect

Replace the temporary branch in `jump`. Preserve surrounding labels and the provided frame and exits.

```asm
    lbu $t8, 1($t0)
    beq $zero, $zero, vm_retire
    nop
```

## Expected observation

JMP zero with budget five returns status zero, PC zero and retired count five.

## Check your understanding

Does a self-branch consume guest budget?

- **A** No, because PC does not change.
- **B** Only after the second visit.
- **C** Yes, for every successful retirement.
