# Reject targets at or beyond image length

Load the branch operand as an unsigned byte and require target less than length. This also rejects the one-past-end position. Perform this check before shifting a mask: a variable shift is not itself a range test and can discard high shift-count bits.

## Write or inspect

Replace the temporary branch in `target_range`. Preserve surrounding labels and the provided frame and exits.

```asm
    lbu $t3, 1($t0)
    sltu $t4, $t3, $s1
    beq $t4, $zero, bad_target
    nop
```

## Expected observation

For JMP two in a two-byte image, validation reports minus three at branch offset zero.
