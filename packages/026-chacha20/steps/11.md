# Copy the sixteen original words

Copy one word at matching offsets from the input to the working output. Advance the byte offset by four until it reaches sixty-four. The destination now holds the initial working state, while the immutable input remains available for feed-forward.

## Write and inspect

Replace the body of region `scalar_copy`. Retain its BEGIN/END markers and supplied labels.

```asm
    daddu $t1, $s0, $t0
    lw $t2, 0($t1)
    daddu $t1, $s1, $t0
    sw $t2, 0($t1)
    daddiu $t0, $t0, 4
    sltiu $t1, $t0, 64
    bnez $t1, scalar_copy
    nop
```

Use `s11-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

All sixteen output words equal the input state; the copy offset is sixty-four.
