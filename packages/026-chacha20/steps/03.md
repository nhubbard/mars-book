# Load the four selected words

Load all four argument words before changing any caller memory. The arguments are addresses; the low word loaded through each address is the corresponding arithmetic input. Keep a through d in `t0` through `t3` for the illustrated calculation.

## Write and inspect

Replace the body of region `qr_load`. Retain its BEGIN/END markers and supplied labels.

```asm
    lw $t0, 0($a0)
    lw $t1, 0($a1)
    lw $t2, 0($a2)
    lw $t3, 0($a3)
```

Use `s03-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The four working registers contain the published inputs, while all four memory words are unchanged.
