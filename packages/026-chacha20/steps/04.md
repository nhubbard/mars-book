# Update a and rotate d

Add b into a with word wraparound, then use the new a in the XOR that updates d. Rotate the XOR result left by sixteen. For this amount the complementary right rotation is also sixteen.

## Write and inspect

Replace the body of region `qr_group1`. Retain its BEGIN/END markers and supplied labels.

```asm
    addu $t0, $t0, $t1
    xor $t3, $t3, $t0
    rotr $t3, $t3, 16
```

Use `s04-1`, `s04-2`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The low words of a and d are 12131415 and 51721330; b and c retain their input values.
