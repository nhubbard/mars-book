# Add the matching original words

Walk the input and working output together, adding matching low words with wraparound. Store each sum over its working word. The target is little-endian, so the word stores also provide the required byte serialization.

## Write and inspect

Replace the body of region `scalar_feed`. Retain its BEGIN/END markers and supplied labels.

```asm
    daddu $t1, $s0, $t0
    lw $t2, 0($t1)
    daddu $t1, $s1, $t0
    lw $t3, 0($t1)
    addu $t2, $t2, $t3
    sw $t2, 0($t1)
    daddiu $t0, $t0, 4
    sltiu $t1, $t0, 64
    bnez $t1, scalar_feed
    nop
```

Use `s22-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The 64-byte output equals the published block, beginning 10 f1 e7 e4; the input is unchanged.
