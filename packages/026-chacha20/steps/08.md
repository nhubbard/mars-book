# Publish the four quarter-round results

Store each final working word through its original argument pointer. A four-byte store publishes the low pattern even when a register's high half is sign-extended. The supplied normal exit then returns zero.

## Write and inspect

Replace the body of region `qr_store`. Retain its BEGIN/END markers and supplied labels.

```asm
    sw $t0, 0($a0)
    sw $t1, 0($a1)
    sw $t2, 0($a2)
    sw $t3, 0($a3)
```

Use `s08-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The four selected words contain the final tuple; bytes between them remain unchanged.
