# Check the bounded count and empty request

Interpret `a3` as an unsigned count. Reject values above 4096 before examining any pointer, and return success immediately for zero. These paths use no frame because no nested work has begun.

## Write and inspect

Replace the body of region `stream_validate`. Retain its BEGIN/END markers and supplied labels.

```asm
    sltiu $t0, $a3, 4097
    beqz $t0, stream_length_error
    nop
    beqz $a3, stream_empty
    nop
```

Use `s33-1`, `s33-2`, `s33-3`, `s33-4`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

A valid positive count reaches preflight; zero returns without pointer access and excessive counts return one.

## Check your understanding

May an empty request dereference its state pointer?

- **A** No; the interface promises no supplied pointer access.
- **B** Yes; every call must read the key.
- **C** Only if the counter is zero.
