# Select diagonal inputs by row shuffling

Leave row zero fixed and rearrange rows one through three with selectors fifty-seven, seventy-eight and one hundred forty-seven. These immediates encode source lanes for successive destinations. Check the marker recipe as well as the cryptographic state.

## Write and inspect

Replace the body of region `msa_select`. Retain its BEGIN/END markers and supplied labels.

```asm
    shf.w $w1, $w1, 57
    shf.w $w2, $w2, 78
    shf.w $w3, $w3, 147
```

Use `s27-1`, `s27-2`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

Lane zero across the working rows selects state positions zero, five, ten and fifteen after the column round.
