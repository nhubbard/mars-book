# Mix column zero

Pass word indices zero, four, eight and twelve to the leaf routine. Multiply each index by four when forming its address. The supplied check after the call propagates an unfinished quarter-round instead of continuing with an invalid working state.

## Write and inspect

Replace the body of region `scalar_call1`. Retain its BEGIN/END markers and supplied labels.

```asm
    daddiu $a0, $s1, 0
    daddiu $a1, $s1, 16
    daddiu $a2, $s1, 32
    daddiu $a3, $s1, 48
    jal chacha_quarter
    nop
```

Use `s13-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

Only column zero of the working copy has changed.
