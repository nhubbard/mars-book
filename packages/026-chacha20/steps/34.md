# Validate the last required counter

Compute the block count by rounding the bounded positive length upward, then form the last required counter in 64 bits. Load the initial counter unsigned. Reject a nonzero high word before allocating the frame or writing output.

## Write and inspect

Replace the body of region `stream_counter_check`. Retain its BEGIN/END markers and supplied labels.

```asm
    daddiu $t0, $a3, 63
    dsrl $t0, $t0, 6
    lwu $t1, 48($a0)
    daddu $t0, $t0, $t1
    daddiu $t0, $t0, -1
    dsrl $t0, $t0, 32
    bnez $t0, stream_counter_error
    nop
```

## Expected observation

A 65-byte request at counter one passes; the same count at ffffffff returns two before stores.

- **A** No; the largest counter is always reserved.
- **B** Yes; the last available block may be used.
- **C** Only when the nonce is zero.
