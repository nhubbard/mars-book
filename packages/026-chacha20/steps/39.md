# XOR exactly one selected fragment

Start a local keystream index at zero. For each byte load the keystream and source before storing the result, then advance full-width source and destination pointers. Stop when the local index reaches the selected fragment size.

## Write and inspect

Replace the body of region `stream_bytes`. Retain its BEGIN/END markers and supplied labels.

```asm
    move $s4, $zero
stream_byte:
    daddu $t0, $sp, $s4
    lbu $t1, 64($t0)
    lbu $t2, 0($s0)
    xor $t1, $t1, $t2
    sb $t1, 0($s1)
    daddiu $s0, $s0, 1
    daddiu $s1, $s1, 1
    daddiu $s4, $s4, 1
    bne $s4, $s3, stream_byte
    nop
```

Use `s39-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The first sixty-four destination bytes are transformed; byte sixty-four remains a guard until the next block.

## Check your understanding

Why load before storing in place?

- **B** In-place output requires reversing byte order.
- **C** Stores automatically retain the original byte.
