# Decide whether another block is needed

Subtract the completed fragment size from the remaining count. A zero remainder takes the normal restore path immediately. With the 65-byte recipe the remainder is one, so execution continues toward the counter advance.

## Write and inspect

Replace the body of region `stream_remaining`. Retain its BEGIN/END markers and supplied labels.

```asm
    dsubu $s2, $s2, $s3
    beqz $s2, stream_done
    nop
```

Use `s40-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The first fragment is complete and `s2` is one; no second block has been generated yet.

## Check your understanding

Should a 64-byte request generate a second block?

- **A** Yes; every loop needs a terminating empty block.
- **B** No; its remainder is zero.
- **C** Only when the first ciphertext byte is zero.
