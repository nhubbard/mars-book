# Copy a private block state

Copy all sixteen input words into the first sixty-four bytes of the frame. Later block counters change only this private copy. The caller's constants, key, initial counter and nonce remain available unchanged.

## Write and inspect

Replace the body of region `stream_copy`. Retain its BEGIN/END markers and supplied labels.

```asm
    daddu $t1, $a0, $t0
    lw $t2, 0($t1)
    daddu $t1, $sp, $t0
    sw $t2, 0($t1)
    daddiu $t0, $t0, 4
    sltiu $t1, $t0, 64
    bnez $t1, stream_copy_state
    nop
```

Use `s36-1`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

## Expected observation

The private state equals the caller state; no destination byte has changed.
