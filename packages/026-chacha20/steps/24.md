# Load the vector rows and retain originals

Load the four rows into `w0` through `w3` and copy them to `w4` through `w7`. Set the scalar double-round count to ten. Lane zero corresponds to the first word loaded from each row.

## Write and inspect

Replace the body of region `msa_load`. Retain its BEGIN/END markers and supplied labels.

```asm
    ld.w $w0, 0($a0)
    move.v $w4, $w0
    ld.w $w1, 16($a0)
    move.v $w5, $w1
    ld.w $w2, 32($a0)
    move.v $w6, $w2
    ld.w $w3, 48($a0)
    move.v $w7, $w3
    li $t0, 10
```

Use `s24-1`, `s24-2`. Prepare each in a separate source from the cumulative program through this edit. The native variants table explains additional cases.

Working and original vector rows agree with the prepared state; no output has been stored.
