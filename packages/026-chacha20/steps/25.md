# Mix the first half of the column groups

Perform the first two dependent groups across all four lanes. Word-vector addition wraps separately in each lane. Use logical right shifts to construct the rotations, retaining the unshifted XOR value until both shift operands have been read.

## Write and inspect

Replace the body of region `msa_column_a`. Retain its BEGIN/END markers and supplied labels.

```asm
    addv.w $w0, $w0, $w1
    xor.v $w3, $w3, $w0
    slli.w $w8, $w3, 16
    srli.w $w9, $w3, 16
    or.v $w3, $w8, $w9
    addv.w $w2, $w2, $w3
    xor.v $w1, $w1, $w2
    slli.w $w8, $w1, 12
    srli.w $w9, $w1, 20
    or.v $w1, $w8, $w9
```

## Expected observation

Every column has completed its first two groups in vector registers; caller output remains unchanged.
