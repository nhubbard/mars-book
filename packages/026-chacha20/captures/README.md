# Verified ChaCha20 IDE figures

The four figures use seventeen actual IntelliJ Light screenshots from the separate
MARS book authoring plugin. Each folder contains unchanged original PNGs, native
capture receipts, a preview rendered from the annotated LaTeX proof, and its reviewed
composition receipt. The book source under includes/chapters/026-chacha20 remains
the editable authority; this package includes a native snapshot with only capture
asset paths relocated to the student package.

The numbered annotations explain the scalar quarter-round before its stores, one
column/diagonal pair before loop-count decrement, vector lane selection while original
rows remain available, and a 65-byte XOR using two successive counters. The full-vector
hex display places lane zero at the right. The ordinary caller state remains unchanged.

The raw views were independently checked against complete public-data images and
access histories, with all lanes checked for the vector checkpoint. The complete
outputs are computed independently. Color and grayscale native proofs were reviewed;
fonts, tagged descriptions, callout coordinates, full image bounds and unchanged
embedded screenshot pixels were checked. These finite checks do not establish
cryptographic certification or independent PDF/UA conformance. Substantive editing
and independent accessibility review remain separate work.
