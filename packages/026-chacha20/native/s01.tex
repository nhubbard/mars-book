\section{Step 1 Identify the byte transformation}\label{chacha-s01}

Use one message byte and one keystream byte to establish the XOR operation before generating any blocks. The source and destination positions must refer to corresponding bytes. A complete block calculation will later supply the keystream, but it will not determine the message length.

\subsection{Expected observation}
Hexadecimal 4c XOR 22 is 6e; XOR with 22 again recovers 4c.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
What fixes the length of the output?

\begin{itemize}
  \item \textbf{A} The number of nonzero key bytes.
  \item \textbf{B} The declared message byte count.
  \item \textbf{C} The nearest terminating zero byte.
\end{itemize}
