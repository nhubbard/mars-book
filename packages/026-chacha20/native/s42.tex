\section{Step 42 Exercise tails, errors and in-place buffers}\label{chacha-s42}

Run the completed wrapper for zero, one, sixty-three, sixty-four and sixty-five bytes, then at the local 4096-byte limit. Use disjoint and exact in-place buffers. Check rejection before output stores at an exhausted counter and with an excessive unsigned count. A fresh call with unchanged state restarts at the same stream position.

\subsection{Expected observation}
The JDK cipher comparison agrees on valid requests; rejected requests preserve caller memory and the zero-length path touches no supplied pointer.

\subsection{Check your understanding}
Can two independent one-byte calls automatically consume consecutive keystream bytes?

\begin{itemize}
\item \textbf{A} No; this interface restarts from its supplied state each time.
\item \textbf{B} Yes; the simulator remembers a hidden byte index.
\item \textbf{C} Only if the two source buffers are adjacent.
\end{itemize}
