# A completed path and a final state answer different questions

After the north leg, the position equals the initial position. That fact alone would
also hold for a program that never enabled movement. Raising the pen and stopping
establish the requested final controls, but they still do not describe the drawing.

The model retains pen strokes. Straight forward movement is merged into one stroke,
while direction changes preserve corners. The square is represented by four ordered
strokes with five vertices, the last repeating the origin. An extra excursion with
the pen down adds a stroke or changes an endpoint and fails the path check.

Movement with the pen up adds no ink. This assignment grades the complete pen trail
and final controls; it does not claim to record every pen-up movement. That scope
allows equivalent control structures without mistaking an intended-corner log for
actual drawing history.
