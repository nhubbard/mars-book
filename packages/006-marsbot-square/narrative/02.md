# The instruction clock is part of the device contract

This MarsBot takes one pixel step after a configured number of completed instructions
while moving. With the default rate of sixty-four, the movement-enable store counts
toward the first step because the model observes that store and then receives the
instruction-completed event. Subsequent loads, branches, delay-slot instructions, and
other executed instructions also count while movement remains enabled.

A source line is not a clock unit. A pseudo-instruction can expand into several machine
instructions, and a loop can execute one source instruction many times. A comment
executes nothing. The setting is also unrelated to a host millisecond: a faster host
can execute the same simulated instructions in less wall time without changing the
modeled sequence of pixel steps.

At a Debug pause, no instructions complete, so the robot stops progressing until
execution resumes. A screen refresh may still occur while paused. The chapter's
capture process must distinguish that refresh from a device step.
