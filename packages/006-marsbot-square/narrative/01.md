# Read screen coordinates before choosing a heading

The robot starts at the top-left corner of a 512 by 512 board. Its coordinates range
from zero through 511 on each axis. Increasing x moves right; increasing y moves down.
Headings are measured clockwise from north: zero is up, ninety is right, one hundred
eighty is down, and two hundred seventy is left.

For side length sixteen, an eastward first leg reaches (16, 0). A southward leg then
reaches (16, 16). West returns x to zero, and north returns y to zero. This ordering
traces a clockwise square in screen coordinates. The word clockwise describes the
visual path, not an assumption that y grows upward.

The model clamps coordinates at the board edges. A northward command at (0, 0) leaves
the robot at the top boundary. Clamping does not turn movement off. A program that
polls for a positive y while facing north can therefore wait indefinitely even though
its memory operations and branch instructions are individually valid.
