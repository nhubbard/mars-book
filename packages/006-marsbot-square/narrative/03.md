# Name the register block and preserve the input

The device base is an address in the simulated machine, not a host pointer. Adding
0x20 selects the pen word; adding 0x50 selects the movement word. These meanings belong
to the MARS peripheral map, not to the MIPS instruction set in every system.

The input word lives in ordinary data memory. Loading its address and then its value
separates two operations that high-level syntax often combines. The reference keeps
the side length in a register throughout all four legs. It does not use the input
allocation as a loop counter or a place to record progress.

The assignment also protects the coordinate words against CPU stores. The device
publishes its own x and y values through application-origin memory updates. Those
updates are allowed and are excluded from execution-store assertions. The CPU must
read the feedback rather than attempt to overwrite it.
