# Step 15 Raise the pen and finish

Writing zero to the pen register raises it. The completed trail remains. The supplied exit code follows the `finished` label, so Debug can inspect the final device before the execution is disposed.

## Write or inspect

Append the final pen command and checkpoint.

```asm
    sw $zero, 0x20($s0)
finished:
```

## Expected observation

The final state is (0, 0), heading zero, stopped, pen up, with four strokes retained.

## Check your understanding

Does raising the pen erase the path?

- **A** No; it changes whether future movement adds ink.
- **B** Yes; it clears all memory.
- **C** Only on the fourth side.
