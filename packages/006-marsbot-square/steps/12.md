# Step 12 Poll x against zero and stop west

The target changes, but the feedback principle remains the same. A load from x reports the current horizontal coordinate; `bne` repeats until that value is zero.

## Write or inspect

Append the west polling loop.

```asm
west_wait:
    lw $t2, 0x30($s0)
    bne $t2, $zero, west_wait
    nop
    sw $zero, 0x50($s0)
west_stopped:
```

## Expected observation

The position is (0, side), and three strokes form an open path.
