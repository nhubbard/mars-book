# Step 13 Turn north and start the last leg

Heading zero decreases y. It is useful now because the robot is below the top boundary. The same heading would have produced no outward motion at the beginning.

## Write or inspect

Append the final turn and start.

```asm
    li $t1, 0
    sw $t1, 0x10($s0)
    sw $t0, 0x50($s0)
```

## Expected observation

The last target is y = 0 while x remains zero.
