# Step 10 Poll y and stop the south leg

The loop structure is unchanged, but the coordinate offset is now 0x40. The target is still the input side length. Only the axis of observation changes.

## Write or inspect

Append the south polling loop.

```asm
south_wait:
    lw $t2, 0x40($s0)
    bne $t2, $s1, south_wait
    nop
    sw $zero, 0x50($s0)
south_stopped:
```

## Expected observation

At `south_stopped`, position is (side, side), with two completed strokes.
