# Step 6 Enable movement

The move register treats a nonzero word as enabled. The reference retains one in `$t0`. Enabling movement resets the tick countdown when the moving state changes. It does not instantly traverse a side.

## Write or inspect

Append the start command.

```asm
    sw $t0, 0x50($s0)
```

## Expected observation

The robot begins accumulating completed instructions toward its next pixel step.
