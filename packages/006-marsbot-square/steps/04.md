# Step 4 Lower the pen before moving

The value one lowers the pen. The base-plus-offset address selects the pen control; the same value at the movement offset will later enable motion. A value alone has no device meaning without its destination.

## Write or inspect

Append the pen command and the first observation label.

```asm
    li $t0, 1
    sw $t0, 0x20($s0)
pen_ready:
```

## Expected observation

The pen is down, but position remains (0, 0) and movement is still disabled.

## Check your understanding

Does lowering the pen immediately draw a line?

- **A** Yes, it fills the whole board.
- **B** No; a line requires movement while the pen is down.
- **C** Yes, it moves to the input side length.
