# Step 2 Map controls and feedback

The register block contains three controls and two coordinate words. Controls request behavior; feedback reports the model's current position. The model republishes coordinates after a CPU write rather than treating that write as a position command.

## Write or inspect

Identify the five register addresses in the port table.

## Expected observation

Heading, pen, and movement are controls; x and y are feedback.
