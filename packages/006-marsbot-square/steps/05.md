# Step 5 Choose east while stopped

Heading 90 points right. Set it before enabling movement so every pixel of this leg uses the intended direction. Heading zero points north and is clamped at the top boundary when the robot starts at the origin.

## Write or inspect

Append the east heading command.

```asm
    li $t1, 90
    sw $t1, 0x10($s0)
```

## Expected observation

The robot is still at (0, 0), now facing east.
