# Step 9 Turn south and start the second leg

Heading 180 increases y while leaving x constant. Because the prior leg stopped, the heading change cannot create a moving diagonal or an extra pixel along the old direction.

## Write or inspect

Append the south turn and start.

```asm
    li $t1, 180
    sw $t1, 0x10($s0)
    sw $t0, 0x50($s0)
```

## Expected observation

The next target is y = side, starting from (side, 0).

## Check your understanding

Which coordinate changes on a southward leg?

- **A** y increases.
- **B** x decreases.
- **C** Both must change equally.
