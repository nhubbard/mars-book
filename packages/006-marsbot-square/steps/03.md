# Step 3 Load the register base and side length

`dli` makes the full 64-bit device base explicit. `la` obtains the address of the input word; `lw` reads its value. The valid side lengths are small positive integers, so the signed extension of `lw` preserves the intended value.

## Write or inspect

Append these address and input loads.

```asm
    dli $s0, BOT_BASE
    la $t0, side
    lw $s1, 0($t0)
```

## Expected observation

`$s0` is 0x00000000ffff8000 and `$s1` is sixteen for the default input. No control has changed.
