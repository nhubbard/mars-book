# Practice variations and review

1. For L = 7, list every corner and the coordinate tested on each leg.
2. Predict the result of starting north at the origin while polling y for positive L.
3. Move the coordinate load outside a polling loop. Explain which value the branch
   repeatedly compares and why that value does not track the device.
4. Draw a rectangle with separately supplied width and height. State which targets
   change and keep the work within the board. Define a new grading contract before
   treating it as the square assignment.
5. Explain why inserting a print service between the load and stop invalidates the
   six-instruction stopping argument, even if one observed run still looks correct.
6. Compare the four explicit legs with a command table. Which data need a stride,
   and which address remains the fixed device base?
7. Predict whether a Debug pause and a slower UI repaint change the robot's logical
   path. Identify what a real screenshot must verify in addition to the model.

Keep experiments in separate copies so their changed contracts do not affect the
submitted square program.
