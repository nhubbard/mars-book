\section{Step 57 Decode the separate distance alphabet}\label{png-huff-s57}
Implement \texttt{huff\_distance\_symbol}. Call the same symbol reader with the distance table at frame offset 800. Require a returned distance symbol below thirty before looking up its base or extra count. Fixed table symbols thirty and thirty-one remain reserved data values.

The fixed-match fixture returns distance symbol zero. This is a code index, not a zero-byte backward distance. Keep the reconstructed match length at offset 32 while interpreting the distance. A literal-only dynamic block with an empty distance alphabet never takes this path.

\paragraph{Observe} Use \texttt{s57-1}; stop before \texttt{huff\_distance\_symbol\_ready}. Inspect the state described above before continuing.
