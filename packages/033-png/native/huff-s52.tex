\section{Step 52 Compare a code in arrival order}\label{png-huff-s52}
Fill \texttt{huff\_symbol\_step}. Take the next low reservoir bit, shift the reservoir right and reduce its count. Accumulate that arriving bit into the current code. Subtract the first code at this length; an unsigned difference below the length's count selects a symbol. Otherwise advance the first-code, symbol-index and code-search state to the next length. Reject after length fifteen without a match.

For the first fixed literal zero, the completed eight-bit code is binary \texttt{00110000}, decimal 48. At \texttt{decode\_found}, the first code is also 48 and its ordered-array index is 24. Reading the same arrivals as one low-bit integer field would give the wrong code interpretation.

\paragraph{Observe} Use \texttt{s52-1}; stop before \texttt{decode\_found}. Inspect the state described above before continuing.

\Needspace{7\baselineskip}
\paragraph{Check} What identifies a matching code at one length?
\begin{itemize}
\item[A.] Its difference from the first code lies within that length’s count.
\item[B.] Its numerical value equals the symbol number.
\item[C.] Its bits are all zero.
\end{itemize}
