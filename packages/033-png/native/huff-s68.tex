\section{Step 68 Expand a short run of zero lengths}\label{png-huff-s68}
Fill \texttt{huff\_repeat17}. Operation seventeen reads three ordinary bits and prepares field plus three zero entries. Other operations reaching this dispatch select the long-zero handler. Use the same bounded store as every other expansion.

The repeat17 fixture uses extra field seven, preparing ten zeros after its first direct length. This operation needs no previous length, unlike sixteen. Ten is the maximum short-zero run, not the size of a buffer that may be written without checking the remaining combined entries.

\paragraph{Observe} Use \texttt{s68-1}; stop before \texttt{huff\_repeat17\_ready}. Inspect the state described above before continuing.

\Needspace{7\baselineskip}

  \item[B.] Ten entries.
  \item[C.] Seventeen entries.
\end{itemize}
