Implement \texttt{collect\_next}. Reload the retained payload length, add twelve, advance the current chunk cursor by that extent, and subtract the same extent from remaining file bytes. Fall through to \texttt{collect\_next\_ready}; the supplied branch returns to the envelope check.

After IHDR, the cursor advances from offset eight to 33, and remaining count from 107 to 82. After the one-byte IDAT, it reaches offset 46 with 69 bytes remaining. Advancing only by payload length would make the following parse start inside the current envelope. Cursor and remaining count describe the same window and must change together.
