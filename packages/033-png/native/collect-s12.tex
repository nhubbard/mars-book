\section{Step 12 Retain the two cursors and their remaining counts}\label{png-collect-s12}
Fill \texttt{collect\_state} with the register roles given above. Retain the source, file count, destination and descriptor before any helper can change argument registers. Load destination capacity from descriptor offset zero using a native doubleword load. Clear the format flags and joined count.

At \texttt{collect\_state\_ready}, the source still points at signature byte 137, the file count is 115, remaining destination capacity is 46, and both counters describing parsing progress are zero. The descriptor output fields remain sentinels. A copied argument is an address; loading the descriptor's first field obtains the count stored at that address.

\paragraph{Observe} Use \texttt{s12-1}; stop before \texttt{collect\_state\_ready}. Inspect the state described above, then continue to the next unfinished boundary.
