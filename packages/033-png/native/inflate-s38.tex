\section{Step 38 Continue nonfinal blocks without publishing success}\label{png-inflate-s38}
Fill \texttt{inflate\_block\_done}. If the retained final flag is zero, branch back to \texttt{deflate\_block} for another three-bit header. Otherwise fall through to \texttt{inflate\_final\_ready}. Do not reset output start or cursor when beginning another block.

The worked input takes the final path. The two-block fixture first produces seven row bytes and then the remaining twenty-eight. Its first block is nonfinal, so returning after those seven bytes would lose valid later output. Adler-32 describes the complete produced sequence, not each stored block separately.

\paragraph{Observe} Use \texttt{s38-1}; stop before \texttt{inflate\_final\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} What must survive a transition to another block?
\begin{itemize}
\item[A.] The accumulated output cursor.
\item[B.] The previous block length as the next length.
\item[C.] A claim of final success.
\end{itemize}
