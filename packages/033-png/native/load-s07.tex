\section{Step 7 Accept only a nonempty EOF}\label{png-load-s07}
Implement \texttt{load\_eof}. If no bytes have arrived, retain the failure candidate and branch to \texttt{load\_close}. Otherwise set \texttt{\$s4} to zero and continue to closing. Both an ordinary zero read and an exact-fit zero probe reach this decision.

Do not return immediately after changing the candidate to zero. The descriptor still belongs to the routine and must be released. At this intermediate step the close region remains unfinished, so continuing still returns development status four after cleanup. A successful candidate is not yet a completed return.

Use \texttt{s07-1} and stop before \texttt{load\_eof\_ready}.

\paragraph{Observe} The worked file has s2 equal to 115 and s4 equal to zero. Its descriptor remains open at this checkpoint and is closed on continuation.

\paragraph{Check} Why is a zero read insufficient by itself for success?
\begin{itemize}
\item[A.] The descriptor must have the numeric value zero.
\item[B.] The file may have been empty from the start.
\item[C.] PNG dimensions are always zero before decompression.
\end{itemize}
