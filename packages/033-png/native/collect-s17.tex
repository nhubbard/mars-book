\section{Step 17 Reuse the reflected CRC calculation}\label{png-collect-s17}
Implement internal \texttt{png\_crc32}, reusing your CRC-32 work from the earlier file-checker chapter. Its arguments are a readable byte address and an exact byte count. Initialize the low 32-bit state to all ones, combine each input byte, process eight reflected bits with polynomial \texttt{0xEDB88320}, and complement the low 32-bit result once at the end. Return that unsigned value in \texttt{\$v0} through \texttt{collect\_crc32\_ready}.

The helper consumes exactly its selected bytes. It must not include an extra terminator or assume that binary data is text. It may change temporary and argument registers. The collector keeps the current chunk's persistent state in saved registers and its frame. Until this helper is complete, its supplied development exit unwinds the collector frame.

\paragraph{Observe} Use \texttt{s17-1}; stop before \texttt{collect\_crc32\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} Which bytes does a zero count permit the CRC helper to read?
\begin{itemize}
  \item[A.] One terminator byte.
  \item[B.] None.
  \item[C.] The next chunk header.
\end{itemize}
