\section{Step 45 Clear one table before counting}\label{png-huff-s45}
Implement \texttt{huff\_tree\_clear} in \texttt{build\_tree}. The arguments select a length-byte vector, its symbol count, a writable table and a policy class. Clear all sixteen count words. Establish a cursor and end for the length vector, and clear the number of present symbols and maximum length accumulators.

The first supplied call selects 288 fixed literal/length symbols and the table at frame offset 160. A native word here is a count, not a PNG field. An old table's counts cannot be added to the new histogram. Keep all addresses at full width, including the end of this private table.

\paragraph{Observe} Use \texttt{s45-1}; stop before \texttt{huff\_tree\_cleared}. Inspect the state described above before continuing.

\Needspace{7\baselineskip}
\paragraph{Check} Why clear the table on every build?
\begin{itemize}
  \item[A.] Counts belong to the new alphabet, not its predecessor.
  \item[B.] The source vector is always a string.
  \item[C.] A cleared count automatically gives every symbol a code.
\end{itemize}
