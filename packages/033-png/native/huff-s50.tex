\section{Step 50 Start a symbol search at the shortest length}\label{png-huff-s50}
Fill \texttt{huff\_symbol\_state} inside \texttt{decode\_symbol}. Clear the accumulating code, the first code at the current length and its index in the ordered array. Select count word one as the first count cursor and retain the symbol-array address at table plus 64.

The first data call selects the literal/length table. Do not carry the previous symbol's accumulated code into this search, and do not clear the shared bit reservoir: it still contains unread bits from the block header or preceding field. Per-symbol search state and per-stream bit state have different lifetimes.

\paragraph{Observe} Use \texttt{s50-1}; stop before \texttt{huff\_symbol\_state\_ready}. Inspect the state described above before continuing.
