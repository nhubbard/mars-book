\section{Sources and draft status}
The format reference is the
\href{https://www.w3.org/TR/2025/REC-png-3-20250624/}{PNG Third Edition recommendation
  of 24 June 2025}. The compression references are
\href{https://www.rfc-editor.org/rfc/rfc1950.html}{RFC 1950 (zlib)} and
\href{https://www.rfc-editor.org/rfc/rfc1951.html}{RFC 1951 (DEFLATE)}.
The bounded RGB subset, separate-buffer development order and failure-publication
requirements are exercise choices. The existing MARS PNG smoke program supplies a
scalar and MSA comparison; the private adaptations are checked against the bounded
interfaces developed here.

This is the chapter's initial reading foundation. Its fixed observations are
host-verified, including independent image decoding. Two private chunk-collector
prototypes also pass 326 container and ownership cases each at ordinary and above-4-GiB
addresses, for 1304 simulator cases. Eight assembled regressions are rejected. The
collector stops at a validated container and joined payload. Two private inflater
variants, adapted from the retained scalar smoke decoder with per-call tables and
full-width pointers, pass 324 cases each at both address layouts (1296 simulator
cases). Ten assembled inflater regressions are rejected. A separate host bit-position
model and recorded zlib comparisons support the expectations; library acceptance is
not used as the sole format rule. The new native interface and worked alphabet explain
what the entry produces before row reconstruction begins.

Two row-kernel variants now pass 4400 scalar/vector cases across both byte orders
and both address layouts. Two complete decoder variants pass another 400 cases,
including full-size output and late failures that retain the framebuffer. Ten
assembled row/publication regressions are rejected. The same full-size input is
publicly reproducible, matches independent PNG pixels, and supports the complete-call
instruction comparison. The new grader byte-order option is covered by the 110-test
CLI suite; its choice precedes assembly. One new code excerpt is highlighted by the
actual IntelliJ exporter, with all earlier exports retained unchanged.

The supplied program now develops ten loader steps, seventeen collector steps,
sixteen stored-inflater steps, twenty-seven Huffman steps, thirteen row steps and
seventeen packing/publication steps. Observation controls
retain the student's instruction edits. The collector delays metadata publication
until accepted IEND. The inflater then develops stored, fixed and dynamic blocks,
canonical tables, bounded bit decoding, overlapping history copies and all three
length-repeat operations. Its completed variants and cumulative observations pass
6868 simulator cases across both byte orders and address layouts. Fourteen assembled
faults are rejected; ten runs with actual host files also pass. These checks include
success and failure sequences in the same session, with private tables rebuilt for
each call. Thirteen further edits develop row admission, all-selector prevalidation, scalar
predictors, bounded MSA Up groups and tails. Their completed variants and cumulative
observations pass 2232 simulator cases, including full-size scalar/MSA callers and
success/failure sequences in one session. Nine assembled row faults are rejected;
twelve actual-file runs compare exact reconstructed bytes, including unchanged rows
after a bad final selector. The final attachment adds fifteen editable packing/publication regions and two
diagnostic observations. Their completed variants, cumulative calls, early count
admission and reused-session checks pass 4036 simulator cases. Thirteen assembled
faults are rejected. Ten successful actual-file runs compare exact framebuffers,
including both full-size modes; two malformed-file runs return the expected failure.
Seeded native checks verify unchanged framebuffer and context bytes after failures,
including failures following an earlier success. The completed caller now publishes
width, height and active byte count after packing succeeds. The private complete viewers also read
the original smoke-test PNG from an actual host file and compare their displayed words
with independently decoded pixels.

The chapter is now registered as package \texttt{033-png} and included in the
integrated manuscript. Its student distribution retains the one hundred native
steps and unfinished stages, with public completed-interface feedback. A separate
private distribution contains completed implementations, quiz keys and additional
grading. The public checks use known independently encoded observations and assess
outputs, selected memory bounds and retained state rather than assembly-source
similarity.

The five PNG figures contain actual IntelliJ Light captures with native annotations
and retained receipts. Their numeric states are independently checked; print review
includes color and grayscale. The capture implementation belongs to the separate
authoring plugin, which depends on MARS. Independent accessibility verification
remains pending. Substantive editing is a later goal; finite checks do not establish
student usability or publication readiness.
