\section{Step 62 Clear all nineteen possible code-length entries}\label{png-huff-s62}
Fill \texttt{huff\_clear\_alphabet}. Set all nineteen length bytes at frame offset 1416 to zero, then reset the incoming-entry index at offset 24. Clear the whole possible alphabet, not only the number about to be transmitted.

This fixture advertises eighteen entries, leaving one symbol without a transmitted value. Its length must remain zero. A previous block's length in that slot would invent a symbol in the new alphabet. The received lengths will be placed by a permutation, so the first eighteen transmitted positions are not symbol numbers zero through seventeen.

\paragraph{Observe} Use \texttt{s62-1}; stop before \texttt{huff\_alphabet\_cleared}. Inspect the state described above before continuing.
