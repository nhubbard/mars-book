\section{Step 60 Copy forward through overlapping history}\label{png-huff-s60}
Fill \texttt{huff\_match\_copy}. Load one source byte, store it at the next output position and advance both addresses. Stop at the admitted destination end, then return to symbol decoding through the supplied branch. Preserve the shared compressed reservoir while copying output history.

The 34-byte match starts by reading output byte zero and writing byte one. Its next read is byte one, which was just produced. Forward copying therefore fills all 35 output bytes with zero. Reading the entire source range before those writes, or copying from its end backward, would use bytes that did not yet belong to history.
