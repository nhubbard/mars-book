# Separate the branch decision from its delay slot

A loop needs both a state update and a decision about repetition. `bne` tests
the count after the current iteration has consumed its bit. When the count is
nonzero, execution returns to `reverse_loop`; when it is zero, execution
continues after the branch's delay slot.

In the current Release 6 environment, this retained delayed branch executes the
instruction immediately following it whether the branch is taken or not. The
example places `nop` there deliberately. The slot has a known harmless effect,
so it adds no hidden update to the reversal argument.

This detail also matters for conditional color selection. Putting the white
color load in a `beq` delay slot would execute that load even when the branch
was intended to skip it. Compact control transfers have different rules; they
are not interchangeable source spellings for this delayed sequence.
