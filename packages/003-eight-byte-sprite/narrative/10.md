# Use a native operation under the same contract

The explicit reversal loop makes the bit movement visible. Release 6 also has
`bitswap`, which reverses the bits within each byte of a word. For an input
loaded by `lbu`, the low byte is the row and all other bytes are zero. One
`bitswap` therefore produces the same low-byte result as this loop.

The alternative must pass the same representation and memory checks before its
instruction count is compared. It is not enough for the default image to look
right. The input contract permits all 256 row-byte patterns, including zeroes,
high bits, and values that are unchanged by reversal.

A completed-instruction count measures simulated work for a specified workload.
It does not directly measure native processor cycles, host execution time, or
IDE response time. The count comparison here concerns two tested implementations
of the same fixed input/output contract.
