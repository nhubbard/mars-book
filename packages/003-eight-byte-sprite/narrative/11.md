# Carry the row format into later projects

The eight-byte representation is small enough to inspect on paper and useful
enough to reuse. A line-drawing routine can generate its bits; a file encoder
can serialize them; a clipped blitter can expand them into a larger destination.
Each extension needs a contract for dimensions, bit order, and memory bounds.

Before moving on, explain the conversion in terms of those contracts. The source
has eight rows of eight bits. The mirror reverses columns within each row. The
frame stores two eight-column images using four bytes per cell and a sixteen-cell
stride. Those facts determine the loop bounds and address updates.

The practice questions ask for a reasoning trace as well as a program. A correct
artifact matters, but the explanation should also account for the instructions
that produced it and for the bounds that make their memory accesses valid.
