# Nest the column loop inside the row loop

One column iteration writes one cell in each image. Its destination pointers
advance by four bytes and its mask shifts right one position. Starting at 128,
the mask reaches zero after exactly eight tested positions. At that point the
sixteen cells in the current display row have all been written.

The row iteration then advances the compact source and reversed-output pointers
by one byte, and the framebuffer row base by 64 bytes. The next row reloads a
new source byte, reinitializes reversal, and derives fresh column pointers. The
outer loop does not depend on the final column pointer values.

Keeping initialization inside the correct loop is essential. A mask initialized
only once before the outer loop would already be zero after row zero. A reversed
accumulator initialized only once would contain bits from the previous row.
Each row starts a new conversion of one independent byte.
