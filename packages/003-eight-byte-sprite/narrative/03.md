# Give each changing position its own register

The source pointer, source end, framebuffer row base, and reversed-output
pointer describe different positions. Their values may coincide with some
other object address at a boundary, but their roles remain separate. The end
pointer is an exclusive bound; the program never needs to load from it.

Within a row, two more pointers locate the next original and mirrored pixels.
Keeping the row base unchanged while those pointers move makes the next-row
update straightforward. The next iteration can derive both column-zero
positions from a single row base again.

The names `$s0` and `$s1` conventionally belong to registers preserved by a
called procedure. This standalone program makes no procedure calls, so it has
no caller to preserve them for. The names do not cause automatic saving. A later
procedure lesson will make that convention part of an explicit interface.
