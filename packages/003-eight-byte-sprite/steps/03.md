# Step 3 Initialize four pointers

A pointer is an address held in a register. The row source, source end, framebuffer row start, and reversed-row output each need an independent position. The end pointer is one byte beyond the source, not another row to process.

## Write or inspect

Append these initializations inside the program region.

```asm
    la $t0, sprite
    la $t1, sprite_end
    la $s0, frame
    la $s1, mirrored_rows
```

## Expected observation

The two source pointers differ by eight. The frame pointer names the first display row. The output pointer names the first reversed byte.

## Check your understanding

Why retain a separate framebuffer row pointer?

- **A** All pointers automatically advance together.
- **B** A framebuffer address is a syscall selector.
- **C** Its stride differs from the one-byte source-row stride.
