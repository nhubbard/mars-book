# Step 5 Initialize the reversal state

Keep the original row in $t3 for drawing. Copy it into $t9, which the reversal loop may consume. Start the reversed accumulator at zero and set a count of eight bits.

## Write or inspect

Append the reversal setup.

```asm
row_loaded:
    move $t9, $t3
    li $t8, 0
    li $t4, 8
```

## Expected observation

$t9 is 22, $t8 is zero, and $t4 is eight for the first row. The source byte in memory is unchanged.
