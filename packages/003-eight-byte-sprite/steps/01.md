# Step 1 Interpret the eight row bytes

One source byte represents eight adjacent pixels. The value is a mask: each bit answers whether its corresponding pixel is white or black. The data initializers use signed byte values accepted without truncation warnings; lbu will later recover their unsigned bit patterns.

## Write or inspect

Read the source-row table and predict the first row of the image. Leave the supplied declarations unchanged.

## Expected observation

The first byte is 0x16, whose bits are 00010110. The set pixels are at columns 3, 5, and 6 when columns are numbered from zero at the left.
