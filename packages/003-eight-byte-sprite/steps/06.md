# Step 6 Extract the low bit

andi combines the source with an immediate mask. A mask of one preserves only bit 0, producing either zero or one. This extracted bit is the next bit to append to the reversed result.

## Write or inspect

Append the bit extraction and its loop label.

```asm
reverse_loop:
    andi $t5, $t9, 1
```

## Expected observation

For the first input 0x16, the first extracted bit is zero. The second extraction, after consuming one source bit, will produce one.
