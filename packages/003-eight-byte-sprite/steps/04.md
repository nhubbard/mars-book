# Step 4 Load one unsigned row

lbu reads one byte and zero-extends it to the integer register width. A row is a bit pattern, so values with bit 7 set must remain ordinary masks from 128 through 255. The row_loop label will become the target of the outer loop.

## Write or inspect

Append the source load.

```asm
row_loop:
    lbu $t3, 0($t0)
```

## Expected observation

The first row loads as decimal 22, or 0x16. A stored byte ff would load as 255 even when its declaration used -1.

## Check your understanding

What does lbu return for a stored byte ff?

- **A** The address of the byte.
- **B** 255.
- **C** -1 because every byte load sign-extends.
