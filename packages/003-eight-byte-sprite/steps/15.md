# Step 15 Complete the two eight-pixel rows

Branch back while a nonzero mask remains. Each iteration consumes one of eight bit positions and writes exactly one pixel in each image. The nop delay slot preserves that accounting on both the final and continuing iterations.

## Write or inspect

Append the column-loop branch.

```asm
    bne $t4, $zero, column_loop
    nop
```

## Expected observation

The first display row now has sixteen written words: eight original pixels and eight mirrored pixels. The next display row has not yet been processed.

## Check your understanding

How many pixel stores does one completed column loop perform?

- **A** Eight total because both images share the same words.
- **B** Sixty-four because the stride is 64 bytes.
- **C** Sixteen: two per iteration for eight iterations.
