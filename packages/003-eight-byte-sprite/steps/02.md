# Step 2 Lay out two images in one frame

The bitmap has 16 columns and 8 rows. Each cell occupies one four-byte RGB word. The first eight columns hold the original; the next eight hold the mirror. Data addresses count bytes, so one display row spans 16 times 4 bytes.

## Write or inspect

Identify frame, frame_guard, sprite, mirrored_rows, and rows_guard. Derive the byte offset of row 1 and the final cell.

## Expected observation

The row stride is 64 bytes. The last cell begins at offset 508 and occupies bytes 508 through 511. frame_guard starts at offset 512.

## Check your understanding

What is the byte displacement from one row start to the next?

- **A** 64.
- **B** 16 because there are 16 columns.
- **C** 8 because the source has eight rows.
