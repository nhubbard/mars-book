# Step 13 Select and store the mirrored pixel

Use the same bit mask on the reversed row value. Its bit 7 is the original row bit 0, so scanning it left to right produces a horizontal mirror. The mirror pointer names a distinct cell in the same framebuffer row.

## Write or inspect

Append the mirror selection and store.

```asm
    li $t6, 0
    and $t5, $t8, $t4
    beq $t5, $zero, write_mirror
    nop
    li $t6, 0x00ffffff
write_mirror:
    sw $t6, 0($t7)
pair_written:
```

## Expected observation

Both first pixels are black for the first row. Other columns will differ because 0x16 and 0x68 have different bit positions set.
