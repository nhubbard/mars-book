# Step 8 Consume one bit and reduce the count

srl shifts the working copy right and inserts zeroes at the high end of the word result. The extracted low bit has already been incorporated. Decrementing the count records that one of the eight required bits is complete.

## Write or inspect

Append the source shift and count update.

```asm
    srl $t9, $t9, 1
    addiu $t4, $t4, -1
```

## Expected observation

After the first iteration, $t9 is 0x0b and $t4 is seven. The original row register remains 0x16.
