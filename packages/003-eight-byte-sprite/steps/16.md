# Step 16 Advance the three row positions

The source and reversed-output arrays advance one byte per row. The framebuffer row base advances 64 bytes. Keeping these strides separate prevents a compact source representation from being confused with its expanded pixel representation.

## Write or inspect

Append the three pointer updates.

```asm
row_drawn:
    daddiu $t0, $t0, 1
    daddiu $s1, $s1, 1
    daddiu $s0, $s0, 64
```

## Expected observation

After the first row, the source points to its second byte, reversed output points to its second byte, and the frame base points to display row one.
