# Step 9 Repeat exactly eight times

bne compares two registers and transfers control when they differ. This retained branch executes the following instruction as a delay slot whether taken or not. The explicit nop performs no state change, so the count test decides whether execution returns to reverse_loop or continues after the slot.

## Write or inspect

Append the branch and its delay slot. Run this partial program and inspect the reversal result.

```asm
    bne $t4, $zero, reverse_loop
    nop
```

## Expected observation

For input 0x16, the loop finishes with $t8 = 0x68, $t9 = 0, and $t4 = 0. It performs eight iterations, including leading zero bits.
