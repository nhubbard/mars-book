# Step 19 Compare a native reversal operation

MIPS Release 6 bitswap reverses the bits within each byte of a word. Here lbu supplied a value from zero through 255, so its low byte is the entire row and its other bytes are zero. The instruction can replace the explicit reversal setup and loop in an equivalent implementation.

## Write or inspect

In a separate completed copy, replace the reversal setup and reverse_loop body with the single instruction shown. Keep row_reversed and all drawing code. Run the same checks before comparing instruction counts.

```asm
    bitswap $t8, $t3
```

## Expected observation

For 0x16, the low byte is 0x68. This is an optional replacement, not another segment to append to the baseline program.

## Check your understanding

Does bitswap reverse the positions of the bytes in a word?

- **A** Yes; it reverses the order of all framebuffer rows.
- **B** No; it reverses the bits within each byte.
- **C** Yes; it only swaps the first and last bytes.
