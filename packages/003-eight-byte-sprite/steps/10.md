# Step 10 Store the reversed row byte

sb writes the low byte of the reversed accumulator to the output array. This result is independent of the RGB framebuffer: it is another compact one-byte row representation that can be reused by later image-format projects.

## Write or inspect

Append the row result store.

```asm
row_reversed:
    sb $t8, 0($s1)
```

## Expected observation

The first reversed output byte is 0x68. The original source byte remains 0x16.

## Check your understanding

How much output does one reversed source row require?

- **A** Sixty-four bytes because the framebuffer stride is 64.
- **B** One byte.
- **C** One 64-bit register per pixel.
