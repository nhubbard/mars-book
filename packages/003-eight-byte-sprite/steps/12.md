# Step 12 Select and store the original pixel

Initialize the color to black, then test the current source bit. If the masked result is zero, beq skips the white-color load after executing the nop delay slot. Otherwise the white load executes. Both paths reach the store.

## Write or inspect

Append the conditional color selection and normal store. The forward branch target is included in this segment.

```asm
column_loop:
    li $t6, 0
    and $t5, $t3, $t4
    beq $t5, $zero, write_normal
    nop
    li $t6, 0x00ffffff
write_normal:
    sw $t6, 0($t2)
```

## Expected observation

The first pixel of the first row is black because bit 7 of 0x16 is zero. An explicit black store replaces any old framebuffer value.
