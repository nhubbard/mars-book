# Sprite project starter

Open this folder in IntelliJ with MARS enabled. Use the default memory layout and
little-endian byte order. Preserve the header and data layout. Add instructions inside
the program region before the supplied exit sequence.

The display is 16 columns by 8 rows: eight columns for the original sprite and eight
for its mirror. The initial template exits silently without drawing. The lesson's
checkpoints can be assembled and run after each required code segment; the optional
bitswap example replaces a completed loop rather than appending another program body.
