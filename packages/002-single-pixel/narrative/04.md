# A store connects the value to its destination

The word store needs a source value and a destination address. `$t1` supplies
the packed color. The expression `0($t0)` forms an effective address by adding
a byte displacement of zero to the base address in `$t0`.

The store writes four bytes. Afterward, a word read at the same address returns
the packed value. Bitmap Display observes the write and uses the completed word's
low 24 bits as its color. Its view is a response to memory activity; the data
initializer is not the drawing step in this program.

The instruction's operands explain the direction of transfer. `sw` reads the
register and writes memory. Later, `lw` will read memory and write a register.
The address expression identifies the location in both directions.
