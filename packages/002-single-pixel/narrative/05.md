# Byte order relates values to addresses

Hexadecimal notation shows a value with its most significant digits on the
left. A memory view usually orders bytes by increasing address. In little-endian
memory, the least significant byte occupies the lowest address, so these two
orders appear reversed for a multibyte value.

The word `0x00336699` therefore appears as bytes `99 66 33 00` when read in
increasing address order in this lesson. The word has not changed. The two
representations describe the same bits with different ordering conventions.

Big-endian memory would put `00` first, followed by `33`, `66`, and `99`.
The RGB field definition still assigns red to bits 23 through 16, green to bits
15 through 8, and blue to bits 7 through 0. Byte order changes which address
reaches those bits.
