# Preserve the contract while changing the implementation

The final-state contract gives room to choose other registers or compute the
same final color with a different instruction sequence. The guided exercise
uses a byte store because it makes the address-to-field relationship visible.
The reference checkpoints verify that particular demonstration.

When judging a free-writing solution, distinguish final behavior from its
execution history. Equal final words do not prove equal writes along the way.
A task that requires an exact kind of memory transaction needs an explicit
trace contract and a checker for that transaction. This task's automated
submission checks concern its final state and interface.

The next project can repeat the address and field reasoning across eight rows
of a sprite. Before writing its loop, the student will need to know what one
row means and how one destination address identifies one cell.
