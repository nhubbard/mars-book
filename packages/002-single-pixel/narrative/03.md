# Pack fields into one integer

The notation `0x00336699` writes a 32-bit word as eight hexadecimal digits.
Each pair describes eight bits. In this RGB format, the low three bytes are blue,
green, and red when counted upward from the least significant end. In the usual
written order, those fields appear as `00 RR GG BB`.

For component values `R`, `G`, and `B`, each between 0 and 255, the packed value
is `(R << 16) | (G << 8) | B`. The shifts place the fields in separate bit
positions, and the bitwise OR combines them. No component overlaps another within
that domain. The highest byte is unused by this display; it is not an alpha
channel.

The chosen values are deliberately different. With three distinct bytes, a
swapped channel or reversed address interpretation is visible in the trace.
