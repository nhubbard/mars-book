# A byte store changes one part of the word

The byte store takes the low eight bits of its source and writes them at the
specified address. With 255 in `$t2`, those bits are `ff`. At offset zero in
this little-endian word, the store replaces the blue component. The neighboring
bytes retain their previous values.

After the store, a complete word read gives `0x003366ff`. Bitmap Display reads
the containing word after the write, so the visible color uses the unchanged
red and green fields together with the new blue field. The byte-sized write does
not reduce the display format to a single color component.

This distinction is useful beyond graphics. A packet field or character buffer
can occupy part of a larger object. The store width and effective address together
determine which bytes may change.
