# Allocate storage before writing it

The starter reserves one word for the pixel and one for its neighbor. A label
names the start of each object. Because a word contains four bytes, the second
label has an address four greater than the first. The address difference is in
bytes, even when the memory view is displaying words.

The first word must match the configured display base. This is an interface
constraint: writing the right value into another word can produce a correct
memory check by name while leaving the intended cell unchanged. The grader
therefore checks the address as well as the final value.

The neighboring word acts as a canary. Its value is arbitrary; preserving it
shows that the operation has not changed the next object. It is not enough to
write the starter's canary constant back unconditionally, because another caller
may supply a different initial value.
