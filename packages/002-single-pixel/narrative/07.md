# Read back the stored representation

Reloading the word checks memory through the opposite direction of transfer.
The result in `$t3` should agree with the memory word, including the three bytes
that the byte store preserved. A byte-sized update does not make a later word
load return only one byte.

`lw` sign-extends a word into a 64-bit integer register. The packed color in
this exercise has bit 31 clear, so the upper register half becomes zero. The
number's low 24 bits still have the same RGB interpretation.

Use the memory and register views to verify representation, and the bitmap view
to verify the drawing interface. A CLI grading pass establishes the checked
memory contract. It does not establish that the IDE selected the correct tool,
connected the view, or finished repainting it. Those are separate capture and
integration checks.
