# Step 7 Prepare a byte value

A byte store uses the low eight bits of its source register. Loading 255 supplies the pattern 0xff in those bits. The destination address will select which byte of the packed word changes.

## Write or inspect

Append the byte-value load after base_ready.

```asm
    li $t2, 255
```

## Expected observation

The low byte of $t2 is ff. The pixel has not changed merely because this register was loaded.
