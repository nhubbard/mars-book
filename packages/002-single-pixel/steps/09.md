# Step 9 Reload and compare

lw reads a 32-bit word and sign-extends it into the 64-bit destination register. This particular value has a zero sign bit, so its upper 32 register bits are zero. Reading the value lets you compare the stored word with a register view.

## Write or inspect

Append the load before the supplied exit sequence. Step it after inspecting final_ready.

```asm
    lw $t3, 0($t0)
```

## Expected observation

$t3 contains 0x00000000003366ff. Reading the word does not itself draw a new color. The following supplied exit completes the program.

## Check your understanding

What should $t3 contain after this load?

- **A** The full word 0x003366ff, sign-extended into the register.
- **B** Only 0xff because the previous store was a byte store.
- **C** The address of pixel rather than its contents.
