# Step 5 Store the complete word

sw writes the low 32 bits of a register to memory. The operand 0($t0) adds a byte displacement of zero to the address in $t0. The display observes the completed write and interprets the word as an RGB value.

## Write or inspect

Append the store and the checkpoint label. The label marks the following instruction location and performs no work itself.

```asm
    sw $t1, 0($t0)
base_ready:
```

## Expected observation

The word at pixel is 0x00336699. In the configured grid, the upper-left cell should show that color. The neighboring word is unchanged.
