# Step 6 Inspect the first color

A breakpoint pauses before its instruction. The label base_ready names the position following the word store. Set the breakpoint on the next executable line after that label. In the completed guide this will be the instruction loading the byte value.

## Write or inspect

Debug the program and inspect the pixel word after sw, before the byte update. Compare the displayed color with the RGB fields, and inspect the four memory bytes in address order.

## Expected observation

In little-endian memory the bytes at offsets 0, 1, 2, and 3 are 99, 66, 33, and 00 in hexadecimal. The packed word remains 0x00336699.

## Check your understanding

Which byte is at the lowest address in this lesson?

- **A** 0x99.
- **B** 0x00 because it is written first in the hexadecimal word.
- **C** 0x33 because red is the first color channel.
