# Step 3 Load the pixel address

la places an address in a register. The store instructions will use the address in $t0 to locate the destination. This is different from putting an RGB value in the register.

## Write or inspect

Append the address load inside the program region.

```asm
    la $t0, pixel
```

## Expected observation

The address register identifies the first data word. No store has changed that word yet.
