# Step 10 Verify the neighboring word

An address error can change memory outside the intended object. A canary word provides an explicit value to check immediately after the object. The final-state contract requires preserving neighbor, including when the grader sets it to another initial value.

## Write or inspect

## Expected observation

The original neighbor is 0x13579bdf. The grader also tests preservation of other initial values. There should be no console output and the program should terminate normally.
