# Step 4 Prepare the packed color

The word 0x00336699 has red component 0x33, green 0x66, and blue 0x99. Each component occupies eight bits and has a value from 0 through 255. Bitmap Display uses the low 24 bits as RGB; the highest byte does not supply alpha transparency.

## Write or inspect

Append this pseudo-instruction. Convert the three component bytes to decimal before running.

```asm
    li $t1, 0x00336699
```

## Expected observation

The components are red 51, green 102, and blue 153. The color is in a register; the pixel word is still unchanged.

## Check your understanding

Which byte specifies blue in the packed word?

- **A** 0x33 because it is the first nonzero pair written.
- **B** 0x00 because the highest byte always specifies blue.
- **C** 0x99, the least significant byte.
