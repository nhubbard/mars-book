# Step 11 Generalize the byte-order argument

Byte order maps a multibyte value to addresses. It does not change the numerical definition of the RGB fields. In big-endian memory, offset zero would select the highest byte of this word, which Bitmap Display ignores as a color component.

## Write or inspect

Use the byte-order table to predict the result of the same sb in big-endian memory. Then write an equivalent free-writing solution for the published little-endian contract. Do not change the lesson environment while comparing its expected output.

## Expected observation

A big-endian offset-zero update would produce 0xff336699 while leaving the low-24-bit RGB color unchanged. This is a prediction outside the graded little-endian environment; later byte-order exercises will execute both configurations.
