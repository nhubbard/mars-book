# Step 1 Configure the display

The first comment is a MARS tool configuration header. The simulator executes no instruction for this comment; the plugin uses it to configure a tool before execution. The display width divided by unit width gives the number of logical columns, and the corresponding heights give the rows.

## Write or inspect

Inspect and preserve this header before the first assembly statement. Run the unchanged starter once. No color write has executed yet.

```asm
# mars:tool bitmap width=64 height=64 unitWidth=32 unitHeight=32 base=static_data
```

## Expected observation

The configuration describes two columns and two rows. Each logical cell occupies a 32 by 32 screen block. A future verified screenshot will show the exact editor and display arrangement.

## Check your understanding

How many logical cells does this header describe?

- **A** 4096: every screen position is a separate memory word.
- **B** One: the assignment name changes the grid dimensions.
- **C** Four: two columns times two rows.
