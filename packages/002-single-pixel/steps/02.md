# Step 2 Locate the data words

The supplied declarations reserve two adjacent 32-bit words. .align 2 places the first at an address divisible by four. With the default layout, the first static word is at 0x10010000. Bitmap Display begins reading its observed writes from that same base.

## Write or inspect

Identify pixel and neighbor in the data section. Preserve their order and keep this data section at the default base.

```asm
.data
.align 2
pixel:    .word 0
neighbor: .word 0x13579bdf
```

## Expected observation

pixel starts at 0x10010000 and neighbor starts at 0x10010004. Their values are initially 0 and 0x13579bdf. A declaration alone is not the runtime drawing operation taught here.
