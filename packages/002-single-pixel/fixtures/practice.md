# Check a new color without changing the representation

Choose red 18, green 52, and blue 86. Write the packed hexadecimal word, then
list its four bytes in each byte order. Predict the result of an offset-zero
byte store with value 255 in the lesson's little-endian environment.

Explain the difference between a word value and its display interpretation.
Then explain why a neighboring canary is useful even when the painted cell looks
correct. Your instructor can check these explanations separately from the program's
final-state tests.
