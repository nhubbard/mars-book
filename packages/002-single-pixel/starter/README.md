# Single pixel starter

Open this folder in IntelliJ with MARS enabled. Preserve the supplied data layout
and tool header. Add the program body inside the marked region and keep the exit
sequence at the end. Use the default memory layout and byte order for this lesson.

The header configures a two-by-two bitmap grid. Only the first cell is the task's
pixel. No console text is expected. The template exits without painting the pixel
and intentionally fails the completed-program checks.
