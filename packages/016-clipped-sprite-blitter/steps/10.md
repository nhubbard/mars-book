# 10. Reject empty intersections before addressing

Subtract left from right and top from bottom with dsubu. A zero or negative width or height means there is no copy. Branch to the common restore section with both results still zero. The u suffix suppresses an overflow exception; it does not make the resulting bit pattern an unsigned geometric quantity.

## Write or inspect

Append in the `extent` region. Keep the supplied labels and balanced scaffold.

```asm
    dsubu $t8, $s7, $s5
    blez $t8, blit_restore
    nop
    dsubu $t9, $t4, $s6
    blez $t9, blit_restore
    nop
```

## Expected observation

The default t8 and t9 are three and four. At x eight, width is zero and there are no pixel accesses.

## Check your understanding

May a negative extent be used as a loop count?

- **A** Yes, after masking.
- **B** No; it indicates an empty intersection.
- **C** Only for a negative x.
