# 3. Trace a padded row

For the default framebuffer, row one begins sixteen words after row zero. The clipped source begins in source column two, so its first selected word is eight bytes after its base. A diagram of adjacent visible cells does not imply adjacent rows in memory.

## Expected observation

The first destination pointer is frame_a plus sixty-four bytes; the source pointer is sprite_a plus eight.

## Check your understanding

What advances the destination row start?

- A. The copy width times four.
- B. The source stride.
- C. The destination stride times four.
