# 12. Load both full pixel addresses

Load the eight-byte base fields with ld. Do not use the descriptor address itself as the pixel base. Later calls may choose another descriptor or a base within a different allocation.

## Write or inspect

Append in the `bases` region. Keep the supplied labels and balanced scaffold.

```asm
    ld $s0, 0($a0)
    ld $s1, 0($a1)
```

## Expected observation

s0 and s1 hold the selected destination and source pixel addresses.
