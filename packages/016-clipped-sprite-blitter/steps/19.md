# 19. Advance within the selected row

Advance each cursor by four bytes, decrement the remaining cell count, and repeat while that count is nonzero. The positive-extent test guarantees that this loop starts with at least one cell. The skip label joins the transparent and opaque paths before these common updates.

## Write or inspect

Append in the `advance` region. Keep the supplied labels and balanced scaffold.

```asm
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 4
    addiu $t2, $t2, -1
    bne $t2, $zero, blit_pixel
    nop
```

## Expected observation

After the first default row, v0 is one and v1 is three.
