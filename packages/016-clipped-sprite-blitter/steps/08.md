# 8. Clamp the right edge

Form x plus source width with daddu, then compare the resulting signed edge with destination width. Retain the smaller edge. Although widths fit in a word, the coordinate sum need not; a trapping word addition here can raise an exception for a valid off-screen call. Full-width addition also keeps the computed edge equal to the stated geometric formula.

## Write or inspect

Append in the `right` region. Keep the supplied labels and balanced scaffold.

```asm
    daddu $s7, $a2, $t2
    slt $t4, $t0, $s7
    beq $t4, $zero, clip_right_ready
    nop
    move $s7, $t0
```

## Expected observation

For x minus two and source width five, s7 becomes three.
