# 6. Clamp the left edge

Start the left edge at x. If it is negative, replace it with zero; otherwise keep it. The branch tests a signed full-register value. The right edge will establish whether this left edge actually intersects the framebuffer.

## Write or inspect

Append in the `left` region. Keep the supplied labels and balanced scaffold.

```asm
    move $s5, $a2
    bgez $s5, clip_left_ready
    nop
    move $s5, $zero
```

## Expected observation

With x minus two, s5 becomes zero. With x eight, it remains eight.

## Check your understanding

May a positive left edge already be outside the framebuffer?

- **A** No.
- **B** Only when the source is transparent.
- **C** Yes; the later extent test detects that case.
