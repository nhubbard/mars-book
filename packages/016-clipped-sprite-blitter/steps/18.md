# 18. Copy an opaque cell and count visibility

Load one source word and increment the visible count. Compare it with the complete key. A matching key branches over both the store and the opaque count. Otherwise store the word unchanged and increment v0, even if its value already existed at the destination.

## Write or inspect

Append in the `pixel` region. Keep the supplied labels and balanced scaffold.

```asm
    lw $t3, 0($t1)
    addiu $v1, $v1, 1
    beq $t3, $s4, blit_skip
    nop
    sw $t3, 0($t0)
    addiu $v0, $v0, 1
```

## Expected observation

The first default cell is transparent: v1 becomes one, v0 stays zero, and there is no destination store.

## Check your understanding

What happens for an opaque value already present at the destination?

- **A** It still contributes one to v0.
- **B** It becomes transparent.
- **C** It contributes only if a store changes bits.
