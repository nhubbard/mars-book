# 14. Locate the first destination pixel

Multiply top by destination byte stride and add four times left. Both terms are bounded after clipping, so the offset fits in a word. Add the offset to the full destination base with daddu. This register now points at the first selected cell rather than the allocation origin.

## Write or inspect

Append in the `destination_address` region. Keep the supplied labels and balanced scaffold.

```asm
    mul $t0, $s6, $s2
    sll $t1, $s5, 2
    addu $t0, $t0, $t1
    daddu $s0, $s0, $t0
```

## Expected observation

The default destination address is frame_a plus sixty-four bytes.
