# 5. Load four logical dimensions

Load destination width and height from a0, then source width and height from a1. These are logical dimensions, not allocation sizes. The valid domain bounds each dimension by eight; a zero dimension is legal.

## Write or inspect

Append in the `dimensions` region. Keep the supplied labels and balanced scaffold.

```asm
    lw $t0, 8($a0)
    lw $t1, 12($a0)
    lw $t2, 8($a1)
    lw $t3, 12($a1)
```

## Expected observation

For the default descriptors, t0 through t3 hold eight, six, five, and four.

## Check your understanding

Which quantity is absent from these four loads?

- A. Stride.
- B. Source width.
- C. Destination height.
