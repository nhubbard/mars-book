# 15. Locate the first source pixel

Use the clipped source row and column with the source byte stride. A negative placement advances the source pointer because invisible source cells precede the first copied cell. The destination and source offsets need not match.

## Write or inspect

Append in the `source_address` region. Keep the supplied labels and balanced scaffold.

```asm
    mul $t0, $t7, $s3
    sll $t1, $t6, 2
    addu $t0, $t0, $t1
    daddu $s1, $s1, $t0
```

## Expected observation

The default source pointer advances eight bytes.
