# 20. Advance each row start by its own stride

Add the destination byte stride to the destination row start and the source byte stride to the source row start. Increment completed rows and compare against copy height. Advancing s0 from its retained row start avoids adding the copy width twice. The final iteration falls through to the restore section.

## Write or inspect

Append in the `next_row` region. Keep the supplied labels and balanced scaffold.

```asm
    daddu $s0, $s0, $s2
    daddu $s1, $s1, $s3
    addiu $s7, $s7, 1
    sltu $t0, $s7, $s6
    bne $t0, $zero, blit_row
    nop
```

## Expected observation

After four default rows, the results are eight and twelve.
