# 7. Clamp the top edge

Apply the same maximum-with-zero operation to y. Keep the horizontal and vertical calculations separate so a top clip cannot alter the selected source column. The fixed label after this region is the branch destination for both paths.

## Write or inspect

Append in the `top` region. Keep the supplied labels and balanced scaffold.

```asm
    move $s6, $a3
    bgez $s6, clip_top_ready
    nop
    move $s6, $zero
```

## Expected observation

With y one, s6 remains one; with y minus two, it becomes zero.
