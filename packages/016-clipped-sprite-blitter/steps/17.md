# 17. Start one row with fresh cursors

Copy the current row starts into t0 and t1 and the copy width into t2. The inner loop changes these cursors without destroying s0 or s1. Reset t2 for every row; otherwise the second row would inherit zero.

## Write or inspect

Append in the `row` region. Keep the supplied labels and balanced scaffold.

```asm
    move $t0, $s0
    move $t1, $s1
    move $t2, $s5
```

## Expected observation

For the first default row, t2 is three.
