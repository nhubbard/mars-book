# Native ring assessment foundation

The ring companion's independent functions and completed-caller observations now
have native data profiles in revision/labs/checks/ring-native. This is assessment
support; it does not by itself complete a native first-use/resume IDE lesson.

All 520 original public kernel trials are retained, in six batches of at most 100
cases and less than one MiB each. Function format 23 supplies relocated full-width
pointer fixtures, exact result bytes, saved-register checks and read/write policies
through both the function return and caller exit. All twelve original caller
prefixes remain in console format 7. Their program executes continuously between
operation_ready markers; each operation has its own permitted stores and complete
published-state expectations. Both native formats reuse existing memory/access
models and introduce no downloaded predicate or alternate simulator.

Two equivalent implementations pass all 532 public cases, both in the original
layout and with data above 4 GiB: 2128 native placements. The existing five semantic
faults and unfinished starter retain their distinguishing failures. The extra
source read is rejected by kernel read bounds while the caller's store-only
profile can pass it; neither profile alone establishes the entire contract.
The generated caller DSL agrees with the original caller checks. The unchanged
original kernel and caller scripts remain available.

Both implementations also pass all 37477 original private kernel trials through
the production native parser and evaluator. The original private DSL agrees.
Those fixtures and implementations remain in the private instructor repository;
expanded private profiles are build artifacts, with generation recipes and exact
hash manifests retained. This selected domain is not every possible queue history
or a whole-address-space safety proof.

MARS `ae3f1e6e` adds bounded public publications and explicit continuation policies.
Complete regression passes 313 CLI / 1348 plugin tests, with all required full
line/branch and parser gates. The later private-history cleanup, MARS `5fb1e46a`,
passes all 314 CLI tests, preserves public post-close snapshots and repeats public,
wide-address, fault and full private native qualification. The original full
plugin regression retains its exact earlier scope. Public tooling passes 647 tests.
