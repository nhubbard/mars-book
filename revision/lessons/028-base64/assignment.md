# Regrouping bytes as Base64 text

Read the Base64 companion to Chapter 17 before continuing in Learn. Start with
the complete base64-codec.asm. Derive numerical sextets from input bits before
looking up their character codes. The complete source variations then separate
padded tails, whole-buffer rejection, vector representation and exact footprints.

Use one line breakpoint at a time. Learn highlights the next requested operation;
the selected Debug frame shows the actual pause. Resume each program to normal
exit after its last observation before changing sources. Three ordinary Runs
complement the paused investigations. A stop at main_done's exit syscall follows
publication: v0 holds service ten, while the earlier function status is in memory.

Write b64url_encode independently in independent/base64url.asm. Its interface is
in independent/README.md. The starter deliberately stops with break. Establish
an explained scalar baseline before choosing vector work. Equivalent schedules
and temporary registers are accepted; the worked codec's guided register states
do not constrain the independent solution.

Keep a bit-group derivation, one canonical-padding counterexample and an exact
source/output footprint argument. Use the first failed value or access to choose
a new observation. Passing the finite public corpus supports those arguments;
it does not establish all possible inputs, a vector strategy or a machine speedup.
