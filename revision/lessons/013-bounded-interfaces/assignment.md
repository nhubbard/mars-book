# Parsing, bounds and unchanged output

Read the bounded-interfaces chapter and lab. Label the header, payload and trailer
in the default packet, then distinguish available, declared and consumed lengths.
Follow the accepted, short-header and checksum-failure Debug routes in their
separate complete sources. At each stop distinguish a tentative register, a
complete return interface and the caller's later metadata stores. Explain the
first bound, checksum residues and output publication before ordinary Run.

Implement the independent binary delimiter parser using its own grammar and
contract. Work the default zero/high-byte input and the exact-capacity LF by
hand. Complete both public function profiles and the normal-exit check for the
current source. Retain a failing input and locate its first incorrect decision
or forbidden access before changing a return value. Use the written lab's fault
experiments to distinguish a final picture from execution-history evidence.
