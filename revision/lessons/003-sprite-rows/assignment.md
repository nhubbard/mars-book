# Sprite rows and pixel addresses

Read Chapter 6 and the corresponding written lab. Derive the row address from
its element sizes before using Debug to follow the worked program. Record the
execution boundary with each pointer and count. Explain why the renderer's
advanced a1 is different from the outer loop's saved row base.

The worked program draws a horizontal mirror. The independent function draws a
vertical flip into the right half of a prefilled frame. Implement that function
using its stated arguments and preservation contract; the helper is optional.
Use the public cases as feedback, retain an address derivation, and investigate
the written lab's deliberate faults on separate copies.
