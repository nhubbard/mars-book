# Integer decisions and dashed rasters

Read Chapter 7 and its written lab before using the complete integer-line.asm.
Derive the selected cells and their word addresses, then follow the saved doubled
error through both coordinate tests. Record the execution boundary with each
cursor, error and count. Use the supplied temporary-breakpoint sequence to
separate repeated visits to the same instruction.

The independent function paints alternate visits along the same canonical raster.
Plan geometry, visit parity and painted count separately. Use public case feedback
without copying a particular register allocation or recurrence. Retain a default
trace, a vertical counterexample to x parity, and a halfway case whose tied cell
is actually painted. The written lab supplies further deliberate faults.
