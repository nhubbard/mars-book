# Native UTF-8 assessment foundation

The UTF-8 companion now has data-only native profiles under revision/labs/checks/utf8-native. Nine bounded function profiles retain all 426 original stream cases in their original order, names, prefix setup, target selection, scratch-register changes and arena offsets. Fifteen console publication cases retain all original caller variants. Twelve additional function cases explicitly interleave two state objects and revisit terminal outcomes.

The oracle reasons about reachable scalar-value intervals for each accepted prefix. Six host tests compare it with the strict host decoder for every one of the 65,536 byte pairs, inspect restricted lead boundaries and scalar splits, and verify complete fixture regeneration. They distinguish a possible final prefix from an impossible current byte. Native profiles check all eight words, per-call accepted counts, saved registers, exact input intervals, permitted selected-state stores and frozen caller data after return. Repeated calls within a case use the same simulator; setup replaces input bytes and scratch registers without resetting persistent state.

Both private algorithms, a stack-using variant, and both algorithms above 4 GiB pass all 453 cases each: 2,265 valid native placements. All twelve historical accuracy mutations and the unfinished scanner retain distinguishing stream failures. The original public stream/caller DSL and the generated caller checks agree for both algorithms. The production native parsers and prepared checkers execute the cases; no second MIPS emulator or downloaded predicate is introduced. Existing console format 7 and function format 23 suffice, with no new main-plugin grading mechanism.

This is assessment foundation evidence. Actual native unit import/PSI checks, first-use and saved-resume interaction, the private edition and written publication are separately recorded in utf8-native-unit.md and private native-utf8-unit-01. These finite domains do not prove every arbitrary stream, corrupted state or whole address space. Historical captures and original construction packages remain preserved.
