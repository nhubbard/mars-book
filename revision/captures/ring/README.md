# Full and empty queue observations

These unchanged 1280 by 900 PNGs are actual light-theme Debug captures of the
seven-byte worked example in the revised written companion. The reference queue
functions execute normally; the example varies the initial descriptor and five
commands. The default student caller instead has capacity eight and fourteen commands.
The visible source shows only the shared public caller; no private function body
is visible. The published crops show the native Memory tab's Address and Bytes
columns. All crop and highlight geometry is native LaTeX, recorded in coordinates.json.

The first four descriptor words are head, tail, used and capacity, in little-endian
order. Full and empty both have head and tail five; used changes from seven to zero.
Raw capture receipts, source/input bindings and state/history checks are retained
privately under verification/restructuring/ring-companion-01. These technical
observations are not representative learner or assistive-technology review.
