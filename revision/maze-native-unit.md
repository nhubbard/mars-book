# Native maze lesson draft

`revision/lessons/010-maze-frontier` packages the existing maze companion as a
native student activity. It follows the sorting unit and retains original
project010's complete independent search and renderer interface. The worked
experiments isolate coordinate geometry; they do not supply a finished search.

The twelve explicit student exports contain three assembly sources, assignment
and independent instructions, lesson metadata, the original worked helper checker,
and two data profiles with matching generated CLI checks. The independent starter
retains both deliberate breaks. No private maze implementation, instructor key
or private fixture is exported.

Thirteen activities comprise seven inline predictions, two three-stop Debug
observations, two ordinary Runs and separate renderer/search assessments. Debug
compares east from cell seven with north from cell nine. Questions distinguish
IDs from geometry, signed table values, open/discovered state, marking before
enqueue, retained FIFO history, nonunique shortest paths and complete publications.
The renderer can be assessed while main is unfinished; a final Run lets students
inspect their completed program in Bitmap Display after the stronger checks.

The two actual native archive/import tests pass, including all fifteen PSI
instruction pointers. Six drafted Debug register boundaries match the actual core.
The complete worked helper passes its original 256-call geometry test and complete
caller case. Public tooling passes641 tests. Source identities retain the original
public helper and unfinished full-search source, with only the north experiment's
two call arguments changed.

The preceding assessment foundation is MARS19b36d7e and public3ac65bf0. It passes
304 CLI /1342 plugin tests, full required coverage, 858 positive native search /
renderer placements, ten rejected faulty profiles and26 generated CLI placements.
The actual archive tests are two additional tests after that full regression;
production code is unchanged. Their scope is not live IDE interaction.

First-use/resume IDE verification, installed-archive comparison, instructor edition
binding and direct written-lab integration remain to be completed. Existing maze
figures and original qualification receipts retain their earlier scope. Neither a
new screenshot nor representative learner, author or accessibility review is
claimed by this draft milestone. The main and lab book PDFs are unchanged.
