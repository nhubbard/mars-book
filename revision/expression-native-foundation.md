# Native expression assessment foundation

All 540 original individual expression trials retain their input bytes, selected arena, salts, offsets, stack seeds, continuation selection and full saved-state contract. The bounded native profiles split into 251 successful and 289 diagnostic cases, each batch no larger than fifty. Twenty complete caller variants use continuous format-8 observations before the call, after return and after publication; no machine reset substitutes for the real call. Six newly authored public recovery sequences exercise three calls per machine. Their native JSON profiles and generated caller DSL reproduce from tools/expression_lesson_cases.py.

The original eleven rotation sequences belong to the private instructor suite. An early local, uncommitted draft incorrectly reused them as public examples; the distribution audit caught this before any commit or push. They were replaced with six distinct public examples. A private preparation script reproduces the original native rotation profile exclusively in the instructor repository. No private rotations are exported to the student archive or public Git history.

Two different parser algorithms at ordinary and wide data addresses each pass all 566 public cases, plus the eleven private native rotations. Nineteen historical fault variants and the starter are rejected by distinguishing cases. Both algorithms pass the unchanged original public kernel/caller DSL, generated caller DSL, 10,230 private grammar cases and eleven private sequences. An independent Python precedence-climbing oracle is checked against fixed first-error examples and a thousand host-AST arithmetic chains. Core probes verify ten guided register boundaries; actual platform PSI/import and first/resume IDE evidence are recorded separately in expression-native-unit.md.

No new grader capability was necessary: function format 23 and the preceding console format 8 carry the complete stated contracts. The publication, IDE and private release receipts are kept separate from these foundation results. Finite testing does not establish universal parser correctness.
