\section{Step 45 Run the whole countdown image}\label{vm-s45}

Complete all regions, then debug the supplied program to vm\_ready. Read the return registers and selected descriptor before continuing. The function has published descriptor outputs, but the caller has not yet copied the return registers into last\_status and last\_steps. The inactive stack cells have no promised values.

Status is one, retired count thirty-three, PC eighteen, depth one, fault minus one and the live value is six. The two caller result words are still ninety-nine.
