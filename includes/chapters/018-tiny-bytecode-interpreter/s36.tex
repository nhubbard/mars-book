\section{Step 36 Locate left and right without popping them}\label{vm-s36}

Require two live values and address index depth minus two. Load the older word as left and the top word as right. Keep depth unchanged while computing a candidate. A failure must return the original live prefix, so consuming operands before checks would publish incorrect state.
