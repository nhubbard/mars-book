\section{Step 20 Complete target validation before execution}\label{vm-s20}

Advance by the selected size and repeat. When all records pass, execute\_begin resets the shared cursor to guest PC zero. The still-unfinished execution region then returns provisionally. An invalid branch anywhere in the image instead reaches the image-error return before any guest retirement.
