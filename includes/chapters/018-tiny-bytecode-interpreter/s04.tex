\section{Step 4 Use the common publication and restore path}\label{vm-s04}

The supplied validation exits record a fault offset before resetting the output PC. Runtime exits retain their current PC. All paths reach vm\_commit, which writes five output words, restores the saved registers and releases the frame. Temporary regions also branch there so incomplete programs return cleanly.

\subsection{Expected observation}
The untouched starter returns provisional state and exits; it does not implement or pass the final interpreter contract.
