\section{Step 11 Record an instruction beginning in full width}\label{vm-s11}

Create one full-width bit at the current byte offset and combine it with the bitmap. The cursor is below length and length is at most sixty-four, so the shift position is zero through sixty-three. Operand positions receive no mark. The next edit will advance past the complete record.

\subsection{Check your understanding}
What does one set bit mean?

\begin{itemize}
  \item \textbf{A} A decoded instruction begins at that offset.
  \item \textbf{B} The byte value equals one.
  \item \textbf{C} A guest instruction retired there.
\end{itemize}
