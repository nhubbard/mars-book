\section{Check the representation before writing handlers}\label{vm-questions}
\begin{MARSExercise}{A mapped byte is not necessarily an instruction}
Why is target six invalid in the default program?
\begin{itemize}
\item \textbf{A} The byte lies outside the eighteen-byte image.
\item \textbf{B} The byte is an operand rather than an instruction beginning.
\item \textbf{C} Every branch must select a larger offset.
\end{itemize}
Explain why a range check alone cannot establish target validity.
\end{MARSExercise}
\begin{MARSExercise}{Budget and failure timing}
Use capacity two. Compare budgets two and three for the default image. State status,
PC, depth, retired count and fault offset for each call. Which instruction is first
attempted by the larger-budget call that the smaller-budget call never attempts?
\end{MARSExercise}
\begin{MARSExercise}{Two stacks}
Identify the memory changed by \texttt{DUP} and the register addressing the interpreter
frame. Explain why a guest target is a byte offset, then give the full-width address
calculation for its opcode.
\end{MARSExercise}
