\section{Step 3 Inspect the saved frame and initial state}\label{vm-s03}

The supplied leaf function reserves sixty-four native stack bytes and saves all eight saved registers with doubleword stores. It copies the state pointer into \texttt{s2} before reusing \texttt{a2} for the fault offset. Full pointers live in \texttt{s0}, \texttt{s2} and \texttt{s3}; the small length, capacity and offsets have separate roles.

\subsection{Expected observation}
The saved frame restores all bits of the original \texttt{s0} through \texttt{s7}. No \texttt{jal} occurs inside this leaf function, so its incoming return address stays live.

\subsection{Check your understanding}
Why copy the state pointer before assigning minus one to \texttt{a2}?

\begin{itemize}
  \item \textbf{A} The state descriptor has no address.
  \item \textbf{B} Minus one is another valid descriptor pointer.
  \item \textbf{C} \texttt{a2} is being reassigned from an input pointer to the fault register.
\end{itemize}
