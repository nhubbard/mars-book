\section*{Contract and implementation sources}
The thirteen-opcode language, descriptor layout and diagnostic priority are defined
by this exercise. They are not a standardized MIPS bytecode format. The native code
uses the pinned MARS MIPS64 Release 6 environment. Its word sign extension, full-width
address arithmetic, byte loads and retained delayed transfers follow that simulator's
instruction implementations. The student package records the exact upstream revision
and includes executable public checks. Instructor checks also exercise an equivalent
boundary representation, malformed images and repeated calls with changed contents.
