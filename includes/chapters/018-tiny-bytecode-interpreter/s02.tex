\section{Step 2 Read the descriptor as an interface}\label{vm-s02}

Capacity and the full stack pointer are inputs. The other five fields are outputs, and every call starts fresh. The selected stack may be a subview of a larger allocation; only capacity words belong to this call. Inspect status before deciding whether the fault field names a failure.

\subsection{Expected observation}
For a valid zero-budget call, outputs are PC zero, depth zero, retired zero, status zero and fault minus one.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
May a later call resume using the old output PC?

\begin{itemize}
  \item \textbf{A} Yes, if capacity is unchanged.
  \item \textbf{B} No, each call begins at zero with an empty logical stack.
  \item \textbf{C} Only if the old status was halt.
\end{itemize}
