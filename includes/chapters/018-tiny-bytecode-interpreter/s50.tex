\section{Step 50 Compare work with the same complete behavior}\label{vm-s50}

Measure whole native function calls for the bitmap design and a dense-byte-map alternative. Include validation, execution and restoration. Compare zero-budget, short, looping and invalid scenes separately. The alternative also changes opcode classification, so the observed differences combine more than boundary representation.

\subsection{Expected observation}
The default full call uses 2394 native instructions in the bitmap design and 2259 in the tested alternative; both retire thirty-three guest instructions.
