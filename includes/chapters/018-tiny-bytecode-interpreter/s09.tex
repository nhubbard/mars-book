\section{Step 9 Recognize a wide constant or reject the opcode}\label{vm-s09}

Select size five only for \texttt{PUSH32}. If no legal opcode matched any earlier group, select invalid-opcode status and use the provided image-error return. That return records the failing decode offset and resets the output PC to zero because execution has not begun.

\Needspace{17\baselineskip}
\subsection{Write or inspect}
Replace the temporary branch in \texttt{format\_wide}. Preserve surrounding labels and the provided frame and exits.

\Needspace{10\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $t1, 5
    li $t2, 2
    beq $t9, $t2, format_size
    nop
    li $v0, -1
    beq $zero, $zero, image_error
    nop
\end{minted}
\subsection{Expected observation}
\texttt{PUSH32} selects size five. Byte ff in opcode position reports minus one at that instruction start.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What does the image-error return preserve separately from output PC?

\begin{itemize}
  \item \textbf{A} The native instruction address.
  \item \textbf{B} The offending encoded-instruction offset.
  \item \textbf{C} The last popped operand.
\end{itemize}
