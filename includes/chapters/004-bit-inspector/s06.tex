\section{Step 6 Add one at doubleword
width}\label{004-bit-inspector-s06-step-6-add-one-at-doubleword-width}

daddiu adds at the 64-bit register width. Its input here is the
sign-extended original word. All allowed input values plus one fit in a
signed doubleword, so this task reaches no 64-bit overflow boundary.

\subsection{Write or
inspect}\label{004-bit-inspector-s06-write-or-inspect}

Append the doubleword addition.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddiu $s3, $s0, 1
wide_added:
\end{minted}

\subsection{Expected
observation}\label{004-bit-inspector-s06-expected-observation}

For the maximum signed word, \texttt{\$s3} is 0x0000000080000000, or
2147483648. That differs from the word-width result.

\subsection{Check your
understanding}\label{004-bit-inspector-s06-check-your-understanding}

For input 2147483647, which result is positive 2147483648?

\begin{itemize}
\tightlist
\item
  \textbf{A} The daddiu result.
\item
  \textbf{B} The sign-extended addiu result.
\item
  \textbf{C} Both results must be negative because the source is a word.
\end{itemize}
