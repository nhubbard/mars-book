\section{Step 4 Load and zero-extend the same
word}\label{004-bit-inspector-s04-step-4-load-and-zero-extend-the-same-word}

lwu reads the same four bytes but fills the upper 32 register bits with
zeroes. The default becomes 00000000ffffffff, representing positive
4294967295. The low words of the two load results are identical.

\subsection{Write or
inspect}\label{004-bit-inspector-s04-write-or-inspect}

Append the unsigned word load.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    lwu $s1, 0($t0)
unsigned_loaded:
\end{minted}

\subsection{Expected
observation}\label{004-bit-inspector-s04-expected-observation}

\texttt{\$s0} is -1 and \texttt{\$s1} is 4294967295, yet both have low
word ffffffff. No input bytes changed.

\subsection{Check your
understanding}\label{004-bit-inspector-s04-check-your-understanding}

When do these load results differ?

\begin{itemize}
\tightlist
\item
  \textbf{A} For every possible source word.
\item
  \textbf{B} Only when the source address is odd.
\item
  \textbf{C} When source bit 31 is one.
\end{itemize}
