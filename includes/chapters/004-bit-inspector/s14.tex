\section{Step 14 Inspect the signed-word
  boundary}\label{004-bit-inspector-s14-step-14-inspect-the-signed-word-boundary}

The default -1 input demonstrates extension, but it does not separate
the two plus-one results. Using 2147483647 makes the word sum cross bit
31 while the doubleword sum remains positive.

\subsection{Write or
  inspect}\label{004-bit-inspector-s14-write-or-inspect}

In a separate copy, set the sample initializer to 2147483647. Predict
all four stored results and the four report lines. Run and Debug that
copy, then restore the default source before the default capture.

\subsection{Expected
  observation}\label{004-bit-inspector-s14-expected-observation}

The loads both yield 2147483647. word\_plus\_one is -2147483648 and
wide\_plus\_one is 2147483648. The report still describes the original
2147483647.

\subsection{Check your
  understanding}\label{004-bit-inspector-s14-check-your-understanding}

Which value is printed by the report for this input?

\begin{itemize}
  \tightlist

        \textbf{A} Only the doubleword-plus-one result.
  \item
        \textbf{B} The original word, 2147483647.
  \item
        \textbf{C} Only the word-plus-one result.
\end{itemize}
