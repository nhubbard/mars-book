\section{Step 3 Load and sign-extend the
  word}\label{004-bit-inspector-s03-step-3-load-and-sign-extend-the-word}

lw reads a 32-bit word and sign-extends it into the 64-bit destination.
It copies word bit 31 into every upper-register bit. For the all-one
input, the full register is ffffffffffffffff, representing -1 as a
signed 64-bit integer.

\subsection{Write or
  inspect}\label{004-bit-inspector-s03-write-or-inspect}

Append the word load and its following checkpoint label.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    lw $s0, 0($t0)
signed_loaded:
\end{minted}

\subsection{Expected
  observation}\label{004-bit-inspector-s03-expected-observation}

\texttt{\$s0} is 0xffffffffffffffff for the default sample. The next
instruction has not yet loaded the unsigned version.

\subsection{Check your
  understanding}\label{004-bit-inspector-s03-check-your-understanding}

Which bit is repeated during sign extension from a word?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Bit 31 of the source word.
  \item
        \textbf{B} Bit 0 of the address.
  \item
        \textbf{C} Bit 63 of an unrelated register.
\end{itemize}
