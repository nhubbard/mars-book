\section{Step 7 Store a complete signed
  result}\label{004-bit-inspector-s07-step-7-store-a-complete-signed-result}

The result fields are doublewords: each occupies eight bytes. sd stores
one complete 64-bit general-purpose register. The .align 3 directive in
the supplied data section establishes eight-byte alignment for the
initial layout.

\subsection{Write or
  inspect}\label{004-bit-inspector-s07-write-or-inspect}

Load the result-block address and store the first value.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t1, results
    sd $s0, 0($t1)
\end{minted}

\subsection{Expected
  observation}\label{004-bit-inspector-s07-expected-observation}

signed\_value now contains all eight bytes of the sign-extended result.
For -1, every one of those bytes is ff.

\subsection{Check your
  understanding}\label{004-bit-inspector-s07-check-your-understanding}

How many bytes does this sd write?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Four because the original input was a word.
  \item
        \textbf{B} One because the input initializer was -1.
  \item
        \textbf{C} Eight.
\end{itemize}
