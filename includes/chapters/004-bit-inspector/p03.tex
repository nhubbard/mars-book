\section{Sign extension preserves a signed
value}\label{004-bit-inspector-p03-sign-extension-preserves-a-signed-value}

When a signed word is widened, copying bit 31 into the upper 32
positions preserves its signed numerical value. A nonnegative word has
bit 31 clear, so sign extension adds zeroes. A negative word has bit 31
set, so it adds ones.

For \ensuremath{-}1, the 32-bit pattern is ffffffff and the 64-bit sign-extended
pattern is ffffffffffffffff. Both represent \ensuremath{-}1 at their respective
widths. For the minimum signed word, 80000000 widens to
ffffffff80000000, still representing \ensuremath{-}2147483648.

\texttt{lw} performs this widening in the current 64-bit MARS
environment. Its result is a full register value, not an unspecified
upper half attached to a loaded word. That guarantee is part of the
instruction semantics and is observable in the debugger or in an
eight-byte store.
