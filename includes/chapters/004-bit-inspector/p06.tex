\section{Store the width that the contract
requires}\label{004-bit-inspector-p06-store-the-width-that-the-contract-requires}

The output fields expose the full register results in memory.
\texttt{sd} transfers one 64-bit general-purpose register into an
eight-byte field. The source was originally a word, but the stored
object now describes the widened result.

Writing only four bytes would leave the other half dependent on the
field\textquotesingle s previous contents. A zero-initialized starter
can hide that mistake when the expected high half is zero. The author
checks therefore poison every output byte before execution and inspect
all eight bytes afterward.

In the default little-endian environment, the low byte is at the lowest
address. The sign-extended \ensuremath{-}1 field contains eight ff bytes; the
zero-extended field contains four ff bytes followed by four 00 bytes.
The byte-order convention explains the address order without changing
either full numerical value.
