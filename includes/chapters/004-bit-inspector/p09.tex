\section{Compare evidence at the required
precision}\label{004-bit-inspector-p09-compare-evidence-at-the-required-precision}

A report showing 0xffffffff establishes the low word. It does not
establish whether the argument register was ffffffffffffffff,
00000000ffffffff, or another 64-bit value with the same low word. A
result contract about all 64 bits requires a full-register observation
or an eight-byte memory check.

The same issue appears when checking arithmetic. The word and doubleword
plus-one results at the signed-word boundary share low word 80000000 but
have different high halves. A low-word check would accept the wrong
result width.

The grader\textquotesingle s existing byte assertions can express the
full requirement directly. Its oracle computes the expected signed and
unsigned 64-bit values, serializes each into eight little-endian bytes,
and compares every byte. That makes the check independent of the
student\textquotesingle s register allocation.
