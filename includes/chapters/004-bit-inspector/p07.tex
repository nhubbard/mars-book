\section{A service formats an argument under its own
contract}\label{004-bit-inspector-p07-a-service-formats-an-argument-under-its-own-contract}

The four report services all read the low word in \texttt{\$a0}. Service
1 formats it as signed decimal; service 36 formats it as unsigned
decimal. Service 34 uses hexadecimal and service 35 uses binary. The
selection in \texttt{\$v0} determines which representation is produced.

The reference passes the sign-extended original value to each service.
It could pass the zero-extended version instead and obtain the same
report, because the low 32 bits are identical. The alternative
implementation does exactly that. The console report is therefore a view
of the word, not a complete dump of the argument register.

The prefix and line ending remain explicit output requests. They make
the report readable while preserving the exact bytes that the grader
compares. The format service does not silently add a newline or change
the stored input.
