    \begin{enumerate}
      \item The next \texttt{la} begins setting up the report. The four \texttt{sd} instructions have already written eight bytes each. Neither the message nor the numeric report has been printed at this stop.
      \item The input and its guard occupy the first eight displayed bytes. The four result fields start at \texttt{0x10010008}, \texttt{0x10010010}, \texttt{0x10010018} and \texttt{0x10010020}. The signed field is eight \texttt{ff} bytes; the unsigned field is \texttt{ff ff ff ff 00 00 00 00}. Both sum fields are eight zero bytes. At \texttt{0x10010028}, \texttt{e0 ac 68 24} is the result guard; the following \texttt{73 69 67 6e} starts the message text.
      \item The register group reads \texttt{\$s0} through \texttt{\$s3}: $-1$, 4294967295, zero, zero. Both additions use the sign-extended source in \texttt{\$s0}. For this particular sample, adding one at either width gives zero; a boundary sample is needed to expose their different widths.
    \end{enumerate}
