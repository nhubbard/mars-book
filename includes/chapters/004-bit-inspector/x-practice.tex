\section{Trace widths before choosing an
instruction}\label{004-bit-inspector-x-practice-trace-widths-before-choosing-an-instruction}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Interpret 0x80000001 as a signed word and as an unsigned word. Predict
  both full-register load results and both plus-one results.
\item
  Explain why service 1 still prints -1 when passed 0x00000000ffffffff.
\item
  Predict service 36 output for a full register containing
  0x0000000100000000. State which bits the service reads.
\item
  Replace one sd with sw in a separate copy. Explain why a zero-filled
  field might hide the mistake and how poisoned high bytes reveal it.
\item
  Explain why addiu and daddiu agree for -1 yet disagree for 2147483647.
\item
  Derive an alternative zero-extension sequence and test it on
  substituted words.
\end{enumerate}

For each answer, state the observation width explicitly. A hexadecimal
numeral with eight digits describes a word; a full 64-bit pattern needs
sixteen.
