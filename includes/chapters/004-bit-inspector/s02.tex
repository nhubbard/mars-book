\section{Step 2 Load the sample
address}\label{004-bit-inspector-s02-step-2-load-the-sample-address}

The program first needs the address of the input word. la supplies that
address in a register; it does not load the word itself. The result
fields and messages are separate objects in the same data section.

\subsection{Write or
inspect}\label{004-bit-inspector-s02-write-or-inspect}

Append the address load in the program region.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, sample
\end{minted}

\subsection{Expected
observation}\label{004-bit-inspector-s02-expected-observation}

\texttt{\$t0} identifies sample. The sample bytes and all output fields
are unchanged.

\subsection{Check your
understanding}\label{004-bit-inspector-s02-check-your-understanding}

What does this instruction put in \texttt{\$t0}?

\begin{itemize}
\tightlist
\item
  \textbf{A} The unsigned value 4294967295.
\item
  \textbf{B} The address of sample.
\item
  \textbf{C} The signed value -1.
\end{itemize}
