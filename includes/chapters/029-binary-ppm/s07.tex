\section{Step 7 Scan a comment within the same limit}\label{ppm-s07}

Treat a hash in a header gap as a comment and mark the gap as present. Advance through comment bytes with the same offset-limit check as other header reads. Stop at LF and let the whitespace path consume that LF; an unterminated comment must fail at the bound.

Author region \texttt{p\_comment}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{after\_p\_gap} for the observation.

Use recipe \texttt{s07-1} with the cumulative source through this edit.

\subsection{Expected observation}
The commented recipe reaches its width digit; the unterminated variant returns status one.
