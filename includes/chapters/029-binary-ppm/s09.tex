\section{Step 9 Accumulate digits without consuming the delimiter}\label{ppm-s09}

For each digit, subtract ASCII zero and update the numerical value to ten times the old value plus the digit. Reject a value above 255 immediately. Leave the first nondigit unconsumed so the next parser state can check the required gap or final LF.

Author region \texttt{p\_digits}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{parse\_number\_done} for the observation.
