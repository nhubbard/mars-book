\section{Step 38 Validate before opening output}\label{ppm-s38}

Retain the path, serialized source and count while the parser uses the private descriptor. Propagate a nonzero parser status. Do not open the destination yet: a valid filename must not let malformed image bytes erase an existing file.

Author region \texttt{sv\_validate}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{after\_sv\_validate} for the observation.

Use recipe \texttt{s38-1} with the cumulative source through this edit.

\subsection{Expected observation}
The private descriptor is valid and the old output file remains untouched.

\subsection{Check your understanding}
Why parse before mode-one open?

\begin{itemize}
  \item \textbf{A} Mode one can truncate existing output.
  \item \textbf{B} Parsing requires a writable descriptor.
  \item \textbf{C} The path contains the raster length.
\end{itemize}
