\section{Sources and development status}
The raw format, header/raster distinction and general sample representation follow the
\href{https://netpbm.sourceforge.net/doc/ppm.html}{Netpbm PPM specification}. The
sixty-four-pixel dimension limit, canonical numeric tokens, bounded header, LF-only
final separator and single-image exact-extent policy are local teaching choices.
Framebuffer word construction follows the display convention developed earlier in the
book. The file-operation discussion follows the current MARS syscall implementation.

The private scalar prototypes implement all five interfaces and a complete caller that
loads an image, fills framebuffer memory and saves the result. A second implementation uses a whitespace mask, field insertion
and byte-oriented serialization. Each passes 785 memory checks and 81 file/caller checks
at ordinary addresses and again above 4 GiB, for 3464 positive executions. Twenty-four
deliberately faulty variants are rejected. Forty-eight actual saved images are also
opened by an independent image reader and checked for dimensions and exact sample bytes.
Three additional runs use actual host files through the normal CLI, and a malformed-file
run preserves an existing destination. These finite checks do not establish exhaustive
equivalence or student usability.

The public reading specifies the interfaces and explains their algorithms. Complete
executable solutions remain private. Cumulative exercises, guided starter regions,
public completion checks and separate distributions remain next. This draft is not yet
included in the main manuscript. Actual annotated light-theme IDE captures, remote
progression and independent accessibility review remain unfinished. The author's
substantial prose rewrite remains deferred until all thirty-five chapter drafts exist.
