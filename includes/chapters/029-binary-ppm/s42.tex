\section{Step 42 Run the connected program and reuse the session}\label{ppm-s42}

Select the connected caller after all regions are complete. Follow loaded byte count into decoding, packed dimensions into encoding and encoded byte count into saving. Repeat after an error and after a longer earlier output so stale state, descriptor positions and old file suffixes cannot hide behind a fresh simulator.

Use \texttt{s42-1} for this observation.

\subsection{Expected observation}
The saved canonical image agrees with independent checks; failure leaves the promised caller objects unchanged.

\subsection{Check your understanding}
Why retain same-session checks?

\begin{itemize}
\item \textbf{A} They remove the need for error checks.
\item \textbf{B} A fresh machine can hide stale private state and descriptor-position bugs.
\item \textbf{C} They permit different RGB byte order.
\end{itemize}
