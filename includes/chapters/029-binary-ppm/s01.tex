\section{Step 1 Trace the header and raster}\label{ppm-s01}

Account for the eleven header bytes and twelve sample bytes in the worked image. Keep the byte offset of the first sample separate from the number of pixels. Before changing instructions, prepare the first parser recipe and inspect the source arena at the caller boundary.

Use \texttt{s02-1} for this observation.

\subsection{Expected observation}
The first raster byte is at offset eleven; four pixels require twelve samples.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Which offset begins the worked raster?

\begin{itemize}
\item \textbf{A} Twelve.
\item \textbf{B} Ten.
\item \textbf{C} Eleven.
\end{itemize}
