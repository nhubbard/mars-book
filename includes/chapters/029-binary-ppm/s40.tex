\section{Step 40 Advance by bytes actually written}\label{ppm-s40}

Track accepted bytes separately from the total. Request the unaccepted suffix and add each positive result to the accepted count. A negative or zero-progress result for a nonempty request takes the close-and-error path. Keep the complete source readable, including its guard byte for the current syscall.

Author region \texttt{sv\_write}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{save\_done} for the observation.
