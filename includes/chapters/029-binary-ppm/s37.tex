\section{Step 37 Preflight a save byte count}\label{ppm-s37}

Reject a zero serialized count with format status one and an unsigned over-limit count with status two. Both decisions precede any source or path access. Enter the supplied frame only after the count is within the parser domain.

Author region \texttt{sv\_bound}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{after\_sv\_bound} for the observation.

Use recipe \texttt{s37-1} with the cumulative source through this edit.

\subsection{Expected observation}
A valid count reaches validation; zero and over-limit counts perform no file operations.
