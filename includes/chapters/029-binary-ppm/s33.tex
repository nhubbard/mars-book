\section{Step 33 Open and retain the input descriptor}\label{ppm-s33}

Retain the byte buffer, capacity and metadata pointers, then open the supplied path read-only. A negative result returns I/O status three. Otherwise retain the actual descriptor and initialize the number of loaded bytes to zero. The supplied development exit closes this descriptor while later regions remain unfinished.

Author region \texttt{l\_open}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{after\_l\_open} for the observation.

Use recipe \texttt{s33-1} with the cumulative source through this edit.

\subsection{Expected observation}
The valid fixture is open at the checkpoint and is closed on the temporary development return.
