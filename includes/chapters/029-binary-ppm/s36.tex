\section{Step 36 Close, parse and publish loaded metadata}\label{ppm-s36}

Close the input after EOF, then parse the complete buffered byte count into the supplied metadata object. Propagate any parser failure. On success return the exact loaded file count, not the parser pixel count.

Author region \texttt{l\_finish}, keeping its BEGIN/END markers and the supplied caller, checkpoint labels and cleanup paths. Stop at \texttt{function\_return} for the observation.

Use recipe \texttt{s36-1} with the cumulative source through this edit.

\subsection{Expected observation}
The loader returns twenty-three bytes and the completed metadata; malformed input leaves metadata unchanged.
