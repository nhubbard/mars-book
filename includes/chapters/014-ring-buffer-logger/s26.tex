\section{Step 26 Move the ring and the byte pointers}\label{ring-s26}

Select the other descriptor and independently select either ring buffer. Vary source and destination byte offsets. The implementation must follow the pointer stored in its selected descriptor rather than a ring label from main.

\subsection{Write or inspect}
Perform the described inspection or experiment while keeping the submitted interfaces unchanged.

Before a manual call through the second descriptor, initialize its stored buffer
address: load the chosen ring label with \texttt{dla} and store that full pointer
at descriptor offset sixteen with \texttt{sd}. Main initializes only the first
descriptor. Both descriptors start with empty indices, but an unset buffer pointer
is not a valid allocation. The automated checks prepare the selected descriptor
before calling either function.

\subsection{Expected observation}
Unaligned byte pointers work, and unrelated descriptors, buffers, and guard words remain unchanged.
