\section{Step 11 Count each completed byte}\label{ring-s11}

Reduce the remaining-byte count after copying and wrapping. Branch back while more bytes remain. The fixed labels let the copy body, wrap, and count increments be inserted separately without unresolved branch targets.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_count} region. Keep the scaffold labels and return stubs.

\Needspace{6\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t7, $t7, -1
    bne $t7, $zero, push_copy
    nop
\end{minted}

\subsection{Expected observation}
Exactly L payload bytes are copied after the single prefix byte.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which count reaches zero here?

\begin{itemize}

  \item \textbf{B} The total ring capacity.
  \item \textbf{C} The occupied-byte count.
\end{itemize}
