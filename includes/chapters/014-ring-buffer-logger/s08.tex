\section{Step 8 Skip the copy for an empty payload}\label{ring-s08}

Copy the source pointer into a full-width cursor and the payload length into a remaining-byte counter. Branch directly to publication when the counter is zero. The prefix has already consumed its own queue slot.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_init} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t6, $a1
    move $t7, $a2
    beq $t7, $zero, push_commit
    nop
\end{minted}

\subsection{Expected observation}
A zero-length push stores one prefix byte and performs no source reads.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What does the zero-length path still publish?

\begin{itemize}
  \item \textbf{A} A payload terminator.
  \item \textbf{B} One newly occupied byte.
  \item \textbf{C} An unchanged used count.
\end{itemize}
