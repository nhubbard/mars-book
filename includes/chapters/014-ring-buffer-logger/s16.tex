\section{Step 16 Reject a destination that is too small}\label{ring-s16}

Select the short-destination status and report the required payload length in \texttt{v1}. Compare destination capacity with that length. If it is too small, return before copying or changing queue state. Equality succeeds.

\subsection{Write or inspect}
Append these instructions in the \texttt{pop\_fit} region. Keep the scaffold labels and return stubs.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -2
    move $v1, $t5
    sltu $t9, $a2, $t5
    bne $t9, $zero, pop_return
    nop
\end{minted}

\subsection{Expected observation}
A seven-byte payload and capacity six return -2 and seven; a retry with capacity seven can still pop that record.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What does \texttt{v1} report on this failure?

\begin{itemize}
\item \textbf{A} The encoded size including the prefix.
\item \textbf{B} The required payload bytes.
\item \textbf{C} Zero for every error in both functions.
\end{itemize}
