\section{Step 14 Detect empty before decoding a prefix}\label{ring-s14}

Select the empty status, clear the auxiliary result, and load used. Return if used is zero. Ring bytes can retain previously popped data, so reading an old prefix is not evidence that a record remains queued.

\subsection{Write or inspect}
Append these instructions in the \texttt{pop\_empty} region. Keep the scaffold labels and return stubs.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -1
    move $v1, $zero
    lw $t2, 8($a0)
    beq $t2, $zero, pop_return
    nop
\end{minted}

\subsection{Expected observation}
An empty queue returns -1 and zero without changing any caller data.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What establishes that a record exists?

\begin{itemize}
  \item \textbf{A} A nonzero occupied-byte count in a valid descriptor.
  \item \textbf{B} A nonzero first ring byte.
  \item \textbf{C} Head and tail being unequal in all representations.
\end{itemize}
