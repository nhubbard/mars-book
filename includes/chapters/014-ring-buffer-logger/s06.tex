\section{Step 6 Write the prefix through the supplied buffer}\label{ring-s06}

Load tail and the descriptor buffer pointer. Form the full effective address from base plus tail, then store the payload length as one byte. All failure conditions have already been decided. The caller source has no prefix to copy.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_prefix} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lw $t1, 4($a0)
    ld $t4, 16($a0)
    daddu $t6, $t4, $t1
    sb $a2, 0($t6)
\end{minted}

\subsection{Expected observation}
For a three-byte payload beginning at tail seven, ring byte seven becomes three.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Where does the stored prefix value come from?

\begin{itemize}
  \item \textbf{A} The first source byte.
  \item \textbf{B} The used count.
  \item \textbf{C} The supplied payload length.
\end{itemize}
