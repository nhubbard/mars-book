\section{Step 19 Copy a payload byte out}\label{ring-s19}

Form the full address from the buffer base and current head index. Load one byte and store it through the linear destination cursor, then advance that cursor at full width. Leave ring storage unchanged.

\subsection{Write or inspect}
Append these instructions in the \texttt{pop\_bytes} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    daddu $t9, $t4, $t0
    lbu $t8, 0($t9)
    sb $t8, 0($t6)
    daddiu $t6, $t6, 1
\end{minted}

\subsection{Expected observation}
The destination receives the oldest record bytes in their original order.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Must pop erase a byte after reading it?

\begin{itemize}
  \item \textbf{A} Yes, to make it free.
  \item \textbf{B} No; occupancy changes through descriptor state.
  \item \textbf{C} Only when its value is zero.
\end{itemize}
