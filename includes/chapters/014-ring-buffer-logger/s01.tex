\section{Step 1 Read the descriptor before the bytes}\label{ring-s01}

Locate the descriptor, its separately allocated ring, the source arena, and the output arena. The descriptor contains a buffer address, not the buffer bytes themselves. Main initializes \texttt{descriptor\_a} with \texttt{ring\_a}; independent tests may select \texttt{descriptor\_b} and a different ring.

\subsection{Write or inspect}
Perform the described inspection or experiment while keeping the submitted interfaces unchanged.

\subsection{Expected observation}
The word at offset twelve is capacity. The eight bytes at offset sixteen hold a full pointer.
