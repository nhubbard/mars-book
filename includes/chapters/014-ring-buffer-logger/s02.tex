\section{Step 2 Count encoded bytes}\label{ring-s02}

Draw a payload of three bytes and place its one-byte length prefix before it. The source contains payload only. Push creates the prefix, while pop returns payload only. A binary zero inside the payload is ordinary data and does not terminate it.

\subsection{Write or inspect}
Perform the described inspection or experiment while keeping the submitted interfaces unchanged.

\subsection{Expected observation}
A three-byte payload occupies four queue bytes. A zero-length payload still occupies one.
