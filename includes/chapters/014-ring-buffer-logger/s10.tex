\section{Step 10 Wrap the payload write index}\label{ring-s10}

Increment the tail index after the store and reset it only when it reaches capacity. The input source cursor remains linear; only the ring index wraps. Keep the wrap label in the scaffold.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_wrap} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t1, $t1, 1
    bne $t1, $t3, push_cursor
    nop
    move $t1, $zero
\end{minted}

\subsection{Expected observation}
A body byte at index seven is followed by the next body byte at index zero.
