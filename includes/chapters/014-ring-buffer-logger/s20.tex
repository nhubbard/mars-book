\section{Step 20 Wrap the payload read index}\label{ring-s20}

Advance the head index after each read and reset at capacity. The destination remains a linear byte array. Head and tail wrap in separate calls and need not cross the physical end at the same time.

\subsection{Write or inspect}
Append these instructions in the \texttt{pop\_wrap} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t0, $t0, 1
    bne $t0, $t3, pop_cursor
    nop
    move $t0, $zero
\end{minted}

\subsection{Expected observation}
A payload split across the ring end becomes a contiguous output sequence.
