\section{Step 4 Reject a record that can never fit}\label{ring-s04}

Initialize the failure auxiliary value to zero. Load capacity and compare payload length with it using an unsigned comparison. Since the prefix needs one additional byte, a payload length equal to capacity is already too large.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_fit} region. Keep the scaffold labels and return stubs.

\Needspace{9\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -2
    move $v1, $zero
    lw $t3, 12($a0)
    sltu $t9, $a2, $t3
    beq $t9, $zero, push_return
    nop
\end{minted}

\subsection{Expected observation}
With capacity eight, payload length eight reports -2 before inspecting current free space.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which condition allows a record to fit an empty ring?

\begin{itemize}
  \item \textbf{A} L is at most C.
  \item \textbf{B} L is less than C.
  \item \textbf{C} L equals C plus one.
\end{itemize}
