\section{Step 7 Advance beyond the prefix}\label{ring-s07}

Increment the bounded tail index. If it equals capacity, reset it to zero; otherwise keep the incremented value. Retain the scaffold label reached after either path. This first advance is required even for an empty record.

\subsection{Write or inspect}
Append these instructions in the \texttt{push\_advance} region. Keep the scaffold labels and return stubs.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t1, $t1, 1
    bne $t1, $t3, push_payload
    nop
    move $t1, $zero
\end{minted}

\subsection{Expected observation}
A prefix written at index seven in an eight-byte ring leaves the next index zero.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
When should a one-byte index advance reset to zero?

\begin{itemize}
\item \textbf{A} When it equals capacity.
\item \textbf{B} When it equals capacity minus one.
\item \textbf{C} Whenever it is nonzero.
\end{itemize}
