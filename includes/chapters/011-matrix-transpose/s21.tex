\section{Step 21 Trace a clipped edge without reading padding}\label{transpose-s21}

A final tile can contain fewer than four rows or columns, and both short dimensions can occur together. The allocation has spare words, so an out-of-domain read may not raise a memory exception. Bounds are a program contract even when a machine access happens to be mapped.

\subsection{Write or inspect}
Trace the second tile in three by five. List its three source indices and three destination indices. Compare those with the ordinary traversal’s last three source indices.

\subsection{Expected observation}
The tile reads source indices four, nine, fourteen and writes output indices twelve, thirteen, fourteen. The ordinary traversal finishes with source indices twelve, thirteen, fourteen instead.

\subsection{Check your understanding}
Does a mapped padding word make an extra tile load valid?

\begin{itemize}
  \item \textbf{A} No; it lies outside the active matrix.
  \item \textbf{B} Yes, if the result is discarded.
  \item \textbf{C} Yes, if the load hits in the cache.
\end{itemize}
