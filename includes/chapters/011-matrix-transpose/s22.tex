\section{Step 22 Compare both outputs and both access orders}\label{transpose-s22}

Run the public checks on the completed program. They compare output words, protected memory, return state, and traversal. They do not require a particular register allocation. The tile order can change if every clipped tile is completed before the next is entered.

\subsection{Write or inspect}
Run each method on identical input. Check rectangular, empty, one-row, one-column, and clipped cases. Compare the source read order of the small default case.

\subsection{Expected observation}
Both functions return fifteen and produce equal output for three by five. Their read orders first differ at the fifth cell: ordinary reads source index four, while tiled reads index five.
