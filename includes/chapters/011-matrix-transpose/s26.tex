\section{Step 26 Keep wide pointers and small offsets separate}\label{transpose-s26}

An active object can be only sixty bytes long and still reside above the 32-bit address range. The address calculation must preserve the base pointer even though the relative index fits in a word. The grader supplies full-width addresses through its address-aware operations and resolves labels without executing a load.

\subsection{Write or inspect}
Inspect every pointer addition in both functions. Explain why the index multiplication can use these bounded word operands while the final base addition uses \texttt{daddu}.

\subsection{Expected observation}
The same coordinate mapping works for a relocated allocation above four GiB. The low word contents and relative byte displacements do not change.
