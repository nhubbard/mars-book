\section{Step 5 Establish row starts and strides}\label{transpose-s05}

Keep the source row start in \texttt{\$t2} and the first destination of that row in \texttt{\$t4}. The source row stride is four times the input width. The destination stride inside a row is four times the output width, which equals the input row count. Copy those starts to inner pointers at \texttt{naive\_row}; the inner loop will advance only the copies.

\subsection{Write or inspect}
Append the strides, row counter, and inner initialization. Distinguish \texttt{t0}, a row index, from \texttt{t2}, a full address.

\Needspace{12\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    sll $t6, $a2, 2
    sll $t7, $a3, 2
    move $t0, $zero
    move $t2, $a0
    move $t4, $a1
naive_row:
    move $t1, $zero
    move $t3, $t2
    move $t5, $t4
\end{minted}

\subsection{Expected observation}
For three by five, \texttt{t6} is twelve and \texttt{t7} is twenty. The inner source pointer names the first input word and the inner destination pointer names the first output word.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which stride advances the destination inside one source row?

\begin{itemize}
  \item \textbf{A} Four times the input column count.
  \item \textbf{B} Four times the input row count.
  \item \textbf{C} One byte.
\end{itemize}
