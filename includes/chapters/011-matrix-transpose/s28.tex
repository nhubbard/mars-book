\section{Step 28 Plan a measured variation}\label{transpose-s28}

Choose a single extension only after the baseline passes. Changing tile side, buffer alignment, or cache geometry can alter reuse. Replacing row multiplications with pointer recurrences can alter instruction counts. Keep the correctness and measurement boundaries the same so the new result has an interpretable cause.

\subsection{Write or inspect}
Write a prediction, choose one change, and record its configuration and results. If you change the published four-by-four traversal contract, treat that as a separate experiment with a corresponding checker rather than silently changing the submitted task.

\subsection{Expected observation}
The experiment records both its checked output and the measured quantity. The baseline remains repeatable for comparison.

\subsection{Check your understanding}
What should accompany a lower cache-miss count?

\begin{itemize}
\item \textbf{A} Evidence that the changed program still meets its stated output and traversal contract.
\item \textbf{B} An assumption that all architectures run it faster.
\item \textbf{C} Removal of the edge cases.
\end{itemize}
