\section{Step 2 Inspect allocation and active dimensions}\label{transpose-s02}

Open the starter source. It reserves 256 words for each matrix, followed by named guard words. The initial dimensions activate only fifteen words in each allocation. The rest is capacity for later experiments, not extra matrix cells. The listed input values make the original linear index visible in memory.

\subsection{Write or inspect}
Inspect \texttt{ROWS}, \texttt{COLS}, and \texttt{METHOD} near the top of the source. Keep them at three, five, and zero. Confirm that the input and output are separate and that each starts at a 64-byte boundary.

\subsection{Expected observation}
The input contains values zero through 255. Only zero through fourteen belong to the current matrix. Neither function stub has copied any of them yet.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
How many words may the current transpose write?

\begin{itemize}
\item \textbf{A} All 256 reserved output words.
\item \textbf{B} Exactly fifteen active output words.
\item \textbf{C} Five guard words.
\end{itemize}
