\section{Step 9 Expose a wrong output stride}\label{transpose-s09}

A square matrix gives the same numeric row width on both sides. A rectangular example forces the two widths apart. Testing both orientations also exposes a loop bound accidentally tied to the wrong dimension.

\subsection{Write or inspect}
Try three by five and five by three. For each, derive the destination of input coordinate (1,2) from the current dimensions. Restore three by five before the tiled walkthrough.

\subsection{Expected observation}
The three-by-five case places that cell at output index seven. The five-by-three case places it at index eleven. The input values at that coordinate also differ because the input row width changed.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why are square-only tests weak here?

\begin{itemize}
  \item \textbf{A} They never contain negative data.
  \item \textbf{B} They hide a swapped row-count and column-count stride.
  \item \textbf{C} They disable word stores.
\end{itemize}
