\section{Step 25 Explain the direct-mapped counterexample}\label{transpose-s25}

A tile’s total bytes can fit in the cache while several of its lines compete for the same set. With this sixteen-word row stride, row starts advance by four line numbers. Direct mapping alternates them between only two set numbers. The destination adds further conflicts.

\subsection{Write or inspect}
Repeat the sixteen-by-sixteen comparison with direct placement, holding capacity and line size constant. Then try two-way placement.

\subsection{Expected observation}
In the measured reference layout, both methods have 344 direct-mapped misses. Both have 320 misses in the two-way experiment. Functional output remains equal and correct.
