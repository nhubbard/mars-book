\section{Step 11 Check the function independently of main}\label{transpose-s11}

The caller is useful for stepping, but the grader invokes each function directly with its own pointers, dimensions, and return continuation. It fills inactive memory with sentinels and checks saved registers before the continuation runs. This catches a kernel that works only with the starter's default argument values or absolute array labels.

\subsection{Write or inspect}
Read the public checks and the calling contract. Run them now to confirm that the ordinary cases pass and the still-empty tiled function fails. A whole-project success is expected only after both functions are complete.

\subsection{Expected observation}
The ordinary function handles the bounded cases without changing input or inactive output. Tiled cases still report incomplete output or traversal.
