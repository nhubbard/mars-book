\section{Step 27 Separate permitted variation from required behavior}\label{transpose-s27}

The grader checks the public function contract and matrix access schedule. It allows different temporary registers, pointer recurrences, tile orders, and scheduling within a completed tile. Auxiliary and stack accesses outside the matrix buffers are allowed and count in cache measurements. They must still respect the calling convention and protected regions.

\subsection{Write or inspect}
Read the public traversal check. Identify one implementation change it should accept and one it should reject. Keep exact reference instruction or miss counts out of correctness assertions.

\subsection{Expected observation}
A column-major outer tile order can pass. A second ordinary function called tiled cannot pass on the rectangular fixture. A restored write to protected memory also fails.
