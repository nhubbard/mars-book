\section{Step 16 Form the first source address in a tile row}\label{transpose-s16}

At the start of each row inside the tile, calculate its full source address from the current matrix row and the tile's first column. The multiplication uses the whole input row width, not the tile width. Tiles partition the visit order; they do not repack the stored matrix.

\subsection{Write or inspect}
Append the source pointer calculation. Step through the multiplication, column addition, scaling, and full pointer addition separately.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
next_tiled_row:
    mul $t6, $t4, $a3
    addu $t6, $t6, $t1
    sll $t6, $t6, 2
    daddu $t6, $a0, $t6
\end{minted}

\subsection{Expected observation}
For tile origin (0,0), the first source address is the input base. For row one in that tile, it is input plus twenty bytes in the default fixture.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which width belongs in the source row multiplication?

\begin{itemize}
  \item \textbf{A} Four, because the tile side is four.
  \item \textbf{B} The matrix column count.
  \item \textbf{C} The cache line size in bytes.
\end{itemize}
