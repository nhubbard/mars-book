\section{Step 23 Keep cache capacity constant when changing placement}\label{transpose-s23}

The source-header settings use the same total eight lines in all placement experiments. Fully associative placement uses one set with eight ways. Direct mapping uses eight sets with one way each. A two-way experiment uses four sets. Increasing both associativity and total capacity would confound the comparison.

\subsection{Write or inspect}
Inspect the placement controls and calculate total bytes before each experiment. Keep four words per line and eight total lines. Select LRU explicitly.

\subsection{Expected observation}
Total modeled capacity remains 128 bytes. The set and way organization changes which memory lines can coexist.
