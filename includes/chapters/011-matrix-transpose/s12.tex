\section{Step 12 Establish a cold observation boundary}\label{transpose-s12}

Cache state is not part of the architectural output. Two correct calls can start with different line contents and therefore produce different counters. For a cold comparison, attach or reset the cache while execution is stopped before the measured work, and start a fresh run for each function.

\subsection{Write or inspect}
Inspect the source-header cache settings. Select eight blocks, four words per block, fully associative placement with eight ways, and LRU replacement. For the current register-only caller, confirm zero data accesses before the call.

\subsection{Expected observation}
The header configures the IDE tool; the standalone grading scripts explicitly configure the same core cache model. Debugger memory inspection does not increase its execution-data counters.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Does reading a word in the debugger count as a simulated data-cache access?

\begin{itemize}
  \item \textbf{A} No; the model filters out external inspection.
  \item \textbf{B} Yes, as an execution load.
  \item \textbf{C} Only when the word is zero.
\end{itemize}
