\section{Step 43 Validate the description before producing output}\label{pcm-wav-s43}
Call \texttt{wav\_bound} with the retained prefix pointer in \texttt{s1}. The supplied guard returns any failed status before writing the destination. On success, retain its canonical byte total in \texttt{s4}. The encoder input is PCM, not a complete WAV file, and the prefix's trailing parser offsets are irrelevant to this call.

Author region \texttt{e\_call}. Use \texttt{s43-1} and stop at \texttt{after\_e\_call}.

\paragraph{Observe} The trace encoder receives sixteen PCM bytes and a successful canonical bound of sixty bytes.

\paragraph{Check} Does the encoder use the parser's stored PCM offset?
\begin{itemize}
\item[A.] Yes; it adds that offset to a0.
\item[B.] Only for stereo.
\item[C.] No; a0 already points directly to PCM.
\end{itemize}
