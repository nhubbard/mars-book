\section{Step 54 Acquire a descriptor and initialize progress}\label{pcm-wav-s54}
Open the input path for reading with syscall thirteen. Preserve the returned nonnegative descriptor in \texttt{s3} and initialize accepted bytes \texttt{s4} to zero. A negative open result takes \texttt{load\_io\_error}. Never assume the first available descriptor is three. Until the open succeeds, the supplied minus-one marker means there is no descriptor to close.

Author region \texttt{l\_open}. Use \texttt{s54-1} and stop at \texttt{after\_l\_open}.

\paragraph{Observe} A successful open leaves a live descriptor and zero accepted bytes. The grading fixture may choose a descriptor other than three.

\paragraph{Check} Which value should later reads use as their descriptor?
\begin{itemize}
  \item[A.] The value actually returned by open.
  \item[B.] Always three.
  \item[C.] The source buffer address.
\end{itemize}
