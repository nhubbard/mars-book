\section{Step 22 Convert a byte length to complete frames}\label{pcm-wav-s22}
Divide the candidate PCM byte length by twice the channel count. Reject a nonzero remainder and any quotient above 65536. Retain the accepted frame count in the private doubleword at stack offset eighty. An empty data chunk has length zero and quotient zero; it remains valid if the complete container and format pass.

Author region \texttt{p\_frames}. Use \texttt{s22-1} and stop at \texttt{after\_p\_frames}.

\paragraph{Observe} Sixteen PCM bytes divided by four bytes per frame gives four frames with no remainder.

\paragraph{Check} What does a two-byte stereo data payload contain?
\begin{itemize}
\item[A.] One complete stereo frame.
\item[B.] A valid zero-frame file.
\item[C.] An incomplete frame, which must fail.
\end{itemize}
