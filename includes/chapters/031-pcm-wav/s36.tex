\section{Step 36 Scatter results back into interleaved order}\label{pcm-wav-s36}
Copy each private output halfword into the disjoint destination using the same frame-and-channel addressing formula as gathering. Copy its two bytes so an unaligned output is allowed. During the left-channel pass, leave every right-channel output slot unchanged. The destination becomes complete only after both channel passes finish.

Author region \texttt{f\_scatter}. Use \texttt{s36-1} and stop at \texttt{after\_f\_scatter}.

\paragraph{Observe} The left output slots contain 1500, 1500, 500 and 4596 while right slots retain their sentinel bytes.

\paragraph{Check} Which output slots may the first channel pass change?
\begin{itemize}
  \item[A.] Only the selected channel's sample slots.
  \item[B.] Every halfword before the current frame.
  \item[C.] The input history slots in source.
\end{itemize}
