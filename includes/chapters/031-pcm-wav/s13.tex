\section{Step 13 Check the PCM encoding tag}\label{pcm-wav-s13}
Read the first two payload bytes as an unsigned little-endian value. Require encoding tag one. Do not infer PCM from a plausible channel count or bits-per-sample field: other encoding tags assign different meanings to sample bytes. Use the existing payload pointer and preserve the chunk's next offset while checking each field.

Author region \texttt{p\_codec}. Use \texttt{s13-1} and stop at \texttt{after\_p\_codec}.

\paragraph{Observe} The format tag is one. Unsupported encoding tags take the format-failure route.

\paragraph{Check} Which value identifies the supported PCM encoding?
\begin{itemize}
\item[A.] The channel count two.
\item[B.] The ASCII identifier WAVE.
\item[C.] Tag one.
\end{itemize}
