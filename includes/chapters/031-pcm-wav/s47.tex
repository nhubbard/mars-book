\section{Step 47 Write consistent rate fields}\label{pcm-wav-s47}
Store the accepted sample rate as four little-endian bytes at offset twenty-four. Compute twice channels times rate and store it at twenty-eight. Deriving the byte rate from validated fields prevents a stale input header value from surviving a channel or rate change. Keep the header pointer and retained PCM length available for the following fields.

Author region \texttt{e\_rate}. Use \texttt{s47-1} and stop at \texttt{after\_e\_rate}.

\paragraph{Observe} The trace writes 16000 frames per second and 64000 bytes per second.

\paragraph{Check} Which rate changes when channel count doubles at a fixed sample rate?
\begin{itemize}
\item[A.] Neither rate.
\item[B.] Byte rate.
\item[C.] Frame rate.
\end{itemize}
