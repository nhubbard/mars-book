\section{Step 14 Read and retain the channel count}\label{pcm-wav-s14}
Assemble the two channel bytes at payload offset two, require one or two, and retain the accepted value in \texttt{s6}. A stereo frame contains one sample from each channel. That changes both the number of bytes per frame and the address stride used by the filter. A channel count of zero must fail rather than becoming a zero stride or divisor.

Author region \texttt{p\_channels}. Use \texttt{s14-1} and stop at \texttt{after\_p\_channels}.

\paragraph{Observe} The retained channel count is two, so each frame contains four PCM bytes.

\paragraph{Check} How many sixteen-bit sample codes are in one stereo frame?
\begin{itemize}
  \item[A.] Four.
  \item[B.] Two.
  \item[C.] One.
\end{itemize}
