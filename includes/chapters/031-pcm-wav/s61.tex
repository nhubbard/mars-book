\section{Step 61 Advance writes by actual progress}\label{pcm-wav-s61}
Request at most the remaining bytes and at most 4096 bytes in this construction. Use the retained descriptor and selected pointer plus written count. A positive result advances by that actual count. Zero or a negative result takes the close-and-error path; completion goes to \texttt{save\_done}. Even a short or failing write reads the requested interval plus its guard in the current syscall implementation.

Author region \texttt{sv\_write}. Use \texttt{s61-1} and stop at \texttt{after\_sv\_write}.

\paragraph{Observe} Forced short writes form a contiguous file prefix. Requested counts and accepted counts can differ.

\paragraph{Check} How should zero progress be handled?
\begin{itemize}
  \item[A.] Retry forever.
  \item[B.] Declare the whole file saved.
  \item[C.] Close and return I/O failure.
\end{itemize}
