\section{Step 4 Validate before multiplying}\label{pcm-wav-s04}
Reject a rate outside 8000 through 48000, a channel count other than one or two, or an unsigned frame count greater than 65536. Route these failures to \texttt{wav\_invalid}. In particular, a frame count with its top bit set is a large unsigned value; it must not pass a signed less-than comparison as a negative number. Leave the valid fields available for the size calculation.

Author region \texttt{b\_domain}. Use \texttt{s04-1} and stop at \texttt{after\_b\_domain}.

\paragraph{Observe} The worked prefix passes. A prefix with 65537 frames must fail with status one and zero count.

\paragraph{Check} Why check the frame count as unsigned?
\begin{itemize}
  \item[A.] Negative frame counts mean silence.
  \item[B.] The helper accepts all register bit patterns.
  \item[C.] A top-bit-set count is outside the supported domain.
\end{itemize}
