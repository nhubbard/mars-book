\section{Step 51 Return the complete encoded byte count}\label{pcm-wav-s51}
Return status zero with the retained canonical total in \texttt{v1}, then restore the caller state. The returned total includes header and PCM bytes. It excludes the destination arena's unused capacity and the readable guard. The pipeline must pass this actual total to saving rather than using either the original input count or the arena size.

Author region \texttt{e\_return}. Use \texttt{s51-1} and stop at \texttt{after\_e\_return}.

\paragraph{Observe} The trace returns sixty complete file bytes; empty audio returns forty-four.

\paragraph{Check} Which count should the saver receive from the encoder?
\begin{itemize}
\item[A.] The actual returned complete file count.
\item[B.] The entire destination capacity.
\item[C.] The original input count.
\end{itemize}
