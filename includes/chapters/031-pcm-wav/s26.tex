\section{Step 26 Publish the descriptor once}\label{pcm-wav-s26}
Store rate and channels as two words at descriptor offsets zero and four. Store frame count, PCM offset and PCM byte length as doublewords at eight, sixteen and twenty-four. Return status zero and the frame count. Publish all fields only on this success path; failure paths restore the invocation frame without changing caller metadata.

Author region \texttt{p\_publish}. Use \texttt{s26-1} and stop at \texttt{after\_p\_publish}.

\paragraph{Observe} The published descriptor is (16000, two, four, fifty-six, sixteen), and the successful return count is four frames.

\paragraph{Check} What is the parser's successful v1 unit?
\begin{itemize}
\item[A.] Clipped samples.
\item[B.] Frames.
\item[C.] Complete file bytes.
\end{itemize}
