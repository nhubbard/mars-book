\section{Step 17 Verify the frame byte width}\label{pcm-wav-s17}
Read the two-byte block-alignment field at payload offset twelve. Require twice the accepted channel count. Despite its name, this field describes the width of one PCM frame; it does not authorize aligned halfword loads from arbitrary input pointers. You will use that width to test data divisibility and to step between channel samples.

Author region \texttt{p\_align}. Use \texttt{s17-1} and stop at \texttt{after\_p\_align}.

\paragraph{Observe} The block alignment is four for stereo and would be two for mono.

\paragraph{Check} Does block alignment make the caller's input pointer aligned?
\begin{itemize}
  \item[A.] Yes; four-byte frames imply an aligned file base.
  \item[B.] No; the byte-pointer contract still permits an unaligned address.
  \item[C.] Yes; all file fields are halfword aligned in memory.
\end{itemize}
