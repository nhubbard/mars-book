\section{Step 15 Read the sample rate as an unsigned field}\label{pcm-wav-s15}
Assemble the four little-endian rate bytes at payload offset four and retain the value in \texttt{s5}. Require 8000 through 48000 inclusive. The rate describes frames per second, so it does not double for stereo. Avoid signed byte loads that would extend a byte such as hexadecimal 80 into the upper bits before combining the field.

Author region \texttt{p\_rate}. Use \texttt{s15-1} and stop at \texttt{after\_p\_rate}.

\paragraph{Observe} The bytes 80 3e 00 00 describe 16000 frames per second.

\paragraph{Check} What does the sample-rate field count for stereo audio?
\begin{itemize}
\item[A.] Frames per second.
\item[B.] The sum of both channels' sample counts per second.
\item[C.] Bytes per second.
\end{itemize}
