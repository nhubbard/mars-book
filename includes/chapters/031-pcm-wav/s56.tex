\section{Step 56 Distinguish an exact fit from excess input}\label{pcm-wav-s56}
When accepted bytes equal capacity, request one byte into private frame offset 112. Zero means exact-fit EOF; a positive result means capacity failure; a negative result means I/O failure. Close the descriptor before returning either failure, using a route that preserves the chosen status. Do not place the probe at buffer plus capacity, which is outside the caller's allowed write interval.

Author region \texttt{l\_probe}. Use \texttt{s56-1} and stop at \texttt{after\_l\_probe}.

\paragraph{Observe} The exact-capacity trace has eighty-two accepted bytes and a zero-byte probe; it proceeds to load\_eof.

\paragraph{Check} Where may the exact-fit probe write?
\begin{itemize}
  \item[A.] The caller descriptor.
  \item[B.] The private one-byte frame slot.
  \item[C.] One byte beyond the caller buffer.
\end{itemize}
