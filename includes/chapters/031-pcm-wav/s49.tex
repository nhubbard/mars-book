\section{Step 49 Write the data header for the exact PCM extent}\label{pcm-wav-s49}
Write data at offset thirty-six and its four-byte PCM length at forty. The canonical payload begins at forty-four and has exactly \texttt{2*C*N} bytes. Because sixteen-bit PCM has an even byte length, this data chunk needs no extra pad. A zero-frame file still includes the data header with a length of zero.

Author region \texttt{e\_data}. Use \texttt{s49-1} and stop at \texttt{after\_e\_data}.

\paragraph{Observe} The trace declares sixteen payload bytes, beginning at offset forty-four.

\paragraph{Check} Where does canonical PCM begin?
\begin{itemize}
  \item[A.] The original input offset fifty-six.
  \item[B.] Immediately after RIFF.
  \item[C.] Offset forty-four.
\end{itemize}
