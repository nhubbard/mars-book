\section{Step 58 Validate the complete count before pointer use}\label{pcm-wav-s58}
Require an unsigned complete count from forty-four through 266240 before reading the path or selected bytes. Counts above the maximum return two; counts below the minimum return one. The saver accepts a complete supported stream, including noncanonical unknown chunks, but never treats an arbitrary buffer prefix as a file merely because writing it would succeed.

Author region \texttt{sv\_bound}. Use \texttt{s58-1} and stop at \texttt{after\_sv\_bound}.

\paragraph{Observe} The eighty-two-byte trace passes the early count checks.

\paragraph{Check} What must the saver receive?
\begin{itemize}
\item[A.] Only PCM bytes.
\item[B.] The full allocation including its guard.
\item[C.] A complete supported stream and its exact count.
\end{itemize}
