\section{Step 8 Check the exact outer extent}\label{pcm-wav-s08}
Assemble bytes four through seven into an unsigned thirty-two-bit RIFF size using byte loads and shifts. Add eight in a sixty-four-bit register and require equality with the supplied complete count. Initialize the next chunk offset \texttt{s3} to twelve. Using a wide addition matters even though accepted files are small: the untrusted size can contain all thirty-two bits before you reject it.

Author region \texttt{p\_outer}. Use \texttt{s08-1} and stop at \texttt{after\_p\_outer}.

\paragraph{Observe} The stored RIFF size is seventy-four, its complete extent is eighty-two, and the first chunk offset is twelve.

\paragraph{Check} What does the RIFF size omit?
\begin{itemize}
  \item[A.] All pad bytes.
  \item[B.] The first eight bytes of the file.
  \item[C.] The data chunk only.
\end{itemize}
