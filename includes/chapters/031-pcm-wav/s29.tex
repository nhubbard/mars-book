\section{Step 29 Validate the prefix through the shared helper}\label{pcm-wav-s29}
The filter frame saves the PCM pointer in \texttt{s0}, destination in \texttt{s3}, coefficients in \texttt{s4} and prefix pointer in \texttt{s5}. Pass the prefix to \texttt{wav\_bound} and call it. The supplied guard propagates a nonzero status before consuming fields. The returned canonical size is useful to the encoder, but the filter must still recover frames and channels from the validated prefix.

Author region \texttt{f\_call}. Use \texttt{s29-1} and stop at \texttt{after\_f\_call}.

\paragraph{Observe} The nested helper returns success and sixty bytes for the worked prefix; filter output is still untouched.

\paragraph{Check} What must the filter do with a failed bound call?
\begin{itemize}
\item[A.] Write a silent output.
\item[B.] Propagate the failure before processing samples.
\item[C.] Treat v1 as a valid frame count.
\end{itemize}
