\section{Step 10 Recognize the uppercase interval}\label{base64-s10}

The helper receives one unsigned character value in a register. Subtract the uppercase lower bound and compare the unsigned difference with 26. An in-range value branches to its supplied numerical return. An unfinished later branch returns the distinct sentinel minus two.
