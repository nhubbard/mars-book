\section{Step 19 Validate before checking capacity and publishing}\label{base64-s19}

Retain all input arguments in the supplied frame. Call validation and check status before interpreting its count. Compare that count with the original unsigned capacity, then retain both total and remaining output. A malformed input wins over a short-capacity error under this contract.
