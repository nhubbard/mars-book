\small
\begin{enumerate}
\setlength{\itemsep}{0pt}
\setlength{\parsep}{0pt}
\item At \texttt{after\_enc12\_right}, both bit contributions have been joined and each lane masked to six bits. The next region begins the alphabet conversion.
\item \texttt{w0} holds twelve source bytes followed by four zero lanes. \texttt{w1}, read from lane zero upward, contains \texttt{0,25,26,51; 52,61,62,63; 0,51,52,61; 62,63,25,26}. These are numerical indices, not ASCII codes. The whole-vector hexadecimal display puts lane zero at the right.
\item The source row contains twelve logical bytes, ending \texttt{fb f6 5a}, then the backing suffix \texttt{a5}. The kernel must not read those four suffix bytes to fill a wide source load.
\item The sixteen-byte private object starts eight bytes into the first scratch row at \texttt{0x10015018}. It contains the twelve source bytes and four explicit zero bytes. The leading \texttt{a5} bytes lie below it; \texttt{41..48} afterward begin the alphabet, outside the scratch object.
\item The destination remains untouched. Resuming maps the sextets to the sixteen characters \texttt{AZaz09+/Az09+/Za} and then performs the output store.
\end{enumerate}
