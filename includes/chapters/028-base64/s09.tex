\section{Step 9 Check short tails independently}\label{base64-s09}

Use the separate one-byte and two-byte recipes, then the complete triple. Compare the exact four-character outputs and their padding positions. A zero input byte is ordinary binary data, while a pad occupies text without adding binary output.

\subsection{Expected observation}
The three tail shapes have two, one and zero padding characters.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
What determines the number of final pads?

\begin{itemize}
  \item \textbf{A} The destination alignment.
  \item \textbf{B} The input remainder modulo three.
  \item \textbf{C} The first zero input byte.
\end{itemize}
