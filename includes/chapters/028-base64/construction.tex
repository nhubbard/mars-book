\section{Work with one cumulative source}
Keep one working copy of \path{drafts/base64-construction/main.asm} and replace its
named BEGIN/END bodies as the steps progress. The default caller selects scalar
encoding of \texttt{Man}. Missing whole-function regions return development status four
with count zero. The classifier instead returns minus two, because four is a valid
sextet and minus one already means an invalid character. Nested guards distinguish
unfinished work from completed errors before restoring the caller.

Use the helper in \path{drafts/base64-construction} to prepare a named recipe from your
current source into a distinct observation file. For example, invoke
\texttt{python3 prepare.py s02-1} with \texttt{--source} naming your working file and
\texttt{--output} naming a new file. Preparation changes only supplied data and controls;
it preserves authored regions and refuses to overwrite existing output.

Recipes name both direct-function and supplied-caller checkpoints. A
\texttt{function\_return} checkpoint means the entry-specific caller return label when
using \texttt{main}. Inspect returned registers before the caller stores its status and
count controls. For classifier recipes the caller records the numerical sextet separately
from status. Intermediate bytes during development are observations, not completed
success results. Guided checks use the illustrated state; completed free-writing checks
accept equivalent implementations of the declared interfaces.
