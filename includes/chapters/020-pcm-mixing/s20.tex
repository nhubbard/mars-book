\section{Step 20 Test the exact in-place cases}\label{pcm-s20}

After completing the scalar loop, use fresh executions to make the output address equal input A, then input B. Keep the inputs otherwise disjoint. Finally use the same source address for both inputs and output. The complete input values must be read before each store. This safety argument supports exact aliases; it does not authorize a destination shifted into a source.

\subsection{Expected observation}
All three alias arrangements produce the same clamped sums and clipping counts as their separate mathematical inputs. A shifted overlap is outside the assignment contract.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Does an output two bytes after A satisfy the exact-alias contract?

\begin{itemize}
  \item \textbf{A} Yes, if the arena is large.
  \item \textbf{B} No.
  \item \textbf{C} Only for negative samples.
\end{itemize}
