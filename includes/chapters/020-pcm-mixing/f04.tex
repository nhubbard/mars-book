\begin{enumerate}
\setlength{\itemsep}{2pt}
\setlength{\parsep}{0pt}
\item This fresh run changes count to 9. The same \texttt{mix\_ready} marker follows one eight-sample vector group and one scalar tail sample. The wrapping call and all caller result stores remain ahead.
\item \texttt{\$v0 = 9} counts samples and \texttt{\$v1 = 4} counts clipping. The first eight samples contribute three clipped lanes; the ninth contributes one. Both paths accumulate into the same per-call result.
\item The ninth A sample begins at \texttt{0x10010014}. Bytes \texttt{e0 b1} encode $-20000$. Its index is eight because sample numbering starts at zero; each two-byte step advances one sample.
\item The ninth B sample at \texttt{0x100100dc} also contains \texttt{e0 b1}. Its exact sum with A is $-40000$. Although more input bytes are mapped, the selected slice ends immediately after this pair.
\item The ninth saturated sample is at \texttt{0x100101a4}, sixteen bytes after the output base. Bytes \texttt{00 80} encode $-32768$. The vector stores cover sixteen output bytes, and the scalar tail supplies the final two; the remaining mapped bytes are unchanged.
\item The caller row contains count 9 and three result sentinels of 99. Each logical source and destination is eighteen bytes long. Access traces verify those bounds even for reads or same-value stores that would leave the final surrounding bytes unchanged.
\end{enumerate}
