\section{Check the arithmetic and alias contract}\label{pcm-questions}
\begin{MARSExercise}{An endpoint is not a clipping event}
  Compare $30000+2767$ with $32767+1$. Both produce the same saturated output.
  State the clipping count for each, then explain why scanning only the stored
  samples cannot recover that distinction.
\end{MARSExercise}
\begin{MARSExercise}{An output that replaces B}
  Explain what goes wrong if code loads A, stores a provisional value to output,
  and then loads B when output equals B. Identify which values a scalar iteration
  and a vector group must retain before their first store.
\end{MARSExercise}
\begin{MARSExercise}{A three-lane clipping mask}
  For the first eight default samples, identify the clipped lanes. Give the low and
  high doubleword population counts, their sum and the shifted result. Why would
  adding the mask halfwords themselves give a different number?
\end{MARSExercise}
\begin{MARSExercise}{Count, duration and channels}
  At 16,000 mono frames per second, how many samples and PCM bytes describe two
  seconds? How many full 64-sample kernel calls are needed? Explain why the two
  input arrays do not make the result stereo.
\end{MARSExercise}
