\section{Step 1 Read the sample-level interface}\label{pcm-s01}

The function receives two full input addresses, a full output address and a sample count. One sample consumes two bytes from each source and produces two output bytes. \texttt{v0} returns how many samples were requested; \texttt{v1} counts exact sums outside the signed halfword range. Byte counts, sample counts and clipping counts have different units even when held in ordinary integer registers.

\subsection{Expected observation}
For count sixteen, each selected slice has thirty-two bytes. The output has sixteen samples, not thirty-two samples.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What does \texttt{v1} report?

\begin{itemize}
\item \textbf{A} The number of source bytes.
\item \textbf{B} The number of exact sums that needed clipping.
\item \textbf{C} The largest output magnitude.
\end{itemize}
