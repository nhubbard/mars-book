\section{Step 28 Copy the low population count to a scalar register}\label{pcm-s28}

Use \texttt{copy\_s.d} to transfer \texttt{w4}[0] into \texttt{t2}. It copies the numerical doubleword count; it does not count again or move the vector’s bytes in memory. Although the operation uses signed transfer, this count is in 0..64, so its interpretation is unambiguous. The second count remains in \texttt{w4}[1].
