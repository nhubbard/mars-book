\section{Step 40 Read a cache candidate without replacing it yet}\label{qoi-s40}
Author \texttt{e\_hash} to calculate the current pixel’s weighted slot, form its entry address in \texttt{t8} and load the old cached word into \texttt{t9}. Do not store the new pixel before comparing it with the old entry. Doing so would make every lookup appear to match, including colors the decoder has never cached.

Work in \texttt{e\_hash}; use \texttt{s40-1} and stop at \texttt{after\_e\_hash}.

\paragraph{Observe} For the first opaque-black pixel, \texttt{t8} selects slot fifty-three and \texttt{t9} is still transparent black.

\paragraph{Check} Why must the old cache word be read before replacement?
\begin{itemize}
\item[A.] It determines the image width.
\item[B.] It is the next input pixel.
\item[C.] It determines whether INDEX is valid.
\end{itemize}
