\section{Step 27 Repeat validation with a trailing byte}\label{qoi-s27}
Keep the completed validator and change only the observation fixture to include a trailing zero. The image’s original commands still describe eight correct pixels, but the exact-extent check must fail. Inspect the caller descriptor after return. Its sentinel pattern must survive; a recognizable image prefix is not authority to publish metadata for a malformed file.

Use \texttt{s27-1} for this observation.

\paragraph{Observe} The validator returns status one and zero count. All caller metadata and framebuffer bytes remain unchanged.

\paragraph{Check} What should happen to metadata on this late error?
\begin{itemize}
\item[A.] It remains unchanged.
\item[B.] It retains fields published before the marker.
\item[C.] It is cleared to zero.
\end{itemize}
