\section{Step 42 Accumulate a run until a flush is required}\label{qoi-s42}
Author \texttt{e\_run} to increment the pending count. Flush when it reaches sixty-two or when the loaded pixel was the last one. Otherwise retain it and proceed to the common per-pixel finish. The first black pixel leaves one pending repetition because seven later pixels remain. No run tag has to be written at that point.

Work in \texttt{e\_run}; use \texttt{s42-1} and stop at \texttt{encode\_finish\_pixel}.

\paragraph{Observe} The pending count is one and the byte cursor remains at the end of the header.

\paragraph{Check} When must a pending run be emitted?
\begin{itemize}
  \item[A.] At length sixty-two or the final pixel.
  \item[B.] Only when the entire input is black.
  \item[C.] After every accepted repeated pixel.
\end{itemize}
