\section{Step 41 Separate repetition from a new-color decision}\label{qoi-s41}
Author \texttt{e\_repeat} to route a pixel equal to the predictor to run accumulation. For a different pixel, emit any already pending run before making the new color’s cache decision. The first worked pixel takes the repeated-color branch immediately. Its cache candidate differs from it because a newly initialized cache contains transparent black, but repetition depends on the predictor instead.

Work in \texttt{e\_repeat}; use \texttt{s41-1} and stop at \texttt{encode\_run}.

\paragraph{Observe} Execution reaches \texttt{encode\_run} with current and previous opaque black, seven later pixels and no emitted payload byte.

\paragraph{Check} Which comparison identifies a repetition?
\begin{itemize}
  \item[A.] Current pixel equals the header’s channels field.
  \item[B.] Current pixel equals previous pixel.
  \item[C.] Current hash equals previous hash.
\end{itemize}
