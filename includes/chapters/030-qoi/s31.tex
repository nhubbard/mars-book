\section{Step 31 Return both decoder dimensions in full}\label{qoi-s31}
Author \texttt{d\_return} to read the accepted private dimensions and form height in the upper thirty-two bits and width in the lower thirty-two. Return that packed value with status zero through the supplied restore. A word-sized store in the caller’s result field would lose the height, so the supplied count/result slot is a doubleword.

Work in \texttt{d\_return}; use \texttt{s31-1} and stop at \texttt{function\_return}.

\paragraph{Observe} \texttt{v1} is 0x 0000000100000008, and all saved registers and the stack pointer are restored.

\paragraph{Check} What would truncating this result to a word lose?
\begin{itemize}
\item[A.] The low width bits only.
\item[B.] The first pixel’s alpha.
\item[C.] Height.
\end{itemize}
