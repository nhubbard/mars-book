\section{Step 36 Clear the encoder cache for this invocation}\label{qoi-s36}
Author \texttt{e\_clear} to zero every private cache entry while retaining the accepted header values. A stale word that happens to equal the first input pixel could otherwise cause an INDEX whose decoder entry is still empty. This requirement is about the meaning of emitted bytes, not just tidying memory. The cache must be ready before any pixel lookup.

Work in \texttt{e\_clear}; use \texttt{s36-1} and stop at \texttt{after\_e\_clear}.

\paragraph{Observe} The complete cache is zero. Header fields and the destination cursor retain their accepted values.

\paragraph{Check} What can an uncleared matching cache word cause?
\begin{itemize}
\item[A.] An INDEX that reconstructs the wrong pixel.
\item[B.] A harmless extra header byte.
\item[C.] Automatic initialization in every external decoder.
\end{itemize}
