\section{Step 35 Retain encoder metadata and locate its private cache}\label{qoi-s35}
Author \texttt{e\_state} to retain the four accepted fields in private frame words and set the cache base to frame offset 112. Initialize the clear-loop pointer and store count without advancing that retained base. Keeping header fields private lets later work use temporary registers without losing the values that must be serialized in the header.

Work in \texttt{e\_state}; use \texttt{s35-1} and stop at \texttt{after\_e\_state}.

\paragraph{Observe} The private fields remain eight, one, four and zero; the clear pointer names the start of a256-byte cache.

\paragraph{Check} Why retain header fields before the pixel loop?
\begin{itemize}
\item[A.] The cache itself stores the header.
\item[B.] Temporary calculations may overwrite their registers.
\item[C.] The file requires a new dimension for every pixel.
\end{itemize}
