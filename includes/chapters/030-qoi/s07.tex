\section{Step 7 Assemble and bound big-endian dimensions}\label{qoi-s07}
Author \texttt{w\_dimensions} to combine bytes four through seven into width and bytes eight through eleven into height. Shift the first byte of each field by twenty-four bits, the next by sixteen and the next by eight before combining the final byte. Validate both fields in the local one-through-sixty-four domain. Retain accepted width in \texttt{t4} and height in \texttt{t5}.

Work in \texttt{w\_dimensions}; use \texttt{s07-1} and stop at \texttt{after\_w\_dimensions}.

\paragraph{Observe} The numerical fields are eight and one. The input cursor has not yet become a command cursor.

\paragraph{Check} What would a little-endian native load of 00 00 00 08 produce?
\begin{itemize}
  \item[A.] Eight.
  \item[B.] The address of the first pixel.
  \item[C.] \texttt{0x08000000}.
\end{itemize}
