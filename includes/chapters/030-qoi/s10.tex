\section{Step 10 Clear all sixty-four cache entries}\label{qoi-s10}
Author \texttt{w\_clear} to zero the complete 256-byte private cache before any index can be fetched. The cache base is eight-byte aligned, so the illustrated loop can clear two entries with each doubleword store. Advance its private pointer by eight and count thirty-two stores. On exit, keep \texttt{s4} at the original cache base for later lookups.

Work in \texttt{w\_clear}; use \texttt{s10-1} and stop at \texttt{after\_w\_clear}.

\paragraph{Observe} All 256 cache bytes are zero. The predictor remains opaque black and the command cursor remains at offset fourteen.

\paragraph{Check} How many eight-byte stores clear the cache?
\begin{itemize}
  \item[A.] Sixty-four.
  \item[B.] Eight.
  \item[C.] Thirty-two.
\end{itemize}
