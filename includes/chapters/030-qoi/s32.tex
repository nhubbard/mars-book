\section{Step 32 Inspect stored alpha separately from displayed RGB}\label{qoi-s32}
Inspect the completed framebuffer and its little-endian bytes before changing the encoder. The seventh pixel has numerical word 0x 80070605 and stored bytes 05 06 07 80. The final pixel is \texttt{0xff} 010101. Connect this buffer to the RGB display when the capture runner is available, but use the stored high bytes to establish alpha correctness; the current display does not blend them.

Use \texttt{s32-1} for this observation.

\paragraph{Observe} The penultimate alpha is 128 and the final alpha is 255. Both can be established from memory even when their RGB display appearance is similar.

\paragraph{Check} Which observation proves that alpha was restored by the final INDEX?
\begin{itemize}
\item[A.] The header says four channels.
\item[B.] The final stored high byte isff.
\item[C.] The displayed pixel is dark.
\end{itemize}
