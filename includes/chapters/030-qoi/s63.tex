\section{Step 63 Close and return the full saved length}\label{qoi-s63}
Author \texttt{sv\_finish} to close after all selected bytes have been accepted, return status zero and restore the selected count in \texttt{v1}. Saving the supplied worked stream writes thirty-eight bytes, while saving the encoder’s compacted output can write thirty-five. The saver preserves whichever valid byte representation its caller selected; it does not re-encode the image.

Work in \texttt{sv\_finish}; use \texttt{s63-1} and stop at \texttt{function\_return}.

\paragraph{Observe} The output file exactly matches the selected thirty-eight bytes and every descriptor is closed. Saved registers and the full stack pointer are restored.
