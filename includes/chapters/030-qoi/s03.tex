\section{Step 3 Reject dimensions before multiplying them}\label{qoi-s03}
Author \texttt{b\_domain} to reject zero or a value above sixty-four in either field. These decisions precede the pixel-count multiplication. Branch to the supplied invalid return for a rejected field, leaving \texttt{v1} zero there. Use unsigned comparisons so that a field with its high bit set cannot pass a signed less-than check as a negative dimension.

Work in \texttt{b\_domain}; use \texttt{s03-1} and stop at \texttt{after\_b\_domain}.

\paragraph{Observe} The eight-by-one argument reaches the checkpoint unchanged in \texttt{t1} and \texttt{t2}. Invalid dimensions take the supplied status-one return.

\paragraph{Check} Why must a high-bit dimension fail?
\begin{itemize}
\item[A.] Its unsigned value exceeds the local limit.
\item[B.] It describes a negative number of transparent pixels.
\item[C.] It is an alternative spelling of zero.
\end{itemize}
