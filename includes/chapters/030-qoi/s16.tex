\section{Step 16 Advance one repeated output pixel at a time}\label{qoi-s16}
Author \texttt{w\_advance} to reduce remaining pixels and the current repetition count after an accepted output position. Repeat the common emission stage while repetitions remain, then return to the next-tag stage. Input has already advanced across the run tag, so this loop consumes no further file bytes. For the first c0, exactly one output position is accounted for.

Work in \texttt{w\_advance}; use \texttt{s16-1} and stop at \texttt{after\_w\_advance}.

\paragraph{Observe} Seven pixels remain, the repetition count is zero and the input cursor is still at offset fifteen.

\paragraph{Check} Which cursor stays fixed during run expansion?
\begin{itemize}
  \item[A.] The output pixel index.
  \item[B.] The remaining-pixel count.
  \item[C.] The input cursor.
\end{itemize}
