\section{Step 62 Advance writes by the accepted count}\label{qoi-s62}
Author \texttt{sv\_write} to request the remaining selected suffix, add only a positive accepted count and repeat. Zero or a negative result takes the supplied close-and-error path. The fixture accepts at most three bytes per write. Preserve the existing extra-readable-byte guard outside the file count; never include that guard in the serialized output.

Work in \texttt{sv\_write}; use \texttt{s62-1} and stop at \texttt{after\_sv\_write}.

\paragraph{Observe} After the first write, \texttt{s4} is three and the output contains 71 6f 69. Continuing reaches the unfinished final-close stage with all thirty-eight selected bytes accepted.

\paragraph{Check} Which count advances the source pointer?
\begin{itemize}
  \item[A.] The descriptor number.
  \item[B.] The positive syscall result.
  \item[C.] The original requested count.
\end{itemize}
