\section{Sources and scope}
The chunk grammar, initial state, cache hash, biases, header fields and marker follow
\href{https://qoiformat.org/qoi-specification.pdf}{QOI specification version 1.0}.
The \href{https://github.com/phoboslab/qoi}{reference implementation} is a separate
interoperability reference. The sixty-four-pixel dimension limit, strict exact extent,
metadata layout, conservative encoder capacity and uniform-image size promises are
local teaching contracts. The MARS display discussion follows its current RGB image
implementation; no alpha-compositing behavior is inferred from a screenshot.
