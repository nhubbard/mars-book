\section{Step 49 Emit a verified cache index}\label{qoi-s49}
Author \texttt{e\_index} to recover the slot number from its retained cache-entry address, write that six-bit index byte and advance the output by one. The first index in the worked trace retrieves opaque black after the red run. The shared finish stage then updates the predictor for subsequent difference calculations. Do not serialize the byte offset within the cache as though it were the slot.

Work in \texttt{e\_index}; use \texttt{s49-1} and stop at \texttt{after\_e\_index}.

\paragraph{Observe} The first index byte is 35 in hexadecimal. The output prefix has eighteen bytes and four later input pixels remain.

\paragraph{Check} How do entry byte offsets become slot numbers?
\begin{itemize}
\item[A.] Multiply the absolute address by four.
\item[B.] Keep the low six address bits directly.
\item[C.] Divide the offset from cache base by four.
\end{itemize}
