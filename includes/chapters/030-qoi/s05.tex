\section{Step 5 Guard the byte count before a pointer access}\label{qoi-s05}
Author v\_count to reject an unsigned count above 20502 with status two and a count below twenty-three with status one. Do not read the file or metadata pointers while making these decisions. After a bounded count reaches the checkpoint, the supplied routing enters the shared walker in validation mode. The unfinished walker will still return development status four.

Work in \texttt{v\_count}; use \texttt{s05-1} and stop at \texttt{after\_v\_count}.

\paragraph{Observe} Count thirty-eight reaches the checkpoint without a source load. The later temporary return is four with zero count.

\paragraph{Check} Which input must be rejected without a header load?
\begin{itemize}
  \item[A.] An unaligned byte pointer by itself.
  \item[B.] A count with bit sixty-three set.
  \item[C.] A valid RGB sample equal to zero.
\end{itemize}
