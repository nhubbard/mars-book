\section{Step 60 Validate before truncating an existing file}\label{qoi-s60}
Author \texttt{sv\_validate} to retain path, bytes and selected count and call \texttt{qoi\_validate} into private metadata at frame offset eighty. The supplied status guard returns on any nonzero result before open. Validation needs no caller metadata publication here. A malformed stream must leave an existing destination intact rather than opening first and discovering the error afterward.

Work in \texttt{sv\_validate}; use \texttt{s60-1} and stop at \texttt{after\_sv\_validate}.

\paragraph{Observe} Validation succeeds in private metadata while the output file still contains its old bytes. No writable descriptor has been opened.

\paragraph{Check} Which event must precede truncate-mode open?
\begin{itemize}
\item[A.] Complete stream validation.
\item[B.] The first write request.
\item[C.] Publishing a new caller framebuffer.
\end{itemize}
