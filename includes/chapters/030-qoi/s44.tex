\section{Step 44 Commit one encoder pixel’s state}\label{qoi-s44}
Author \texttt{e\_finish} to insert the accepted current pixel into its cache entry, update the predictor and loop when more input pixels remain. Use the same one-pixel recipe to observe the non-looping boundary before marker writing. Updating the cache here also makes an initial run’s opaque black available for a later index in a larger image.

Work in \texttt{e\_finish}; use \texttt{s44-1} and stop at \texttt{after\_e\_finish}.

\paragraph{Observe} Slot fifty-three and the predictor contain opaque black; no pixels remain. The current output is header plus c0, without a marker yet.

\paragraph{Check} Why update cache state for a repeated pixel?
\begin{itemize}
  \item[A.] It changes the repeat count’s bias.
  \item[B.] A later index can depend on that value.
  \item[C.] It adds a mandatory extra command byte.
\end{itemize}
