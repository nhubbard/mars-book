\section{Step 51 Use RGB when differences cannot represent the color}\label{qoi-s51}
Use the one-pixel red 100 recipe to reach a literal path. Its unchanged alpha permits RGB, but red change 100 does not fit the chosen DIFF or LUMA fields. Author \texttt{e\_rgb} to emit fe followed by red, green and blue, retaining alpha implicitly. The already completed finish and marker stages then return a complete file for this subset.

Work in \texttt{e\_rgb}; use \texttt{s51-1} and stop at \texttt{after\_e\_rgb}.

\paragraph{Observe} The prefix is a fourteen-byte header and fe 64 00 00; the complete returned file has twenty-six bytes.

\paragraph{Check} Why is no alpha byte needed for this literal?
\begin{itemize}
  \item[A.] Alpha is unchanged from the predictor.
  \item[B.] The input has no stored alpha.
  \item[C.] RGB always forces alpha to 255.
\end{itemize}
