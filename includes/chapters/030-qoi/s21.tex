\section{Step 21 Apply three biased two-bit changes}\label{qoi-s21}
Author \texttt{w\_diff} to split the tag’s three fields, subtract two from each and add them to the previous components. Mask each updated component to eight bits before packing. For tag 7f after opaque black, every stored field is three, so each actual change is plus one. Alpha is retained, and this command has no payload bytes after its tag.

Work in \texttt{w\_diff}; use \texttt{s21-1} and stop at \texttt{after\_w\_diff}.

\paragraph{Observe} The unpacked components are one, one, one and 255. The input cursor is twenty-two.

\paragraph{Check} What operation follows each component addition?
\begin{itemize}
\item[A.] Reduction modulo 256.
\item[B.] Saturation to the range 0..255.
\item[C.] Multiplication by alpha.
\end{itemize}
