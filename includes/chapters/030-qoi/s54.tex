\section{Step 54 Bound a file buffer before opening its path}\label{qoi-s54}
Author \texttt{l\_bound} to accept unsigned byte capacities from one through 20502. A zero, over-limit or high-bit capacity returns status two before pointer access or a file operation. The supplied frame is entered only after this guard. The buffer’s capacity concerns complete input bytes, not pixel count or private marker storage.

Work in \texttt{l\_bound}; use \texttt{s54-1} and stop at \texttt{after\_l\_bound}.

\paragraph{Observe} The prepared capacity reaches the checkpoint without reading a path or opening a descriptor.

\paragraph{Check} Which capacity is valid for the loader?
\begin{itemize}
\item[A.] Thirty-eight bytes for this thirty-eight-byte file.
\item[B.] Zero bytes because EOF can be probed privately.
\item[C.] An unsigned value above 20502.
\end{itemize}
