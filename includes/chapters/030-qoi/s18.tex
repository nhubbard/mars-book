\section{Step 18 Load RGB while retaining previous alpha}\label{qoi-s18}
Author \texttt{w\_rgb} to prove that three payload bytes remain before loading them. Put the new red, green and blue values in \texttt{t4}, \texttt{t5} and \texttt{t6}, and recover alpha from the previous word into \texttt{t7}. Advance the command cursor by three. The supplied route then reaches the shared pack stage, which is still unfinished; no new color should be invented by a native-endian word load.

Work in \texttt{w\_rgb}; use \texttt{s18-1} and stop at \texttt{after\_w\_rgb}.

\paragraph{Observe} The component values are 255, zero, zero and 255. The input cursor is nineteen, just after the explicit red samples.

\paragraph{Check} Where does this command obtain alpha?
\begin{itemize}
  \item[A.] From the previous pixel.
  \item[B.] From a fourth sample byte.
  \item[C.] From the header’s channels count.
\end{itemize}
