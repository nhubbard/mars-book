\section{Keep a single working source and change its observation inputs}
Work in a copy of \path{drafts/qoi-construction/main.asm}. Its caller can select bound,
validate, decode, encode, load, save or the connected pipeline. The source arena begins
with the worked thirty-eight-byte stream. Other arenas begin as sentinels until an
observation recipe prepares the values appropriate to that interface. In particular,
preparing an encoder call supplies RGBA input words and a descriptor; preparing a
decoder call supplies bytes and an untouched output arena.

Each named BEGIN/END region initially takes a safe development return. Author that
region in place and retain the supplied labels, frames and routes. Development status
four and zero count identify an unfinished body. That status is outside completed
statuses zero through three: an earlier authored region may already have written a
header prefix, accepted file bytes or updated private cache state. Inspect the named
checkpoint before interpreting the later temporary return.

Use \texttt{python3 prepare.py} with a recipe ID, \texttt{--source} naming the current
working file and \texttt{--output} naming a new observation file. Preparation replaces
data fixtures and caller controls only, preserves authored instructions and refuses an
existing output. A direct \texttt{function\_return} checkpoint maps to the entry-specific
caller return when running through \texttt{main}. The connected pipeline uses
\texttt{results\_ready}, before caller result publication. The result slot is eight bytes;
its unit depends on the interface rather than on the label \texttt{count}.
Supplied after-labels name separate \texttt{nop} instructions, so a branch to a shared
handler cannot appear to have executed the preceding authored body. Stop before that
checkpoint instruction, then continue through its supplied route.

The file recipes also declare in-memory grading files, permitted writes, short-operation
sizes and descriptor numbers. Preparing assembly does not install those facilities in
an ordinary IDE run. Successful host-file examples need a real \texttt{input.qoi} in
the configured working directory; the fixed fixture helper can create it at a fresh
path. For the worked trace, run \texttt{python3 drafts/qoi-fixtures/fixture.py --fixture trace input.qoi} from the public repository root. The helper defaults to the different sprite fixture when no selection is given. Forced errors and deterministic short transfers belong to the grading fixture.
Actual automated light-theme capture and fixture provisioning remain subsequent work.

\section{Use the supplied invocation frames and guards}
The shared walker and encoder use 384-byte frames. Bytes zero through seventy-nine
retain all saved registers, frame pointer and return address. Walker frame offset eighty
retains its metadata pointer; offsets 88..100 hold four private descriptor words; the
cache occupies 256 bytes beginning at 112. The decoder uses a 128-byte frame with its
private sixteen-byte descriptor at 80. These are aids to the illustrated construction,
not frame-layout requirements for completed free-writing solutions.

The loader and saver also use 128-byte frames. Their supplied descriptor marker in s3
starts at minus one, private metadata begins at 80 and the loader's EOF probe is at 96.
The development exit closes a nonnegative live descriptor once before returning four.
Completed error paths have their own close-and-restore routes. Guards after nested
validation or reconstruction propagate a nonzero status before consuming unfinished
results. Keep those guards and routes while authoring the requested bodies.

A region can branch to another chunk handler before its textual after-label. The recipe
names the checkpoint actually reached by its chosen input. Some early encoder recipes
use a one-pixel image to complete a small working subset before new-color paths exist.
Guided observations therefore constrain this illustrated state. Final-interface checks
accept equivalent algorithms, private frames, register allocations and encodings that
meet the declared output and compression contracts.
