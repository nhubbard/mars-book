\section{Step 59 Reject an impossible selected save count}\label{qoi-s59}
Author \texttt{sv\_bound} to apply the saver’s count guards before reading either path or byte pointer. Counts above 20502 return two, and counts below twenty-three return one. A selected count is not inferred from mapped padding or a remembered earlier encode. The supplied save frame is entered only after this guard passes.

Work in \texttt{sv\_bound}; use \texttt{s59-1} and stop at \texttt{after\_sv\_bound}.

\paragraph{Observe} Thirty-eight selected bytes reach the checkpoint without any file operation or source read.

\paragraph{Check} Which value defines the bytes selected for saving?
\begin{itemize}
\item[A.] The previous input file’s length automatically.
\item[B.] The caller’s unsigned count.
\item[C.] The physical arena size.
\end{itemize}
