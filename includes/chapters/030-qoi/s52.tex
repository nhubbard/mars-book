\section{Step 52 Emit explicit alpha with RGBA}\label{qoi-s52}
Author \texttt{e\_rgba} to emit ff followed by all four current components. In the worked trace this represents 7,6,5 with alpha 128. Its RGB values alone do not reveal the alpha change. The remaining index, common finish and marker paths are already present, so this edit connects the full eight-pixel encoding. Check the returned count independently of the conservative capacity.

Work in \texttt{e\_rgba}; use \texttt{s52-1} and stop at \texttt{function\_return}.

\paragraph{Observe} The complete encoder returns status zero and thirty-five bytes for the worked trace, preserving every RGBA value and both descriptive flags.

\paragraph{Check} Which byte order follows ff?
\begin{itemize}
  \item[A.] Blue, green, red, alpha.
  \item[B.] Alpha, red, green, blue.
  \item[C.] Red, green, blue, alpha.
\end{itemize}
