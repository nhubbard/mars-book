\section{Step 39 Load one complete input word}\label{qoi-s39}
Author \texttt{e\_pixel} to load the current four-byte pixel with a consistent unsigned word representation, advance the input pointer by four and reduce the remaining pixel count. The count now describes pixels after the one currently held in \texttt{t0}. Do not advance the output yet: repeat, cache and difference decisions determine how many bytes this pixel will need.

Work in \texttt{e\_pixel}; use \texttt{s39-1} and stop at \texttt{after\_e\_pixel}.

\paragraph{Observe} \texttt{t0} is opaque black, the input cursor advanced four bytes and seven pixels remain after the loaded pixel.

\paragraph{Check} What does the reduced remaining count exclude?
\begin{itemize}
\item[A.] The pixel already loaded into \texttt{t0}.
\item[B.] Only pixels that have explicit RGBA chunks.
\item[C.] The header and marker.
\end{itemize}
