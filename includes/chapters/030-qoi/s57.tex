\section{Step 57 Probe EOF outside an exactly full caller buffer}\label{qoi-s57}
Use capacity thirty-eight to make the worked file fill the caller buffer exactly. Author \texttt{l\_probe} to request one more byte into the supplied private probe at frame offset 96. Zero confirms EOF; a positive result means excess input and status two; a negative result is an I/O error. None of these results authorizes a thirty-ninth caller-buffer store.

Work in \texttt{l\_probe}; use \texttt{s57-1} and stop at \texttt{load\_eof}.

\paragraph{Observe} The exact file reaches load\_eof after a zero-byte probe. The caller buffer has thirty-eight bytes, metadata is untouched and the descriptor is still live.

\paragraph{Check} Where should the extra probe byte go?
\begin{itemize}
  \item[A.] Private storage outside the caller buffer.
  \item[B.] Immediately after its declared capacity.
  \item[C.] Into the metadata width field.
\end{itemize}
