\section{Step 20 Explain and vary the
  representation}\label{003-eight-byte-sprite-s20-step-20-explain-and-vary-the-representation}

The program separates source representation, reversal, and drawing. Each
has a distinct contract. A different correct implementation may combine
them, but the final bytes and pixels must still agree for substituted
source rows.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s20-write-or-inspect}

Choose an eight-byte asymmetric marker of your own, predict its mirror,
and test it. Explain the row invariant and why the final store stays
within the frame. Submit the required trace and address derivation.

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s20-expected-observation}

The grader accepts equivalent implementations of the published contract.
Source spelling, private labels, and register choices are not part of
free-writing grading.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s20-check-your-understanding}

Which evidence supports correctness for a changed input image?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} A representation argument together with checks using
        substituted source rows.
  \item
        \textbf{B} A screenshot of the original default image alone.
  \item
        \textbf{C} An instruction count lower than the reference regardless of
        output.
\end{itemize}
