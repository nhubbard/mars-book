\section{Step 13 Select and store the mirrored
pixel}\label{003-eight-byte-sprite-s13-step-13-select-and-store-the-mirrored-pixel}

Use the same bit mask on the reversed row value. Its bit 7 is the
original row bit 0, so scanning it left to right produces a horizontal
mirror. The mirror pointer names a distinct cell in the same framebuffer
row.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s13-write-or-inspect}

Append the mirror selection and store.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $t6, 0
    and $t5, $t8, $t4
    beq $t5, $zero, write_mirror
    nop
    li $t6, 0x00ffffff
write_mirror:
    sw $t6, 0($t7)
pair_written:
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s13-expected-observation}

Both first pixels are black for the first row. Other columns will differ
because 0x16 and 0x68 have different bit positions set.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s13-check-your-understanding}

What pairs the two images at one column-loop iteration?

\begin{itemize}
\tightlist
\item
  \textbf{A} The framebuffer changes byte order halfway through each
  row.
\item
  \textbf{B} The same bit position is tested in the original and
  reversed row masks.
\item
  \textbf{C} The same destination address is written twice.
\end{itemize}
