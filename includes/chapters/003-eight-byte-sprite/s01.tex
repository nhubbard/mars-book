\section{Step 1 Interpret the eight row
  bytes}\label{003-eight-byte-sprite-s01-step-1-interpret-the-eight-row-bytes}

One source byte represents eight adjacent pixels. The value is a mask:
each bit answers whether its corresponding pixel is white or black. The
data initializers use signed byte values accepted without truncation
warnings; lbu will later recover their unsigned bit patterns.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s01-write-or-inspect}

Read the source-row table and predict the first row of the image. Leave
the supplied declarations unchanged.

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s01-expected-observation}

The first byte is 0x16, whose bits are 00010110. The set pixels are at
columns 3, 5, and 6 when columns are numbered from zero at the left.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s01-check-your-understanding}

Which bit supplies the leftmost pixel?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The sign bit of a 64-bit address.
  \item
        \textbf{B} Bit 7.
  \item
        \textbf{C} Bit 0 because it is named first numerically.
\end{itemize}
