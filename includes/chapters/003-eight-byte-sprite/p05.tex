\section{State what one iteration
  preserves}\label{003-eight-byte-sprite-p05-state-what-one-iteration-preserves}

At the start of reversal iteration k, the working source is the original
byte shifted right by k. The accumulator contains the reverse of the k
bits already consumed, with exactly k positions accounted for, and the
remaining count is \texttt{8\ \ensuremath{-}\ k}. This statement is the loop
invariant: it describes the relationship that must remain true as the
loop repeats.

The extraction takes the next bit from the working source. Shifting the
result and OR-ing that bit extends the accumulator by one position.
Shifting the source and reducing the count establishes the same
relationship for k + 1. The initial state has k = 0 and an empty zero
accumulator. At count zero, k = 8, so the accumulator is the complete
reversed byte.

All intermediate values fit comfortably in a word. The accumulator never
needs more than eight bits, and the counter moves from eight to zero.
The word instructions\textquotesingle{} sign extension therefore
introduces no negative masks in this loop.
