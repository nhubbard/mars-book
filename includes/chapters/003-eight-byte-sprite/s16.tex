\section{Step 16 Advance the three row
  positions}\label{003-eight-byte-sprite-s16-step-16-advance-the-three-row-positions}

The source and reversed-output arrays advance one byte per row. The
framebuffer row base advances 64 bytes. Keeping these strides separate
prevents a compact source representation from being confused with its
expanded pixel representation.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s16-write-or-inspect}

Append the three pointer updates.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
row_drawn:
    daddiu $t0, $t0, 1
    daddiu $s1, $s1, 1
    daddiu $s0, $s0, 64
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s16-expected-observation}

After the first row, the source points to its second byte, reversed
output points to its second byte, and the frame base points to display
row one.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s16-check-your-understanding}

Which pointer advances by 64 bytes?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The source row pointer because one byte has eight bits.
  \item
        \textbf{B} The framebuffer row-base pointer.
  \item
        \textbf{C} Every pointer because all data uses words.
\end{itemize}
