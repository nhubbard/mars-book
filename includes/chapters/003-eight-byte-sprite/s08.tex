\section{Step 8 Consume one bit and reduce the
  count}\label{003-eight-byte-sprite-s08-step-8-consume-one-bit-and-reduce-the-count}

srl shifts the working copy right and inserts zeroes at the high end of
the word result. The extracted low bit has already been incorporated.
Decrementing the count records that one of the eight required bits is
complete.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s08-write-or-inspect}

Append the source shift and count update.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    srl $t9, $t9, 1
    addiu $t4, $t4, -1
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s08-expected-observation}

After the first iteration, \$t9 is 0x0b and \$t4 is seven. The original
row register remains 0x16.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s08-check-your-understanding}

What does the count measure after an iteration?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} How many source bits remain to be processed.
  \item
        \textbf{B} The number of framebuffer rows already drawn.
  \item
        \textbf{C} The current RGB color.
\end{itemize}
