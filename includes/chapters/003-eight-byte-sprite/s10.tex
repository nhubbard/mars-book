\section{Step 10 Store the reversed row
  byte}\label{003-eight-byte-sprite-s10-step-10-store-the-reversed-row-byte}

sb writes the low byte of the reversed accumulator to the output array.
This result is independent of the RGB framebuffer: it is another compact
one-byte row representation that can be reused by later image-format
projects.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s10-write-or-inspect}

Append the row result store.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
row_reversed:
    sb $t8, 0($s1)
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s10-expected-observation}

The first reversed output byte is 0x68. The original source byte remains
0x16.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s10-check-your-understanding}

How much output does one reversed source row require?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Sixty-four bytes because the framebuffer stride is 64.
  \item
        \textbf{B} One byte.
  \item
        \textbf{C} One 64-bit register per pixel.
\end{itemize}
