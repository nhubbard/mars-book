\section{Expand a bit into an RGB
word}\label{003-eight-byte-sprite-p07-expand-a-bit-into-an-rgb-word}

The source bit is a one-bit decision, while the destination cell needs a
complete RGB word. The program begins each decision with a black value
of zero. If the masked bit is nonzero, it replaces that value with
white, 0x00ffffff. Both paths then execute the same store.

Every output cell is written. A clear source bit does not mean that the
old framebuffer contents can be left alone. The previous frame, another
task, or a grading fixture may have placed nonzero data there. Writing
black establishes the specified background independently of that initial
state.

The original and mirrored rows use the same mask progression. The only
changed input is the row byte: the mirror tests the reversed
accumulator. A correct reversal therefore changes the
picture\textquotesingle s horizontal order without changing its row
height, pixel format, or destination stride.
