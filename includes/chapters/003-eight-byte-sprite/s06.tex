\section{Step 6 Extract the low
bit}\label{003-eight-byte-sprite-s06-step-6-extract-the-low-bit}

andi combines the source with an immediate mask. A mask of one preserves
only bit 0, producing either zero or one. This extracted bit is the next
bit to append to the reversed result.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s06-write-or-inspect}

Append the bit extraction and its loop label.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
reverse_loop:
    andi $t5, $t9, 1
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s06-expected-observation}

For the first input 0x16, the first extracted bit is zero. The second
extraction, after consuming one source bit, will produce one.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s06-check-your-understanding}

What values can this masked result have?

\begin{itemize}
\tightlist
\item
  \textbf{A} Every value from zero through 255.
\item
  \textbf{B} Only zero or 128.
\item
  \textbf{C} Only zero or one.
\end{itemize}
