\section{Reverse a byte by moving one bit at a
time}\label{003-eight-byte-sprite-p04-reverse-a-byte-by-moving-one-bit-at-a-time}

The reversal loop reads the source from its low end. On each iteration
it extracts bit zero, shifts the accumulating result left, appends that
extracted bit, and shifts the working source right. The first source bit
becomes the first result bit appended; later shifts move it toward the
opposite end.

For 0x16, the source bits arrive in the order 0, 1, 1, 0, 1, 0, 0, 0.
After eight iterations, the result is binary 01101000, or 0x68.
Processing the final zeroes matters. If the loop stopped as soon as the
working source became zero, it would leave the accumulator at 0x0d after
five iterations, before the three remaining shifts placed those bits
correctly.

A fixed count of eight expresses the representation\textquotesingle s
width. It is independent of how many bits are set and how quickly the
working copy becomes zero. This same distinction appears in fixed-width
integer encodings and packet fields.
