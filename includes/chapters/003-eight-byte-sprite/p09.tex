\section{Test representations
  independently}\label{003-eight-byte-sprite-p09-test-representations-independently}

The reversed-byte array and framebuffer give two independent places to
inspect the algorithm. If reversed bytes are wrong, investigate reversal
before studying RGB stores. If the bytes are right but the frame is
wrong, examine masks, destination addresses, and row stride.

The default image contains an asymmetric row because a symmetric row can
agree with its own mirror. A program that merely copies rows could pass
a test using only symmetric input. Walking-bit rows isolate the mapping
between a single source bit and one destination column. Empty and full
rows check black filling and the high-bit cases.

Poisoning the frame before execution ensures that the checks observe
actual replacement of old cell values. Canaries test preservation just
beyond the allocated outputs. These final-state checks do not prove that
no temporary out-of-bounds write was made and later restored; that
stronger property would need a memory-access contract and trace
checking.
