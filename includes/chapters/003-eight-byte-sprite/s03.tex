\section{Step 3 Initialize four
  pointers}\label{003-eight-byte-sprite-s03-step-3-initialize-four-pointers}

A pointer is an address held in a register. The row source, source end,
framebuffer row start, and reversed-row output each need an independent
position. The end pointer is one byte beyond the source, not another row
to process.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s03-write-or-inspect}

Append these initializations inside the program region.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, sprite
    la $t1, sprite_end
    la $s0, frame
    la $s1, mirrored_rows
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s03-expected-observation}

The two source pointers differ by eight. The frame pointer names the
first display row. The output pointer names the first reversed byte.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s03-check-your-understanding}

Why retain a separate framebuffer row pointer?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} All pointers automatically advance together.
  \item
        \textbf{B} A framebuffer address is a syscall selector.
  \item
        \textbf{C} Its stride differs from the one-byte source-row stride.
\end{itemize}
