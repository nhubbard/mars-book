\section{Step 4 Load one unsigned
row}\label{003-eight-byte-sprite-s04-step-4-load-one-unsigned-row}

lbu reads one byte and zero-extends it to the integer register width. A
row is a bit pattern, so values with bit 7 set must remain ordinary
masks from 128 through 255. The row\_loop label will become the target
of the outer loop.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s04-write-or-inspect}

Append the source load.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
row_loop:
    lbu $t3, 0($t0)
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s04-expected-observation}

The first row loads as decimal 22, or 0x16. A stored byte ff would load
as 255 even when its declaration used -1.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s04-check-your-understanding}

What does lbu return for a stored byte ff?

\begin{itemize}
\tightlist
\item
  \textbf{A} The address of the byte.
\item
  \textbf{B} 255.
\item
  \textbf{C} -1 because every byte load sign-extends.
\end{itemize}
