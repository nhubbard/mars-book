\section{Step 12 Select and store the original
pixel}\label{003-eight-byte-sprite-s12-step-12-select-and-store-the-original-pixel}

Initialize the color to black, then test the current source bit. If the
masked result is zero, beq skips the white-color load after executing
the nop delay slot. Otherwise the white load executes. Both paths reach
the store.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s12-write-or-inspect}

Append the conditional color selection and normal store. The forward
branch target is included in this segment.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
column_loop:
    li $t6, 0
    and $t5, $t3, $t4
    beq $t5, $zero, write_normal
    nop
    li $t6, 0x00ffffff
write_normal:
    sw $t6, 0($t2)
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s12-expected-observation}

The first pixel of the first row is black because bit 7 of 0x16 is zero.
An explicit black store replaces any old framebuffer value.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s12-check-your-understanding}

Why store black as well as white?

\begin{itemize}
\tightlist
\item
  \textbf{A} A clear source bit means the source row must be deleted.
\item
  \textbf{B} Skipping a store always clears memory automatically.
\item
  \textbf{C} The destination may contain old or deliberately poisoned
  values.
\end{itemize}
