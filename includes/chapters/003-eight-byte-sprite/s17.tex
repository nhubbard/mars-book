\section{Step 17 Repeat until the source
  end}\label{003-eight-byte-sprite-s17-step-17-repeat-until-the-source-end}

The source-end address is one past the eight source bytes. After
processing each row, compare the advanced pointer with that end. The
last increment reaches the end exactly; the not-taken branch executes
its nop and falls through to the exit sequence.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s17-write-or-inspect}

Append the outer-loop branch. Run the complete program and then use
Debug to compare row checkpoints.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bne $t0, $t1, row_loop
    nop
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s17-expected-observation}

All eight source rows and eight reversed rows have been processed. Both
images occupy exactly 512 framebuffer bytes and both canaries remain
unchanged.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s17-check-your-understanding}

Should the byte at sprite\_end be processed as another source row?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} No; the end is an exclusive bound.
  \item
        \textbf{B} Yes; every end pointer names the final valid element.
  \item
        \textbf{C} Only when the first row contains zero.
\end{itemize}
