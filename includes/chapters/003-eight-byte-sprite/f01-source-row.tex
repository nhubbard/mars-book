\small
\begin{enumerate}
\item The highlighted \texttt{move \$t9, \$t3} is next. The preceding \texttt{lbu} has loaded the first source byte into \texttt{\$t3}; reversal has not begun. Keeping \texttt{\$t3} unchanged lets the program draw the original row later.
\item The address row begins with the frame canary, \texttt{df 9b 57 13}. The source starts four bytes later, at \texttt{0x10010204}: \texttt{16 3c 7e db ff 24 42 81}. The four zero bytes at the row end are the start of the separate mirrored-byte output.
\item \texttt{\$t3}=\texttt{0x16}=22, or the eight-bit pattern \texttt{00010110}. \texttt{lbu} zero-extends a byte, so its result lies from 0 through 255. Later source bytes such as \texttt{db} remain positive masks when loaded this way.
\end{enumerate}
