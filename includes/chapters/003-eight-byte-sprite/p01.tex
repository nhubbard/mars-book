\section{Signed declarations and unsigned
masks}\label{003-eight-byte-sprite-p01-signed-declarations-and-unsigned-masks}

The starter uses byte initializers within the
assembler\textquotesingle s signed range to avoid truncation warnings.
For example, the initializer \ensuremath{-}37 stores the pattern 0xdb, and \ensuremath{-}1 stores
0xff. These patterns can also be interpreted as the unsigned values 219
and 255. The byte\textquotesingle s stored bits do not identify one
interpretation as its permanent meaning.

\texttt{lbu} supplies the unsigned interpretation when loading the row
into a register. It zero-extends the byte: the
register\textquotesingle s low eight bits contain the stored pattern and
its other bits become zero. A row with its high bit set therefore
remains a mask in the range 128 through 255. A signed byte load,
\texttt{lb}, would sign-extend instead.

The drawing algorithm examines bits, so unsigned loading keeps its
working values easy to reason about. Each source row is always between
zero and 255, including rows whose declaration was written as a negative
signed byte.
