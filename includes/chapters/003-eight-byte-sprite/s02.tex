\section{Step 2 Lay out two images in one
frame}\label{003-eight-byte-sprite-s02-step-2-lay-out-two-images-in-one-frame}

The bitmap has 16 columns and 8 rows. Each cell occupies one four-byte
RGB word. The first eight columns hold the original; the next eight hold
the mirror. Data addresses count bytes, so one display row spans 16
times 4 bytes.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s02-write-or-inspect}

Identify frame, frame\_guard, sprite, mirrored\_rows, and rows\_guard.
Derive the byte offset of row 1 and the final cell.

\subsection{Expected
observation}\label{003-eight-byte-sprite-s02-expected-observation}

The row stride is 64 bytes. The last cell begins at offset 508 and
occupies bytes 508 through 511. frame\_guard starts at offset 512.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s02-check-your-understanding}

What is the byte displacement from one row start to the next?

\begin{itemize}
\tightlist
\item
  \textbf{A} 64.
\item
  \textbf{B} 16 because there are 16 columns.
\item
  \textbf{C} 8 because the source has eight rows.
\end{itemize}
