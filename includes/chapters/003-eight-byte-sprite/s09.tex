\section{Step 9 Repeat exactly eight
times}\label{003-eight-byte-sprite-s09-step-9-repeat-exactly-eight-times}

bne compares two registers and transfers control when they differ. This
retained branch executes the following instruction as a delay slot
whether taken or not. The explicit nop performs no state change, so the
count test decides whether execution returns to reverse\_loop or
continues after the slot.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s09-write-or-inspect}

Append the branch and its delay slot. Run this partial program and
inspect the reversal result.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bne $t4, $zero, reverse_loop
    nop
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s09-expected-observation}

For input 0x16, the loop finishes with \$t8 = 0x68, \$t9 = 0, and \$t4 =
0. It performs eight iterations, including leading zero bits.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s09-check-your-understanding}

Why continue until eight bits have been processed?

\begin{itemize}
\tightlist
\item
  \textbf{A} All loops must always have eight iterations.
\item
  \textbf{B} The branch automatically inserts missing zero bits.
\item
  \textbf{C} Stopping when the source becomes zero can omit leading-zero
  positions in the reversal.
\end{itemize}
