\section{Step 5 Initialize the reversal
state}\label{003-eight-byte-sprite-s05-step-5-initialize-the-reversal-state}

Keep the original row in \$t3 for drawing. Copy it into \$t9, which the
reversal loop may consume. Start the reversed accumulator at zero and
set a count of eight bits.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s05-write-or-inspect}

Append the reversal setup.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
row_loaded:
    move $t9, $t3
    li $t8, 0
    li $t4, 8
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s05-expected-observation}

\$t9 is 22, \$t8 is zero, and \$t4 is eight for the first row. The
source byte in memory is unchanged.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s05-check-your-understanding}

Why consume a copy of the row?

\begin{itemize}
\tightlist
\item
  \textbf{A} The original mask is still needed to draw the original
  image.
\item
  \textbf{B} Reading a byte removes it from memory.
\item
  \textbf{C} The reversed value must use the same register as its input.
\end{itemize}
