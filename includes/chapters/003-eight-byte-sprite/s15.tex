\section{Step 15 Complete the two eight-pixel
  rows}\label{003-eight-byte-sprite-s15-step-15-complete-the-two-eight-pixel-rows}

Branch back while a nonzero mask remains. Each iteration consumes one of
eight bit positions and writes exactly one pixel in each image. The nop
delay slot preserves that accounting on both the final and continuing
iterations.

\subsection{Write or
  inspect}\label{003-eight-byte-sprite-s15-write-or-inspect}

Append the column-loop branch.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bne $t4, $zero, column_loop
    nop
\end{minted}

\subsection{Expected
  observation}\label{003-eight-byte-sprite-s15-expected-observation}

The first display row now has sixteen written words: eight original
pixels and eight mirrored pixels. The next display row has not yet been
processed.

\subsection{Check your
  understanding}\label{003-eight-byte-sprite-s15-check-your-understanding}

How many pixel stores does one completed column loop perform?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Eight total because both images share the same words.
  \item
        \textbf{B} Sixty-four because the stride is 64 bytes.
  \item
        \textbf{C} Sixteen: two per iteration for eight iterations.
\end{itemize}
