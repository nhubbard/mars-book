\section{Mirror columns by reversing a row
byte}\label{003-eight-byte-sprite-x-bit-order-mirror-columns-by-reversing-a-row-byte}

The original first row is \texttt{00010110}. The reversed row is
\texttt{01101000}. Original columns 3, 5, and 6 map to mirror columns 4,
2, and 1 respectively. For a column c, the mirrored column is
\texttt{7\ \ensuremath{-}\ c}.

The digits provide the pattern independently of the filled cells. The
native TikZ source is the publication diagram; this SVG is a Markdown
preview.
