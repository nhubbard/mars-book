\section{Step 19 Compare a native reversal
operation}\label{003-eight-byte-sprite-s19-step-19-compare-a-native-reversal-operation}

MIPS Release 6 bitswap reverses the bits within each byte of a word.
Here lbu supplied a value from zero through 255, so its low byte is the
entire row and its other bytes are zero. The instruction can replace the
explicit reversal setup and loop in an equivalent implementation.

\subsection{Write or
inspect}\label{003-eight-byte-sprite-s19-write-or-inspect}

In a separate completed copy, replace the reversal setup and
reverse\_loop body with the single instruction shown. Keep row\_reversed
and all drawing code. Run the same checks before comparing instruction
counts.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bitswap $t8, $t3
\end{minted}

\subsection{Expected
observation}\label{003-eight-byte-sprite-s19-expected-observation}

For 0x16, the low byte is 0x68. This is an optional replacement, not
another segment to append to the baseline program.

\subsection{Check your
understanding}\label{003-eight-byte-sprite-s19-check-your-understanding}

Does bitswap reverse the positions of the bytes in a word?

\begin{itemize}
\tightlist
\item
  \textbf{A} Yes; it reverses the order of all framebuffer rows.
\item
  \textbf{B} No; it reverses the bits within each byte.
\item
  \textbf{C} Yes; it only swaps the first and last bytes.
\end{itemize}
