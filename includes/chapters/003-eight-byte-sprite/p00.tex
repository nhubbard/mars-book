\section{One byte describes a
row}\label{003-eight-byte-sprite-p00-one-byte-describes-a-row}

An 8 by 8 monochrome sprite has 64 on-or-off pixel decisions. Encoding
one decision per bit packs the image into eight bytes. Expanding it for
Bitmap Display produces 64 RGB words. The compact source and the
expanded destination represent the same image at different storage
costs.

The bit-to-column convention makes the representation precise: bit 7
names the leftmost column and bit 0 names the rightmost. The first row
byte 0x16 is binary 00010110, so its set pixels are at columns 3, 5, and
6. A horizontal mirror reverses those column positions within each row.
It leaves the order of the rows unchanged.

This project keeps both representations. It stores eight reversed row
bytes, then draws the original and mirrored images beside one another.
The output byte array allows a check of the reversal independently of
the RGB drawing. That separation will also be useful when a later
project needs to encode an image without displaying it.
