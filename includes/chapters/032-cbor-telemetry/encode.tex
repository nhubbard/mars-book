\section{Write the required fields in one chosen representation}
Emit a three-pair map with keys zero, one and two in that order. Use the shortest head
for every argument. Emit the counter big-endian, the identifier as its counted raw
bytes, and each signed reading using the argument rule already applied by the bound.
For these three small unsigned keys, their order is also the bytewise order of their
preferred encodings.

First establish the exact bound and compare it with unsigned output capacity. Capacity
failure returns two with unchanged destination. Computing that bound is allowed to
read the active samples, because their magnitudes determine their encoded widths.
Do not read identifier bytes or write output before this capacity check passes. An
unsigned capacity with its high bit set is large, not a negative request.

Write exactly the returned number of bytes and leave the rest of the destination
unchanged. A zero-length identifier causes no identifier read; a zero-length readings
array causes no sample read. The result still contains their keys and empty-value heads.
The writer discards the input's optional key three and its wider argument forms because
they are absent from, or unnecessary for, the specified deterministic result.
