\section{State the bounded subset explicitly}
This exercise accepts definite unsigned integers, negative integers, byte strings,
arrays and maps. Every map uses unsigned keys zero through seven without duplicates.
Every byte string has at most thirty-two payload bytes; every array has at most
sixty-four elements; every map has at most eight pairs. These limits apply inside
optional metadata as well as at the root.

Permit at most eight simultaneously open containers. The telemetry root counts as the
first container. Primitives do not add a container level. Select at most 1024 input
bytes and require exactly one complete outer telemetry map. The minimum complete
record occupies seven bytes: the map head, three keys, a zero counter, an empty byte
string and an empty array.

Text strings, tags, floating-point and simple values, and indefinite lengths are outside
the supported subset. Some are valid CBOR in other applications. Reserved head forms,
truncated arguments and incomplete child sequences also fail, but for a different
reason: their requested structure was not established. The entries use the same format
failure status for both classes, while the explanation and tests keep the distinction
visible.
