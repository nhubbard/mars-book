\section{Step 4 Separate inline arguments from width selectors}\label{cbor-s04}
Mask the lower five bits. Values below twenty-four are the argument itself and take the inline path. Values twenty-four through twenty-seven select following bytes; twenty-eight through thirty-one fail in this subset. The trace selects twenty-four, which means one following argument byte, not twenty-four map pairs.

Author region \texttt{h\_form}. Use \texttt{s04-1} and stop before \texttt{after\_h\_form}.
