\section{Step 37 Reject invalid lengths before payload access}\label{cbor-s37}
Reject an identifier length above thirty-two or a reading count above sixty-four, using their unsigned values. Return status one and zero size without reading identifier or sample storage on an invalid prefix. All counter bit patterns remain permitted. The fixture retains valid lengths here; invalid-prefix experiments follow after completion.

Author region \texttt{b\_lengths}. Use \texttt{s37-1} and stop before \texttt{after\_b\_lengths}.

\paragraph{Observe} The trace lengths pass without reading any active sample yet.

\paragraph{Check} What may an invalid prefix authorize reading?
\begin{itemize}
\item[A.] The first sample as a plausibility check.
\item[B.] All reserved identifier storage.
\item[C.] Only the prefix.
\end{itemize}
