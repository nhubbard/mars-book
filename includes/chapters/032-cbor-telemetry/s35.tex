\section{Step 35 Return a size without changing the argument's value}\label{cbor-s35}
Complete the helper's successful return convention: status zero and the selected complete head width in \texttt{v1}. Test the all-ones sixty-four-bit argument. It needs nine head bytes, and no byte of the argument should be lost while deciding that width. An unfinished helper instead returns four and zero for its callers to propagate.

Author region \texttt{z\_success}. Use \texttt{s35-1} and stop before \texttt{after\_z\_success}.

\paragraph{Observe} The all-ones argument returns width nine.

\paragraph{Check} What width is needed for an eight-byte argument?
\begin{itemize}
  \item[A.] Nine complete head bytes.
  \item[B.] Eight complete head bytes.
  \item[C.] One complete head byte.
\end{itemize}
