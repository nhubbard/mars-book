\section{Step 23 Choose validation by the field key}\label{cbor-s23}
Route key zero to the counter, one to the identifier and two to the readings array. Keys three through seven use generic optional-value validation. Keep the key check separate from the value's major type: the identifier is recognized because its key is one, not because every byte string is an identifier. The trace enters the optional route first.

Author region \texttt{d\_dispatch}. Use \texttt{s23-1} and stop before \texttt{after\_d\_dispatch}.

\paragraph{Observe} Key three reaches the optional-value route without publishing a field.

\paragraph{Check} What determines which application field is being read?
\begin{itemize}
\item[A.] The value's major type alone.
\item[B.] The decoded root key.
\item[C.] Its position in the input.
\end{itemize}
