\section{Step 24 Validate metadata that will be dropped}\label{cbor-s24}
Call the completed generic walker with inherited depth one, because the telemetry root is already open. Advance by the returned item prefix and decrement the root pair counter after success. Do not copy this value into the flat record. Dropping metadata removes it from the application representation, not from the structural validation workload.

Author region \texttt{d\_optional}. Use \texttt{s24-1} and stop before \texttt{after\_d\_optional}.

\paragraph{Observe} The trace's optional value consumes nine bytes, leaving cursor offset twelve and forty bytes.

\paragraph{Check} Which depth does an optional root value inherit?
\begin{itemize}
  \item[A.] Zero.
  \item[B.] The root pair count.
  \item[C.] One.
\end{itemize}
