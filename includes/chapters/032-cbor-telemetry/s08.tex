\section{Step 8 Publish a successful head}\label{cbor-s08}
After either route has established the full argument, publish its major type, retain its argument bits and clear the status. Return through the incoming return address. Run the trace head again: its map count can now be observed independently of its children. A successful head does not establish that four key/value pairs actually follow.

Author region \texttt{h\_success}. Use \texttt{s08-1} and stop before \texttt{after\_h\_success}.

\paragraph{Observe} The head returns status zero, length two, type five and argument four.

\paragraph{Check} What has this successful call proved?
\begin{itemize}
  \item[A.] The entire map is valid.
  \item[B.] The complete supported head exists.
  \item[C.] The telemetry record contains every required field.
\end{itemize}
