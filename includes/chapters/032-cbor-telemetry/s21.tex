\section{Step 21 Consume a head without losing the decoder's return}\label{cbor-s21}
The supplied helper saves its own incoming return address at frame offset eighty-eight. Use the decoder's retained cursor and remaining extent as head-reader inputs. If the call succeeds, advance both quantities by its head width; otherwise retain the failure for the outer routine. Do not confuse the helper's return address with the decoder's saved caller return.

Author region \texttt{d\_head}. Use \texttt{s21-1} and stop before \texttt{after\_d\_head}.

\paragraph{Observe} The first root head leaves s0 at source plus two, s1 at fifty and a2 equal to five.

\paragraph{Check} Why keep the helper return separately?
\begin{itemize}
  \item[A.] It makes a nested call before returning to the decoder.
  \item[B.] A CBOR head stores a return address.
  \item[C.] It must return directly to main.
\end{itemize}
