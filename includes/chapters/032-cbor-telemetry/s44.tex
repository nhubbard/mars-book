\section{Step 44 Combine an inline value directly}\label{cbor-s44}
For a one-byte head, combine the shifted type with the argument itself and store that initial byte. Do not reserve or write an argument byte after it. The recipe uses unsigned twenty-three, whose complete head is hexadecimal \texttt{17}. The same construction works for a permitted short byte-string or container argument under the helper's internal preconditions.

Author region \texttt{w\_inline}. Use \texttt{s44-1} and stop before \texttt{after\_w\_inline}.

\paragraph{Observe} Exactly one byte, 17, is written.

\paragraph{Check} What follows an inline integer's initial byte as part of its head?
\begin{itemize}
\item[A.] Nothing.
\item[B.] A repeated argument byte.
\item[C.] A zero terminator.
\end{itemize}
