\section{Step 5 Prove that the complete head fits}\label{cbor-s05}
Convert selectors twenty-four through twenty-seven to one, two, four and eight argument bytes. Add the initial byte to obtain the complete head width, then compare that width with available input using unsigned arithmetic. Do not start loading argument bytes until this comparison passes; a partial argument must not influence a failed result.

Author region \texttt{h\_width}. Use \texttt{s05-1} and stop before \texttt{after\_h\_width}. 

\paragraph{Observe} The trace needs two head bytes and fifty-two available bytes suffice.

\paragraph{Check} When may argument-byte loads begin?
\begin{itemize}
\item[A.] After the complete head width has passed its extent check.
\item[B.] As soon as the initial byte exists.
\item[C.] After the first argument byte gives a plausible count.
\end{itemize}
