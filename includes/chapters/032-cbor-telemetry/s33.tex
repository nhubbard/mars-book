\section{Step 33 Size an inline argument}\label{cbor-s33}
The private \texttt{head\_size} helper takes an unsigned argument in \texttt{a0}. For arguments below twenty-four, select width one and return success without examining any memory. Its result counts the complete head, including the initial byte. This helper supports the illustrated construction; the public free-writing contract does not require this private label or algorithm.

Author region \texttt{z\_inline}. Use \texttt{s33-1} and stop before \texttt{after\_z\_inline}. 

\paragraph{Observe} Argument twenty-three needs a one-byte head.

\paragraph{Check} Does this size include an initial byte?
\begin{itemize}
\item[A.] Yes.
\item[B.] Only for byte strings.
\item[C.] No; it counts following argument bytes.
\end{itemize}
