\section{Step 25 Retain every counter bit}\label{cbor-s25}
Consume the counter value head and require unsigned major type zero. Store its raw sixty-four-bit argument in the private candidate, without applying a signed range test or floating-point conversion. The trace counter is hexadecimal \texttt{0102030405060708}. A counter with its top bit set remains valid even if a signed register display presents it as negative.

Author region \texttt{d\_counter}. Use \texttt{s25-1} and stop before \texttt{after\_d\_counter}. 

\paragraph{Observe} The private counter holds 0102030405060708; caller record bytes are still unchanged.

\paragraph{Check} Does a set top counter bit make the field invalid?
\begin{itemize}
\item[A.] Yes; the local record uses eight bytes.
\item[B.] No; all unsigned sixty-four-bit patterns are valid.
\item[C.] Only when the identifier is empty.
\end{itemize}
