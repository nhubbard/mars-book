\section{Step 53 Return the complete output extent}\label{cbor-s53}
Return zero status and the difference between the final destination cursor and its original start. That extent must agree with preflight's exact bound. Restore the encoder's saved state before returning to the caller. On the trace, the three required fields occupy thirty-seven bytes even though the accepted input occupied fifty-two.

Author region \texttt{e\_finish}. Use \texttt{s53-1} and stop before \texttt{after\_e\_finish}. 

\paragraph{Observe} Encode returns zero and thirty-seven, with destination tails unchanged.

\paragraph{Check} Which count belongs in the encoder's successful v1?
\begin{itemize}
\item[A.] The original input length.
\item[B.] The local record size.
\item[C.] The complete output bytes written.
\end{itemize}
