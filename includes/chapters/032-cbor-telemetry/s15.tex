\section{Step 15 Bound the array's item counter}\label{cbor-s15}
Require an unsigned array argument from zero through sixty-four. Retain that argument as the number of remaining children, not a byte count. The supplied route then reaches the common child loop. An array with one empty-array child must perform one child traversal even though the child itself has no elements.

Author region \texttt{k\_array}. Use \texttt{s15-1} and stop before \texttt{after\_k\_array}. 

\paragraph{Observe} The selected outer array has one remaining child.

\paragraph{Check} What does an array argument count?
\begin{itemize}
\item[A.] Items.
\item[B.] Bytes.
\item[C.] Key/value pairs.
\end{itemize}
