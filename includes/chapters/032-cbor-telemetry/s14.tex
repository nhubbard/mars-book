\section{Step 14 Open a container only below the limit}\label{cbor-s14}
An inherited depth of eight permits a primitive, but cannot admit another container, even an empty one. For a permitted array or map, increment the open-container depth once before walking its children. Test an array containing an empty array with inherited depth zero. The child inherits depth one rather than restarting from zero.

Author region \texttt{k\_depth}. Use \texttt{s14-1} and stop before \texttt{after\_k\_depth}.

\paragraph{Observe} The outer array opens at depth one; its child must retain that inherited depth.

\paragraph{Check} When can a container open?
\begin{itemize}
\item[A.] Whenever it contains no children.
\item[B.] When inherited depth is below eight.
\item[C.] When its byte length is below eight.
\end{itemize}
