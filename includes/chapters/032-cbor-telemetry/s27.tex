\section{Step 27 Copy only the active identifier}\label{cbor-s27}
Copy exactly the accepted identifier byte count into private candidate storage. Use byte loads and stores because input need not be aligned. Advance the input cursor and subtract the accepted count from the remaining extent. Do not initialize the candidate's unused tail merely to make a later whole-record copy convenient.

Author region \texttt{d\_id\_copy}. Use \texttt{s27-1} and stop before \texttt{after\_d\_id\_copy}.

\paragraph{Observe} The candidate holds 00 ff 41 and the reordered input cursor reaches offset eight.

\paragraph{Check} How many identifier bytes should be copied here?
\begin{itemize}
\item[A.] Three.
\item[B.] Thirty-two.
\item[C.] Until a zero byte appears.
\end{itemize}
