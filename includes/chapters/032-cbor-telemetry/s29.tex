\section{Step 29 Validate an integer before narrowing it}\label{cbor-s29}
For each reading, consume a head and accept only unsigned or negative integer types. Its unsigned argument must be at most 32767 for either type. Convert a negative argument with minus one minus argument, then store the result in one two-byte candidate slot. Use a register-held bound for 32768; the immediate in \texttt{sltiu} is sign-extended on this target.

Author region \texttt{d\_sample}. Use \texttt{s29-1} and stop before \texttt{after\_d\_sample}.

\paragraph{Observe} The first sample stores zero in the first private two-byte slot and advances the index to one.

\paragraph{Check} Why check the argument before storing a halfword?
\begin{itemize}
\item[A.] Every halfword store checks the application range.
\item[B.] Narrowing could hide an out-of-range encoded integer.
\item[C.] Negative CBOR integers cannot use halfwords.
\end{itemize}
