\section{Step 7 Return an inline argument without a second load}\label{cbor-s07}
On the inline route, use the masked low bits directly and select a complete head width of one. There is no argument-byte loop on this path. Prepare the one-byte item \texttt{17} and stop after this region; its argument is decimal twenty-three. Keep payload interpretation outside the head reader.

Author region \texttt{h\_inline}. Use \texttt{s07-1} and stop before \texttt{after\_h\_inline}.

\paragraph{Observe} The inline argument is twenty-three and the head width is one.

\paragraph{Check} How many bytes does item 17 require for its head?

  \item[B.] One.
  \item[C.] Twenty-three.
\end{itemize}
