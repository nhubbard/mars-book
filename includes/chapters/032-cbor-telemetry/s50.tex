\section{Step 50 Copy the selected binary bytes}\label{cbor-s50}
Copy exactly the active identifier bytes from record offset sixteen to the output cursor. Use byte accesses and retain the leading zero. Advance only by the accepted count; the remaining thirty-two-byte local capacity is not output. The trace contributes three bytes and brings the cursor to sixteen.

Author region \texttt{e\_identifier\_copy}. Use \texttt{s50-1} and stop before \texttt{after\_e\_identifier\_copy}. 

\paragraph{Observe} Output offsets thirteen through fifteen are 00 ff 41.

\paragraph{Check} Does the leading zero reduce this copy's length?
\begin{itemize}
\item[A.] Yes; it ends the identifier.
\item[B.] Only in free-writing mode.
\item[C.] No; the accepted length remains three.
\end{itemize}
