\section{Step 9 Check the selected extent before walking}\label{cbor-s09}
For \texttt{cbor\_skip}, reject an unsigned selected count above 1024 before examining inherited depth or input. Next reject depth above eight and a zero count. Use status two for an excessive selected count and one for the other failures. This step precedes the supplied frame allocation, so an early return must not restore an unallocated frame.

Author region \texttt{k\_count}. Use \texttt{s09-1} and stop before \texttt{after\_k\_count}.
