\section{Step 43 Emit argument bytes in wire order}\label{cbor-s43}
Write exactly the selected argument-byte width in big-endian order. A high-to-low shift loop is one option; storing low bytes backwards from the last destination position is another. Keep the complete head width available as the return result. For unsigned twenty-four, the finished two-byte head is \texttt{18 18}.

Author region \texttt{w\_argument}. Use \texttt{s43-1} and stop before \texttt{after\_w\_argument}.

\paragraph{Observe} The destination head is 18 18.

\paragraph{Check} Why can a backwards store loop be correct?
\begin{itemize}
\item[A.] CBOR arguments are little-endian.
\item[B.] The head reader reverses every payload later.
\item[C.] It places low argument bytes at higher wire addresses.
\end{itemize}
