\section{Step 42 Write the initial byte for an extended head}\label{cbor-s42}
For a width greater than one, derive the additional-information selector from the following-byte width, combine it with the major type shifted left by five, and store the initial byte. Retain the following-byte counter separately from the complete returned width. For unsigned twenty-four, the initial byte is hexadecimal \texttt{18}.

Author region \texttt{w\_info}. Use \texttt{s42-1} and stop before \texttt{after\_w\_info}.

\paragraph{Observe} The first destination byte is 18; one argument byte remains to write.

\paragraph{Check} What belongs in the initial byte's low field here?
\begin{itemize}
  \item[A.] The selector for one following byte.
  \item[B.] The argument twenty-four reduced to five bits.
  \item[C.] The destination capacity.
\end{itemize}
