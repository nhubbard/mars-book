\section{Step 36 Load one byte at the full scan address}\label{delta-s36}

Add the private byte index to the full source base and load through that address with \texttt{lbu} into \texttt{t4}. Unlike word readings, these bytes may start at any alignment. Keep the raw byte until both payload and continuation have been interpreted.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the supplied temporary branch and nop in \texttt{d\_load}. Keep surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    daddu $t4, $s0, $t0
    lbu $t4, 0($t4)
\end{minted}
Use \texttt{s36-1} from the companion construction inputs. Pause at \texttt{codec\_done} before caller result storage.

\subsection{Expected observation}
The default first raw byte is decimal 208, hexadecimal d0.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why use a byte operation here?

\begin{itemize}
\item \textbf{A} Each input reading is one byte.
\item \textbf{B} It automatically validates canonical length.
\item \textbf{C} The encoded stream has arbitrary byte boundaries and alignment.
\end{itemize}
