\small
\begin{enumerate}
\setlength{\itemsep}{1pt}
\setlength{\parsep}{0pt}
\item The malformed-input call returns \texttt{v0 = 1} and \texttt{v1 = 1}: one committed byte and one reading. The failed candidate contributes no committed bytes.
\item The range-failure call returns \texttt{v0 = 5} and \texttt{v1 = 1}. Five bytes form a valid first reading; the next candidate remains uncommitted.
\item Malformed-wire status is \texttt{a3 = 2}. This reports a representation error in the next candidate, while retaining the first reading.
\item Reconstructed-range status is \texttt{a3 = 3}. The next representation is canonical, but its exact reconstructed reading does not fit a signed word.
\item In \texttt{02 80 00}, the first byte maps to reading one. The following two-byte representation ends with a zero high payload and redundantly encodes zero. Both examined bytes remain outside the committed input prefix.
\item In \texttt{fe ff ff ff 0f 02}, the first candidate reconstructs 2147483647. The final \texttt{02} maps to a delta of one. Exact addition gives 2147483648, which must be rejected before narrowing to a stored word.
\item The malformed call stores one reading, encoded as \texttt{01 00 00 00}. Later words retain their sentinel pattern. Wire rejection does not undo a prior committed reading.
\item The range call stores \texttt{ff ff ff 7f}, the signed-word maximum. The following word is still untouched. Both photographs stop before the caller saves the result registers.
\end{enumerate}
