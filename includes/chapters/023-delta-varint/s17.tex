\section{Step 17 Reject a candidate that cannot fit completely}\label{delta-s17}

Compare remaining bytes with \texttt{t4} and branch to \texttt{enc\_full} only when the remainder is smaller. Equality permits the complete candidate. This test precedes all candidate stores, so a rejected value cannot leave a partial prefix in output.
