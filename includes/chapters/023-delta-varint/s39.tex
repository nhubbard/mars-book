\section{Step 39 Shift a payload to its group position}\label{delta-s39}

At \texttt{dec\_accumulate}, use \texttt{dsllv} to shift \texttt{t5} by the private bit position \texttt{t2}. The first payload uses shift zero. A later fifth payload may contribute bits above the word boundary, so keep this operation in a doubleword.

The first shifted payload is \texttt{t6}=80.

\subsection{Check your understanding}
Why keep a full-width shifted payload?

\begin{itemize}
\item \textbf{A} All inputs are eight-byte memory objects.
\item \textbf{B} The continuation bit must remain set.
\item \textbf{C} A fifth group can contribute above bit thirty-one.
\end{itemize}
