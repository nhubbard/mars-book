\small
\begin{enumerate}
\setlength{\itemsep}{2pt}
\setlength{\parsep}{0pt}
\item The function has returned at \texttt{codec\_done}. The highlighted instruction begins the caller\textquotesingle s publication; saved counts have not been stored yet.
\item \texttt{v0 = 4} counts committed readings and \texttt{v1 = 5} counts committed bytes. Reading count and byte count are different units.
\item \texttt{a3 = 1} reports capacity exhaustion. The next reading would add a three-byte candidate, while only two bytes remain. Earlier complete readings stay committed.
\item The five source words are 1000, 1002, 1001, 1001 and 20000. The fifth can be read to determine its encoded length without counting it as consumed. Input remains unchanged.
\item The stream begins \texttt{d0 0f 04 01 00}. The following two \texttt{a5} bytes lie inside the seven-byte capacity but outside the committed prefix. No partial candidate or restored temporary store is allowed there.
\item The control rows show five input readings and capacity seven, then decoder capacity 32, method zero and saved input/output counts $-1$. The backing stream allocation is larger than the selected byte capacity.
\end{enumerate}
