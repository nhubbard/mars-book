\section{Step 60 Compare size and work without assuming compression}\label{delta-s60}

Use the deterministic datasets and complete-call measurements from the foundation. Steady values become small deltas, while an isolated spike creates two large transitions. The alternative threshold encoder changes instruction counts without changing bytes. State which baseline each size comparison uses.

\subsection{Expected observation}
Steady data uses 33 bytes versus 128 fixed bytes. The spike uses 36 delta bytes versus 34 independently mapped bytes.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which conclusion follows from those measurements?

\begin{itemize}
  \item \textbf{A} Delta encoding always beats independent mapping.
  \item \textbf{B} Compression benefit depends on the data and chosen baseline.
  \item \textbf{C} Fewer bytes establishes an elapsed-time speedup.
\end{itemize}
