\section{Step 5 Finish an empty encoder before checking capacity}\label{delta-s05}

At \texttt{enc\_next}, compare the committed reading count \texttt{s5} with the input count \texttt{s1}. Return immediately when they are equal. This makes empty input successful even when capacity is zero, and also recognizes a completed nonempty sequence on the next loop visit.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the supplied temporary branch and nop in \texttt{e\_end}. Keep surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    beq $s5, $s1, enc_return
    nop
\end{minted}
Use \texttt{s05-1}, \texttt{s05-2} from the companion construction inputs. Pause at \texttt{codec\_done} before caller result storage.

\subsection{Expected observation}
Empty input returns \texttt{v0}=0,\texttt{v1}=0,\texttt{a3}=0 without input or output access.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which test comes first at encoder entry?

\begin{itemize}
\item \textbf{A} Whether five bytes remain.
\item \textbf{B} Whether all input readings are already committed.
\item \textbf{C} Whether a continuation bit is set.
\end{itemize}
