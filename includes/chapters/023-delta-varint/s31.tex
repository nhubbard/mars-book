\section{Step 31 Reserve an output slot before inspecting a candidate}\label{delta-s31}

Compare output-reading count \texttt{s6} with capacity \texttt{s3}. Use \texttt{dec\_full} when they are equal. This gives capacity priority over malformed data that belongs to the next unstarted candidate. A nonempty zero-capacity input must remain unread.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the supplied temporary branch and nop in \texttt{d\_capacity}. Keep surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    beq $s6, $s3, dec_full
    nop
\end{minted}
Use \texttt{s31-1}, \texttt{s31-2} from the companion construction inputs. Pause at \texttt{codec\_done} before caller result storage.

\subsection{Expected observation}
Malformed input 80 00 at zero capacity returns status one, not malformed status two.
