\section{Step 22 Close the update-and-publication loop}\label{ball-s22}

Both live axes now belong to the next state. Decrement the remaining count, increment the tick, and branch back to publish that complete state. The initial publication precedes the first update, so the total is one greater than the number of updates.

\subsection{Write or inspect}
Append the counter changes and back edge. This completes the normal animation. Try zero, one, eight, and thirty-two requested steps. The supplied fallback exit is no longer reached after a positive-step update.
