\section{Step 18 Render and publish the selected pixel ID}\label{ball-s18}

Supply the full frame pointer, raw coordinates, and rounding mode as arguments. The call returns the row-major ID, which is stored with the other publication fields before the ready marker. The frame and numeric state then describe the same tick.
