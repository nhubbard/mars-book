\section{Step 11 Convert the selected cell to a word index}\label{ball-s11}

The coordinates passed to this renderer are nonnegative, so a logical right shift by eight gives their integer cell indices after the optional adjustment. Multiply the row by eight and add the column. The result is a word index, not yet a byte address.

\subsection{Write or inspect}
Append the two shifts and row-major index calculation. Inspect the returned ID for raw position (320,448) in both modes.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    srl $t2, $t2, 8
    srl $t3, $t3, 8
    sll $t3, $t3, 3
    addu $v0, $t3, $t2
\end{minted}

\subsection{Expected observation}
Floor selects cell (1,1), ID nine. Nearest selects cell (1,2), ID seventeen. The partial frame is still black until the store is added.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
How is the row-major pixel ID calculated?

\begin{itemize}
\item \textbf{A} Eight times the row plus the column.
\item \textbf{B} Eight times the column plus the row.
\item \textbf{C} Four times the raw x coordinate.
\end{itemize}
