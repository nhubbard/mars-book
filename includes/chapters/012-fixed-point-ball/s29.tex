\section{Step 29 Distinguish a trapped addition from a wrapped result}\label{ball-s29}

The trapping word instruction is a different experiment. With the same overflowing operands, it reports an arithmetic-overflow error rather than returning the wrapped word. A simulator fault is an observable outcome that must be distinguished from a normal return containing an unexpected value.

\subsection{Write or inspect}
In the separate demo only, temporarily replace the probe’s word \texttt{addu} with \texttt{add}. Observe the arithmetic-overflow error. Restore \texttt{addu} and \texttt{DEMO=0} immediately afterward; the submitted probe must return both specified results.

\subsection{Expected observation}
The intentional trapping experiment stops with an arithmetic-overflow report. Restoring the nontrapping word operation restores the two normal probe results.

\subsection{Check your understanding}
What does the intentional ADD experiment demonstrate?

\begin{itemize}
\item \textbf{A} A native signed word overflow exception.
\item \textbf{B} That every fixed-point update must trap.
\item \textbf{C} That nearest rounding changes the raw sum.
\end{itemize}
