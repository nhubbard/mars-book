\section{Step 30 Submit a checked equivalent and plan a variation}\label{ball-s30}

The final checks assess the public numeric and publication contracts. They allow different scratch registers, branch arrangements, and rendering strategies. A larger velocity range, changed scale, trail, or different marker protocol is a new experiment with a changed contract, not an unnoticed submission variation.

\subsection{Write or inspect}
Run both public check scripts with the completed default program. Verify all three function interfaces as well as the animation. For a follow-up experiment, choose one change and state how its proof and expected observations must change.

\subsection{Expected observation}
The reference and alternative both pass despite different work counts. Inputs, guards, caller-owned data, saved registers where required, and every published state satisfy the declared contract.

Which variation is accepted under the current rendering contract?

\item \textbf{B} Rounding the stored raw position after each step.
