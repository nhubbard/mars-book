\section{Step 25 Compare equal motion before comparing work}\label{ball-s25}

The two verified renderers produce the same observable trajectory with different internal work. One clears then draws; the other classifies each cell in one pass. Fewer stores alone do not prove fewer instructions or less host time.

\subsection{Write or inspect}
Read the measured whole-run table. Record the input, rounding mode, requested count, and observation scope when trying a change. Recheck every required state before treating a lower count as useful.

\subsection{Expected observation}
The default reference counts 3901 instructions in floor mode and 3919 in nearest. The alternative counts 6165 in either mode. These are workload measurements, not grading requirements.
