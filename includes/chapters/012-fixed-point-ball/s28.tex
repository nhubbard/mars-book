\section{Step 28 Run the separate overflow demonstration}\label{ball-s28}

The supplied \texttt{DEMO} constant selects the numeric experiment before normal animation initialization. This keeps the larger-domain arithmetic example separate from the ball’s valid motion inputs. Stop before the result registers are reused for exit.

\subsection{Write or inspect}
Set \texttt{DEMO} to one, assemble, and stop at \texttt{overflow\_ready}. Inspect both signed values and their hexadecimal register views. Restore \texttt{DEMO} to zero afterward for normal animation and submission checks.

\subsection{Expected observation}
The wrapped register view is ffffffff80000100; the wider positive sum is 0000000080000100. The ordinary ball state has not been advanced in this mode.

\begin{itemize}

  \item \textbf{B} Its operand range is broader than the bounded motion update.
