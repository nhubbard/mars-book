\section{Step 9 Clear a complete destination frame}\label{ball-s09}

The frame shows the current point rather than its trail. Start the renderer by writing black to all 64 destination words. Use the full pointer argument, not the main frame’s global label. Another valid implementation can classify every cell in one pass later.

\subsection{Write or inspect}
Append the clear loop in the \texttt{render} region. Test with a poisoned frame and a destination pointing at \texttt{spare\_frame}. This partial renderer returns without drawing the point yet.

\Needspace{11\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t0, $a0
    li $t1, 64
clear_pixel:
    sw $zero, 0($t0)
    daddiu $t0, $t0, 4
    addiu $t1, $t1, -1
    bne $t1, $zero, clear_pixel
    nop
\end{minted}

\subsection{Expected observation}
All 64 destination words are zero. The other frame and all guards are unchanged. The returned pixel ID has not been implemented.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why clear cells other than the new point?

\begin{itemize}
  \item \textbf{A} To erase the old point and any stale frame contents.
  \item \textbf{B} To reset the raw position.
  \item \textbf{C} To reverse the velocity.
\end{itemize}
