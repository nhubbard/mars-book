\section*{Project contract}
Use signed 32-bit raw values with eight fractional bits. Each position is in
\(0\ldots1792\), each velocity in \(-1024\ldots1024\), and the requested step
count in \(0\ldots32\). Implement the independently callable axis updater,
renderer, and raw-sum probe. Their interfaces are specified below and in the
student assignment. Preserve full saved registers and the stack pointer.

Normal main publishes the initial state and every requested update. At each
\texttt{frame\_ready} boundary, all four raw state words, the tick, pixel ID,
and complete 64-word frame agree. Preserve the provided one-instruction marker
ending at \texttt{frame\_continue}. Its executed count is the requested steps
plus one after exit. Inputs, guards, and the spare frame remain unchanged by main.
Keep the provided memory layout and Bitmap Display base. Return normally through
the supplied function-call interfaces and produce no console output.

The arithmetic probe has a separate full signed-word input domain. It returns
both a wrapped word and an exact wider raw sum. The temporary trapping-addition
experiment is not the submitted implementation. Restore the ordinary animation
mode and nontrapping word sum before final checks. Guided edits illustrate one
implementation; free-writing solutions may vary internal registers, branches,
and frame-write order while satisfying the public contract.
