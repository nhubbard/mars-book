\section{Check a formula with a different formulation}\label{ball-x-proof}
The private axis oracle uses a periodic folding view rather than repeating the
assembly branches. Let \(z=p+v\), and take its nonnegative remainder \(r\) modulo
\(2L=3584\). The position is \(r\) for \(r\leq L\), and \(2L-r\) otherwise.
At remainder zero the outgoing velocity is nonnegative; at remainder \(L\) it
is nonpositive. Away from those contacts, retain or reverse the original direction
according to the half of the period.

This gives an independent way to compute the same bounded reflection. It also
makes the endpoint convention explicit. Ordinary language remainder operations
can differ for negative dividends, so use a nonnegative modular remainder for
this formulation. The actual assembly can continue to use the simpler bounded
branches; equivalent formulas need not have the same cost.

Renderer checks use integer quotients and fractional remainders to classify half
thresholds. They poison both frame arenas and protect the inactive one. Main
checks inspect every raw state and complete frame, then continue to exit and
inspect again. Kernel calls use full saved-register canaries and different
return continuations. These observations test the stated interfaces rather than
one set of temporary registers or an exact whole-program instruction total.
