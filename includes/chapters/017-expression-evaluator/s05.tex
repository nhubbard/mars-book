\section{Step 5 Check the bound before reading a character}\label{expression-s05}

Test the shared cursor against the length before forming an address. Equality means no byte remains. Otherwise add the cursor to the full input base and load one unsigned byte. The helper does not advance the cursor yet; it first has to decide whether this character is whitespace.

\Needspace{13\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{space\_read} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    beq $s1, $s2, space_return
    nop
    daddu $t0, $s0, $s1
    lbu $t1, 0($t0)
\end{minted}
\subsection{Expected observation}
For the slice " 7", the first byte read is decimal 32 and the cursor remains zero.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What must be established before \texttt{lbu}?

\begin{itemize}
  \item \textbf{A} That the next byte is nonzero.
  \item \textbf{B} That the cursor identifies an available byte.
  \item \textbf{C} That the base fits in a word.
\end{itemize}
