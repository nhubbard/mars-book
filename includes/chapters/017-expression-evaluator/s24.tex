\section{Step 24 Delegate an unsigned primary spelling}\label{expression-s24}

Call the primary routine when no prefix sign is selected. Its value or shared error state is returned unchanged after restoring this unary frame. The explicit branch skips the sign path, preventing an ordinary number from being treated as a recursive prefix operation.

\Needspace{13\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{unary\_primary} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    jal parse_primary
    nop
    beq $zero, $zero, unary_return
    nop
\end{minted}
\subsection{Expected observation}
For 7, unary now returns seven with cursor one.
