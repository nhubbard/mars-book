\section{Step 38 Return the accumulated expression value}\label{expression-s38}

When this level has no next operator, reload its accumulator and restore the frame. Consuming only the part owned by this rule is essential: a expression can finish before the whole byte slice does. The outermost wrapper alone decides whether complete input consumption has been achieved.

\Needspace{10\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{expr\_value} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{4\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    ld $v0, 0($sp)
\end{minted}
\subsection{Expected observation}
All parser regions are now complete. The default expression returns twenty-four with cursor seventeen; the public wrapper reports success.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Who performs the final complete-input check?

\begin{itemize}
  \item \textbf{A} The primary rule as soon as one literal ends.
  \item \textbf{B} Every term before returning to the expression rule.
  \item \textbf{C} The public wrapper after the expression and final whitespace skip.
\end{itemize}
