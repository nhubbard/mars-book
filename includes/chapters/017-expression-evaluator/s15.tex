\section{Step 15 Distinguish a group from a decimal literal}\label{expression-s15}

Skip permitted whitespace, reject end of input as a missing primary, and inspect the next byte. An opening parenthesis selects the group path. Otherwise subtract ASCII zero and use an unsigned comparison with ten. Values below ASCII zero become large unsigned values after subtraction, so they fail this digit test. Initialize the literal accumulator only after the first digit is established.

\Needspace{23\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{primary\_entry} region. Preserve its surrounding labels and frame scaffolding.

    move $t3, $zero

\subsection{Expected observation}
For 7, \texttt{t1} is digit value seven, \texttt{t2} is one, \texttt{t3} is zero, and the cursor is still zero.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why does the unsigned digit comparison reject a slash?

\begin{itemize}
\item \textbf{A} Slash becomes digit nine.
\item \textbf{B} The slash is a whitespace byte.
\item \textbf{C} Subtracting ASCII zero gives a negative value, which is outside unsigned zero through nine.
\end{itemize}
