\section{Step 27 Obtain the first term value}\label{expression-s27}

Call the unary routine for the first operand and propagate any existing error. Store a successful value in this invocation's accumulator slot. This slot survives later calls even when those calls use the same temporary registers. A single operand is a valid term, so the loop must also support returning this initial value without an operator.

\Needspace{14\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{term\_first} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}

    sd $v0, 0($sp)

\subsection{Expected observation}
For 3, the first unary value is three and the cursor reaches one.
