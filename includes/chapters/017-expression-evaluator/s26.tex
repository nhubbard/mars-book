\section{Step 26 Apply the saved sign with a range check}\label{expression-s26}

Unary plus returns its operand unchanged. For minus, compute zero minus the full operand, test word representability, and either select the provided value return or report overflow at the saved sign position. A nested failure is already handled by the earlier guard, so this code cannot overwrite it.

\subsection{Write or inspect}
Replace the temporary return in the \texttt{unary\_negate} region. Preserve its surrounding labels and frame scaffolding.
