\section{Step 13 Test representability before returning a value}\label{expression-s13}

A word shift by zero takes the low word and sign extends that word to a full register. Compare this canonical word value with the original wide candidate. Equality permits the value path. Inequality sets overflow status and transfers to the provided error return, which records the operator offset and returns provisional value zero.
