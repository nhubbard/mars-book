\section{Step 36 Apply the pending expression operation}\label{expression-s36}

Move the right value into \texttt{a1}, reload the left value into \texttt{a0}, and recover the operator and its position into \texttt{a2} and \texttt{a3}. Call the checked arithmetic helper. A new arithmetic failure returns immediately; a successful value is ready to become the next accumulator.

\Needspace{17\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{expr\_apply} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{11\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $a1, $v0

    ld $a2, 8($sp)
    ld $a3, 16($sp)
    jal apply_binary
    nop
    bne $s3, $zero, expr_return

\subsection{Expected observation}
For 1+2*3, the checked operation now returns seven.

\begin{itemize}
