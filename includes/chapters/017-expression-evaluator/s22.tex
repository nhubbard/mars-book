\section{Step 22 Report an unexpected byte or missing primary}\label{expression-s22}

Set syntax status and retain the current cursor. At end of input, that cursor equals the length and identifies the missing item. The same exit handles a non-digit primary and a missing or incorrect closing parenthesis. Earlier nested errors take their separate early return and are preserved.

\Needspace{12\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{primary\_syntax} region. Preserve its surrounding labels and frame scaffolding.

\subsection{Expected observation}
An empty slice reports syntax error at zero without an input read. A question mark at the first position also reports offset zero.

\subsection{Check your understanding}
How is a missing operand at end of input located?

\begin{itemize}
  \item \textbf{A} By the length offset.
  \item \textbf{B} By reading the next mapped byte.
  \item \textbf{C} By assuming an implicit zero operand.
\end{itemize}
