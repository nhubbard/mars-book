\section{Step 1 Read status before interpreting the second result}\label{expression-s01}

The same second result register represents a signed expression value on success and a byte offset on failure. The supplied default input is seventeen bytes long and evaluates to twenty-four. Read \texttt{v0} first; a negative value there is a status, not an arithmetic result.

\subsection{Expected observation}
At expression\_ready for the complete program, \texttt{v0} is zero and \texttt{v1} is twenty-four.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What does \texttt{v1} contain after a syntax error?

\begin{itemize}
  \item \textbf{A} A byte offset.
  \item \textbf{B} An expression result.
  \item \textbf{C} The input address.
\end{itemize}
