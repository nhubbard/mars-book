\section{Step 8 Select a binary arithmetic operation}\label{expression-s08}

The private arithmetic helper receives the left value in \texttt{a0}, right value in \texttt{a1}, operator byte in \texttt{a2}, and operator offset in \texttt{a3}. Compare against ASCII plus, minus, and asterisk. The remaining valid operator is slash; only the parser calls this helper, so it supplies one of those four bytes.

\Needspace{18\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{apply\_dispatch} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{12\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $t0, 43
    beq $a2, $t0, apply_add
    nop
    li $t0, 45
    beq $a2, $t0, apply_subtract
    nop
    li $t0, 42
    beq $a2, $t0, apply_multiply
    nop
\end{minted}
\subsection{Expected observation}
The plus byte, decimal 43, selects apply\_add. Arithmetic regions that are still unfinished return provisional zero.
