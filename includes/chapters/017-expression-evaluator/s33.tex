\section{Step 33 Obtain the first expression value}\label{expression-s33}

Call the term routine for the first operand and propagate any existing error. Store a successful value in this invocation's accumulator slot. This slot survives later calls even when those calls use the same temporary registers. A single operand is a valid expression, so the loop must also support returning this initial value without an operator.

\Needspace{14\baselineskip}
\subsection{Write or inspect}
Replace the temporary return in the \texttt{expr\_first} region. Preserve its surrounding labels and frame scaffolding.

\Needspace{8\baselineskip}

\subsection{Expected observation}
For 1+2*3, the first term returns one and leaves the cursor at one.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Where does the live left value survive nested calls?

\begin{itemize}
  \item \textbf{A} In this invocation's stack slot.
  \item \textbf{B} In the input bytes.
  \item \textbf{C} In an unpreserved temporary register.
\end{itemize}
