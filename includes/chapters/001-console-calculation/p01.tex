\section{Source text and
execution}\label{001-console-calculation-p01-source-text-and-execution}

MARS has two distinct jobs in this exercise. Its assembler reads the
source, resolves labels, and encodes instructions. Its simulator
executes the resulting program and maintains registers and memory. A
syntax error stops assembly; a wrong arithmetic result can occur in a
program that assembled successfully.

The starter contains a valid exit sequence. Adding declarations or
instructions above that sequence produces a series of short programs.
Each can be run as soon as it has enough instructions to demonstrate the
current operation. Keep the exit at the end while building the body. An
early exit would prevent the later work from executing.

The comments marking editable regions help readers find the intended
locations. They have no effect on execution. Changing a comment cannot
repair a missing instruction or an incorrect operand.
