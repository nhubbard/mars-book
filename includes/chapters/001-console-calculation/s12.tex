\section{Step 12 Select string output
again}\label{001-console-calculation-s12-step-12-select-string-output-again}

The service selector must be set for each request. After reading input,
\$v0 contains the input value, so relying on its previous role would
select the wrong service.

\subsection{Write or
inspect}\label{001-console-calculation-s12-write-or-inspect}

Append the string-output selector.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $v0, 4
\end{minted}

\subsection{Expected
observation}\label{001-console-calculation-s12-expected-observation}

\$v0 contains 4 and \$a0 still identifies the answer prefix.

\subsection{Check your
understanding}\label{001-console-calculation-s12-check-your-understanding}

Why explicitly load 4 again?

\begin{itemize}
\tightlist
\item
  \textbf{A} All registers are cleared after each instruction.
\item
  \textbf{B} The read service returned its result in \$v0.
\item
  \textbf{C} The string text has changed itself.
\end{itemize}
