\section{Reestablish the request
  contract}\label{001-console-calculation-p12-reestablish-the-request-contract}

The input service returned its value in \texttt{\$v0}. The program
therefore cannot assume that register still selects a console service.
Loading 4 establishes the selector required by the next string request.

For input 20, using the register without resetting it would attempt a
request with selector 20. The exact failure or effect would depend on
the selected service. The reasoning error is already visible before
execution: the register does not satisfy the intended
service\textquotesingle s contract.

The service table is a reference for this reasoning. Check both the
selector and its arguments whenever a request behaves unexpectedly. A
register containing a plausible number is insufficient if it serves the
wrong role.
