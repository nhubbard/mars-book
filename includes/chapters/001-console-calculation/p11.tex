\section{Preserve a value across interface
setup}\label{001-console-calculation-p11-preserve-a-value-across-interface-setup}

The answer is now in \texttt{\$t0}. The next operations prepare a
string-printing request, so \texttt{\$a0} becomes an address and
\texttt{\$v0} becomes a service selector again. Keeping the answer in
\texttt{\$t0} lets that setup proceed without losing the value to be
printed later.

This is a small example of managing the lifetime of a value. The result
must remain available from the end of the arithmetic through the
printing of the answer prefix. Each write in that interval should have a
stated purpose.

A correct printed prefix does not establish that the number is still
available. The debugger\textquotesingle s register view lets us check
both parts independently. This reference deliberately uses \texttt{\$t0}
so that its intermediate observations have a consistent name.
