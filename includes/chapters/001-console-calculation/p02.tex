\section{Data declarations describe
bytes}\label{001-console-calculation-p02-data-declarations-describe-bytes}

A string in the source becomes a sequence of bytes in simulated memory.
\texttt{.asciiz} adds a zero byte after the characters. For the
print-string service, that byte marks the end of the string. The label
names the location where the sequence begins.

The newline string illustrates two separate conventions. In assembly
source, \texttt{\textbackslash{}n} inside the quoted string represents a
newline character. The zero byte appended by \texttt{.asciiz} terminates
the string. The newline affects the displayed line; the terminator tells
the service when to stop reading bytes. The terminator is not printed.

The prompt also contains an ordinary space after the colon. That space
separates the prompt from the input in an interactive console. It is
part of the assignment\textquotesingle s output contract, even though a
reader may overlook it in a screenshot.
