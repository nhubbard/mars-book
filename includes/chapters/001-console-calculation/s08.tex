\section{Step 8 Read the
input}\label{001-console-calculation-s08-step-8-read-the-input}

The input syscall waits until a complete input is available. In the
default console mode, type a number and press Enter. Reading replaces
the service number in \$v0 with the input value.

\subsection{Write or
inspect}\label{001-console-calculation-s08-write-or-inspect}

Append syscall. Run and enter 20; then try -3.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    syscall
\end{minted}

\subsection{Expected
observation}\label{001-console-calculation-s08-expected-observation}

The partial program prompts, accepts input, and exits. In Debug, \$v0 is
20 after reading 20, or -3 after reading -3.

\subsection{Check your
understanding}\label{001-console-calculation-s08-check-your-understanding}

After reading 20, what does \$v0 contain?

\begin{itemize}
\tightlist
\item
  \textbf{A} 5, because service selectors can never change.
\item
  \textbf{B} 40, because input automatically doubles the number.
\item
  \textbf{C} 20, the returned input.
\end{itemize}
