\section{Choose tests for different failure
modes}\label{001-console-calculation-p20-choose-tests-for-different-failure-modes}

Input 20 exercises an ordinary positive calculation. Zero makes a
missing final addition visible: the expected answer is one. Input \ensuremath{-}3
checks that a negative value is handled with the intended signed result.

The endpoints \ensuremath{-}1000 and 1000 check the published limits and should
produce \ensuremath{-}1999 and 2001. These examples help find mistakes; executing a
few inputs does not establish a result for every allowed value. The
arithmetic explanation supplies the general argument: doubling
\texttt{x} and adding one implements the specified expression, with all
demonstrated intermediates in range.

When a check fails, classify the difference before editing. It may
concern the calculated number, the output bytes, termination, or an
assembly error. Each points to a different part of the program.
