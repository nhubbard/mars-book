\section{Step 4 Put the prompt address in an argument
register}\label{001-console-calculation-s04-step-4-put-the-prompt-address-in-an-argument-register}

la means load address. The print-string service needs the location of
the string, not its first character. \$a0 is the argument register for
that service. la is a pseudo-instruction: the assembler may expand it
into more than one machine instruction.

\subsection{Write or
inspect}\label{001-console-calculation-s04-write-or-inspect}

Insert this instruction at the beginning of the student program region.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $a0, prompt
\end{minted}

\subsection{Expected
observation}\label{001-console-calculation-s04-expected-observation}

\$a0 now identifies the prompt bytes. Nothing has been printed yet.

\subsection{Check your
understanding}\label{001-console-calculation-s04-check-your-understanding}

What should \$a0 contain before printing a string?

\begin{itemize}
\tightlist
\item
  \textbf{A} The address of its zero-terminated bytes.
\item
  \textbf{B} The first character only.
\item
  \textbf{C} The length of the source filename.
\end{itemize}
