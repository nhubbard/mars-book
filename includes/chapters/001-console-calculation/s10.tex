\section{Step 10 Add the final
one}\label{001-console-calculation-s10-step-10-add-the-final-one}

addiu adds an immediate to a source register and writes a word result.
Using \$t0 as both destination and source replaces its previous value.
The u means signed overflow does not trap; a word result is still
sign-extended. For this input domain the result is the ordinary integer
2 \ensuremath{\times} x + 1.

\subsection{Write or
inspect}\label{001-console-calculation-s10-write-or-inspect}

Append this instruction and calculate the expected intermediate values
for 0, 20, and -3.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    addiu $t0, $t0, 1
\end{minted}

\subsection{Expected
observation}\label{001-console-calculation-s10-expected-observation}

The final result is 1 for 0, 41 for 20, and -5 for -3. Keep it in \$t0
while preparing output.

\subsection{Check your
understanding}\label{001-console-calculation-s10-check-your-understanding}

For input 20, which value is replaced by this instruction?

\begin{itemize}
\tightlist
\item
  \textbf{A} The 40 in \$t0 is replaced by 41.
\item
  \textbf{B} The prompt bytes are replaced by 41.
\item
  \textbf{C} The service number is permanently changed to 41.
\end{itemize}
