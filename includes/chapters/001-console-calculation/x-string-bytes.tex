  memory}\label{001-console-calculation-x-string-bytes-a-zero-terminated-string-in-memory}

\texttt{A} be the address assigned to \texttt{greeting}.

An argument containing \texttt{A} identifies the beginning of the
sequence. The print service reads successive bytes until it reaches the
terminator. The specific numeric address depends on the assembled
layout.
