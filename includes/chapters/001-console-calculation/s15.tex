\section{Step 15 Select integer
output}\label{001-console-calculation-s15-step-15-select-integer-output}

Service 1 prints the signed integer supplied in \$a0. Setting \$v0 does
not change the argument in \$a0, so the result remains available for the
request.

\subsection{Write or
inspect}\label{001-console-calculation-s15-write-or-inspect}

Append the integer-output selector.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $v0, 1
\end{minted}

\subsection{Expected
observation}\label{001-console-calculation-s15-expected-observation}

\$v0 is 1 and \$a0 contains the answer. These registers now have
different roles in one request.

\subsection{Check your
understanding}\label{001-console-calculation-s15-check-your-understanding}

Which register selects the service?

\begin{itemize}
\tightlist
\item
  \textbf{A} \$t0 automatically selects it.
\item
  \textbf{B} \$v0.
\item
  \textbf{C} \$a0.
\end{itemize}
