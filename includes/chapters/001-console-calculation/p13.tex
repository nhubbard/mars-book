\section{Compose one line with several
  requests}\label{001-console-calculation-p13-compose-one-line-with-several-requests}

The answer line is produced in pieces: a fixed prefix, a computed
integer, and a newline. Each output request appends its result to the
output already produced. There is no need to build one combined string
in memory for this task.

This arrangement also provides checkpoints. After the prefix request,
the numeric result should still be available, but no decimal digits have
been requested yet. Seeing only the prefix is the expected behavior of
this partial program.

When evaluating a completed submission, use the whole output contract. A
checkpoint that is correct for a partial version would be incomplete as
a final answer. The assignment and the current lesson step describe
different scopes for the same observation.
