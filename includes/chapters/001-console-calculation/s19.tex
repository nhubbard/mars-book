\section{Step 19 Finish the line and
exit}\label{001-console-calculation-s19-step-19-finish-the-line-and-exit}

The final output syscall emits the newline. Execution then reaches the
existing done label and exit sequence. This straight-line program needs
no branch to reach the next instruction.

understanding}\label{001-console-calculation-s19-check-your-understanding}

How does execution reach the exit scaffold?

\begin{itemize}
\tightlist
\item
  \textbf{A} It continues to the following instructions in order.
\item
  \textbf{B} The label done calls itself.

  \textbf{C} A newline is a branch instruction.
\end{itemize}
