\section{Step 5 Select string
  output}\label{001-console-calculation-s05-step-5-select-string-output}

li means load immediate: an immediate is a constant written in the
source. MARS uses \$v0 to choose a syscall service. Service 4 prints a
zero-terminated string whose address is in \$a0. Selecting the service
and requesting it are separate operations.

\subsection{Write or
  inspect}\label{001-console-calculation-s05-write-or-inspect}

Append the instruction after the address load.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $v0, 4
\end{minted}

\subsection{Expected
  observation}\label{001-console-calculation-s05-expected-observation}

\$v0 contains the service selector 4. The string has not been printed
yet.

\subsection{Check your
  understanding}\label{001-console-calculation-s05-check-your-understanding}

Does loading 4 into \$v0 print the string?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Yes; every write to \$v0 prints a string.
  \item
        \textbf{B} Yes; la already printed it.
  \item
        \textbf{C} No; syscall must request the selected service.
\end{itemize}
