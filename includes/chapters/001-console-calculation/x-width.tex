\section{A word result in a 64-bit
  register}\label{001-console-calculation-x-width-a-word-result-in-a-64-bit-register}

For the in-range result \ensuremath{-}5, the low word is \texttt{0xfffffffb}. Sign
extension copies bit 31 into the upper 32 bits, yielding
\texttt{0xfffffffffffffffb} in the 64-bit register. For positive 41, the
full register is \texttt{0x0000000000000029}.

The \texttt{addu} and \texttt{addiu} operations in this example produce
word results. Their \texttt{u} suffix selects non-trapping
signed-overflow behavior; it does not select zero-extension. The input
domain keeps this program away from overflow.
