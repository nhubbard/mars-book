\section{Step 7 Select integer
  input}\label{001-console-calculation-s07-step-7-select-integer-input}

Service 5 reads a signed decimal integer and returns it in \$v0. That
register is reused: it holds the service number before the request and
the input afterward.

\subsection{Write or
  inspect}\label{001-console-calculation-s07-write-or-inspect}

Append the selector after the prompt syscall.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $v0, 5
\end{minted}

\subsection{Expected
  observation}\label{001-console-calculation-s07-expected-observation}

\$v0 contains 5 before the next syscall. Merely selecting service 5 does
not wait for input.

\subsection{Check your
  understanding}\label{001-console-calculation-s07-check-your-understanding}

Where will service 5 return the integer?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} \$v0.
  \item
        \textbf{B} \$a0 always holds every syscall result.
  \item
        \textbf{C} The label prompt.
\end{itemize}
