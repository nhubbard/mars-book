\section{Step 3 Read the entry and exit
  scaffold}\label{001-console-calculation-s03-step-3-read-the-entry-and-exit-scaffold}

The .text directive selects the instruction section. The .globl main
directive exports main; main: names the entry in this starter. li puts a
constant into a register. With service number 10 in \$v0, syscall
requests normal termination from MARS. Registers beginning with \$ are
processor storage locations.

\subsection{Write or
  inspect}\label{001-console-calculation-s03-write-or-inspect}

Read the scaffold, including the two exit instructions. Add all
subsequent instruction fragments above done, in the listed order. Leave
the exit sequence at the end.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
done:
    li $v0, 10
    syscall
\end{minted}

\subsection{Expected
  observation}\label{001-console-calculation-s03-expected-observation}

The supplied exit makes the first partial versions safe to run. A label
names a location and does not execute an operation.

\subsection{Check your
  understanding}\label{001-console-calculation-s03-check-your-understanding}

Which line requests the exit service?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} .globl main by itself.
  \item
        \textbf{B} syscall, after \$v0 has been set to 10.
  \item
        \textbf{C} done: by itself.
\end{itemize}
