\section{The service determines how an argument is
  used}\label{001-console-calculation-p14-the-service-determines-how-an-argument-is-used}

The same argument register can carry an address for one service and a
number for another. Before integer output, \texttt{move\ \$a0,\ \$t0}
copies the answer\textquotesingle s bit pattern into \texttt{\$a0}.
Service 1 will interpret that argument as the signed integer to print.

The copy leaves \texttt{\$t0} available. Its source value is not removed
by the move. The instruction is another assembler pseudo-instruction;
its purpose here is to express a register-to-register copy clearly.

Interpret the argument together with the selector. A screenshot of
\texttt{\$a0} alone cannot establish whether the program is about to
print text or a decimal number. The next service contract supplies that
context.
