\section{The first visible side
  effect}\label{001-console-calculation-p06-the-first-visible-side-effect}

Printing the prompt changes the console output. It does not compute the
answer or read an integer. At this checkpoint, the program has completed
one request and then reaches the supplied exit sequence.

The result is useful even though the assignment is incomplete. It
establishes that the program can address its message, select the
expected service, and make the request. If the prompt is wrong, inspect
those operations before adding input or arithmetic. A short checkpoint
narrows the portion of the program that could explain the observed
failure.

The characters typed by a person may also appear in the console. Such
terminal echo is distinct from bytes emitted by the program. The grader
compares the program\textquotesingle s captured output and supplies
input through its own fixture.
