\section{Step 20 Check the output
  contract}\label{001-console-calculation-s20-step-20-check-the-output-contract}

Testing several values catches mistakes that one positive input can
hide. Zero distinguishes 2 \ensuremath{\times} x + 1 from 2 \ensuremath{\times} x; a negative input checks
the signed result. The public grader compares the output produced by the
program, not terminal echo.

\subsection{Write or
  inspect}\label{001-console-calculation-s20-write-or-inspect}

Run with 20, 0, and -3. Then run the public checks using the repository
instructions.

\subsection{Expected
  observation}\label{001-console-calculation-s20-expected-observation}

Expected results are 41, 1, and -5 with exact prompts and one trailing
newline. A wrong answer and a formatting mismatch are different failures
to investigate.

\subsection{Check your
  understanding}\label{001-console-calculation-s20-check-your-understanding}

Why test zero as well as 20?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Zero makes every possible program correct.
  \item
        \textbf{B} Only zero can be used with syscall 5.
  \item
        \textbf{C} It helps expose a missing final addition of one.
\end{itemize}
