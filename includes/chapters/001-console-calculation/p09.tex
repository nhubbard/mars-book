\section{Read the operands from left to
right}\label{001-console-calculation-p09-read-the-operands-from-left-to-right}

In \texttt{addu\ \$t0,\ \$v0,\ \$v0}, the destination is \texttt{\$t0}.
The two source operands both name \texttt{\$v0}, so the result is the
sum of two copies of the input. The instruction writes \texttt{\$t0}; it
does not consume the value in \texttt{\$v0}.

Reading the same source twice is valid. The instruction has two input
positions, and both can refer to the same register. For an input of \ensuremath{-}3,
the sum is \ensuremath{-}6. The letter \texttt{u} does not force a positive result.
This addition produces a word result without trapping on signed
overflow, then sign-extends that result into the 64-bit destination
register.

Our bounded inputs keep this particular sum in range. A later lesson can
change the input contract and examine overflow directly without changing
the meaning of the instruction name.
