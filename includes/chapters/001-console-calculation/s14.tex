\section{Step 14 Pass the numeric
  result}\label{001-console-calculation-s14-step-14-pass-the-numeric-result}

move copies a register value without changing the source. For integer
output, \$a0 holds the number itself. Contrast that with string output,
where \$a0 holds an address. The service contract determines how the
bits are interpreted.

\subsection{Write or
  inspect}\label{001-console-calculation-s14-write-or-inspect}

Append the move into the output argument register.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    move $a0, $t0
\end{minted}

\subsection{Expected
  observation}\label{001-console-calculation-s14-expected-observation}

For input 20, \$a0 and \$t0 both contain 41. This instruction alone
produces no output.

\subsection{Check your
  understanding}\label{001-console-calculation-s14-check-your-understanding}

What does \$a0 represent for integer output?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Always a string address, regardless of service.
  \item
        \textbf{B} An instruction count.
  \item
        \textbf{C} The integer value to print.
\end{itemize}
