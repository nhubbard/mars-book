\section{Check the selector after changing the
  argument}\label{001-console-calculation-p18-check-the-selector-after-changing-the-argument}

Loading a new address does not change the service selector. The
preceding request used integer output, so the program explicitly loads 4
before printing the newline string.

This order exposes a useful debugging habit. Stop immediately before a
syscall and state its intended contract aloud: ``service 4, with the
newline address in \texttt{\$a0}.'' Compare that statement with the
displayed register values. It ties each number to the operation that
will use it.

The program can now request the final newline and then continue into the
supplied exit sequence.
