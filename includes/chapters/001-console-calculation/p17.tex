\section{Reuse the address and string
pattern}\label{001-console-calculation-p17-reuse-the-address-and-string-pattern}

The newline is stored as a short zero-terminated string. Loading its
address prepares the same interface used for the prompt and answer
prefix. Its contents are different, but the request structure is
unchanged.

After this load, \texttt{\$a0} holds an address again. The earlier
numeric argument has been replaced. That replacement is safe because the
integer-printing request has already completed; it no longer needs the
old argument value.

Following these changes in order is enough to explain why register reuse
works in this program. The question at each write is whether a later
operation still needs the previous value.
