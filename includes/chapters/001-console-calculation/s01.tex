\section{Step 1 Open the
  starter}\label{001-console-calculation-s01-step-1-open-the-starter}

An assembly source file describes data and instructions. MARS assembles
the text into executable machine instructions before running it. This
first program is a standalone source file; it does not need a build
framework.

\subsection{Write or
  inspect}\label{001-console-calculation-s01-write-or-inspect}

Open starter/main.asm. Identify the two marked regions and the supplied
exit sequence. Run the unchanged file once.

\subsection{Expected
  observation}\label{001-console-calculation-s01-expected-observation}

The template should terminate without printing anything. If Run is
unavailable, check that the MARS plugin is enabled and the file has the
.asm extension.

\subsection{Check your
  understanding}\label{001-console-calculation-s01-check-your-understanding}

What happens before the simulator can execute your source?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The assembler translates source into machine instructions.
  \item
        \textbf{B} The processor executes the comments as instructions.
  \item
        \textbf{C} The console converts every source line to an input value.
\end{itemize}
