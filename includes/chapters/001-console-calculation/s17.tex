\section{Step 17 Prepare the newline
  string}\label{001-console-calculation-s17-step-17-prepare-the-newline-string}

The declaration newline contains a newline byte followed by a zero
terminator. Loading its address prepares the same print-string interface
used earlier.

\subsection{Write or
  inspect}\label{001-console-calculation-s17-write-or-inspect}

Append the address load.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $a0, newline
\end{minted}

\subsection{Expected
  observation}\label{001-console-calculation-s17-expected-observation}

\$a0 now contains a string address rather than the numeric answer. \$t0
still retains that answer.

\subsection{Check your
  understanding}\label{001-console-calculation-s17-check-your-understanding}

Does la change the contents of the newline string?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Yes; it replaces the newline with its address.
  \item
        \textbf{B} Yes; it immediately appends the string to the console.
  \item
        \textbf{C} No; it loads its address into a register.
\end{itemize}
