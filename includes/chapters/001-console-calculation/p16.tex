\section{Formatting is observable
behavior}\label{001-console-calculation-p16-formatting-is-observable-behavior}

Printing the integer produces decimal digits, including a minus sign for
a negative result. Service 1 does not append the line ending needed by
this assignment. That operation belongs to the following string request.

A program can have the right arithmetic and still produce output that
differs from the specified bytes. Missing spaces and extra line endings
are common examples. Checking the exact output makes the interface
reproducible and gives the grader an unambiguous result.

A visible console line is useful for reading, but it may conceal the
difference between one newline and two. An escaped string representation
makes such bytes explicit when explaining a failure.
