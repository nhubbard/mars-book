\section{The complete output for input
  20}\label{001-console-calculation-x-output-bytes-the-complete-output-for-input-20}

The program\textquotesingle s output, represented with a visible escape
for the newline, is:

\MARSCodeLabel{Literal output}
\begin{verbatim}
"Enter a small integer: Twice your number plus one is: 41\n"
\end{verbatim}

The quotation marks delimit this representation; they are not output.
There is one space after each colon and one trailing newline. Typed
input echoed by an interactive terminal is not part of this captured
output.
