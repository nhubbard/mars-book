\section{Step 7 Clamp the top edge}\label{blit-s07}

Apply the same maximum-with-zero operation to y. Keep the horizontal and vertical calculations separate so a top clip cannot alter the selected source column. The fixed label after this region is the branch destination for both paths.

\subsection{Write or inspect}
Append these instructions in the \texttt{top} region. Keep the scaffold labels and return section.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}

    nop
    move $s6, $zero

\subsection{Expected observation}
With y one, \texttt{s6} remains one; with y minus two, it becomes zero.
