\section{Step 10 Reject empty intersections before addressing}\label{blit-s10}

Subtract left from right and top from bottom with \texttt{dsubu}. A zero or negative width or height means there is no copy. Branch to the common restore section with both results still zero. The u suffix suppresses an overflow exception; it does not make the resulting bit pattern an unsigned geometric quantity.

\subsection{Write or inspect}
Append these instructions in the \texttt{extent} region. Keep the scaffold labels and return section.

\Needspace{9\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    dsubu $t8, $s7, $s5
    blez $t8, blit_restore
    nop
    dsubu $t9, $t4, $s6
    blez $t9, blit_restore
    nop
\end{minted}

\subsection{Expected observation}
The default \texttt{t8} and \texttt{t9} are three and four. At x eight, width is zero and there are no pixel accesses.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
May a negative extent be used as a loop count?

\begin{itemize}
\item \textbf{A} Yes, after masking.
\item \textbf{B} No; it indicates an empty intersection.
\item \textbf{C} Only for a negative x.
\end{itemize}
