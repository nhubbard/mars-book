\section{Step 19 Advance within the selected row}\label{blit-s19}

Advance each cursor by four bytes, decrement the remaining cell count, and repeat while that count is nonzero. The positive-extent test guarantees that this loop starts with at least one cell. The skip label joins the transparent and opaque paths before these common updates.

\subsection{Write or inspect}
Append these instructions in the \texttt{advance} region. Keep the scaffold labels and return section.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 4
    addiu $t2, $t2, -1
    bne $t2, $zero, blit_pixel
    nop
\end{minted}

\subsection{Expected observation}
After the first default row, \texttt{v0} is one and \texttt{v1} is three.
