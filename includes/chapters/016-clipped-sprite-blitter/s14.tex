\section{Step 14 Locate the first destination pixel}\label{blit-s14}

Multiply top by destination byte stride and add four times left. Both terms are bounded after clipping, so the offset fits in a word. Add the offset to the full destination base with \texttt{daddu}. This register now points at the first selected cell rather than the allocation origin.

\subsection{Write or inspect}
Append these instructions in the \texttt{destination\_address} region. Keep the scaffold labels and return section.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    mul $t0, $s6, $s2
    sll $t1, $s5, 2
    addu $t0, $t0, $t1
    daddu $s0, $s0, $t0
\end{minted}

\subsection{Expected observation}
The default destination address is frame\_a plus sixty-four bytes.
