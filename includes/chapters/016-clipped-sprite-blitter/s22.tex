\section{Step 22 Change the key without changing RGB policy}\label{blit-s22}

Test key zero, a key with bit 31 set, and words differing only in their high byte. Equality is defined by the function contract. The display masks a different set of bits for a different purpose, so it cannot decide whether a cell was transparent.


\subsection{Expected observation}
With default key 00ff00ff, black and 01ff00ff are opaque.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Are 00ff00ff and 01ff00ff equal transparency words?

\begin{itemize}
  \item \textbf{A} Yes, because they display alike.
  \item \textbf{B} No.
  \item \textbf{C} Only on the first row.
\end{itemize}
