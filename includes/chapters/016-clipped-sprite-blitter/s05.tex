\section{Step 5 Load four logical dimensions}\label{blit-s05}

Load destination width and height from \texttt{a0}, then source width and height from \texttt{a1}. These are logical dimensions, not allocation sizes. The valid domain bounds each dimension by eight; a zero dimension is legal.

\subsection{Write or inspect}
Append these instructions in the \texttt{dimensions} region. Keep the scaffold labels and return section.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lw $t0, 8($a0)
    lw $t1, 12($a0)
    lw $t2, 8($a1)
    lw $t3, 12($a1)
\end{minted}

\subsection{Expected observation}
For the default descriptors, \texttt{t0} through \texttt{t3} hold eight, six, five, and four.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which quantity is absent from these four loads?

\begin{itemize}
\item \textbf{A} Stride.
\item \textbf{B} Source width.
\item \textbf{C} Destination height.
\end{itemize}
