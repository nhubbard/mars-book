\section{Step 3 Trace a padded row}\label{blit-s03}

For the default framebuffer, row one begins sixteen words after row zero. The clipped source begins in source column two, so its first selected word is eight bytes after its base. A diagram of adjacent visible cells does not imply adjacent rows in memory.


\subsection{Expected observation}
The first destination pointer is frame\_a plus sixty-four bytes; the source pointer is sprite\_a plus eight.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What advances the destination row start?

\begin{itemize}
  \item \textbf{A} The copy width times four.
  \item \textbf{B} The source stride.
  \item \textbf{C} The destination stride times four.
\end{itemize}
