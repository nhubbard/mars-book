\section{Step 20 Advance each row start by its own stride}\label{blit-s20}

Add the destination byte stride to the destination row start and the source byte stride to the source row start. Increment completed rows and compare against copy height. Advancing \texttt{s0} from its retained row start avoids adding the copy width twice. The final iteration falls through to the restore section.

\subsection{Write or inspect}
Append these instructions in the \texttt{next\_row} region. Keep the scaffold labels and return section.

\Needspace{9\baselineskip}

    sltu $t0, $s7, $s6
    bne $t0, $zero, blit_row
    nop

\subsection{Expected observation}
After four default rows, the results are eight and twelve.
