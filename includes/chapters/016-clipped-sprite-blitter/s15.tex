\section{Step 15 Locate the first source pixel}\label{blit-s15}

Use the clipped source row and column with the source byte stride. A negative placement advances the source pointer because invisible source cells precede the first copied cell. The destination and source offsets need not match.

\subsection{Write or inspect}
Append these instructions in the \texttt{source\_address} region. Keep the scaffold labels and return section.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    mul $t0, $t7, $s3
    sll $t1, $t6, 2
    addu $t0, $t0, $t1
    daddu $s1, $s1, $t0
\end{minted}

\subsection{Expected observation}
The default source pointer advances eight bytes.
