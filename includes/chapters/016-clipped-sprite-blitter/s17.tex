\section{Step 17 Start one row with fresh cursors}\label{blit-s17}

Copy the current row starts into \texttt{t0} and \texttt{t1} and the copy width into \texttt{t2}. The inner loop changes these cursors without destroying \texttt{s0} or \texttt{s1}. Reset \texttt{t2} for every row; otherwise the second row would inherit zero.
