\section{Step 6 Clamp the left edge}\label{blit-s06}

Start the left edge at x. If it is negative, replace it with zero; otherwise keep it. The branch tests a signed full-register value. The right edge will establish whether this left edge actually intersects the framebuffer.

\subsection{Write or inspect}
Append these instructions in the \texttt{left} region. Keep the scaffold labels and return section.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $s5, $a2
    bgez $s5, clip_left_ready
    nop
    move $s5, $zero
\end{minted}

\subsection{Expected observation}
With x minus two, \texttt{s5} becomes zero. With x eight, it remains eight.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
May a positive left edge already be outside the framebuffer?

\begin{itemize}
  \item \textbf{A} No.
  \item \textbf{B} Only when the source is transparent.
  \item \textbf{C} Yes; the later extent test detects that case.
\end{itemize}
