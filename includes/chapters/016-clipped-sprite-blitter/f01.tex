The surviving columns 2 through 4 span destination columns 0 through 2, and all four source rows remain visible: $3\cdot4=12$. Transparent cells contribute to the visible count but receive no destination store.
      \item The image has sixteen physical columns and eight rows. Logical framebuffer cell $(0,0)$ is physical column 1, row 0, after the leading guard; each logical row has eight active cells and a sixteen-word stride. The dashed white outline marks the eight-by-six logical framebuffer. Gray cells include padding and the guard. The display omits the final padding word and trailing guard, which are checked separately in memory. For this placement, the selected source slice occupies logical columns 0 through 2 and rows 1 through 4. Background remains where a selected source word equals the key. The thin outline at the first physical cell is a native selection marker.
      \item The first displayed word at \texttt{0x10010040} is padding at the end of the preceding allocation row. Logical row 1 starts at \texttt{0x10010044}. Its first three words are background \texttt{0x00102030}, green \texttt{0x0000ff00}, and background again. These come from source columns 2, 3 and 4: the two key words are skipped, while green is copied. The trace verifies no read of the clipped source columns and no store to the skipped destinations.
    \end{enumerate}
