\section{Step 2 Inspect the descriptors}\label{blit-s02}

Read the descriptor fields by byte offset, not by counting source directives. An eight-byte address precedes the word dimensions. Source and destination descriptors have independent base addresses and strides; only the sprite descriptor contains the key.


\subsection{Expected observation}
The source stride field is at byte sixteen, and its key is at byte twenty.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Where is the sprite height?

\begin{itemize}
  \item \textbf{A} Byte twelve.
  \item \textbf{B} Byte sixteen.
  \item \textbf{C} Byte twenty.
\end{itemize}
