\section{Compare the explicit and table-driven
programs}\label{006-marsbot-square-p10-compare-the-explicit-and-table-driven-programs}

The explicit solution repeats four leg bodies so their differences are
easy to inspect. A table-driven solution can represent each leg with a
heading, a coordinate offset, and a choice between side and zero as its
target. One outer loop loads a record, prepares the leg, and runs the
same short polling loop.

This change moves repetition from instructions into data. It also
introduces record stride: three word fields occupy twelve bytes. The
input side remains separate from those command records, so the same
records work for every permitted square size.

Both programs are tested against the same path and final-state
assertions. Their private labels and scratch registers need not match.
The illustrated register checks apply only to the reference program used
for the chapter\textquotesingle s Debug figures.
