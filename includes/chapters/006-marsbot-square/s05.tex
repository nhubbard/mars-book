\section{Step 5 Choose east while
  stopped}\label{006-marsbot-square-s05-step-5-choose-east-while-stopped}

Heading 90 points right. Set it before enabling movement so every pixel
of this leg uses the intended direction. Heading zero points north and
is clamped at the top boundary when the robot starts at the origin.

\subsection{Write or
  inspect}\label{006-marsbot-square-s05-write-or-inspect}

Append the east heading command.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $t1, 90
    sw $t1, 0x10($s0)
\end{minted}

\subsection{Expected
  observation}\label{006-marsbot-square-s05-expected-observation}

The robot is still at (0, 0), now facing east.

\subsection{Check your
  understanding}\label{006-marsbot-square-s05-check-your-understanding}

Why use east for the first leg?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} It points into the board from the top-left starting point.
  \item
        \textbf{B} Ninety is the movement-enable value.
  \item
        \textbf{C} All headings move right.
\end{itemize}
