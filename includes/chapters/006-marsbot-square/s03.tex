\section{Step 3 Load the register base and side
length}\label{006-marsbot-square-s03-step-3-load-the-register-base-and-side-length}

\texttt{dli} makes the full 64-bit device base explicit. \texttt{la}
obtains the address of the input word; \texttt{lw} reads its value. The
valid side lengths are small positive integers, so the signed extension
of \texttt{lw} preserves the intended value.

\subsection{Write or
inspect}\label{006-marsbot-square-s03-write-or-inspect}

Append these address and input loads.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    dli $s0, BOT_BASE
    la $t0, side
    lw $s1, 0($t0)
\end{minted}

\subsection{Expected
observation}\label{006-marsbot-square-s03-expected-observation}

\texttt{\$s0} is 0x00000000ffff8000 and \texttt{\$s1} is sixteen for the
default input. No control has changed.

\subsection{Check your
understanding}\label{006-marsbot-square-s03-check-your-understanding}

What is in \texttt{\$s1} after the load?

\begin{itemize}
\tightlist
\item
  \textbf{A} The address of side.
\item
  \textbf{B} The right-display byte port.
\item
  \textbf{C} The requested distance in pixels.
\end{itemize}
