\section{Step 15 Raise the pen and
  finish}\label{006-marsbot-square-s15-step-15-raise-the-pen-and-finish}

Writing zero to the pen register raises it. The completed trail remains.
The supplied exit code follows the \texttt{finished} label, so Debug can
inspect the final device before the execution is disposed.

\subsection{Write or
  inspect}\label{006-marsbot-square-s15-write-or-inspect}

Append the final pen command and checkpoint.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    sw $zero, 0x20($s0)
finished:
\end{minted}

\subsection{Expected
  observation}\label{006-marsbot-square-s15-expected-observation}

The final state is (0, 0), heading zero, stopped, pen up, with four
strokes retained.

\subsection{Check your
  understanding}\label{006-marsbot-square-s15-check-your-understanding}

Does raising the pen erase the path?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} No; it changes whether future movement adds ink.
  \item
        \textbf{B} Yes; it clears all memory.
  \item
        \textbf{C} Only on the fourth side.
\end{itemize}
