\section{Step 6 Enable
movement}\label{006-marsbot-square-s06-step-6-enable-movement}

The move register treats a nonzero word as enabled. The reference
retains one in \texttt{\$t0}. Enabling movement resets the tick
countdown when the moving state changes. It does not instantly traverse
a side.

\subsection{Write or
inspect}\label{006-marsbot-square-s06-write-or-inspect}

Append the start command.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    sw $t0, 0x50($s0)
\end{minted}
