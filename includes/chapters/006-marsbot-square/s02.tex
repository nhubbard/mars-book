\section{Step 2 Map controls and
  feedback}\label{006-marsbot-square-s02-step-2-map-controls-and-feedback}

The register block contains three controls and two coordinate words.
Controls request behavior; feedback reports the model\textquotesingle s
current position. The model republishes coordinates after a CPU write
rather than treating that write as a position command.

\subsection{Write or
  inspect}\label{006-marsbot-square-s02-write-or-inspect}

Identify the five register addresses in the port table.

\subsection{Expected
  observation}\label{006-marsbot-square-s02-expected-observation}

Heading, pen, and movement are controls; x and y are feedback.

\subsection{Check your
  understanding}\label{006-marsbot-square-s02-check-your-understanding}

Which action moves the robot toward a target?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Set a heading and movement control, then observe feedback.
  \item
        \textbf{B} Store the target directly into x and y.
  \item
        \textbf{C} Change only a label in the data section.
\end{itemize}
