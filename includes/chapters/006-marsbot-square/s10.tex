\section{Step 10 Poll y and stop the south
  leg}\label{006-marsbot-square-s10-step-10-poll-y-and-stop-the-south-leg}

The loop structure is unchanged, but the coordinate offset is now 0x40.
The target is still the input side length. Only the axis of observation
changes.

\subsection{Write or
  inspect}\label{006-marsbot-square-s10-write-or-inspect}

Append the south polling loop.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
south_wait:
    lw $t2, 0x40($s0)
    bne $t2, $s1, south_wait
    nop
    sw $zero, 0x50($s0)
south_stopped:
\end{minted}

\subsection{Expected
  observation}\label{006-marsbot-square-s10-expected-observation}

At \texttt{south\_stopped}, position is (side, side), with two completed
strokes.

\subsection{Check your
  understanding}\label{006-marsbot-square-s10-check-your-understanding}

What would happen if this loop polled x against side?

\begin{itemize}
  \tightlist

        \textbf{A} It would measure y indirectly.
  \item
        \textbf{B} x is already equal, so it could stop before drawing the
        south side.
  \item

\end{itemize}
