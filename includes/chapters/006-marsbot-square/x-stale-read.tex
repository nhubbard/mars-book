\section{A load that misses the tick still leads to a timely
  stop}\label{006-marsbot-square-x-stale-read-a-load-that-misses-the-tick-still-leads-to-a-timely-stop}

Let T be the completion callback that reaches the target after returning
an older coordinate from the current load. For the reference polling
loop:

The next movement tick is at T + rate. The permitted rate is at least
eight, so no extra pixel occurs in this worst phase. This argument
depends on the shown short path; adding instructions requires revisiting
the bound.
