\section{Reuse the control pattern on the other
  axes}\label{006-marsbot-square-p08-reuse-the-control-pattern-on-the-other-axes}

The second leg begins from (side, 0). Its x coordinate is already
correct, so polling x against side would permit an immediate stop.
Polling y instead measures progress toward the next corner. This is a
useful example of a program whose comparison can be mathematically true
while answering the wrong question.

The return legs use absolute target zero. They do not subtract side
repeatedly from an input word, and they do not rely on an arbitrary
instruction delay to cover the distance. The target describes a
location; the heading supplies the direction of travel.

Stopping before turning keeps the proof local to each leg. While east is
active, y remains zero; while south is active, x remains side. At each
corner, one completed stroke extends the known prefix of the square and
the next leg starts from a known state.
