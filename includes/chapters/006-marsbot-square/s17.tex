understanding}\label{006-marsbot-square-s17-check-your-understanding}

Why is a fixed busy-wait count a weaker control method?

\begin{itemize}
\tightlist
\item
  \textbf{A} It is independent of the device clock.
\item
  \textbf{B} It always draws a diagonal.
\item

  instructions permit.
\end{itemize}
