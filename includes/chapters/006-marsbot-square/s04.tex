\section{Step 4 Lower the pen before
  moving}\label{006-marsbot-square-s04-step-4-lower-the-pen-before-moving}

The value one lowers the pen. The base-plus-offset address selects the
pen control; the same value at the movement offset will later enable
motion. A value alone has no device meaning without its destination.

\subsection{Write or
  inspect}\label{006-marsbot-square-s04-write-or-inspect}

Append the pen command and the first observation label.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $t0, 1
    sw $t0, 0x20($s0)
pen_ready:
\end{minted}

\subsection{Expected
  observation}\label{006-marsbot-square-s04-expected-observation}

The pen is down, but position remains (0, 0) and movement is still
disabled.

\subsection{Check your
  understanding}\label{006-marsbot-square-s04-check-your-understanding}

Does lowering the pen immediately draw a line?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Yes, it fills the whole board.
  \item
        \textbf{B} No; a line requires movement while the pen is down.
  \item
        \textbf{C} Yes, it moves to the input side length.
\end{itemize}
