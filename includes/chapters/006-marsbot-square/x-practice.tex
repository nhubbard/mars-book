\section{Practice variations and
review}\label{006-marsbot-square-x-practice-practice-variations-and-review}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  For L = 7, list every corner and the coordinate tested on each leg.
\item
  Predict the result of starting north at the origin while polling y for
  positive L.
\item
  Move the coordinate load outside a polling loop. Explain which value
  the branch repeatedly compares and why that value does not track the
  device.
\item
  Draw a rectangle with separately supplied width and height. State
  which targets change and keep the work within the board. Define a new
  grading contract before treating it as the square assignment.
\item
  Explain why inserting a print service between the load and stop
  invalidates the six-instruction stopping argument, even if one
  observed run still looks correct.
\item
  Compare the four explicit legs with a command table. Which data need a
  stride, and which address remains the fixed device base?
\item
  Predict whether a Debug pause and a slower UI repaint change the
  robot\textquotesingle s logical path. Identify what a real screenshot
  must verify in addition to the model.
\end{enumerate}

Keep experiments in separate copies so their changed contracts do not
affect the submitted square program.
