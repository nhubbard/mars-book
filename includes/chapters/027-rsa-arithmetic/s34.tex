\section{Step 34 Publish a full modular product}\label{rsa-s34}

Write all sixteen result bytes, then let the supplied return restore the frame. Test a zero multiplier and one with only bit 127 set as separate cases. A correct toy result is insufficient evidence that the multiplier's high half participates.

Replace only the body of region \texttt{modproduct\_publish}, retaining its BEGIN and END comments.

\Needspace{14\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
mulmod_done:
    lwu $t0, 32($sp)
    sw $t0, 0($s1)
    lwu $t0, 36($sp)
    sw $t0, 4($s1)
    lwu $t0, 40($sp)
    sw $t0, 8($s1)
    lwu $t0, 44($sp)
    sw $t0, 12($s1)
\end{minted}

Use recipe \texttt{s34-1} with the cumulative source through this edit. Stop at \texttt{after\_modproduct\_publish} before continuing to the temporary or normal return.

\subsection{Expected observation}
The output is seven and the surrounding bytes remain unchanged.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Which multiplier checks the high-end scan?

\begin{itemize}
\item \textbf{A} Only a multiplier whose low byte is odd.
\item \textbf{B} One with only bit 127 set.
\item \textbf{C} Only the integer one.
\end{itemize}
