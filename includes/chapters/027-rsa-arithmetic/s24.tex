\section{Step 24 Initialize the prefix remainder}\label{rsa-s24}

After the supplied saves, retain the input, modulus and output pointers in saved registers. Initialize a private remainder zero and a private integer one. Set the bit index to 127. The first loop iteration therefore consumes the most significant input bit, even if many leading bits are zero.

Replace only the body of region \texttt{reduce\_identity}, retaining its BEGIN and END comments.

\Needspace{15\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $s0, $a0
    move $s1, $a1
    move $s2, $a2
    sd $zero, 0($sp)
    sd $zero, 8($sp)
    sd $zero, 16($sp)
    sd $zero, 24($sp)
    li $t0, 1
    sw $t0, 16($sp)
    li $s3, 127
\end{minted}

Use recipe \texttt{s24-1} with the cumulative source through this edit. Stop at \texttt{reduce\_bit} before continuing to the temporary or normal return.

\subsection{Expected observation}
The private remainder is zero, the private one is one, and the bit index is 127.
