\section{Step 12 Begin a row with a fresh carry}\label{rsa-s12}

Load one unsigned limb of the first operand. Reset the second operand's byte offset and the carry at the start of this row. The row will contribute to four consecutive columns, beginning at the first operand's limb index. Retain earlier output columns between rows.

Replace only the body of region \texttt{product\_row}, retaining its BEGIN and END comments.

\Needspace{11\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t0, $zero
mul_outer:
    daddu $t1, $a0, $t0
    lwu $t1, 0($t1)
    move $t2, $zero
    move $t3, $zero
\end{minted}

Use recipe \texttt{s12-1} with the cumulative source through this edit. Stop at \texttt{mul\_inner} before continuing to the temporary or normal return.

\subsection{Expected observation}
The first row uses unsigned ffffffff with column offset zero and carry zero.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Which value resets between rows?

\begin{itemize}
  \item \textbf{A} The incoming carry for the new row.
  \item \textbf{B} Every accumulated product column.
  \item \textbf{C} The original input object.
\end{itemize}
