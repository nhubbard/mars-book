\section{Sources and draft status}
The RSA primitive and scheme distinctions follow
\href{https://www.rfc-editor.org/rfc/rfc8017.html}{RFC 8017}, sections 5, 7.1 and 8.1.
The host numerical comparisons use the documented
\href{https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/math/BigInteger.html}{JDK 25 BigInteger API}.
The four-limb bound, call interfaces, error statuses, allowed aliases and observation
points are local teaching contracts. MARS instruction semantics were checked against
the current core's wide-integer catalog and loads. A separate Python integer model
checks the worked divisions, powers, product limbs and carry examples.

This directly edited native foundation contains the explanatory sequence and selected
assembly fragments. Private reference and alternative implementations exercise the
whole interfaces; the alternative scans exponent bits in the opposite direction.
Each passes 423 cases at ordinary addresses and again with code and data above 4 GiB,
for 1,692 successful case executions. Twelve deliberately faulty variants are rejected.
Granular cumulative construction, public starter and instructor distributions, quizzes,
actual light-theme IDE figures, remote progression and independent accessibility review
are subsequent work. This foundation is not yet included in the cumulative manuscript.
The author's requested major exposition and length edit remains deferred until all
thirty-five chapter drafts are complete.
