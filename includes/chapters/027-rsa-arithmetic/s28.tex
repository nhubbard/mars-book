\section{Step 28 Inspect the supplied frame paths}\label{rsa-s28}

Locate the slow reducer's 80-byte frame and its four full-width saves plus return address. Contrast it with the supplied direct-copy and unit-modulus returns. Only the slow path allocated a frame. In the following routines, inspect the analogous 80-byte and 96-byte layouts before authoring calls.

\subsection{Expected observation}
Every development path restores exactly the frame it actually allocated.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
Which path must restore the reducer's slow frame?

\begin{itemize}
\item \textbf{A} Only a path whose result is nonzero.
\item \textbf{B} A path that reached reduce\_slow and allocated it.
\item \textbf{C} Every path including the early zero-modulus error.
\end{itemize}
