    \begin{enumerate}
      \setlength{\itemsep}{0pt}
            \setlength{\parsep}{0pt}
      \item At \texttt{after\_reduce\_accumulate}, all 128 input bits have been processed. The next region copies the private remainder to caller memory.
      \item \texttt{s3 = -1} is the exhausted bit index, displayed as sixteen hexadecimal \texttt{f} digits. It is a loop sentinel, not a remainder.
      \item \texttt{sp = 0x100106b8} is eighty bytes below the caller stack top \texttt{0x10010708}. The frame is still active.
      \item The private remainder starts eight bytes into the first row and equals one. Its high eight bytes occupy the beginning of the second row. The last eight bytes of the second row begin the separate constant one used for accumulation; the leading \texttt{a5} bytes are below the frame.
      \item All sixteen caller output bytes remain \texttt{a5}. Finishing the arithmetic does not publish the value; the following copy region performs that transfer.
      \item The modulus is five, stored low byte first. The full prepared input is $2^{127}+13$, whose remainder modulo five is one. Resuming copies that remainder, restores the frame and returns success.
    \end{enumerate}
