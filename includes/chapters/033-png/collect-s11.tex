\section{Step 11 Reject impossible file counts before reading}\label{png-collect-s11}
Implement \texttt{collect\_bounds}. Set failure status one and returned count zero. An unsigned count below eight cannot contain the signature; a count above 1 MiB is outside the entry contract. Branch to \texttt{collect\_early} in either case, before allocating the frame or accessing the descriptor. A supported count falls through to \texttt{collect\_bounds\_ready} and the supplied saves.

Use a direct-entry check with count seven and an unreadable source address. It must return failure without following that address. The worked file's count is 115. It passes this outer bound; that does not establish that its first eight bytes are correct.

\paragraph{Observe} Use \texttt{s11-1}; stop before 	exttt{collect\_bounds\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} Which operation must wait until the outer count is accepted?
\begin{itemize}
\item[A.] Reading the signature.
\item[B.] Setting a failure return value.
\item[C.] Comparing the count with eight.
\end{itemize}
