\section{Step 48 Apply the permitted sparse-alphabet cases}\label{png-huff-s48}
Fill \texttt{huff\_tree\_shape}. A complete prefix space is accepted. For nonzero remaining space, policy zero requires rejection. Policies for the data alphabets allow a single present symbol only when its length is one; the distance policy additionally permits no present symbols. Reject other incomplete shapes.

The fixed table is complete and reaches this checkpoint directly. The distinction becomes important for dynamic blocks: the code-length alphabet must form the strict tree, whereas a literal-only block can carry an unused distance alphabet. Accepting an empty distance table does not authorize decoding a distance from it.

\paragraph{Observe} Use \texttt{s48-1}; stop before \texttt{huff\_tree\_shape\_ready}. Inspect the state described above before continuing.
