\section{Observe correctness before comparing work}
First compare joined compressed bytes, then exact inflated rows, compact RGB samples
and active framebuffer words. Cover all five filters on the first and later rows,
wraparound sample additions, Paeth ties and Average sums above 255. Repeat with
unaligned source starts, short rows and both target byte orders. Check full-width
saved state and addresses above 4 GiB independently from ordinary-address runs.

Container failures need separate cases: truncated envelopes, impossible lengths,
bad CRCs, duplicate or misplaced chunks, split IDAT streams, missing IEND and trailing
file bytes. Compression failures include short headers, invalid block types, bad
stored complements, invalid code tables, unavailable match history, output underflow,
output overflow and a damaged Adler trailer. Recompute enclosing checksums in tests
that are intended to reach a deeper error, so the parser does not reject them earlier.

Compare simulated instructions per pixel only after scalar and vector outputs match
exactly. Record whether counts include input loading, table construction, chunk CRCs,
inflation and publication. Use the same file and the same measurement boundary for
both programs. A tiny stored-block image and a large dynamic-block image spend their
work differently; report them separately. Simulated instruction counts are neither
host elapsed time nor IDE launch latency. No new PNG assembly measurements are
claimed by this reading foundation.
