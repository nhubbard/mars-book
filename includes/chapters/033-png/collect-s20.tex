\section{Step 20 Accept one bounded RGB header}\label{png-collect-s20}
Fill \texttt{collect\_ihdr}. Require an empty flag set and payload length 13. Decode width and height from payload offsets zero and four; require each from one through 512. Retain them in \texttt{\$s6} and \texttt{\$s7}. Require the next four payload bytes to encode depth 8, color type 2, compression method 0 and filter method 0. The final payload byte, interlace method, must also be zero.

Only after all checks set the IHDR-seen flag to one. At \texttt{collect\_ihdr\_ready}, width is 2, height is 5, and the output descriptor is still unchanged. Parsing a width does not publish it: a later chunk may invalidate the whole container.

\paragraph{Observe} Use \texttt{s20-1}; stop before \texttt{collect\_ihdr\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} When are parsed dimensions published in the descriptor?
\begin{itemize}
\item[A.] Immediately after reading width.
\item[B.] After the whole accepted container reaches the publication region.
\item[C.] Before checking IHDR length.
\end{itemize}
