\section{Step 56 Expand a length code and its extra bits}\label{png-huff-s56}
Fill \texttt{huff\_length}. The classification region has bounded the length-table index. Read the prescribed extra-bit count and native halfword base, retain the base across the ordinary bit-reader call, and add the returned field. Keep the reconstructed length at frame offset 32.

Switch to the fixed-match fixture. It emits one zero byte, then code 272 with extra field three. This code's base is 31 and its extra count is two, so the requested match length is 34. Output cursor remains at one until the later copy; decoding a length does not itself produce bytes.
