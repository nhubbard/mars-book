\section{Step 75 Advance from one row to the next}
Every row path reaches \texttt{filter\_row\_done}: None skips its samples, the scalar path consumes them one at a time, and the future vector path will also end there. Fill \texttt{row\_finish}. Make the current first-sample address the next row’s upper address. Move the input cursor to the current exclusive end, which is the following selector, decrement rows remaining. Leave the repeat test to the supplied continuation so the checkpoint is reached after the transition.

At the checkpoint after the first None row, the upper address is buffer plus one, the next selector is buffer plus seven, and four rows remain. The supplied continuation tests the remaining count. After the final row it recovers the original count, releases the frame and returns success. Those shared cleanup instructions are already supplied; this region develops the row-to-row state transition.

Completing this region lets a None row advance to the next selector. Other predictors and sample storage are still unfinished. Continue with those regions before expecting a complete row call. Even when reconstruction later succeeds, the actual file program will retain its development message until packing and publication are implemented.
