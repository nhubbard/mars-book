\section{Step 25 Join payload bytes without their envelopes}\label{png-collect-s25}
Fill \texttt{collect\_copy}. Copy exactly the reserved payload count using unsigned byte loads and byte stores. Advance the payload cursor and destination cursor by one for each byte. Stop at zero and fall through to \texttt{collect\_copy\_ready}; do not copy the following CRC or the next chunk's length.

The first worked payload contributes byte \texttt{78}. The second IDAT contributes the remaining 45 bytes, beginning with \texttt{01}. Thus the joined stream starts \texttt{78 01} even though its two-byte zlib header crossed a chunk boundary. The destination cursor advances continuously across IDAT chunks while each source payload cursor is established anew.

\paragraph{Observe} Use \texttt{s25-1}; stop before 	exttt{collect\_copy\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} What follows the first copied 0x78 in the joined stream?
\begin{itemize}
\item[A.] The first IDAT CRC.
\item[B.] The next IDAT payload byte 0x01.
\item[C.] The next chunk length word.
\end{itemize}
