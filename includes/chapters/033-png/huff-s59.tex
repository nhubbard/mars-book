\section{Step 59 Admit a match before deriving copy addresses}\label{png-huff-s59}
Implement \texttt{huff\_match\_bounds}. Require distance within the zlib-advertised window and no greater than bytes already produced. Require match length no greater than remaining output space. Only after these checks derive source as output cursor minus distance and destination end as output cursor plus length.

Here one byte has been produced, distance is one, and exactly 34 output bytes remain. The source is output offset zero and destination end is offset 35. A distance of two at this point would reach before produced history, even though it is much smaller than the advertised window.

\paragraph{Observe} Use \texttt{s59-1}; stop before \texttt{huff\_match\_bounds\_ready}. Inspect the state described above before continuing.
