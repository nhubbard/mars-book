\section{Step 49 Place symbols in length and numerical order}\label{png-huff-s49}
Implement \texttt{huff\_tree\_symbols}. Scan symbol numbers from zero upward. Skip absent entries; for each present length, obtain and advance that length's scratch placement cursor, then store the symbol as a native unsigned halfword after the table's 64-byte count area. Return through the supplied checkpoint.

For the fixed table the ordered array starts with symbol 256. Its index 24 contains symbol zero, after the twenty-four seven-bit symbols. The scratch cursors change during placement; they are no longer the original exclusive offsets. The decoder will use the counts and ordered array, not those consumed scratch positions.

\paragraph{Observe} Use \texttt{s49-1}; stop before \texttt{huff\_tree\_symbols\_ready}. Inspect the state described above before continuing.
