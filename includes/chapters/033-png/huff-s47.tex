\section{Step 47 Compute placement offsets and prefix space}\label{png-huff-s47}
Implement \texttt{huff\_tree\_prefix}. Starting at length one, write each length's exclusive symbol offset into the scratch cursor array: the number of present symbols with shorter lengths. Accumulate counts in increasing length order. Independently update remaining prefix space as twice the previous space minus the current count, starting with one root slot. A negative value is oversubscription and must fail.

Before placement, the fixed alphabet's offsets for lengths seven, eight and nine are 0, 24 and 176. These are positions in the ordered-symbol array, not Huffman code numbers. The remaining space reaches zero after length nine. Do not include the absent-symbol count when computing these offsets.

\paragraph{Observe} Use \texttt{s47-1}; stop before \texttt{huff\_tree\_prefix\_ready}. Inspect the state described above before continuing.
