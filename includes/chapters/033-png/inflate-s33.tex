\section{Step 33 Separate the final flag from the block type}\label{png-inflate-s33}
Implement \texttt{inflate\_dispatch} after the supplied three-bit read. Retain bit zero as the final flag and interpret the remaining two bits as the type. Select stored, fixed or dynamic handlers for types zero, one or two. Reject type three. The two Huffman handlers still leave through development cleanup.

The worked field is one: final flag one and stored type zero. Stop before \texttt{stored\_block}. This flag describes the block, not whether the input is already valid. Its payload, exact completion and checksum still need checks before returning success.

\paragraph{Observe} Use \texttt{s33-1}; stop before \texttt{stored\_block}. Inspect the state described above, then continue to the next unfinished boundary.
