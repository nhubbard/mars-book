\section{Sources and draft status}
The format reference is the
\href{https://www.w3.org/TR/2025/REC-png-3-20250624/}{PNG Third Edition recommendation
of 24 June 2025}. The compression references are
\href{https://www.rfc-editor.org/rfc/rfc1950.html}{RFC 1950 (zlib)} and
\href{https://www.rfc-editor.org/rfc/rfc1951.html}{RFC 1951 (DEFLATE)}.
The bounded RGB subset, separate-buffer development order and failure-publication
requirements are exercise choices. The existing MARS PNG smoke program supplies a
scalar and MSA comparison; its current address assumptions and acceptance behavior
must be audited when adapting it to these contracts.

This is the chapter's initial reading foundation. Its fixed observations are
host-verified, including independent image decoding. Two private chunk-collector
prototypes also pass 326 container and ownership cases each at ordinary and above-4-GiB
addresses, for 1304 simulator cases. Eight assembled regressions are rejected. The
collector stops at a validated container and joined payload. Two private inflater
variants, adapted from the retained scalar smoke decoder with per-call tables and
full-width pointers, pass 324 cases each at both address layouts (1296 simulator
cases). Ten assembled inflater regressions are rejected. A separate host bit-position
model and recorded zlib comparisons support the expectations; library acceptance is
not used as the sole format rule. The new native interface and worked alphabet explain
what the entry produces before row reconstruction begins.

Two row-kernel variants now pass 4400 scalar/vector cases across both byte orders
and both address layouts. Two complete decoder variants pass another 400 cases,
including full-size output and late failures that retain the framebuffer. Ten
assembled row/publication regressions are rejected. The same full-size input is
publicly reproducible, matches independent PNG pixels, and supports the complete-call
instruction comparison. The new grader byte-order option is covered by the 110-test
CLI suite; its choice precedes assembly. One new code excerpt is highlighted by the
actual IntelliJ exporter, with all earlier exports retained unchanged.

The supplied file-loading caller and first ten cumulative loader steps now accompany
this reading. Nine editable regions develop bounded reads, exact-fit probing and
descriptor cleanup; fourteen recipes retain the student's instruction edits while
selecting observation controls. The decoder entries in the public starter remain
unfinished. The private complete viewers also read the original smoke-test PNG from
an actual host file and compare their displayed words with independently decoded pixels.

The remaining decoder construction, public/private final feedback, separate chapter
distributions and actual IDE captures remain next. No PNG IDE screenshots have been
captured for this chapter. Capture recipes and native annotations will accompany actual
light-theme IDE observations later. This foundation is not yet a registered exercise
package or part of the integrated manuscript.
