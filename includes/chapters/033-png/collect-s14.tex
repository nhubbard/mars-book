\section{Step 14 Consume the eight-byte signature}\label{png-collect-s14}
Fill \texttt{collect\_signature}. Call the byte-assembly helper on the first four bytes and compare the result with \texttt{0x89504E47}. Then call it on the four bytes at original source plus four and compare with \texttt{0x0D0A1A0A}. Either mismatch branches to \texttt{collect\_bad}. The original source is retained in \texttt{\$s0}; do not assume a helper retained its argument cursor.

Only after both comparisons advance the file cursor by eight and subtract eight from its remaining count. At \texttt{collect\_signature\_ready}, the cursor is at file offset eight and 107 bytes remain. Continuing still returns development status because the next region is unfinished. A damaged signature must instead return failure one.

\paragraph{Observe} Use \texttt{s14-1}; stop before \texttt{collect\_signature\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} When may the file cursor advance past the signature?
\begin{itemize}
  \item[A.] After checking only its first byte.
  \item[B.] After both four-byte comparisons succeed.
  \item[C.] After any helper returns a nonzero number.
\end{itemize}
