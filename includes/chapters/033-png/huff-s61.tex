\section{Step 61 Read the three dynamic description counts}\label{png-huff-s61}
Implement \texttt{huff\_dynamic\_counts}. Read five bits and add 257 for the literal/length count, rejecting values above 286. Read five bits and add one for the declared distance count. Read four bits and add four for the code-length-alphabet count. Retain these three native doublewords at frame offsets zero, eight and sixteen.

The dynamic-literals fixture declares 258, 1 and 18. These counts describe later metadata, not produced row bytes. Distance declarations can occupy up to 32 slots even though data symbols thirty and thirty-one may not be used. Do not apply a data-symbol rule to the declaration count.

\paragraph{Observe} Use \texttt{s61-1}; stop before \texttt{huff\_dynamic\_counts\_ready}. Inspect the state described above before continuing.
