\section{Step 36 Check readable and writable payload extents}\label{png-inflate-s36}
Fill \texttt{inflate\_stored\_bounds}. Require LEN no greater than compressed end minus input cursor and no greater than expected output end minus output cursor. Establish both comparisons before any copy. Retain the source payload end as current input cursor plus LEN.

The worked block has 35 bytes before its reserved checksum and 35 output bytes available, so it fits exactly on both sides. A forged length with a correct complement can still exceed either range. Reaching mapped memory beyond a logical window does not make that read or write part of this call.

\paragraph{Observe} Use \texttt{s36-1}; stop before \texttt{inflate\_stored\_bounds\_ready}. Inspect the state described above, then continue to the next unfinished boundary.
