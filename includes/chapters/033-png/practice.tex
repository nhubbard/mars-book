\section{Questions and extensions}
\begin{MARSExercise}{Locate the first incorrect stage}
  A viewer shows correct first-row pixels and incorrect second-row red channels. The
  joined IDAT bytes and inflated row bytes match their expected files. Which remaining
  buffers would you inspect next, and which byte distances would you check? Give the
  addresses for both red samples in row one of the compact two-pixel RGB fixture.
\end{MARSExercise}
\begin{MARSExercise}{Separate the checksums}
  Change one inflated filter selector, recompress the row stream and recompute every
  PNG CRC. Explain which decoder stage can now reject the file and why the valid
  checksums do not establish that its filter selector is supported.
\end{MARSExercise}
\begin{MARSExercise}{Expand a short match}
  Start with output bytes \texttt{41 42}. Append a length-seven, distance-two match.
  Write every resulting byte in order, and identify the first copy whose source was
  itself produced by the match. Explain why loading the entire match source before
  any stores does not implement this operation.
\end{MARSExercise}
\begin{MARSExercise}{Explain a performance result}
  Suppose vectorizing Up reduces total instructions on one image but changes almost
  nothing on another. State which filter distribution and stage counts you would
  collect before concluding that the optimization failed. Keep format acceptance,
  framebuffer equality and performance observations as separate questions.
\end{MARSExercise}
