\section{Step 44 Initialize the fixed code lengths}\label{png-huff-s44}
Fill \texttt{huff\_fixed}. Write the four prescribed literal/length ranges into the byte vector at frame offset 1096: symbols 0--143 have length 8, 144--255 length 9, 256--279 length 7 and 280--287 length 8. Append thirty-two distance lengths of 5. Retain counts 288 and 32 at frame offsets zero and eight.

Use the fixed-literals input. The supplied continuation calls the table builder for each alphabet. The last two literal/length symbols and last two distance symbols participate in these fixed tables, but their use as data remains invalid. Table membership and permitted data meaning are separate checks.

\paragraph{Observe} Use \texttt{s44-1}; stop before \texttt{huff\_fixed\_ready}. Inspect the state described above before continuing.

\Needspace{7\baselineskip}
\paragraph{Check} Which values are stored in the fixed length vector?
\begin{itemize}
\item[A.] The output pixel values.
\item[B.] The number of code bits assigned to each symbol.
\item[C.] The compressed input addresses.
\end{itemize}
