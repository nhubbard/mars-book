\section{Step 53 Look up the selected symbol ID}\label{png-huff-s53}
Implement \texttt{huff\_symbol\_found}. Add the matching code's within-length difference to the current ordered-array base index. Multiply that symbol index by two and load the native unsigned halfword from the retained symbol-array address. Return the symbol in \texttt{\$v0}.

The first fixed lookup reads ordered index 24 and returns literal value zero. The same helper can later return 256 for end-of-block or a code-length operator from another table. It returns a symbol number; its caller supplies the meaning of that number. The loaded halfword follows target byte order, unlike big-endian PNG fields.

\paragraph{Observe} Use \texttt{s53-1}; stop before \texttt{huff\_symbol\_ready}. Inspect the state described above before continuing.

\Needspace{7\baselineskip}
\paragraph{Check} Does every value returned by this helper represent a row byte?
\begin{itemize}
  \item[A.] Yes, in every alphabet.
  \item[B.] No; the selected alphabet and caller determine its meaning.
  \item[C.] Only if the source address is aligned.
\end{itemize}
