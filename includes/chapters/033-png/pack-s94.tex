\section{Step 94 Shuffle and write the first four words}
Fill \texttt{pack\_shuffle\_first}. Copy the first retained mask into \texttt{\$w3}, shuffle bytes from input vector zero, and store four numeric words at destination offsets zero through fifteen. Use a word-vector store so each word follows the target’s memory byte order.

For width17, the first word is \texttt{0x000061C2}; the second is \texttt{0x002586E7}. The first mask inserts zero as the fourth byte lane of each word. Do not copy those zero lanes from an arbitrary input byte.

At \texttt{pack\_first\_written}, only the first four output words of this group have been published. The source and destination cursors have not advanced, and the retained masks are unchanged. This separation lets the next shuffles use the same origin for their destination offsets.

\paragraph{Observe} Use \texttt{s94-1}; stop before \texttt{pack\_first\_written}. Inspect the state described above before continuing.
