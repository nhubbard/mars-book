\section{Step 16 Validate the four type letters}\label{png-collect-s16}
Fill \texttt{collect\_type}. Check the four bytes beginning at current chunk plus four. Each must be an ASCII letter. One way is to set bit five, subtract the code for lowercase a, and require the unsigned difference below 26. Other bytes must fail; setting a bit is not by itself a letter test.

Then require the third original type byte to have bit five clear: PNG reserves that case bit. The accepted \texttt{IHDR} bytes are \texttt{49 48 44 52}. Retain the original bytes, since their cases also distinguish critical and ancillary types. At \texttt{collect\_type\_ready}, the payload length still belongs to this same checked envelope.

\paragraph{Observe} Use \texttt{s16-1}; stop before \texttt{collect\_type\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} Which original type byte carries the reserved case bit?
\begin{itemize}
  \item[A.] The first.
  \item[B.] The third.
  \item[C.] The last CRC byte.
\end{itemize}
