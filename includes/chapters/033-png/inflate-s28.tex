\section{Step 28 Reject unsupported counts before pointer access}\label{png-inflate-s28}
Fill \texttt{inflate\_bounds}. Initialize failure one and result count zero. Require unsigned input count from six through 1048576 and expected output count at most 786944. An output count of zero is permitted. Reject before the frame or either stream load; otherwise fall through to \texttt{inflate\_bounds\_ready}.

The worked arguments are 46 compressed bytes and 35 expected row bytes. For a direct boundary check, select input count five and an unreadable stream address. Failure must arise from the count check. Reading that address first would turn a recoverable input error into a memory fault.

\paragraph{Observe} Use \texttt{s28-1}; stop before \texttt{inflate\_bounds\_ready}. Inspect the state described above, then continue to the next unfinished boundary.

\paragraph{Check} Why is six the minimum outer input count?
\begin{itemize}
  \item[A.] Two zlib header bytes and four checksum bytes require six bytes.
  \item[B.] Every supported stream produces six pixels.
  \item[C.] The bit reader always loads six bytes at once.
\end{itemize}
