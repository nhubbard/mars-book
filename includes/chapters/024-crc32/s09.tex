\section{Step 9 Compare a changed input bit}\label{crc-s09}

Run the complete bit update on the original check bytes and on a copy whose first byte is 30 instead of 31. Compare the first mixed state before investigating later input. A difference begins at that first byte, and subsequent steps propagate it through the remainder.

Use \texttt{s09-1}, \texttt{s09-2}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
The finalized results are \texttt{cbf43926} and \texttt{dc8f2d65}.
