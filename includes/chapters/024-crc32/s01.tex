\section{Step 1 Choose a raw-state boundary}\label{crc-s01}

The update entries return a running state. The complete-file entry returns a complemented checksum and a separate status. Before editing, follow the same nine bytes through those two interfaces. A register can contain a correct value for one boundary and the wrong value for the other.
