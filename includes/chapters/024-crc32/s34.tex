\section{Step 34 Reuse the update for a PNG chunk interval}\label{crc-s34}

For IEND, check only the four type bytes, initialize once and complement once. Exclude the chunk length and stored checksum field. Interpret the stored result in PNG byte order when comparing it with a numeric register value.

Use \texttt{s34-1}, \texttt{s34-2}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
The four bytes 49 45 4e 44 produce finalized \texttt{ae426082}, stored as ae 42 60 82.
