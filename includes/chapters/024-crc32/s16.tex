\section{Step 16 Inspect the first and last table entries}\label{crc-s16}

Check selected words and the guard after the logical table. The table updater will receive independently prepared table data during guided observations. That isolates its lookup behavior from initialization and avoids treating two matching mistakes as proof of correctness.

Use \texttt{s16-1}. Prepare the exact memory inputs in a separate source file and pause at \texttt{kernel\_done}, before the caller stores the result.

\subsection{Expected observation}
Indices 0,1,128,255 contain \texttt{00000000},\texttt{77073096},\texttt{edb88320},\texttt{2d02ef8d}.
