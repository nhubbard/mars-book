\section{Step 32 Run through the actual caller result stores}\label{crc-s32}

Let the complete file routine return to \texttt{file\_done}, inspect \texttt{v0} and \texttt{v1}, then continue to \texttt{results\_ready}. The caller stores the low checksum word and status for inspection. High checksum bit 31 is data, not a negative-error test; file status is separate.

Use \texttt{s32-1}. The CLI checks install explicit in-memory files and read/error controls. Ordinary IDE files do not force these short-read or failure conditions.

\subsection{Expected observation}
Before caller stores, file\_crc/file\_status retain sentinels; afterward they contain \texttt{cbf43926} and zero.
