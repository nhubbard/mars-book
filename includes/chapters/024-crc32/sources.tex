\section*{Sources and editorial status}
The \href{https://www.w3.org/TR/2025/REC-png-3-20250624/\#5CRC-algorithm}{PNG third-edition CRC definition}
and \href{https://www.w3.org/TR/2025/REC-png-3-20250624/\#D-CRCAppendix}{informative implementation appendix}
anchor the polynomial, bit orientation, conditioning and chunk coverage. The
\href{https://www.rfc-editor.org/rfc/rfc1952.html}{GZIP specification, RFC 1952}
provides another primary description of this CRC family. The project's function
interfaces, limits, status values and workspace rules are local teaching contracts.

The MARS syscall environment and its open, read and close instruction services define
the file behavior used here. Revision \texttt{d41d95ec} adds explicit read-only file
fixtures to the existing grader, including short reads, injected failures and descriptor
history. The normal simulator arithmetic and syscall data stores are retained.
The prototypes use an independent left-shifting model for arbitrary raw states and
JDK CRC32 for finalized message results. Python's CRC32 calculation independently
checks the worked numerical examples.

This directly edited native foundation precedes the cumulative instruction sequence.
Student templates, guided observations, quizzes, separate distributions and actual
light-theme IDE captures remain to be authored. It has not yet joined the main
manuscript's twenty-three text packages. The author has requested a substantial rewrite
after all thirty-five chapters are drafted, with particular attention to length and
missing exposition. Executable verification does not establish student usability.
Independent accessibility validation and the full book objective remain pending.
