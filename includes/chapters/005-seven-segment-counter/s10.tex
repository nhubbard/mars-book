\section{Step 10 Advance the table cursor
  only}\label{005-seven-segment-counter-s10-step-10-advance-the-table-cursor-only}

The next glyph is one byte later in the table. The device address stays
unchanged because every new mask replaces the same right-display
register. This differs from the framebuffer lesson, where successive
destination addresses named different cells.

\subsection{Write or
  inspect}\label{005-seven-segment-counter-s10-write-or-inspect}

Append the cursor update.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddiu $s1, $s1, 1
\end{minted}

\subsection{Expected
  observation}\label{005-seven-segment-counter-s10-expected-observation}

The cursor moves to the next table entry. \texttt{\$s0} still identifies
the right port; it must not move to the left or control ports.

\subsection{Check your
  understanding}\label{005-seven-segment-counter-s10-check-your-understanding}

What would advancing the device pointer by one do?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Select a different byte port on the next store.
  \item
        \textbf{B} Select the next digit on the same right display
        automatically.
  \item
        \textbf{C} Advance the table pointer as well.
\end{itemize}
