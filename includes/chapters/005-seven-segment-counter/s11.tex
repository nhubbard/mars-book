\section{Step 11 Update the logical index and remaining
  count}\label{005-seven-segment-counter-s11-step-11-update-the-logical-index-and-remaining-count}

The index records the next entry and the count records how many are
still required. After these updates, the state is ready for another loop
test. \texttt{iteration\_done} names that boundary.

\subsection{Write or
  inspect}\label{005-seven-segment-counter-s11-write-or-inspect}

Append the two word-sized updates.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    addiu $s2, $s2, 1
    addiu $s3, $s3, -1
iteration_done:
\end{minted}

\subsection{Expected
  observation}\label{005-seven-segment-counter-s11-expected-observation}

After the first default transaction, the next index is one and the
remaining count is fifteen. Immediately after the store but before these
updates, they were zero and sixteen.

\subsection{Check your
  understanding}\label{005-seven-segment-counter-s11-check-your-understanding}

Which observation boundary has remaining count fifteen after the first
output?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} \texttt{displayed}, before the updates.
  \item
        \textbf{B} The initial state before any table load.
  \item
        \textbf{C} \texttt{iteration\_done}, after the updates.
\end{itemize}
