\section{Step 16 Compare an exclusive-end-pointer
loop}\label{005-seven-segment-counter-s16-step-16-compare-an-exclusive-end-pointer-loop}

An alternative can compute the address immediately after the selected
window and loop until its cursor reaches that address. A pre-test
handles the empty interval. This is the same half-open interval used by
the index/count version.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s16-write-or-inspect}

Study the verified alternative in your instructor discussion, then build
an equivalent solution in a separate copy. Explain its termination
condition before comparing the store trace.

\subsection{Expected
observation}\label{005-seven-segment-counter-s16-expected-observation}

Different registers and branch arrangements are accepted when they
produce the same byte transactions and preserve the data objects.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s16-check-your-understanding}

Which property can differ in an equivalent solution?

\begin{itemize}
\tightlist
\item
  \textbf{A} Its register allocation and loop implementation.
\item
  \textbf{B} The number or order of required device writes.
\item
  \textbf{C} Which adjacent ports it changes.
\end{itemize}
