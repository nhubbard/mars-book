\section{Step 3 Load the complete device
address}\label{005-seven-segment-counter-s03-step-3-load-the-complete-device-address}

\texttt{dli} is a pseudo-instruction for a doubleword constant. The
supplied literal makes the intended 64-bit pointer explicit, with zeroes
in its high half. Loading the address does not yet write the device.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s03-write-or-inspect}

Append the device-address load.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    dli $s0, RIGHT_DISPLAY
\end{minted}

\subsection{Expected
observation}\label{005-seven-segment-counter-s03-expected-observation}

\texttt{\$s0} is 0x00000000ffff0010. The device has received no program
store.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s03-check-your-understanding}

Which part of the program changes the device?

\begin{itemize}
\tightlist
\item
  \textbf{A} The label \texttt{RIGHT\_DISPLAY} executes as a store.
\item
  \textbf{B} The later store to its port, not this constant load.
\item
  \textbf{C} Every load into \texttt{\$s0} changes the device
  automatically.
\end{itemize}
