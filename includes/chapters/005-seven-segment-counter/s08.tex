\section{Step 8 Load one glyph
byte}\label{005-seven-segment-counter-s08-step-8-load-one-glyph-byte}

\texttt{lbu} reads the selected table byte as an unsigned value from
zero through 255. The \texttt{display\_loop} label names the start of
one iteration. The \texttt{port\_write} label gives a debugger stop
before the transaction.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s08-write-or-inspect}

Append the table lookup.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
display_loop:
    lbu $t1, 0($s1)
port_write:
\end{minted}

\subsection{Expected
observation}\label{005-seven-segment-counter-s08-expected-observation}

For default index zero, \texttt{\$t1} contains 0x3f. The table cursor is
an address; the loaded value is the segment mask.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s08-check-your-understanding}

What is loaded into \texttt{\$t1}?

\begin{itemize}
\tightlist
\item
  \textbf{A} The address of the right display.
\item
  \textbf{B} An automatically generated ASCII digit.
\item
  \textbf{C} The selected mask byte, not the index itself.
\end{itemize}
