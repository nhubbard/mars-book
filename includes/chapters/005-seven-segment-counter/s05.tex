\section{Step 5 Read the requested
window}\label{005-seven-segment-counter-s05-step-5-read-the-requested-window}

The \texttt{first\_digit} word is the starting table index, and the
following word is the number of entries to emit. The supplied objects
are adjacent, so \texttt{digit\_count} is four bytes beyond
\texttt{first\_digit} in this starter.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s05-write-or-inspect}

Append the input loads.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    lw $s2, 0($t0)
    lw $s3, 4($t0)
\end{minted}

\subsection{Expected
observation}\label{005-seven-segment-counter-s05-expected-observation}

For the default fixture, the index is zero and the remaining count is
sixteen. All valid inputs are small nonnegative values.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s05-check-your-understanding}

What does \texttt{digit\_count} = 16 mean here?

\begin{itemize}
\tightlist
\item
  \textbf{A} Emit only the entry whose index is sixteen.
\item
  \textbf{B} Wait sixteen seconds between stores.
\item
  \textbf{C} Emit sixteen table entries.
\end{itemize}
