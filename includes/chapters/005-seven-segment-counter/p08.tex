\section{Observe output history instead of a claimed
  log}\label{005-seven-segment-counter-p08-observe-output-history-instead-of-a-claimed-log}

A final display value describes only the most recent mask. A program
that writes F once would end with the same right-port value as the full
default counter, but it would not have visited the requested sequence.

The grader subscribes to native memory-access notifications before
executing the program. It checks the complete ordered MMIO history
against the selected table bytes. Repeated equal values remain separate
transactions. An extra write, a different port, or a wider store changes
the observed protocol.

A RAM log maintained by the student program is weaker evidence: the
program could record the intended values without performing the
corresponding device writes. Watching execution at the actual port ties
the check to the behavior required by the interface.
