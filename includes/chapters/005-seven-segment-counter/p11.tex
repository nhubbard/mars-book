\section{Compare implementations under the same
protocol}\label{005-seven-segment-counter-p11-compare-implementations-under-the-same-protocol}

An index-and-count loop and an exclusive-end-pointer loop can describe
the same window. The latter computes an end address and repeats while
the cursor differs from it. Both implementations need an empty-window
path and a one-byte cursor stride.

Their instruction sequences and counts can differ while their I/O
histories match. Replacing the whole loop with one final-value store
does not preserve that history. An optimization must retain the
observations named by the task, not merely the state that is easiest to
inspect afterward.

The protected-data checks also allow a useful separation: implementation
choices can vary without changing the inputs. The grader does not
require the reference register names or private checkpoint labels; it
checks the published data and device interface.
