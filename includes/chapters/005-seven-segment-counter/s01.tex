\section{Step 1 Read the segment
mask}\label{005-seven-segment-counter-s01-step-1-read-the-segment-mask}

Each bit in the display byte controls one segment. The table value 3f
turns on segments a through f and leaves the middle segment and decimal
point off, producing the zero glyph. The device does not translate the
integer zero into that pattern for the program.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s01-write-or-inspect}

Use the segment map to derive the masks for 0 and 1. Compare a blank
mask with the zero glyph.

\subsection{Expected
observation}\label{005-seven-segment-counter-s01-expected-observation}

Blank is 00, zero is 3f, and one is 06. These are hexadecimal bit
patterns, not character codes.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s01-check-your-understanding}

What must the program send to show zero with this wiring?

\begin{itemize}
\tightlist
\item
  \textbf{A} The mask 0x3f.
\item
  \textbf{B} The integer 0 because the device decodes decimal numbers.
\item
  \textbf{C} The ASCII byte for the character 0.
\end{itemize}
