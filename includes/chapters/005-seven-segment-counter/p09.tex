\section{Protect inputs throughout
execution}\label{005-seven-segment-counter-p09-protect-inputs-throughout-execution}

The glyph table and input words are not scratch storage. This assignment
requires them and their guards to receive no program stores, including
stores later undone. That is stronger than requiring their final bytes
to match.

The label-based trace can observe each object\textquotesingle s actual
allocation address. Its \texttt{expectNone} assertion rejects any
overlapping execution store, regardless of width. It does not confuse
the grader\textquotesingle s setup edits with program behavior:
application-origin edits are excluded from the trace.

Reads are excluded as well, so ordinary table lookup is allowed. The
write trace does not establish the absence of extra reads or prove that
the IDE repainted a glyph. Those properties need different observations
when they are part of a task\textquotesingle s contract.
