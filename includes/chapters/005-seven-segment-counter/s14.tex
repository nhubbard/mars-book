\section{Step 14 Test a short and an empty
range}\label{005-seven-segment-counter-s14-step-14-test-a-short-and-an-empty-range}

The final two entries are E and F. An end window with count zero has no
selected entry at all. These cases separate loop bounds from the default
whole-table example.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s14-write-or-inspect}

Use separate copies or the public checks to test \texttt{first\_digit} =
14 with \texttt{digit\_count} = 2, and \texttt{first\_digit} = 16 with
\texttt{digit\_count} = 0.

\subsection{Expected
observation}\label{005-seven-segment-counter-s14-expected-observation}

The short range emits 79, then 71. The empty range emits no port writes.
Neither case changes its inputs or table.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s14-check-your-understanding}

What is the expected output sequence for the empty end window?

\begin{itemize}
\tightlist
\item
  \textbf{A} The guard byte after the table.
\item
  \textbf{B} A blanking write followed by F.
\item
  \textbf{C} An empty sequence.
\end{itemize}
