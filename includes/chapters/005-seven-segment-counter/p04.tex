\section{Describe a window with a half-open
interval}\label{005-seven-segment-counter-p04-describe-a-window-with-a-half-open-interval}

Let f be the starting index and n be the requested count. The selected
entries are the half-open interval from f through f + n, with the end
excluded. The bounds \texttt{0\ \ensuremath{\leq}\ f\ \ensuremath{\leq}\ 16} and
\texttt{0\ \ensuremath{\leq}\ n\ \ensuremath{\leq}\ 16\ \ensuremath{-}\ f} ensure that every selected index is
between zero and fifteen.

An empty interval has n = 0. It selects no entry, including when f
equals sixteen. Forming a pointer to that exclusive end is different
from loading a byte there. The reference tests the count before its
first table access.

For f = 14 and n = 2, the selected indices are fourteen and fifteen. The
pointer after the final iteration is table base + 16. The code reaches
that pointer as a boundary and does not use it for another lookup.
