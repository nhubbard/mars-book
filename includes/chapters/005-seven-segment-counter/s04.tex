\section{Step 4 Locate the table and input
words}\label{005-seven-segment-counter-s04-step-4-locate-the-table-and-input-words}

The glyphs are a byte array. The starting index and count are word-sized
inputs. Separate pointers identify these objects so that table traversal
does not move the fixed device address.

\subsection{Write or
inspect}\label{005-seven-segment-counter-s04-write-or-inspect}

Append the two data-address loads.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $s1, glyphs
    la $t0, first_digit
\end{minted}

\subsection{Expected
observation}\label{005-seven-segment-counter-s04-expected-observation}

\texttt{\$s1} identifies table byte zero and \texttt{\$t0} identifies
the first input word. The device pointer remains fixed.

\subsection{Check your
understanding}\label{005-seven-segment-counter-s04-check-your-understanding}

Which address should remain constant while counting?

\begin{itemize}
\tightlist
\item
  \textbf{A} The right-display port address.
\item
  \textbf{B} The pointer to the current table byte.
\item
  \textbf{C} The conceptual current digit index.
\end{itemize}
