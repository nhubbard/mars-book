\section{A number is not a display
command}\label{005-seven-segment-counter-p00-a-number-is-not-a-display-command}

The bit inspector printed an integer through a service that chose its
textual representation. Digital Lab uses another interface: a byte
directly controls individual segments. To display a digit, the program
must first choose the pattern of segments that forms its shape.

The index ten, the ASCII character A, and the glyph mask for A are three
distinct values. Index ten selects table entry ten. ASCII A is 0x41. The
default segment mask is 0x77. Sending the index or the ASCII byte
directly would light a different set of bars, because this peripheral
has no character decoder between the byte and its segments.

The counter therefore separates indexing, lookup, and output. That
separation makes it possible to change a font by editing the table while
keeping the loop unchanged. It also gives the grader a meaningful input
to vary.
