\section{Step 12 Repeat while entries
  remain}\label{005-seven-segment-counter-s12-step-12-repeat-while-entries-remain}

\texttt{bne} returns to the table load if the remaining count is
nonzero. Its \texttt{nop} delay slot has no state update. After the last
iteration, the count is zero and execution falls through to the supplied
exit.

\subsection{Write or
  inspect}\label{005-seven-segment-counter-s12-write-or-inspect}

Append the loop branch and slot.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bne $s3, $zero, display_loop
    nop
\end{minted}

\subsection{Expected
  observation}\label{005-seven-segment-counter-s12-expected-observation}

The default sequence has sixteen byte transactions and ends with mask
71. It does not include a seventeenth write or an automatic blanking
write.

\subsection{Check your
  understanding}\label{005-seven-segment-counter-s12-check-your-understanding}

What should be written after the final requested glyph?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The first byte beyond the table.
  \item
        \textbf{B} Nothing; the program should exit normally.
  \item
        \textbf{C} A blank mask in every case.
\end{itemize}
