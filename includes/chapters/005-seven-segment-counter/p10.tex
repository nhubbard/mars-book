\section{Separate execution rate from observation
rate}\label{005-seven-segment-counter-p10-separate-execution-rate-from-observation-rate}

The program can emit sixteen bytes much faster than a person can inspect
them. The IDE may repaint only a later state before the run reaches its
end. That does not by itself indicate that transactions were skipped.

For observation, stop in Debug after a chosen write and allow the tool
to show that stable state. The capture process must verify the visible
mask label and the paused program state before taking an image. A fixed
sleep in a screenshot script would not establish that the correct
execution and value were selected.

This project specifies order, count, address, width, and data values,
but no wall-clock spacing. A busy-wait or sleep service is unnecessary
for the graded contract. A timed device task would need an additional
timing contract and appropriate checks.
