\section{Step 6 Apply the starting byte
  index}\label{005-seven-segment-counter-s06-step-6-apply-the-starting-byte-index}

The table has one byte per glyph. Adding \texttt{first\_digit} to its
base therefore reaches the first selected entry without multiplying the
index by four. \texttt{daddu} performs a full-width address addition.

\subsection{Write or
  inspect}\label{005-seven-segment-counter-s06-write-or-inspect}

Append the pointer adjustment.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddu $s1, $s1, $s2
\end{minted}

\subsection{Expected
  observation}\label{005-seven-segment-counter-s06-expected-observation}

For a window starting at fourteen, the cursor is fourteen bytes beyond
glyphs. For the empty end window it can equal the one-past-table address
without being dereferenced.

\subsection{Check your
  understanding}\label{005-seven-segment-counter-s06-check-your-understanding}

Why is no scale-by-four operation needed?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The display uses four-byte glyph codes.
  \item
        \textbf{B} Each table element occupies one byte.
  \item
        \textbf{C} All addresses ignore object sizes.
\end{itemize}
