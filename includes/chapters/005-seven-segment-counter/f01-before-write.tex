\small
\begin{enumerate}
\item The blue line is \texttt{sb \$t1, 0(\$s0)}, before it executes. The preceding \texttt{lbu} has read one byte from the table. Loading a mask into a CPU register does not send it to the display.
\item \texttt{\$t1}=\texttt{0x3f} is the mask for zero, not the character code for \texttt{0}. \texttt{\$s0}=\texttt{0x00000000ffff0010} is the fixed right-display port. The current index is \texttt{\$s2}=0 and the remaining count is \texttt{\$s3}=16. These are data values, an address and loop state, each with a different role.
\item Both masks are \texttt{0x00}, so all segments and both decimal points are off. The left display will remain blank throughout this program. The transaction check independently requires no port writes before this stop.
\end{enumerate}
