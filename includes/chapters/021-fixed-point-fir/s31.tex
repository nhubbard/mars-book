\section{Step 31 Load one complete eight-tap input window}\label{fir-s31}

Load sixteen bytes from \texttt{a0} into \texttt{w0} for this output. Even count one has eight input samples because its seven history samples precede the current sample. The load fits the logical input slice. After storage the outer loop advances by two, so subsequent loads intentionally overlap most of these bytes.
