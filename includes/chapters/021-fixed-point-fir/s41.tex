\section{Step 41 Read the caller’s completed results at their boundary}\label{fir-s41}

Restore the default input and count sixteen after construction. Pause at filter\_ready: output memory is complete, but processed and clipped still contain 99. The result registers contain sixteen and zero. Continue to results\_ready to see those values stored. Inspecting a later syscall’s result register would no longer describe the filter return.

\subsection{Expected observation}
At results\_ready, processed=16 and clipped=0; output is eight halfwords 2000 followed by eight zeros.
