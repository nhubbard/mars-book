\section{Step 47 Explore another strategy under the same arithmetic rule}\label{fir-s47}

Try caching coefficients in a scalar implementation or retaining part of the vector window between outputs. Keep exact accumulation, the one final rounding and all logical boundaries unchanged. If you extend to another tap count or coefficient format, write a new width proof and contract first. A familiar fixed-point instruction name does not establish numerical equivalence.

\subsection{Expected observation}
An optimization is accepted when it preserves the public behavior, including negative ties, large sums, clipping counts and chunk continuity.
