\section*{Format and instruction sources}
The eight-tap interface, coefficient order, rounding and clipping count are this
exercise's explicit contract. Instruction behavior is checked against pinned MARS
\texttt{MsaWideningInstructions.kt}, \texttt{MsaPermutationInstructions.kt},
\texttt{MsaIntegerInstructions.kt} and \texttt{WideInstructionCatalog.kt}, plus
execution of the independent scalar and vector implementations.

Arm's \href{https://arm-software.github.io/CMSIS-DSP/v1.10.1/group__FIR.html}{CMSIS-DSP FIR documentation}
provides a primary implementation reference for reversed coefficient storage and
64-bit Q15 accumulation. Its quantization convention does not define this assignment:
the book explicitly chooses the final rounding rule above. This kernel also keeps
its supplied input prefix immutable rather than adopting that library's state API.

This full native text draft has forty-seven steps, thirty-six cumulative edits,
seven supplied assembly excerpts and sixty-six reproducible observations. The student
package includes public per-step construction checks, final behavior and chunk checks,
forty-seven quizzes with two available hints each, six verified listening files and a
separately authored public reproduction renderer. Instructor keys and private test
cases are distributed separately.

Five numerical capture models accompany planned light-theme IDE figures. The actual
captures, interactive runner and enforced instructor progression controls remain in
development. Human review and independent accessibility validation remain pending.
Twenty-one text packages do not complete the full book and capture objective.
