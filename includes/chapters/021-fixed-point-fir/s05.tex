\section{Step 5 Start one complete eight-tap window}\label{fir-s05}

Clear \texttt{t0} for the exact sum, copy the outer input address into \texttt{t1} and the coefficient address into \texttt{t2}, then set the tap count in \texttt{t3} to eight. The outer input address identifies this output window. Its private walker will traverse eight samples while the outer address stays in place until the output is stored. Coefficients restart from their base for every scalar output.
