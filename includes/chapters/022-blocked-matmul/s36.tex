\section{Step 36 Address the right input at the same reduction start}\label{matmul-s36}

Compute L*N+j, scale by four, and add the B base. The two walkers now agree on reduction position L. Use the full physical row width N even when the tile contains fewer columns.

\Needspace{10\baselineskip}
\subsection{Check your understanding}
Why use N in L*N+j?

\begin{itemize}
\item \textbf{A} A tile has repacked the right input.
\item \textbf{B} Every matrix is square.
\item \textbf{C} N is the actual right-input row width.
\end{itemize}
