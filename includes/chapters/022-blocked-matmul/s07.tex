\section{Step 7 Start a fresh reduction for each output cell}\label{matmul-s07}

At \texttt{naive\_column}, clear \texttt{t2} for the reduction index and \texttt{t3} for its exact accumulator. Every output has a separate sum, even when neighboring outputs share many input values. These initializations will run again when the column loop advances.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the temporary branch and nop in \texttt{n\_sum}. Keep its surrounding labels and region markers.

\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t2, $zero
    move $t3, $zero
\end{minted}
Use \texttt{s07-1} from the companion construction inputs. Pause at \texttt{matmul\_done} before the caller stores the returned count.

\subsection{Expected observation}
The current sum and reduction index are both zero.

\Needspace{10\baselineskip}
\subsection{Check your understanding}
Why clear the sum inside the column loop?

\begin{itemize}
  \item \textbf{A} Every output cell has its own dot product.
  \item \textbf{B} All matrix elements are unsigned.
  \item \textbf{C} The previous sum is always an input operand.
\end{itemize}
