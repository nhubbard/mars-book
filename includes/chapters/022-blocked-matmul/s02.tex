\section{Step 2 Separate row stride from tile edge}\label{matmul-s02}

Derive each address from the matrix representation. The left row contains K words; the right and output rows contain N elements of different widths. Tile edge T bounds the work scheduled together and does not repack either input. Use the address table to predict the first three pairs for the second output row.

\subsection{Expected observation}
The right column advances by 4N bytes and the output row by 8N bytes.

\Needspace{10\baselineskip}
\subsection{Check your understanding}
What determines the right-input reduction stride?

\begin{itemize}
\item \textbf{A} The left row count M.
\item \textbf{B} The tile edge T.
\item \textbf{C} The right row width N.
\end{itemize}
