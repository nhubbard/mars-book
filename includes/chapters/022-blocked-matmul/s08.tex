\section{Step 8 Form the full left-row address}\label{matmul-s08}

Multiply the row index by K to count left-input elements before this row, then multiply that offset by four. Add the byte offset to the full base with \texttt{daddu}. The bounded index arithmetic does not permit narrowing the base pointer. Retain this walker in \texttt{t4}.

\Needspace{10\baselineskip}
\subsection{Write and inspect}
Replace the temporary branch and nop in \texttt{n\_left}. Keep its surrounding labels and region markers.

Use \texttt{s08-1} from the companion construction inputs. Pause at \texttt{matmul\_done} before the caller stores the returned count.

\subsection{Expected observation}
For the first output, \texttt{t4} addresses the first left element.
