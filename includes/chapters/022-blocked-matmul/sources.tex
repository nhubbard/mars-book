\section*{Implementation and editorial status}
The mathematical examples and measurements accompany executable private prototypes.
Their checker covers every combination of dimensions zero through four, eight additional
boundary shapes, and tile edges one, two, three, four and eight. It verifies exact
output, selected intervals, initialized partial-sum reads, saved registers and caller
completion. Separate experiments cover full-width pointers and repeated calls.
This domain is stated explicitly; it is not an exhaustive test of every legal
shape and tile edge.

Instruction semantics and the cache observation rules were checked against the pinned
MARS revision \texttt{f1ddaef8}. The relevant source files are
\begin{itemize}
\item \texttt{WideInstructionCatalog.kt}, for native multiply, load and store instructions;
\item \texttt{InstructionContext.kt}, for full-width data operations;
\item \texttt{MemoryState.kt}, for observed memory accesses; and
\item \texttt{DataCacheSimulator.kt}, for placement and miss accounting.
\end{itemize}
The current input restriction makes signed-word
multiplication a valid equivalent for each individual product. The accumulator and
output still require full width.

This directly editable native foundation precedes the full cumulative instruction
sequence. Student templates, per-step observations, quizzes and separate distributions
are still to be authored. It is not yet included in the main manuscript's completed
text-package sequence. No IDE screenshots have been captured for this chapter.
Human editorial review and independent accessibility validation remain pending.
