\section{Step 4 Inspect the supplied frame and safe exits}\label{matmul-s04}

The starter supplies both function frames and exits. Each frame saves all nine required full registers, retains the three input pointers, and loads M, K, N and T into working registers. An unfinished region branches to its own restoring exit. These exits calculate the cell count, restore caller registers and return through \texttt{ra}. Select the scalar path first; a provisional return is evidence about construction, not a completed matrix product.

\subsection{Expected observation}
The untouched starter returns four for the default shape while leaving the output sentinel unchanged.

\subsection{Check your understanding}
When should the saved registers be restored?

\begin{itemize}
  \item \textbf{A} After releasing the stack frame and overwriting its contents.
  \item \textbf{B} Only for nonempty matrices.
  \item \textbf{C} Before releasing their private stack storage.
\end{itemize}
