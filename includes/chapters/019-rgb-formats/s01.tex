\section{Step 1 Read the two conversion interfaces}\label{rgb-s01}

Both functions use full source and destination pointers and a pixel count. The source bytes and output size depend on which conversion is called. The same original count is returned for either operation. Source and destination allocations are disjoint, and logical slices may begin at any byte alignment.

\subsection{Expected observation}
Packing one pixel consumes three source bytes and produces two; expansion consumes two and produces three.

\subsection{Check your understanding}
What does \texttt{v0} report?

\begin{itemize}
  \item \textbf{A} The original pixel count.
  \item \textbf{B} A packed color.
  \item \textbf{C} The number of source bytes.
\end{itemize}
