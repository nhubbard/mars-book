\section{Step 2 Work the stored bytes before writing the loop}\label{rgb-s02}

Use the pixel (123,45,67) to follow field truncation, positioning and little-endian storage. Its packed value and stored bytes describe the same sixteen bits in different forms. Then apply the exact bit-repetition expansion to see which original low component bits are lost.

\subsection{Expected observation}
The packed value is hexadecimal 7968, its stored bytes are 68 79, and the expanded pixel is (123,44,66).

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which stored byte appears at the lower address?

\begin{itemize}
\item \textbf{A} 79.
\item \textbf{B} 68.
\item \textbf{C} The original red value, 123.
\end{itemize}
