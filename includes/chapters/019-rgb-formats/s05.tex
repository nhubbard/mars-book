\section{Step 5 Load three unsigned component bytes}\label{rgb-s05}

Load the red, green and blue bytes at offsets zero, one and two from the current full source pointer. Use unsigned byte loads. The input is packed RGB, so these are three components of one pixel, not three little-endian pieces of a display word. No pointer advances in this edit.

\Needspace{13\baselineskip}
\subsection{Write or inspect}
Replace the temporary branch and nop in \texttt{pack\_load}. Preserve surrounding labels and the provided entry and return.

\Needspace{6\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lbu $t0, 0($a0)
    lbu $t1, 1($a0)
    lbu $t2, 2($a0)
\end{minted}
Use \texttt{s05-1} (count 1) from the companion input recipes. Pause at \texttt{pack\_ready} before comparing the construction state.

\subsection{Expected observation}
Input bytes 123, 45 and 67 leave those unsigned values in \texttt{t0}, \texttt{t1} and \texttt{t2}.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Why use \texttt{lbu} rather than an uncorrected \texttt{lb}?

\begin{itemize}
\item \textbf{A} Every input component is below 128.
\item \textbf{B} Components range from zero through 255.
\item \textbf{C} The source pointer is a halfword.
\end{itemize}
