\section{Step 37 Collect the even component bytes}\label{rgb-s37}

Pack even bytes from each red and green register using that register as both sources. The low eight bytes become the eight component values in order, and the high eight repeat them. Blue remains in halfwords for the final shuffle. This changes layout while preserving the component values.

\Needspace{12\baselineskip}
