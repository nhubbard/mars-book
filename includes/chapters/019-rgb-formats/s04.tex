\section{Step 4 Return before reading an empty slice}\label{rgb-s04}

The initial vector placeholder transfers directly to the scalar tail. Test the remaining pixel count before loading any input byte. At zero, use the supplied return; at positive count, enter the pixel body. The original count is already retained in \texttt{v0}, so this guard must not replace it with another value.

\Needspace{12\baselineskip}
\subsection{Write or inspect}
Replace the temporary branch and nop in \texttt{pack\_bound}. Preserve surrounding labels and the provided entry and return.

\subsection{Expected observation}
A zero-count pack returns zero without a caller-data read or write. A positive call still stops at the next unfinished region.
