\section*{Contract and instruction sources}
The byte layout, truncation and bit-repetition formulas are this exercise's explicit
conversion contract. The native vector operations were checked against the pinned
MARS implementations in \texttt{MsaPermutationInstructions.kt},
\texttt{MsaRegisterInstructions.kt} and \texttt{MsaIntegerInstructions.kt}, and the
core's permutation tests. QEMU's
\href{https://github.com/qemu/qemu/blob/1f7fe57fce1ea3902db5c99ea1cb1db97c98e9a0/target/mips/tcg/msa_helper.c}{MSA instruction helpers}
provide a separate implementation reference for shuffle, even-byte packing and
interleaving. The independent conversion oracle uses integer division and arithmetic
on component values rather than reproducing the vector algorithm.

The student package pins the upstream revision and supplies public behavioral checks.
Private instructor checks add broader component domains, repeated-call sequences,
intermediate lane observations and a scalar alternative. Actual IDE captures,
human review and independent accessibility validation remain pending.
