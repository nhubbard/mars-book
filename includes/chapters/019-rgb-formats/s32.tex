\section{Step 32 Read eight packed halfwords as bytes}\label{rgb-s32}

Load the sixteen-byte packed group into \texttt{w0}. Its bytes are low then high for each pixel, so the same register bits form eight RGB565 halfword lanes in the pinned little-endian environment. The load width is sixteen bytes even though the instruction suffix is b.

\Needspace{11\baselineskip}
\subsection{Write or inspect}
Replace the temporary branch and nop in \texttt{vector\_unpack\_load}. Preserve surrounding labels and the provided entry and return.

\Needspace{4\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    ld.b $w0, 0($a0)
\end{minted}
Use \texttt{s32-1} (count 8) from the companion input recipes. Pause at \texttt{unpack\_ready} before comparing the construction state.

\subsection{Expected observation}
The eight \texttt{w0} halfwords equal the input packed values in pixel order.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
How many bytes does \texttt{ld.b} transfer?

\begin{itemize}
  \item \textbf{A} One.
  \item \textbf{B} Sixteen.
  \item \textbf{C} The remaining pixel count.
\end{itemize}
