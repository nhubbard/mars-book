\section{Step 11 Advance by each format size}\label{rgb-s11}

Advance the full source pointer by three and the destination pointer by two. Decrement the pixel count once, then repeat the pixel body while a pixel remains. The loop body is now complete for every count; the vector gate is still a direct transfer to this scalar path.

\Needspace{15\baselineskip}
\subsection{Write or inspect}
Replace the temporary branch and nop in \texttt{pack\_next}. Preserve surrounding labels and the provided entry and return.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    daddiu $a0, $a0, 3
    daddiu $a1, $a1, 2
    addiu $a2, $a2, -1
    bne $a2, $zero, pack_pixel
    nop
\end{minted}
Use \texttt{s11-1} (count 1), \texttt{s11-2} (count 2) from the companion input recipes. Pause at \texttt{pack\_ready} before comparing the construction state.

\subsection{Expected observation}
Two RGB pixels produce four packed bytes. The remaining count becomes zero while \texttt{v0} still contains two.
