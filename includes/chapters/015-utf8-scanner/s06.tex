\section{Step 6 Test the chunk bound before loading}\label{utf8-s06}

Compare the per-call accepted count with the supplied byte count. At equality, branch to end handling without reading input. Otherwise load one unsigned byte. If need is positive, dispatch directly to continuation validation.

\subsection{Write or inspect}
Append these instructions in the \texttt{loop} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    beq $t7, $a2, scan_end
    nop
    lbu $t8, 0($t6)
    bne $t2, $zero, scan_tail
    nop
\end{minted}

\subsection{Expected observation}
An empty chunk performs no input loads. A pending prefix uses its retained bounds.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
May mapped bytes after the chunk be used as continuations?

\begin{itemize}
\item \textbf{A} Yes, if a load succeeds.
\item \textbf{B} No; they are outside this call input.
\item \textbf{C} Only for the final chunk.
\end{itemize}
