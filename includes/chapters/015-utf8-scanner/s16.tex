\section{Step 16 Require the \texttt{e0} lower bound}\label{utf8-s16}

Set need to two for a three-byte lead. For \texttt{e0}, set the next minimum to decimal 160, hexadecimal \texttt{a0}. Other three-byte leads continue to the upper-bound distinction.

\subsection{Write or inspect}
Append these instructions in the \texttt{three\_low} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.
