\section{Step 5 Load the active stream into temporaries}\label{utf8-s05}

Load the six working state fields into \texttt{t0} through \texttt{t5}. Copy the full input pointer into \texttt{t6} and initialize the per-call accepted count in \texttt{t7}. No scalar or byte has been accepted by these instructions.

\subsection{Write or inspect}
Append these instructions in the \texttt{load} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.

\Needspace{11\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lw $t0, 0($a0)
    lw $t1, 4($a0)
    lw $t2, 8($a0)
    lw $t3, 12($a0)
    lw $t4, 16($a0)
    lw $t5, 20($a0)
    move $t6, $a1
    move $t7, $zero
\end{minted}

\subsection{Expected observation}
A pending state restores its remaining count, next-byte bounds, and original lead position.
