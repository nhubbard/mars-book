\section{Step 7 Select the ASCII completion path}\label{utf8-s07}

For an idle state, compare the unsigned byte with 128. Values below it encode one complete scalar and can share the later scalar-completion code. A pending state never reaches this test, so an ASCII byte cannot silently interrupt a multibyte encoding.

\subsection{Write or inspect}
Append these instructions in the \texttt{ascii} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.

\Needspace{6\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    sltiu $t9, $t8, 128
    bne $t9, $zero, scan_ascii
    nop
\end{minted}

\subsection{Expected observation}
The comparison accepts every byte from hexadecimal \texttt{00} through \texttt{7f}, including zero.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
How is an ASCII byte handled while need is positive?

\begin{itemize}
  \item \textbf{A} As a new scalar.
  \item \textbf{B} As an automatic stream reset.
  \item \textbf{C} By the pending continuation check, where it fails.
\end{itemize}
