\section{Step 4 Reject a terminal stream}\label{utf8-s04}

Load status before accessing input. A nonzero stored status means the stream has finished or failed. Return minus three and zero immediately. This path performs no state stores and preserves the earlier status and diagnostic.

\subsection{Write or inspect}
Append these instructions in the \texttt{gate} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.

\Needspace{10\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lw $v0, 24($a0)
    beq $v0, $zero, scan_active
    nop
    li $v0, -3
    move $v1, $zero
    jr $ra
    nop
\end{minted}

\subsection{Expected observation}
A previously finished state remains finished even when the new input is invalid.
