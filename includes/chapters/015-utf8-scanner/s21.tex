\section{Step 21 Accept one byte and repeat}\label{utf8-s21}

Increment absolute total and this call accepted count, then advance the full input cursor with \texttt{daddiu}. Branch back to the chunk-bound test. Error paths bypass these instructions, preserving the first impossible byte as unaccepted.

\subsection{Write or inspect}
Append these instructions in the \texttt{accept} region. Keep the scaffold labels and return stub. Intermediate values do not yet establish the final interface.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    addiu $t0, $t0, 1
    addiu $t7, $t7, 1
    daddiu $t6, $t6, 1
    beq $zero, $zero, scan_loop
    nop
\end{minted}

\subsection{Expected observation}
For one accepted ASCII byte, total and scalar count are one and the input cursor has advanced one byte.
