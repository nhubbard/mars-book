\section{Step 20 Verify order and multiplicities at every
snapshot}\label{009-sorting-visualizer-s20-step-20-verify-order-and-multiplicities-at-every-snapshot}

The checker derives the expected exchange states, checks each actual
array and frame, and finally compares against a separately sorted input.
It also checks guards and the inactive tail for forbidden writes.

\subsection{Write or
inspect}\label{009-sorting-visualizer-s20-write-or-inspect}

Run both public check scripts.

\subsection{Expected
observation}\label{009-sorting-visualizer-s20-expected-observation}

A sorted array with lost duplicates or an altered inactive word is
rejected.

\subsection{Check your
understanding}\label{009-sorting-visualizer-s20-check-your-understanding}

Why check intermediate permutations?

\begin{itemize}
\tightlist
\item
  \textbf{A} Every temporary register must equal the reference.
\item
  \textbf{B} A half-exchange or lost value can precede an apparently
  sorted final result.
\item
  \textbf{C} It makes signed comparison unnecessary.
\end{itemize}
