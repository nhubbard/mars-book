\section{Make progress visible without prescribing private
registers}\label{009-sorting-visualizer-p09-make-progress-visible-without-prescribing-private-registers}

Main publishes phase zero for the initial state, phase one after each
actual exchange, and phase two for completion. The final status can
repeat the last array while adding useful information: the algorithm is
done. A sorted input with no exchanges still produces initial and final
observations, and an empty input produces two all-black frames.

The public ready label lies inside the renderer, so each call naturally
exposes one complete frame. The caller sets metadata; the renderer
leaves it alone. An independent renderer call can therefore preserve
arbitrary caller metadata without pretending that it is a normal
phase-zero or phase-one sorting call.

The grading scripts derive the required exchange states and inspect the
real active array, inactive tail, metadata, and full frame at each
callback. The final active values are also compared with a separately
sorted input. Private implementation labels and exact instruction totals
are excluded from free-writing correctness, while the published function
and exchange protocol remain mandatory interfaces.
