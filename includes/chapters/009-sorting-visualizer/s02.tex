\section{Step 2 Decode the bar
representation}\label{009-sorting-visualizer-s02-step-2-decode-the-bar-representation}

The signed value is converted to a positive visible height by adding
five. Values \ensuremath{-}4 through 3 map to heights one through eight. Screen y
increases downward, so a bar fills rows at or below its top.

\subsection{Write or
inspect}\label{009-sorting-visualizer-s02-write-or-inspect}

Use the height table to predict two columns.

\subsection{Expected
observation}\label{009-sorting-visualizer-s02-expected-observation}

Value \ensuremath{-}4 lights only row seven; value three lights all eight rows.

\subsection{Check your
understanding}\label{009-sorting-visualizer-s02-check-your-understanding}

How tall is the bar for value zero?

\begin{itemize}
\tightlist
\item
  \textbf{A} Zero cells.
\item
  \textbf{B} Five cells.
\item
  \textbf{C} Eight cells.
\end{itemize}
