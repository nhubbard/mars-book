\section{Step 16 Retain the first suffix
  minimum}\label{009-sorting-visualizer-s16-step-16-retain-the-first-suffix-minimum}

Compare each candidate with the current minimum using signed less-than.
Replace the minimum index only for a strictly smaller value. Continue
scanning the whole suffix before any exchange.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s16-write-or-inspect}

Insert this fragment in selection\_scan.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    slt $t0, $s3, $s1
    beq $t0, $zero, selection_exchange
    nop
    sll $t0, $s4, 2
    daddu $t0, $s0, $t0
    lw $t1, 0($t0)
    sll $t2, $s3, 2
    daddu $t2, $s0, $t2
    lw $t3, 0($t2)
    slt $t4, $t3, $t1
    beq $t4, $zero, selection_keep
    nop
    move $s4, $s3
selection_keep:
    addiu $s3, $s3, 1
    beq $zero, $zero, selection_scan
    nop
\end{minted}

\subsection{Expected
  observation}\label{009-sorting-visualizer-s16-expected-observation}

The first default scan chooses index three, containing \ensuremath{-}4.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s16-check-your-understanding}

What happens when a later candidate equals the current minimum?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Keep the earlier minimum index.
  \item
        \textbf{B} Choose the last equal candidate.
  \item
        \textbf{C} Exchange immediately during the scan.
\end{itemize}
