\section{Encode signed values without hiding
them}\label{009-sorting-visualizer-p01-encode-signed-values-without-hiding-them}

The active values are deliberately limited to \ensuremath{-}4 through 3 so eight rows
can represent them distinctly. Height is value plus five. This is a
monotone encoding: a smaller signed value always has a smaller bar, but
height zero is not the representation of numeric zero. Zero has height
five, and the minimum value still has a visible one-cell bar.

For row y, a bar is filled when y is at least 8\ensuremath{-}height, or equivalently
3\ensuremath{-}value. Rows increase downward, so the filled region grows upward from
the bottom. Inactive columns are black regardless of the words stored
beyond the active prefix.

The renderer must check the length before loading a
column\textquotesingle s value. Its caller may pass an offset pointer
and a shorter length, and the inactive words may not even satisfy the
small value domain. Array bounds and display bounds are related but
distinct: the frame always has eight columns, while the input may have
fewer active items.
