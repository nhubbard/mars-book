\section{Selection fixes one minimum at a
  time}\label{009-sorting-visualizer-p07-selection-fixes-one-minimum-at-a-time}

Before a selection pass, the completed prefix contains the smallest
items in their final ascending positions. The remaining suffix is
scanned for a minimum. Starting with its first index and updating only
for a strictly smaller candidate selects the first minimum among equal
values.

After the scan, exchange that minimum with the suffix start unless it is
already there. Then advance the start. The entire suffix is scanned
before the exchange; publishing an exchange every time a new candidate
minimum is found would describe another algorithm.

For eight active items the suffix scans make 7+6+5+4+3+2+1 = 28 value
comparisons regardless of initial ordering. This implementation performs
at most seven index-changing exchanges. That comparison count is not a
branch count: loop checks, minimum tests, and back-edges also execute
branches, while calls and returns are jumps under the measured
definition.
