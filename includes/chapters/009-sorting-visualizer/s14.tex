\section{Step 14 Relate adjacent exchanges to
  inversions}\label{009-sorting-visualizer-s14-step-14-relate-adjacent-exchanges-to-inversions}

An inversion is an earlier value greater than a later one. Exchanging an
inverted adjacent pair removes exactly one inversion without changing
other pair orders.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s14-write-or-inspect}

Count inversions in the default and reversed fixtures.

\subsection{Expected
  observation}\label{009-sorting-visualizer-s14-expected-observation}

The default has seventeen inversions; eight distinct reversed values
have twenty-eight.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s14-check-your-understanding}

How many adjacent exchanges does this insertion policy need on already
sorted input?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Twenty-eight.
  \item
        \textbf{B} Zero.
  \item
        \textbf{C} One for every equal pair.
\end{itemize}
