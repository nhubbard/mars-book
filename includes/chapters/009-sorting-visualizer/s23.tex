\section{Step 23 Measure whole-run and selected code
  work}\label{009-sorting-visualizer-s23-step-23-measure-whole-run-and-selected-code-work}

The whole counter includes setup, rendering, sorting, and exit. The
range counter counts PCs from \texttt{sort\_begin} through just before
\texttt{sort\_end}, excluding the renderer body. Caller argument setup,
call instructions, and their delay slots inside the range still count.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s23-write-or-inspect}

Read the measured sorted/reversed/shuffled table.

\subsection{Expected
  observation}\label{009-sorting-visualizer-s23-expected-observation}

A large whole-run difference can be dominated by how many frames were
rendered.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s23-check-your-understanding}

What is excluded by the selected code range?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Every branch in the sorting loops.
  \item
        \textbf{B} Instructions in the renderer body outside the address
        interval.
  \item
        \textbf{C} The caller\textquotesingle s in-range \texttt{jal} and
        \texttt{nop}.
\end{itemize}
