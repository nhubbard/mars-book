\section{Step 8 Test the function
  independently}\label{009-sorting-visualizer-s08-step-8-test-the-function-independently}

The public function must work when main has not initialized any saved
registers. The checker passes changed arguments, supplies a return
continuation, and seeds saved registers with unrelated values.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s08-write-or-inspect}

Run the renderer checks before adding sorting logic.

\subsection{Expected
  observation}\label{009-sorting-visualizer-s08-expected-observation}

All saved registers and \texttt{sp} retain their caller values; only the
frame changes.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s08-check-your-understanding}

What would expose a hidden dependency on \texttt{s0} as the input
pointer?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Only testing the default main call.
  \item
        \textbf{B} Calling render directly with \texttt{a0} set and
        \texttt{s0} holding an unrelated value.
  \item
        \textbf{C} Changing a comment.
\end{itemize}
