\section{Step 10 Start an insertion sorted
  prefix}\label{009-sorting-visualizer-s10-step-10-start-an-insertion-sorted-prefix}

A prefix of length one is already ordered. Start the outer index at one;
if it is outside count, the input needs no insertion work. Set the inner
index to the new item.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s10-write-or-inspect}

Insert this fragment in insertion\_init.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $s2, 1
insertion_outer:
    slt $t0, $s2, $s1
    beq $t0, $zero, sort_end
    nop
    move $s3, $s2
\end{minted}

\subsection{Expected
  observation}\label{009-sorting-visualizer-s10-expected-observation}

Empty and singleton inputs exit without loading a pair.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s10-check-your-understanding}

What is the sorted-prefix invariant before an insertion?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The items before the new outer index are already ordered.
  \item
        \textbf{B} Every unvisited item is zero.
  \item
        \textbf{C} The whole array is always reversed.
\end{itemize}
