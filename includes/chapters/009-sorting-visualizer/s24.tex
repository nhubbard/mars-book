\section{Step 24 Read branch totals with their
  definition}\label{009-sorting-visualizer-s24-step-24-read-branch-totals-with-their-definition}

Branch counts use the core\textquotesingle s taken/not-taken decisions.
An always-taken \texttt{beq} counts as a branch; \texttt{jal} and
\texttt{jr} are jumps and do not. Delay-slot nops count as instructions,
not branch decisions.

\subsection{Write or
  inspect}\label{009-sorting-visualizer-s24-write-or-inspect}

Compare taken, not-taken, and total branch counts.

\subsection{Expected
  observation}\label{009-sorting-visualizer-s24-expected-observation}

The reference selection range executes 115 branch decisions on each
measured eight-item ordering, with different directions.

\subsection{Check your
  understanding}\label{009-sorting-visualizer-s24-check-your-understanding}

What does a taken-branch count measure?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Prediction misses on a physical processor.
  \item
        \textbf{B} Host-time stalls.
  \item
        \textbf{C} Executed core branch decisions whose outcome was taken.
\end{itemize}
