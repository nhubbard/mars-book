\section{Step 6 Draw one column cell with a bounds
check}\label{009-sorting-visualizer-s06-step-6-draw-one-column-cell-with-a-bounds-check}

Start with black. Test the column against \texttt{a1} before loading the
array. For an active column, compute its word address, convert the value
to a top-row threshold, and choose white only at or below that
threshold.

\subsection{Write or
inspect}\label{009-sorting-visualizer-s06-write-or-inspect}

Append this fragment inside render.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    move $t3, $zero
    slt $t4, $t2, $a1
    beq $t4, $zero, render_store
    nop
    sll $t4, $t2, 2
    daddu $t4, $a0, $t4
    lw $t5, 0($t4)
    addiu $t5, $t5, 5
    li $t6, 8
    subu $t5, $t6, $t5
    slt $t6, $t1, $t5
    bne $t6, $zero, render_store
    nop
    li $t3, 0x00ffffff
render_store:
    sw $t3, 0($t0)
    daddiu $t0, $t0, 4
\end{minted}

\subsection{Expected
observation}\label{009-sorting-visualizer-s06-expected-observation}

Only the first frame cell has been rendered; inactive columns never need
an array load.

\subsection{Check your
understanding}\label{009-sorting-visualizer-s06-check-your-understanding}

Why test x\textless count before loading?

\begin{itemize}
\tightlist
\item
  \textbf{A} To make every value positive.
\item
  \textbf{B} To stop the whole program on column zero.
\item
  \textbf{C} The inactive tail is not an input to this render call.
\end{itemize}
