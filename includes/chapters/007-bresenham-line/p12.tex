\section{Use exhaustive geometry checks with a bounded
claim}\label{007-bresenham-line-p12-use-exhaustive-geometry-checks-with-a-bounded-claim}

An 8 by 8 canvas has sixty-four possible endpoint positions. Pairing
each with every other gives 4,096 ordered endpoint pairs. That finite
domain is small enough to test in full, including both orders, all slope
classes, axis-aligned lines, exact ties, and all sixty-four
coincident-point cases.

The grading oracle uses a rational formula along the major axis, not the
reference\textquotesingle s running-error recurrence. Every final word
is checked against either the selected color or its original value.
Input and guard traces also reject temporary writes that a final-value
comparison could miss.

Exhaustive endpoint coverage is not exhaustive coverage of every RGB
word and every possible initial image. Those dimensions use varied
fixtures and explicit color boundaries. The tests also do not establish
that IntelliJ rendered a frame. Four planned Debug captures will require
actual light-theme IDE images, verified visible state, and native LaTeX
annotations when the authoring plugin is available.
