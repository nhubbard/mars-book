\section{Step 14 Save twice the old
  error}\label{007-bresenham-line-s14-step-14-save-twice-the-old-error}

Both coordinate decisions must use the same error value from the start
of this update. \texttt{sll} copies its double into a separate register
before either decision changes the running error. The small declared
domain makes this word shift exact.

\subsection{Write or
  inspect}\label{007-bresenham-line-s14-write-or-inspect}

Append the saved doubled error.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    sll $t2, $s7, 1
\end{minted}

\subsection{Expected
  observation}\label{007-bresenham-line-s14-expected-observation}

\texttt{\$t2} is four on the first default update and remains four
through both coordinate decisions.

\subsection{Check your
  understanding}\label{007-bresenham-line-s14-check-your-understanding}

Why save this value separately?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The color instruction needs it as an address.
  \item
        \textbf{B} The first update can change err before the second decision.
  \item
        \textbf{C} MIPS forbids comparing the same register twice.
\end{itemize}
