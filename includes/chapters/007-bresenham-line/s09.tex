\section{Step 9 Initialize the signed decision
  state}\label{007-bresenham-line-s09-step-9-initialize-the-signed-decision-state}

Negate the vertical magnitude to obtain dy = \ensuremath{-}D. Then initialize err =
dx + dy. The negative convention makes an x step add dy and a y step add
dx. This value is a scaled decision state, not a memory address or a
displayed distance.

\subsection{Write or
  inspect}\label{007-bresenham-line-s09-write-or-inspect}

Append the signed difference and error initialization.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    subu $s5, $zero, $s5
    addu $s7, $s4, $s5
\end{minted}

\subsection{Expected
  observation}\label{007-bresenham-line-s09-expected-observation}

For dx=5 and D=3, dy is \ensuremath{-}3 and err is two.
