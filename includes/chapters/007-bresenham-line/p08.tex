\section{Translate inclusive comparisons with strict
  tests}\label{007-bresenham-line-p08-translate-inclusive-comparisons-with-strict-tests}

The reference uses \texttt{slt} and delayed branches to implement two
inclusive inequalities. For e2 \ensuremath{\geq} dy, it tests the opposite, e2
\textless{} dy, and skips when that opposite is true. For e2 \ensuremath{\leq} dx, it
tests dx \textless{} e2 and skips when true. Equality belongs to the
update path in both cases, which implements the published halfway
convention.

Every shown retained branch has an explicit \texttt{nop} delay slot. The
slot executes whether the branch is taken or not. Moving a coordinate
update into a slot would change more than scheduling: it could make an
update occur on a path that was intended to skip it.

The unconditional back-edge uses \texttt{beq} with two zero operands.
Its \texttt{nop} performs no hidden store. These choices make the
instructional trace easier to verify. They are not a requirement that an
equivalent submission use exactly these branch mnemonics.
