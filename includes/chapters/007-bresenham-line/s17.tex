\section{Step 17 Return to address
calculation}\label{007-bresenham-line-s17-step-17-return-to-address-calculation}

An unconditional \texttt{beq} with equal zero operands returns to
\texttt{line\_loop}. Its \texttt{nop} delay slot performs no extra write
or coordinate change. Endpoint equality is checked after each store, so
the loop does not plot beyond the endpoint.

\subsection{Write or
inspect}\label{007-bresenham-line-s17-write-or-inspect}

Append the loop back-edge.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    beq $zero, $zero, line_loop
    nop
\end{minted}

\subsection{Expected
observation}\label{007-bresenham-line-s17-expected-observation}

The default final image contains six white cells, with every off-line
word preserved.

\subsection{Check your
understanding}\label{007-bresenham-line-s17-check-your-understanding}

What keeps a delay slot from painting an extra cell here?

\begin{itemize}
\tightlist
\item
  \textbf{A} Delay slots never execute.
\item
  \textbf{B} The slot is explicitly \texttt{nop}.
\item
  \textbf{C} The display ignores the final instruction.
\end{itemize}
