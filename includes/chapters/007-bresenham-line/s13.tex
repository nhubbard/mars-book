\section{Step 13 Test the endpoint after
painting}\label{007-bresenham-line-s13-step-13-test-the-endpoint-after-painting}

The line includes the current point even when it is already the
endpoint. If x differs, continue to advance. If x agrees, compare y too
and exit only when both coordinates agree. \texttt{advance} labels the
unfinished path.

\subsection{Write or
inspect}\label{007-bresenham-line-s13-write-or-inspect}

Append the endpoint test.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    bne $s0, $s2, advance
    nop
    beq $s1, $s3, done
    nop
advance:
\end{minted}

\subsection{Expected
observation}\label{007-bresenham-line-s13-expected-observation}

Coincident endpoints paint one cell and exit without a coordinate
update.

\subsection{Check your
understanding}\label{007-bresenham-line-s13-check-your-understanding}
