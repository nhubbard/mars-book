\section{Practice and extension
  questions}\label{007-bresenham-line-x-practice-practice-and-extension-questions}

\begin{enumerate}
  \def\labelenumi{\arabic{enumi}.}
  \tightlist
  \item
        Trace (0,0) to (2,1), then reverse the supplied endpoints. Identify
        the exact tie and show why the canonical output remains unchanged.
  \item
        Trace one update of (1,6) to (3,0). Explain why y can change without
        x.
  \item
        Replace the two independent conditions with if/else in pseudocode.
        Which default update first loses a required diagonal step?
  \item
        Explain why comparing only x for termination fails on a vertical line.
  \item
        Derive the address of (7,7) and the location of the frame guard.
  \item
        Change the framebuffer width to sixteen in a separate project. List
        the header, allocation, row-stride, input bounds, and expected-image
        checks that need revision.
  \item
        Add a second color layer or clipping as a new assignment. State its
        tie, endpoint, preservation, and out-of-bounds contracts before
        changing code.
  \item
        Compare simulated instruction counts for another line using both
        methods. Include the endpoints and explain why the result does not
        establish physical cycle cost.
\end{enumerate}

For review, state the error relation at the loop boundary and name which
registers are invariant. Explain the difference between exhausted
endpoint cases and sampled colors/backgrounds.
