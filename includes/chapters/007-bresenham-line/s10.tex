\section{Step 10 Load the fixed frame base and
color}\label{007-bresenham-line-s10-step-10-load-the-fixed-frame-base-and-color}

The frame base and color are invariant across the line.
\texttt{line\_loop} names the boundary before a cell address is
calculated. It will become the loop-back target after the
coordinate-update logic is complete.

\subsection{Write or
inspect}\label{007-bresenham-line-s10-write-or-inspect}

Append the invariant loads and loop label.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t8, frame
    la $t0, color
    lw $t9, 0($t0)
line_loop:
\end{minted}

\subsection{Expected
observation}\label{007-bresenham-line-s10-expected-observation}

\texttt{\$t8} is 0x10010000 and \texttt{\$t9} is the default white word
0x00ffffff.

\subsection{Check your
understanding}\label{007-bresenham-line-s10-check-your-understanding}

Which address stays fixed across every pixel?

\begin{itemize}
\tightlist
\item
  \textbf{A} The frame base.
\item
  \textbf{B} The address of the currently selected cell.
\item
  \textbf{C} The running error interpreted as a pointer.
\end{itemize}
