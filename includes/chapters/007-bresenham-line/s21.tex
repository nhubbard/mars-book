The line overlay changes only selected cell words. The checks vary
off-line bytes and watch protected inputs for stores, including writes
that are later restored.

\subsection{Write or
inspect}\label{007-bresenham-line-s21-write-or-inspect}

Run against a nonzero initial frame and compare all cells.

\subsection{Expected
observation}\label{007-bresenham-line-s21-expected-observation}

Selected cells become the exact color word; every other word and all
inputs remain unchanged.

\subsection{Check your
understanding}\label{007-bresenham-line-s21-check-your-understanding}

Why does a black-background-only test miss errors?

\begin{itemize}
\tightlist
\item
  \textbf{A} Black is not a legal color.
\item
  \textbf{B} All cells share one memory address.
\item
  \textbf{C} A program that clears unrelated cells could accidentally
  pass.
\end{itemize}
