\section{Step 24 Verify the declared domain and
  limits}\label{007-bresenham-line-s24-step-24-verify-the-declared-domain-and-limits}

The private checks cover every ordered endpoint pair on this finite
canvas. Colors and old frames vary across cases, but that does not
exhaust every possible input image or color word. A larger domain
requires revisiting address strides, arithmetic widths, and the proof.

\subsection{Write or
  inspect}\label{007-bresenham-line-s24-write-or-inspect}

Run the public checks and write the invariant, tie rule, and arithmetic
limits.

\subsection{Expected
  observation}\label{007-bresenham-line-s24-expected-observation}

The executable checks establish the final image and protected-data
contract; actual IDE display captures are still separate.

\subsection{Check your
  understanding}\label{007-bresenham-line-s24-check-your-understanding}

Which claim is justified by checking all 4096 endpoint pairs?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Every possible framebuffer and color has been tested.
  \item
        \textbf{B} The program works for arbitrary unbounded coordinates.
  \item
        \textbf{C} The declared endpoint-coordinate domain has been exhausted
        for the tested fixtures.
\end{itemize}
