\section{Step 6 Name the decision
  registers}\label{007-bresenham-line-s06-step-6-name-the-decision-registers}

The working coordinates, target coordinates, differences, y direction,
and running error need distinct meanings. The register table records
those meanings at named boundaries.

\subsection{Write or
  inspect}\label{007-bresenham-line-s06-write-or-inspect}

Use the register table to predict which values can change inside the
loop.

\subsection{Expected
  observation}\label{007-bresenham-line-s06-expected-observation}

Coordinates and error change; endpoint targets, differences, direction,
frame base, and color stay fixed.

\subsection{Check your
  understanding}\label{007-bresenham-line-s06-check-your-understanding}

Which quantity is preserved as the endpoint target?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The address scratch register.
  \item
        \textbf{B} The changing error value.
  \item
        \textbf{C} The ordered second coordinate pair.
\end{itemize}
