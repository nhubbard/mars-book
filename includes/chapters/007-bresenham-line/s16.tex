\section{Step 16 Apply the independent y
  decision}\label{007-bresenham-line-s16-step-16-apply-the-independent-y-decision}

The condition for stepping y is e2 \ensuremath{\leq} dx. \texttt{slt} computes dx
\textless{} e2, and a true result skips the update. Otherwise add dx to
err and add the signed direction to y. This is a second independent
decision, not an else branch.

\subsection{Write or
  inspect}\label{007-bresenham-line-s16-write-or-inspect}

Append the y decision and its join label.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    slt $t3, $s4, $t2
    bne $t3, $zero, skip_y
    nop
    addu $s7, $s7, $s4
    addu $s1, $s1, $s6
skip_y:
\end{minted}

\subsection{Expected
  observation}\label{007-bresenham-line-s16-expected-observation}

The first update finishes at (2,2), err four, with the original e2 still
four.

\subsection{Check your
  understanding}\label{007-bresenham-line-s16-check-your-understanding}

Can both x and y step in one update?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Yes; diagonal progress requires both independent
        conditions.
  \item
        \textbf{B} No; one condition must always exclude the other.
  \item
        \textbf{C} Only when the color is zero.
\end{itemize}
