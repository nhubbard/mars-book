\section{Define the output before translating the
algorithm}\label{007-bresenham-line-p01-define-the-output-before-translating-the-algorithm}

The default line runs from (1, 1) to (6, 4). Its horizontal change is
five and its vertical change is three, so x is the major axis: there is
one selected cell at each of the six x positions. The corresponding y
positions are 1, 2, 2, 3, 3, 4.

The major axis is the coordinate whose total change has greater
magnitude. Sampling once per major-axis position avoids gaps along that
axis. At each sample, the minor coordinate is the nearest integer to the
ideal segment value. A halfway value needs a further rule because two
cells are equally near.

The output contract states that rule before any assembly is written. It
also states which memory must remain unchanged. A grader can then accept
an incremental algorithm, a rational formula, or another implementation
without depending on one register allocation. Equivalent code means code
that preserves those named observations.
