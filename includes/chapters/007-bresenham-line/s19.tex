convention chooses the forward minor-axis step, selecting (1,1). Ordered
endpoints make the reversed input use the same choice.

inspect}\label{007-bresenham-line-s19-write-or-inspect}

Predict and test this line in both supplied endpoint orders.

\subsection{Expected
observation}\label{007-bresenham-line-s19-expected-observation}

Both orders paint (0,0), (1,1), and (2,1).

understanding}\label{007-bresenham-line-s19-check-your-understanding}
