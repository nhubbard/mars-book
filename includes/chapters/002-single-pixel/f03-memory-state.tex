\small
\begin{enumerate}
\item The blue line is \texttt{li \$v0, 10}, which prepares the exit service. The preceding \texttt{lw \$t3, 0(\$t0)} has completed; execution has not yet selected the exit service or invoked \texttt{syscall}.
\item Read the first two groups of four bytes separately: \texttt{ff 66 33 00} is the updated pixel and \texttt{df 9b 57 13} is the retained neighbor. The next eight zero bytes are outside these words. A word load reads memory without modifying it.
\item \texttt{\$t3}=\texttt{0x00000000003366ff}. The word load sign-extends its 32-bit value. Because bit 31 is zero here, all upper 32 bits are zero. The load returns the complete word, including the bytes the byte store preserved.
\end{enumerate}
