\section{Pack fields into one
integer}\label{002-single-pixel-p03-pack-fields-into-one-integer}

The notation \texttt{0x00336699} writes a 32-bit word as eight
hexadecimal digits. Each pair describes eight bits. In this RGB format,
the low three bytes are blue, green, and red when counted upward from
the least significant end. In the usual written order, those fields
appear as \texttt{00\ RR\ GG\ BB}.

For component values \texttt{R}, \texttt{G}, and \texttt{B}, each
between 0 and 255, the packed value is
\texttt{(R\ \textless{}\textless{}\ 16)\ \textbar{}\ (G\ \textless{}\textless{}\ 8)\ \textbar{}\ B}.
The shifts place the fields in separate bit positions, and the bitwise
OR combines them. No component overlaps another within that domain. The
highest byte is unused by this display; it is not an alpha channel.

The chosen values are deliberately different. With three distinct bytes,
a swapped channel or reversed address interpretation is visible in the
trace.
