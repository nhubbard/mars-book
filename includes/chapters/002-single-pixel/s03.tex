\section{Step 3 Load the pixel
  address}\label{002-single-pixel-s03-step-3-load-the-pixel-address}

la places an address in a register. The store instructions will use the
address in \$t0 to locate the destination. This is different from
putting an RGB value in the register.

\subsection{Write or
  inspect}\label{002-single-pixel-s03-write-or-inspect}

Append the address load inside the program region.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, pixel
\end{minted}

\subsection{Expected
  observation}\label{002-single-pixel-s03-expected-observation}

The address register identifies the first data word. No store has
changed that word yet.

\subsection{Check your
  understanding}\label{002-single-pixel-s03-check-your-understanding}

What is the purpose of \$t0 here?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} To identify the destination memory location.
  \item
        \textbf{B} To hold the red component only.
  \item
        \textbf{C} To choose a syscall service.
\end{itemize}
