\small
\begin{enumerate}
\item The blue line is the next instruction: \texttt{li \$t2, 255}. The earlier \texttt{sw \$t1, 0(\$t0)} has already written the packed color. At this stop the byte-update value has not yet been loaded.
\item The first four bytes, \texttt{99 66 33 00}, form the little-endian word \texttt{0x00336699}. The next four, \texttt{df 9b 57 13}, belong to the unchanged neighbor \texttt{0x13579bdf}. The remaining eight displayed bytes are padding after these two words.
\item The upper-left cell uses red \texttt{33}, green \texttt{66} and blue \texttt{99}. Only this cell has received a store. The other three cells remain black; initializing the neighboring word in \texttt{.data} does not draw it.
\end{enumerate}
