\section{Step 4 Prepare the packed
  color}\label{002-single-pixel-s04-step-4-prepare-the-packed-color}

The word 0x00336699 has red component 0x33, green 0x66, and blue 0x99.
Each component occupies eight bits and has a value from 0 through 255.
Bitmap Display uses the low 24 bits as RGB; the highest byte does not
supply alpha transparency.

\subsection{Write or
  inspect}\label{002-single-pixel-s04-write-or-inspect}

Append this pseudo-instruction. Convert the three component bytes to
decimal before running.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    li $t1, 0x00336699
\end{minted}

\subsection{Expected
  observation}\label{002-single-pixel-s04-expected-observation}

The components are red 51, green 102, and blue 153. The color is in a
register; the pixel word is still unchanged.

\subsection{Check your
  understanding}\label{002-single-pixel-s04-check-your-understanding}

Which byte specifies blue in the packed word?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} 0x33 because it is the first nonzero pair written.
  \item
        \textbf{B} 0x00 because the highest byte always specifies blue.
  \item
        \textbf{C} 0x99, the least significant byte.
\end{itemize}
