\section{Step 10 Verify the neighboring
  word}\label{002-single-pixel-s10-step-10-verify-the-neighboring-word}

An address error can change memory outside the intended object. A canary
word provides an explicit value to check immediately after the object.
The final-state contract requires preserving neighbor, including when
the grader sets it to another initial value.

\subsection{Write or
  inspect}\label{002-single-pixel-s10-write-or-inspect}

Run the public checks. Compare the pixel and neighboring word in memory
and explain the difference between a four-byte sw and a one-byte sb.

\subsection{Expected
  observation}\label{002-single-pixel-s10-expected-observation}

The original neighbor is 0x13579bdf. The grader also tests preservation
of other initial values. There should be no console output and the
program should terminate normally.

\subsection{Check your
  understanding}\label{002-single-pixel-s10-check-your-understanding}

What property should hold for neighbor?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} It must always be overwritten with the original constant.
  \item
        \textbf{B} It must match the final pixel color.
  \item
        \textbf{C} Its initial value must be preserved.
\end{itemize}
