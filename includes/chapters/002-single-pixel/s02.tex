\section{Step 2 Locate the data
  words}\label{002-single-pixel-s02-step-2-locate-the-data-words}

The supplied declarations reserve two adjacent 32-bit words. .align 2
places the first at an address divisible by four. With the default
layout, the first static word is at 0x10010000. Bitmap Display begins
reading its observed writes from that same base.

\subsection{Write or
  inspect}\label{002-single-pixel-s02-write-or-inspect}

Identify pixel and neighbor in the data section. Preserve their order
and keep this data section at the default base.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
.data
.align 2
pixel:    .word 0
neighbor: .word 0x13579bdf
\end{minted}

\subsection{Expected
  observation}\label{002-single-pixel-s02-expected-observation}

pixel starts at 0x10010000 and neighbor starts at 0x10010004. Their
values are initially 0 and 0x13579bdf. A declaration alone is not the
runtime drawing operation taught here.

\subsection{Check your
  understanding}\label{002-single-pixel-s02-check-your-understanding}

How far apart are these word addresses?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Thirty-two bytes because a word has 32 bits.
  \item
        \textbf{B} Four bytes.
  \item
        \textbf{C} One byte because each is one word.
\end{itemize}
