\section{A one-byte offset changes another
field}\label{002-single-pixel-x-wrong-offset-a-one-byte-offset-changes-another-field}

If the byte store used \texttt{1(\$t0)} in little-endian memory, it
would replace the green byte. The result would be \texttt{0x0033ff99},
with bytes \texttt{99\ ff\ 33\ 00}. A store at \texttt{4(\$t0)} would
reach the neighboring word instead of the pixel.

Predict both cases before experimenting in a separate copy. Restore
offset zero before running the assignment checks. A color change alone
does not establish that the intended field was changed.
