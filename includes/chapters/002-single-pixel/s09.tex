\section{Step 9 Reload and
  compare}\label{002-single-pixel-s09-step-9-reload-and-compare}

lw reads a 32-bit word and sign-extends it into the 64-bit destination
register. This particular value has a zero sign bit, so its upper 32
register bits are zero. Reading the value lets you compare the stored
word with a register view.

\subsection{Write or
  inspect}\label{002-single-pixel-s09-write-or-inspect}

Append the load before the supplied exit sequence. Step it after
inspecting final\_ready.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    lw $t3, 0($t0)
\end{minted}

\subsection{Expected
  observation}\label{002-single-pixel-s09-expected-observation}

\$t3 contains 0x00000000003366ff. Reading the word does not itself draw
a new color. The following supplied exit completes the program.

\subsection{Check your
  understanding}\label{002-single-pixel-s09-check-your-understanding}

What should \$t3 contain after this load?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} The full word 0x003366ff, sign-extended into the register.
  \item
        \textbf{B} Only 0xff because the previous store was a byte store.
  \item
        \textbf{C} The address of pixel rather than its contents.
\end{itemize}
