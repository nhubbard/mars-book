\section{Step 1 Configure the
  display}\label{002-single-pixel-s01-step-1-configure-the-display}

The first comment is a MARS tool configuration header. The simulator
executes no instruction for this comment; the plugin uses it to
configure a tool before execution. The display width divided by unit
width gives the number of logical columns, and the corresponding heights
give the rows.

\subsection{Write or
  inspect}\label{002-single-pixel-s01-write-or-inspect}

Inspect and preserve this header before the first assembly statement.
Run the unchanged starter once. No color write has executed yet.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
# mars:tool bitmap width=64 height=64 unitWidth=32 unitHeight=32 base=static_data
\end{minted}

\subsection{Expected
  observation}\label{002-single-pixel-s01-expected-observation}

The configuration describes two columns and two rows. Each logical cell
occupies a 32 by 32 screen block. A future verified screenshot will show
the exact editor and display arrangement.

\subsection{Check your
  understanding}\label{002-single-pixel-s01-check-your-understanding}

How many logical cells does this header describe?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} 4096: every screen position is a separate memory word.
  \item
        \textbf{B} One: the assignment name changes the grid dimensions.
  \item
        \textbf{C} Four: two columns times two rows.
\end{itemize}
