\section{From a printed number to a stored
  color}\label{002-single-pixel-p00-from-a-printed-number-to-a-stored-color}

The console program passed an integer to a service that printed it. A
display cell uses a different interface. The program writes a packed
value into simulated memory; Bitmap Display observes the write and turns
the value into a color. The same stored bits can be examined as a word,
as four bytes, or as RGB fields.

Those views answer different questions. A register view shows the value
about to be stored. A memory view shows which bytes changed. The bitmap
view shows the color interpretation of the word. Following the
transition through all three makes it possible to diagnose a correct
calculation sent to the wrong address, or a correct address supplied
with the wrong packed value.

The project draws one cell in a small grid. Enlarging that cell makes
the result easy to see while keeping the program short enough to trace
instruction by instruction.
