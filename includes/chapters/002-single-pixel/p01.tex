\section{A tool header describes the
view}\label{002-single-pixel-p01-a-tool-header-describes-the-view}

The configuration comment is metadata for the plugin. Width and height
describe the displayed area; unit width and height describe the block
used for a logical cell. Dividing 64 by 32 gives two cells along either
direction. A logical cell uses one word, so four words span this grid.

The base selects the memory region associated with the first cell. The
upper-left cell corresponds to the first word at the selected base;
subsequent words advance across the row and then into the next row. This
project writes only the first cell. The source header makes that view
reproducible when the file is launched.

The header does not allocate memory, select an instruction, or write a
pixel. It connects an observer to a region. The data declarations and
executed stores still determine which memory locations exist and which
writes take place.
