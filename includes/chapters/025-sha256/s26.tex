\section{Step 26 Compress the complete buffer}\label{sha-s26}

Pass the context state, its block buffer and its schedule workspace to the completed compression entry. The outer update frame retains all values needed after the nested call. Compression changes the state to include this full message block; the original byte total is already correct and must not be incremented again here.

\subsection{Write and inspect}
