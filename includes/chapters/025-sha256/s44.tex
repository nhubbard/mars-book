\section{Step 44 Publish only after successful EOF and close}\label{sha-s44}

Finalize the private context into the caller's output, select success status zero and branch to the common close path. Error branches already select their own status and preserve output. The close path then restores the caller's full saved values and returns. The complete wrapper now has a single publication event at successful EOF.

\subsection{Write and inspect}
Replace only the temporary instructions between \texttt{\# BEGIN file\_final} and \texttt{\# END file\_final}. Keep the supplied labels outside that region.
