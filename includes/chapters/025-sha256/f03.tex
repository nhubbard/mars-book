    \small
    \begin{enumerate}
      \setlength{\itemsep}{0pt}
            \setlength{\parsep}{0pt}
      \item The stop at \texttt{sha\_fin\_compress} precedes compression of the completed final block. This example began with a three-byte buffered tail and needs one final block.
      \item \texttt{s2 = 56} is the zero-fill cursor, while \texttt{s3 = 24} is the original bit length. These working registers have different units; neither is the total padded length.
      \item The context row stores original byte count three in eight bytes and buffered count three in the next word. Padding does not increase the original count. The remaining four \texttt{a5} bytes in this row are reserved context bytes.
      \item The first half of the buffer begins \texttt{61 62 63 80}, followed by zeroes. The marker is a single one bit followed by seven zero bits; it is not an extra source character.
      \item The second half completes the zero fill and ends with \texttt{00 00 00 00 00 00 00 18}. Together the two buffer details show all sixty-four bytes of this final block.
      \item The output interval still contains thirty-two \texttt{a5} bytes. Resuming performs compression and then serializes the state most significant byte first. Finalization consumes this context; reinitialize it before another message.
    \end{enumerate}
