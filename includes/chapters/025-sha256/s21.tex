\section{Step 21 Install the initial eight-word state}\label{sha-s21}

Walk the fixed initial-state constants and the supplied context together, copying eight numeric words. This code initializes meaningful state without clearing every workspace byte. The context pointer supplied in \texttt{a0} remains available after the temporary walker has advanced. No source message is consumed by initialization.

\subsection{Write and inspect}
Replace only the temporary instructions between \texttt{\# BEGIN init\_copy} and \texttt{\# END init\_copy}. Keep the supplied labels outside that region.

\Needspace{15\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    dla $t0, sha_iv
    move $t1, $a0
    li $t2, 8
init_word:
    lw $t3, 0($t0)
    sw $t3, 0($t1)
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 4
    addiu $t2, $t2, -1
    bne $t2, $zero, init_word
    nop
\end{minted}

Use recipe \texttt{s21-1} with the cumulative program through this edit. The exact recipe names the entry, prepared input and checkpoint. Observe the checkpoint before continuing to its temporary or normal return.

\subsection{Expected observation}
Context words zero through seven equal the standard initial state; the count fields have not yet been reset by this edit.
