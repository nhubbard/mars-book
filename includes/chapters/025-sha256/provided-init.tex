\section{Initialize meaningful context fields}
The initializer is a leaf routine. It receives one context pointer and does not need a
saved frame. The supplied exits distinguish a completed reset from an unfinished copy.
The old context may contain high count bits or bytes left by an earlier message, so
initialization must replace its meaningful state and both counters. Its buffer and
schedule remain scratch storage until later calls give their bytes meaning.
