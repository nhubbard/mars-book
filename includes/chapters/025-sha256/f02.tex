      \item This is the first \texttt{compress\_round\_done} visit, before the round walker advances. The function is inside its frame; its saved registers are restored before the eventual return.
      \item \texttt{s0..s3} contain new $a,b,c,d$: \texttt{5d6aebcd}, \texttt{6a09e667}, \texttt{bb67ae85}, \texttt{3c6ef372}. New $a$ is $T_1+T_2$ modulo $2^{32}$; the other three words shift from the previous working vector.
      \item \texttt{s4..s7} contain new $e,f,g,h$: \texttt{fa2a4622}, \texttt{510e527f}, \texttt{9b05688c}, \texttt{1f83d9ab}. New $e$ uses old $d+T_1$. Interpret the low thirty-two bits; leading \texttt{ffffffff} comes from word sign extension in the 64-bit register display.
      \item The two memory rows still hold all eight incoming state words, starting with \texttt{6a09e667} stored as \texttt{67 e6 09 6a}. Feed-forward occurs only after sixty-four rounds. These working registers are neither the published next state nor serialized digest bytes.
    \end{enumerate}
