\section{Sources and draft status}
\texttt{MLV1} is the exercise contract defined in this chapter. Its fixed geometry,
period rule, CRC coverage and accepted equivalent command streams are design choices
for the book. The public fixture writer encodes explicitly planned updates. Private
independent validation and reconstruction check its ordinary decode and every seek
result before the fixed observations are accepted.

The native-word kernel is checked against the pinned MARS implementation of MSA
word loads/stores, vector XOR and element transfers. The time-service description
follows the current educational syscall implementations. The comparison boundary
for any recorded kernel instruction count is function entry through return, excluding
assembly, fixture setup, console printing and waiting.

This standalone reading is not yet a registered student package or part of the
integrated manuscript. Full file-codec assembly construction, final feedback,
student/instructor distributions and actual annotated IDE captures remain unfinished.
No IDE screenshot is claimed by the native timeline figure. The requested broader
prose editing pass remains deferred while the remaining chapter drafts are composed.

The host foundation checks all 22 reference frames and every seek target, verifies
record CRCs with a separate bitwise calculation, and rejects 74 malformed files.
Equivalent payload choices and the maximal command payload are also checked. The
scalar/MSA kernel variants and cumulative observations pass 3944 simulator cases,
with eleven assembled faults rejected and ten ordinary caller runs verified.
These results establish the format examples and first kernel; they do not yet
certify an assembly file encoder, decoder, seeker or presentation loop.

The scalar record construction adds seventeen verified edits, thirty-seven public
recipes and an untouched control. Its separate gate passes 1012 simulator cases,
rejects thirteen assembled faulty routines and verifies eight ordinary caller
runs. Conditional and mask-based CRC implementations and a larger private frame
are checked in both native byte orders and both address layouts. Persistent calls
include a rejected late command between accepted records. The gate compares every
image byte, guards, source retention, context publication and saved caller state;
it also checks source and image access bounds. These checks establish the single
record interface through step 23. File reading, directory construction, seeking,
encoding and playback construction remain open.

The complete-file index construction adds thirteen edits through step 36, with
thirteen quizzes, twenty-six hints and twenty-five public observation recipes.
Its independent gate passes 868 simulator cases, rejects eleven assembled faulty
routines and verifies eleven ordinary caller runs, including an unfinished record
prerequisite. Both native byte orders and normal/high address layouts are checked.
Twelve six-call reuse cases retain earlier directory and context results across
rejection. Active scratch contents are deliberately unspecified. This stage
validates a complete file already in memory and publishes its record directory;
actual file I/O, seeking, encoding and playback assembly remain unfinished.
