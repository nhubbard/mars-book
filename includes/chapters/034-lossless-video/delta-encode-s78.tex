\section{Step 78 Emit the same skip that was measured}
Fill \texttt{dr\_emit\_skip}. Restart the pixel walk from zero and the output cursor from offset sixteen. Count a maximal zero run, serialize that skip as two big-endian bytes, retain a pointer to the following changed-count field in \texttt{\$t5}, and advance the output cursor past the four-byte command header. Leave changed-count bytes for the next region.

Use \texttt{s78-1} and stop before \texttt{dr\_skip\_written}.

\paragraph{Observe} At the first \texttt{dr\_skip\_written} stop, the skip is zero and the output cursor is four bytes into the payload. No XOR triple has been written yet.
