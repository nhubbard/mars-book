\section{Step 96 Acquire the selected output descriptor}
Fill \texttt{vs\_open}. Use service thirteen with the provided path, flag one for truncate-write mode and the ABI's unused permissions argument set to zero. A negative result means the open failed. Return the completed failure without attempting to close that negative result. On success, save the actual returned descriptor as the owned descriptor.

A grader may choose descriptor nineteen or thirty-one. Neither is an error merely because a small example happened to receive three. Once the open succeeds, the target may already be empty. Subsequent failure cannot promise retention of its earlier contents.

Use \texttt{s96-1} and stop before \texttt{vs\_open\_ready}.

\paragraph{Observe} A successful open has produced an owned descriptor. Its numeric value comes from the service result.

\Needspace{8\baselineskip}
\paragraph{Check} Which descriptor must later writes and close use?
\begin{enumerate}[label=\Alph*.]
  \item Always descriptor three.
  \item The descriptor from the preceding input file.
  \item The successful result of this open.
\end{enumerate}
