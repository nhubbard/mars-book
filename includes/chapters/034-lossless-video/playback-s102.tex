\section{Step 102 Request the two clock halves}
Fill \texttt{vn\_read} in \texttt{video\_now}. Select service thirty and execute the syscall. Its result occupies \texttt{\$a0} and \texttt{\$a1}, rather than the ordinary integer result register. The low and high halves each describe thirty-two bits of one millisecond count. They are not two separate samples.

Do not retain a live source pointer only in either argument register across this call. The player will keep persistent addresses in saved registers and prepare nested-call arguments again when needed.

Use \texttt{s102-1} and stop before \texttt{vn\_read\_ready}.

\paragraph{Observe} The grading clock returns low half 1000 and high half zero for its first scripted reading. An interactive run returns the current host clock instead.

\Needspace{8\baselineskip}
\paragraph{Check} Where does service thirty return its clock value?
\begin{enumerate}[label=\Alph*.]
\item In two thirty-two-bit halves in the argument registers.
\item As a file descriptor in the ordinary result register.
\item As an instruction count.
\end{enumerate}
