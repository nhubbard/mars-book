\section{Step 86 Keep two independent cursors}
Fill \texttt{fe\_state}. Set the sequence to zero and the produced offset to twenty-four, the size of the global header. Retain the source base separately from its moving cursor. A source cursor advances by the fixed native image size; a staging cursor advances by a variable record size.

In the illustrated register arrangement, \texttt{\$s4} is the sequence and \texttt{\$s5} is the produced offset. Both survive calls to the record encoder. Treat the offset as a byte count relative to the staging base, not as an address. Form the address only when preparing a particular record destination.

Use \texttt{s86-1} and stop before \texttt{fe\_state\_ready}.

\paragraph{Observe} The first source image is still selected. Sequence is zero and produced offset is twenty-four.

\Needspace{8\baselineskip}
\paragraph{Check} Which quantity advances by a variable amount after a successful record?
\begin{enumerate}[label=\Alph*.]
  \item The native source image size.
  \item The staging byte offset.
  \item The global header size.
\end{enumerate}
