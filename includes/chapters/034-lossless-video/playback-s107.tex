\section{Step 107 Validate the entire reloaded file}
Fill \texttt{vp\_index}. Call \texttt{video\_index} with the current file base, exact loaded count, caller-supplied directory and private index context. Propagate a completed failure or development status before starting the clock or changing the display.

A matching reload byte count cannot reveal a changed payload byte, a bad late CRC or an appended suffix. Whole-file validation checks those relationships before the first frame is presented. Once accepted, keep file and directory immutable throughout this playback call. The later record calls may rely on that validated structure.

Use \texttt{s107-1} and stop before \texttt{vp\_indexed}.

\paragraph{Observe} All records and the exact file end have been accepted. The default directory contains eight offsets, but the display is still untouched.

\paragraph{Check} What does equal reload size establish by itself?
\begin{enumerate}[label=\Alph*.]
  \item That every CRC is correct.
  \item That the byte counts agree; the contents still require validation.
  \item That the old directory is safe to reuse.
\end{enumerate}
