\section{Step 39: Open read-only and acquire the descriptor}
Set flags to zero, select service 13 and open the supplied path. Treat a
negative return as failure and take the unowned failure path. Otherwise keep
the exact returned descriptor in \texttt{\$s3}. The next regions own that
handle until closing it.

Fill \texttt{io\_open}. Do not assume the descriptor is three. Another file
may already occupy an earlier handle, and the grading inputs deliberately return
other valid descriptors. A successfully acquired descriptor creates a closing
obligation even when a later read or unfinished construction region fails.

\paragraph{Observe} Prepare \texttt{s39-1} and stop before
\texttt{io\_open\_ready}. At \texttt{io\_open\_ready}, \texttt{\$s3} contains the
returned handle. The ordinary example commonly receives three; the illustrated
grading observation uses its configured handle. No data has been read yet.

\paragraph{Check} Which descriptor must later reads use?
\begin{itemize}
  \item[A.] Always three.
  \item[B.] The filename address.
  \item[C.] The handle returned by open.
\end{itemize}
