\section{Step 84 Admit a packed sequence}
The source now contains several consecutive images. One image still occupies 16\,384 bytes: 4096 native words of four bytes each. The file routine accepts between one and 256 images, so admit a source byte count from 16\,384 through 4\,194\,304. A range check alone cannot establish that the count contains a whole number of images; the context check in the next step will establish the exact relationship.

Fill \texttt{fe\_admit}. Test the full-width count, four-byte source alignment and eight-byte context alignment before loading the context. An unaligned byte destination remains legal. Keep the initial status one and result count zero on a completed rejection. An unfinished region instead returns development status four.

Use \texttt{s84-1} and stop before \texttt{fe\_admitted}.

\paragraph{Observe} No image or context access has occurred. The default packed source count is 131\,072 bytes for eight images.

\Needspace{8\baselineskip}
\paragraph{Check} What additional fact is needed after admitting the source count range?
\begin{enumerate}[label=\Alph*.]
\item The count must equal the declared frame count multiplied by 16,384.
\item The destination must be word-aligned.
\item The input must already contain serialized RGB triples.
\end{enumerate}
