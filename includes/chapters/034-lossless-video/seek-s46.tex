\section{Step 46 Admit the native context before loading it}
Fill \texttt{seek\_admit}. The entry already initializes failure status one and count zero. Test the low three bits of \texttt{\$a3}; an eight-byte context requires all three to be zero. Return through \texttt{seek\_return} on failure, before creating a frame or reading context fields. The caller promises valid storage at an aligned supplied address; alignment alone does not prove an address is allocated.

Use \texttt{s46-1} and stop before \texttt{seek\_admitted}.

\paragraph{Observe} With the ordinary target-six recipe, the low-bit result is zero at \texttt{seek\_admitted}. The file, directory and images have not been accessed by this routine.

\paragraph{Check} Which check belongs before the first context load?
\begin{enumerate}[label=\Alph*.]
  \item Its eight-byte alignment.
  \item The kind of the target record.
  \item The current displayed color.
\end{enumerate}
