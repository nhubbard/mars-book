\section{Step 81 Commit the current image after record completion}
Fill \texttt{dr\_previous}. Copy all 16\,384 current-image bytes into the previous-image window, using the same native-byte copy technique as the full encoder. The XOR scratch words are not the next previous image. This copy occurs only after the selected record, including CRC, is complete.

Use \texttt{s81-1} and stop before \texttt{dr\_previous\_ready}.

\paragraph{Observe} At \texttt{dr\_previous\_ready}, every previous-image word equals the current source. The native context still has input sequence one and its earlier kind/count outputs.

\Needspace{8\baselineskip}
\paragraph{Check} Which data becomes the next previous image?
\begin{enumerate}[label=\Alph*.]
\item The current source pixels.
\item The XOR difference words.
\item The serialized command headers.
\end{enumerate}
