\section{Step 110 Continue sequentially after the seek}
Fill \texttt{vp\_record\_context}. Build a private single-record context with display capacity, admitted period and expected sequence equal to start plus one. Its image will be the display image after the first seek succeeds.

If start is six, the seek supplies frame six and the next direct record call expects seven. Reusing a record context from another playback could instead expect an unrelated sequence. Reset this state on every invocation. A start at the final frame legitimately prepares an expected sequence equal to the file count; no further record call will use it.

Use \texttt{s110-1} and stop before \texttt{vp\_record\_context\_ready}.

\paragraph{Observe} The default first direct record sequence is one. With start six it is seven.

\Needspace{8\baselineskip}
\paragraph{Check} Which sequence follows a successful seek to start six?
\begin{enumerate}[label=\Alph*.]
\item Six.
\item Seven.
\item Zero.
\end{enumerate}
