\section{Step 74 Measure a maximal run of unchanged pixels}
Fill \texttt{dr\_measure\_skip}. The supplied measure loop starts pixel cursor \texttt{\$t0} at zero and accumulated bytes \texttt{\$s7} at zero. Reset skip count \texttt{\$t1}, then advance while the cursor is below 4096 and the corresponding scratch word is zero. Bound the cursor before loading. A trailing all-zero run is valid and can reach the image end.

Use \texttt{s74-1} and stop before \texttt{dr\_skip\_measured}.

\paragraph{Observe} At the first \texttt{dr\_skip\_measured} stop, pixel zero is changed, so cursor and skip count are both zero. The still recipe later measures a skip of 4096 without reading a word after the image.

\Needspace{8\baselineskip}
\paragraph{Check} What permits a skip scan to stop at pixel 4096?
\begin{enumerate}[label=\Alph*.]
\item There is a required sentinel word after every frame.
\item The next word belongs to the checksum.
\item The cursor is an exclusive end and must be tested before loading.
\end{enumerate}
