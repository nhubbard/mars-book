\section{Step 59 Retain sequence state while walking pixels}
Fill \texttt{ef\_state}. Load the previous-image address into \texttt{\$s3}, the input sequence into \texttt{\$s4}, and the period into \texttt{\$s5}. The supplied frame retains source, output and context in \texttt{\$s0} through \texttt{\$s2}. Initialize a source cursor \texttt{\$t0} and exclusive source end \texttt{\$t1}. The sequence remains the value for this record until final publication increments the context.

Use \texttt{s59-1} and stop before \texttt{ef\_state\_ready}.

\paragraph{Observe} At \texttt{ef\_state\_ready}, \texttt{\$s4} is zero, \texttt{\$t0} names the first source word, and \texttt{\$t1} is 16\,384 bytes later.

\paragraph{Check} Which sequence belongs in the new record header?
\begin{enumerate}[label=\Alph*.]
\item The already incremented next-sequence value.
\item The source byte count.
\item The input next-sequence value.
\end{enumerate}
