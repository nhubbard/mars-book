\section{Step 26: Check the format and geometry}
Read the four magic bytes and compare them with the numeric big-endian
value \texttt{0x4d4c5631}, the bytes of \texttt{MLV1}. Then read width and
height as unsigned two-byte big-endian values and require both to be 64. The
fixed geometry is part of this exercise's format; it is not a request to allocate
an image of whatever dimensions the input declares.

Fill \texttt{index\_geometry}. Use byte loads and shifts as in the record
header. The same parser must accept a valid file in either simulator byte order.
The earlier total-count check guarantees that all global-header bytes exist.

\paragraph{Observe} Prepare \texttt{s26-1} and stop before
\texttt{index\_geometry\_ready}. At \texttt{index\_geometry\_ready}, the last decoded
dimension in \texttt{\$t0} is 64. The directory still contains only its entry
bytes.
