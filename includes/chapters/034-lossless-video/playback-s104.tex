\section{Step 104 Admit the loaded byte extent}
Fill \texttt{vp\_admit}. Require a file count from twenty-four through 7\,344\,152, four-byte display alignment and eight-byte context alignment. Compare the full-width count before deriving file addresses. The serialized file base itself may be unaligned.

The display is an output image, not the decoder scratch area. Rejecting an invalid argument must happen before the player reads or changes display pixels, and before it requests time. This makes an invalid initial call distinct from a later clock failure after a frame has already become visible.

Use \texttt{s104-1} and stop before \texttt{vp\_admitted}.

\paragraph{Observe} The default file count is 24\,795. No context, file, display or clock access has occurred at this boundary.

\paragraph{Check} Which pointer may be byte-aligned rather than word-aligned?
\begin{enumerate}[label=\Alph*.]
\item The native playback context.
\item The native display image.
\item The serialized file base.
\end{enumerate}
