\section{Step 58 Admit output and previous-image capacity}
Fill \texttt{ef\_context}. Require at least 12\,304 output bytes and 16\,384 previous-image bytes, using unsigned capacity comparisons. Require next sequence below 256, period from one through 64, and four-byte alignment of the previous-image pointer. These tests read context inputs but do not modify them. This encoder always emits a full frame; the period remains valid metadata for later delta selection.

Use \texttt{s58-1} and stop before \texttt{ef\_context\_ready}.

\paragraph{Observe} At \texttt{ef\_context\_ready}, default capacities fit exactly, sequence is zero and period is four. A capacity of 12\,303 is one byte short even though it exceeds the RGB payload length.

\paragraph{Check} What must the output capacity include?
\begin{enumerate}[label=\Alph*.]
\item Only the 12,288 RGB bytes.
\item The sixteen-byte header and all RGB payload bytes.
\item The native previous image as well as the record.
\end{enumerate}
