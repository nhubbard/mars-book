\section{Step 32: Advance the validation walk}
Load the saved total record bytes, add them to the file offset, and
increment the record index. The supplied loop repeats while that index differs
from the admitted frame count. Because each complete record had to fit, the
new offset cannot exceed the file count. Every admitted record advances by at
least its sixteen-byte header.

Fill \texttt{index\_advance}. The file offset counts bytes from the file base;
the record index counts records. Adding one to both would cause the next header
to be read from inside the current record. Use 64-bit offset arithmetic so
forming later source addresses retains the file base's high bits.

\paragraph{Observe} Prepare \texttt{s32-1} and stop before
\texttt{index\_record\_advanced}. At the first \texttt{index\_record\_advanced},
\texttt{\$s6} is 12\,328 and \texttt{\$s7} is one. Continuing validates
all remaining declared records before the next unfinished region.
