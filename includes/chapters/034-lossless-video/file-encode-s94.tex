\section{Step 94 Admit a byte transfer before opening}
The next routine transports an already admitted byte sequence. Fill \texttt{vs\_admit}. Require a positive full-width byte count no larger than 7\,344\,152 and eight-byte alignment for the result context before opening the path. The byte source may be unaligned. The caller supplies readable source and NUL-terminated path windows.

\texttt{video\_store} does not inspect MLV1 headers or CRCs. The example caller runs the existing indexer and seeker before requesting storage. Keeping this validation before the open matters because truncate-write mode can replace an existing file as soon as the descriptor is acquired.

Use \texttt{s94-1} and stop before \texttt{vs\_admitted}.

\paragraph{Observe} The default transfer count is 24\,795. No open request has occurred at this checkpoint.

\Needspace{8\baselineskip}
\paragraph{Check} Where does container validation occur in this calling sequence?
\begin{enumerate}[label=\Alph*.]
\item In the caller before opening the output path.
\item After the output file has been truncated.
\item Inside every write request.
\end{enumerate}
