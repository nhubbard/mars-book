\section{Step 108 Choose the playback suffix}
Fill \texttt{vp\_range}. Read the admitted frame count and duration from the private index result. Load the requested start index from the caller context and require it to be strictly below the frame count. Initialize the current index to that start.

Playback includes the start frame and every remaining frame. For an eight-frame file, start six means two display intervals, not six milliseconds or two encoded records chosen from the beginning. The first seek will reconstruct frame six from its appropriate full-frame predecessor.

Use \texttt{s108-1} and stop before \texttt{vp\_range\_ready}.

\paragraph{Observe} With default start zero, eight intervals remain. Start six instead selects frames six and seven.

\Needspace{8\baselineskip}
\paragraph{Check} How many intervals remain when an eight-frame file starts at six?
\begin{enumerate}[label=\Alph*.]
\item Six.
\item One.
\item Two.
\end{enumerate}
