\section{Step 3 Read the memory contract}\label{maze-s03}

The program keeps a byte per cell for walls, states, parents, distance, queue entries, and the final path mask. Public metadata words describe each checkpoint.

\subsection{Write or inspect}

Identify the fixed 64-cell capacities, the four-byte array alignment, and the guard words. Read the sentinel table before choosing a load instruction.

\subsection{Expected observation}

The value 255 marks an unknown parent or distance. It lies outside the valid cell IDs zero through 63 and the possible finite distances zero through 63.

\subsection{Check your understanding}

Why can 255 serve as the parent sentinel?

\begin{itemize}
  \item \textbf{A} It is the goal in every fixture.
  \item \textbf{B} It is a valid row number.
  \item \textbf{C} It cannot name any cell in this grid.
\end{itemize}
