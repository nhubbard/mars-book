\section{Step 22 Report an exhausted frontier}\label{maze-s22}

An empty queue means every reachable cell has been processed. If no dequeued cell was the goal, the search has exhausted the entire reachable component.

\subsection{Write or inspect}

Append the unreachable fragment. Retain minus one as the route length and leave every path byte zero.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, result
    sw $zero, 0($t0)
\end{minted}

\subsection{Expected observation}

The row-boundary fixture with only cells seven and eight open returns result zero. The algorithm must not invent a connection between those indices.

\subsection{Check your understanding}

What proves failure in this bounded search?

\begin{itemize}
\item \textbf{A} The queue empties without processing the goal.
\item \textbf{B} The first neighbor is a wall.
\item \textbf{C} The start has parent 255.
\end{itemize}
