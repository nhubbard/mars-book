\section{Validate relations before comparing work}\label{maze-p12}

The free-writing checks follow the submitted queue order. At each phase-one boundary they require exactly the unseen open neighbors of the current cell, in any order, as the newly appended suffix. Previously recorded queue entries and predecessor values must remain consistent. Final checks validate the chosen chain and compare distances with an independent shortest-distance calculation.

The alternative solution changes direction order and uses explicit signed bounds. It produces a different parent for the small room's goal. Both implementations pass because their state transitions satisfy the same stated relations. Scratch registers, private helper labels, and exact instruction counts are outside that free-writing contract.

Whole-program measurements include initialization, every redraw, and normal exit. For a reachable far-corner goal in an open 8 by 8 room, all 64 cells are processed and 66 frames are published: one initial, one per processed cell, and one final. Redrawing the entire grid is a substantial part of that work. A larger-grid extension should consider both algorithmic complexity and the observation policy before drawing performance conclusions.
