\section{Step 16 Append the new work item}\label{maze-s16}

A queue entry stores a cell ID, not a pointer to the cell. The tail counter identifies the first unused byte.

\subsection{Write or inspect}

Append the candidate ID and advance tail once.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddu $t0, $s4, $s6
    sb $t3, 0($t0)
    addiu $s6, $s6, 1
\end{minted}

\subsection{Expected observation}

Each successful discovery will append one queue entry. No entry is added for a wall, an out-of-range coordinate, or an already discovered cell. With the default start, north is rejected and no append is observed until the next step completes the direction loop.

\subsection{Check your understanding}

What is stored in one queue byte?

\begin{itemize}
\item \textbf{A} A cell ID from zero through 63.
\item \textbf{B} A full memory address.
\item \textbf{C} A color word.
\end{itemize}
