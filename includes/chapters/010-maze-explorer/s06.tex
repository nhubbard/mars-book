\section{Step 6 Discover the start once}\label{maze-s06}

The start is the first discovered cell. It has distance zero and no predecessor. The queue contains it before the first dequeue.

\subsection{Write or inspect}

Append the start initialization. Leave its parent as 255, set its state to one, and store its ID in the first queue byte.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, start
    lw $t1, 0($t0)
    sb $t1, 0($s4)
    daddu $t2, $s1, $t1
    li $t3, 1
    sb $t3, 0($t2)
    daddu $t2, $s3, $t1
    sb $zero, 0($t2)
    li $t3, -1
    la $t0, result
    sw $t3, 0($t0)
    la $t0, length
    sw $t3, 0($t0)
\end{minted}

\subsection{Expected observation}

The counters in saved registers describe one active entry: head zero through tail one, excluding tail. The next step publishes those counters in the metadata words. Result and route length are now minus one.

\subsection{Check your understanding}

How many queue entries are initially active?

\begin{itemize}
  \item \textbf{A} Zero.
  \item \textbf{B} Sixty-four.
  \item \textbf{C} One.
\end{itemize}
