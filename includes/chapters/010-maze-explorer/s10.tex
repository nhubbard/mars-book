\section{Step 10 Check the renderer on its own}\label{maze-s10}

The renderer reads the public arrays and writes the frame. It does not discover cells, change counters, or choose a path.

\subsection{Write or inspect}

Run the renderer checks independently, with a return address targeting \texttt{done}. Inspect cases that combine wall, state, and path flags.

\subsection{Expected observation}

The caller can seed the arrays and preserved registers without running main. A full redraw erases a poisoned old frame, and the renderer leaves its input arrays and metadata unchanged.

\subsection{Check your understanding}

What does an independent renderer test remove?

\begin{itemize}
  \item \textbf{A} A hidden dependency on main having prepared scratch registers.
  \item \textbf{B} The need for a return address.
  \item \textbf{C} All stores to the framebuffer.
\end{itemize}
