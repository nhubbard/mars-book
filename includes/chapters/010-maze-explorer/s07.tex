\section{Step 7 Publish the initial state}\label{maze-s07}

An animation checkpoint must expose a complete logical state. The search stores its register counters into metadata and asks the renderer to write the entire frame.

\subsection{Write or inspect}

Append the initial publication in the initial region. Set a breakpoint at \texttt{maze\_ready}.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, head
    sw $s5, 0($t0)
    la $t0, tail
    sw $s6, 0($t0)
    la $t0, current
    sw $s7, 0($t0)
    li $t1, 0
    la $t0, phase
    sw $t1, 0($t0)
    jal render
    nop
\end{minted}

\subsection{Expected observation}

Phase zero has head zero, tail one, and current minus one. At this stage the renderer stub returns without drawing; the state is initialized but the image is unfinished.

\subsection{Check your understanding}

Does the renderer stub already prove a correct picture?

\begin{itemize}
  \item \textbf{A} No; it has not written the frame.
  \item \textbf{B} Yes; a call paints automatically.
  \item \textbf{C} Yes; the queue is nonempty.
\end{itemize}
