\section{Practice with changed contracts}\label{maze-x-practice}
\begin{enumerate}
  \item Change the fixed direction order. Predict the first three removals and the selected
        parent of the small-room goal, then rerun the unchanged free-writing checks.
  \item Add a report of frontier size. Define whether it is sampled before or after processing
        and verify the chosen interval using \(\texttt{tail}-\texttt{head}\).
  \item Construct a reachable maze with a longer route than the corner-to-corner Manhattan
        distance. Explain which walls force the extra moves.
  \item Propose a rectangular-grid interface with independent width and height. Specify ID
        conversion, capacity, pixel stride, valid endpoint range, and sentinel bounds.
  \item Explain why changing a cell's display color is insufficient to introduce weighted
        terrain. State what quantity the search would need to minimize.
\end{enumerate}
Only the original 8 by 8 unit-cost contract is graded by this package. Each extension
needs its own stated domain, expected artifact, and checks before it becomes an assignment.
