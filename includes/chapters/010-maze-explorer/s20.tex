\section{Step 20 Record a reachable result}\label{maze-s20}

When the dequeued cell is the goal, its stored distance is the shortest edge count. The result word distinguishes success from the unfinished state and from an exhausted search.

\subsection{Write or inspect}

Append the success fragment. Prepare to walk backward from the goal using parent bytes.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    la $t0, result
    li $t1, 1
    sw $t1, 0($t0)
    daddu $t0, $s3, $s7
    lbu $t1, 0($t0)
    la $t0, length
    sw $t1, 0($t0)
    move $t0, $s7
    la $t1, path
    la $t2, start
    lw $t2, 0($t2)
    li $t3, 1
\end{minted}

\subsection{Expected observation}

For the small room, result is one and length is two. The path mask is still empty until the predecessor walk is implemented.

\subsection{Check your understanding}

What does length count?

\begin{itemize}
  \item \textbf{A} The number of bytes in parents.
  \item \textbf{B} Edges from start to goal.
  \item \textbf{C} All discovered cells.
\end{itemize}
