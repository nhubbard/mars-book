\section{Step 9 Redraw the entire frame}\label{maze-s09}

A frontier cell can later become processed or part of a route. Leaving old pixels unchanged would confuse persistent memory with current search state.

\subsection{Write or inspect}

Append the pointer increments and loop branch. Advance the frame pointer by four bytes and each classification pointer by one byte.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddiu $t0, $t0, 4
    daddiu $t1, $t1, 1
    daddiu $t2, $t2, 1
    daddiu $t3, $t3, 1
    addiu $t4, $t4, -1
    bne $t4, $zero, render_cell
    nop
\end{minted}

\subsection{Expected observation}

All 64 cells now match the initial metadata. Walls are dark, unseen open cells are white, and the start is orange.

\subsection{Check your understanding}

Why does the frame pointer advance by four?

\begin{itemize}
  \item \textbf{A} The grid has four neighbors.
  \item \textbf{B} The queue contains words.
  \item \textbf{C} Each RGB pixel occupies one 32-bit word.
\end{itemize}
