\section{Step 29 State where BFS stops applying}\label{maze-s29}

The proof relies on every edge having the same cost. A shorter count of moves can be more expensive if terrain assigns different costs to different edges.

\subsection{Write or inspect}

Propose a weighted-terrain extension and name the contract changes before changing instructions.

\subsection{Expected observation}

Ordinary FIFO BFS is no longer a sufficient general shortest-cost algorithm for unequal positive weights. Distances, queue discipline, tests, and explanatory figures would all need revision.

Does ordinary FIFO BFS solve arbitrary weighted shortest paths?
