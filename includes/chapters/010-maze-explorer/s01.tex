\section{Step 1 Define a shortest route}\label{maze-s01}

A maze cell is a graph vertex. An edge joins two open cells that share a side. Each edge costs one move, so a shortest route is one with the fewest edges.

\subsection{Write or inspect}

Read the input domain before selecting a search algorithm. This chapter permits four directions and gives all moves the same cost.

\subsection{Expected observation}

The route from cell zero to cell nine in the small room has two edges and three cells. Two different routes satisfy that length.

\subsection{Check your understanding}

What does this task minimize?

\begin{itemize}
  \item \textbf{A} The number of cells stored in the maze.
  \item \textbf{B} The number of orthogonal moves from start to goal.
  \item \textbf{C} The number of different colors.
\end{itemize}
