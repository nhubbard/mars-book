\section{A parent chain is both an answer and a termination argument}\label{maze-p10}

After success, start at the goal and mark each cell named by the predecessor chain. Each move backward follows an adjacent open cell and decreases the distance by exactly one. A nonnegative integer cannot decrease forever, so the chain reaches the zero-distance start in a bounded number of steps.

Mark the current cell before deciding whether to stop. Otherwise the start would be absent from the mask, even though it is an endpoint of the route. Do not read the start's parent afterward: its sentinel deliberately names no cell. The start-equals-goal case follows the same procedure and marks one cell without following any predecessor.

The word length counts edges. The number of marked cells is therefore length plus one. The grader checks the entire mask against the reconstructed chain; extra disconnected blue cells would not become a route merely because the goal distance was correct.
