\section{Step 28 Run the full-grid fixture}\label{maze-s28}

A fully open grid exercises capacity, many equal-length routes, and overlapping discovery opportunities. A larger visible search should follow the same interface as the stepping room.

\subsection{Write or inspect}

In a copy of main.asm, replace the walls initializer with 64 zero bytes and set goal to 63 while keeping start zero. The full-room JSON fixture records these same values for automation; it is not an IDE import command. Use breakpoints or run-to-cursor rather than stepping through every pixel store.

\subsection{Expected observation}

The shortest distance is fourteen. With this far-corner goal, all 64 cells are discovered and the queue reaches its full capacity without an out-of-range append.
