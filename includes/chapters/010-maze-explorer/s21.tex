\section{Step 21 Reconstruct the route backward}\label{maze-s21}

Each non-start route cell has a predecessor whose distance is one smaller. Following these links reaches the start without searching the maze again.

\subsection{Write or inspect}

Append the predecessor loop. Mark the current route cell before checking whether it is the start.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    daddu $t4, $t1, $t0
    sb $t3, 0($t4)
    beq $t0, $t2, finished
    nop
    daddu $t4, $s2, $t0
    lbu $t0, 0($t4)
    j path_loop
    nop
\end{minted}

\subsection{Expected observation}

The path mask includes goal, intermediate cells, and start. In the reference it marks zero, one, and nine. The next final redraw will make those cells blue.

\subsection{Check your understanding}

Why mark before the start test?

\begin{itemize}
\item \textbf{A} To add an extra edge.
\item \textbf{B} To overwrite the queue.
\item \textbf{C} To include the start in the path mask.
\end{itemize}
