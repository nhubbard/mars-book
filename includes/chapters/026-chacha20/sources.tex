\section{Sources and draft status}
The algorithm and fixed numerical anchors follow
\href{https://www.rfc-editor.org/rfc/rfc8439.html}{RFC 8439}, sections 2.1 through 2.4.
The interfaces, 4096-byte limit, error statuses, memory ownership and observation
boundaries are local teaching choices. MARS instruction behavior was checked in its
word arithmetic, MSA integer, vector memory and permutation implementations. The
\texttt{shf.w} selectors explicitly follow destination-lane selection in the current
core. The private arithmetic model uses wraparound word operations; JDK ChaCha20
provides a separate whole-message comparison.

This independent native foundation awaits its cumulative exercise package and main
integration. Actual IDE captures, remote progression, independent accessibility
validation and the author’s deferred editing remain unfinished.
