      \item \texttt{s2 = 10} is still the initialized count. It becomes nine after the repeat region executes. Counting this stop as ten completed double-rounds would skip most of the block function.
      \item The first eight input words contain the four ChaCha constants and the first half of the key. The function copied them into a separate working output before arithmetic.
      \item The last eight input words contain the remaining key, counter and nonce. These rows remain unchanged throughout this block call.
      \item The first eight working words now reflect both the column and diagonal quarter-rounds. Interpret each four-byte group as a little-endian numeric word; the row order is the original sixteen-word state order.
      \item The last eight working words complete that intermediate state. Nine further double-rounds and addition of the original state are still required before these bytes become the block output.
    \end{enumerate}
