\section{Step 32 Compare scalar and MSA at the same boundary}\label{chacha-s32}

Use identical input state and output alignment for both block entries. Compare bytes before counting work. The MSA layout changes register residency, pointer setup and nested calls as well as the number of lanes processed together.

\subsection{Expected observation}
Both outputs agree while their simulated instruction counts differ.

\Needspace{9\baselineskip}
\subsection{Check your understanding}
What does a lower simulator instruction count establish?

\begin{itemize}
  \item \textbf{A} A measured hardware cycle speedup.
  \item \textbf{B} A guarantee of constant-time hardware execution.
  \item \textbf{C} Less simulated instruction work at the measured boundary.
\end{itemize}
