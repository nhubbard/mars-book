\section{Step 11 Prepare a bounded header scan}\label{packet-s11}

Clear the full-packet sum, copy the input pointer to \texttt{t5}, and set an eight-byte counter. These registers belong to the parser. The original \texttt{a0} remains available for constructing the returned payload address.

\subsection{Write or inspect}
Append these instructions in the \texttt{header\_init} region. Keep the scaffold labels and return stub.

\Needspace{6\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    move $t3, $zero
    move $t5, $a0
    li $t6, 8
\end{minted}

\subsection{Expected observation}
The cursor starts at header offset zero and the remaining count is eight.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which register here is an address?

\begin{itemize}
\item \textbf{A} \texttt{t5}.
\item \textbf{B} The checksum in \texttt{t3}.
\item \textbf{C} The count in \texttt{t6}.
\end{itemize}
