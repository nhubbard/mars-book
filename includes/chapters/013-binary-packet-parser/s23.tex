\section{Step 23 Retain high pointer bits}\label{packet-s23}

Repeat the call with the data section relocated above four GiB. Compare the full returned pointer with the full input address plus eight. A word-sized pointer increment can pass every default low-address test and fail this relocation. Saved-register canaries also contain nonzero high halves.

\subsection{Write or inspect}
Perform the described inspection or experiment without changing the submitted interface.

\subsection{Expected observation}
A successful return preserves the high address bits and the full values of \texttt{s0} through \texttt{s7} and \texttt{sp}.
