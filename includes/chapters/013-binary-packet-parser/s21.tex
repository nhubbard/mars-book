\section{Step 21 Check the absence of failed writes}\label{packet-s21}

Fill the output with recognizable nonzero words, corrupt a checksum, and verify the failure. A final-byte comparison checks preservation but cannot detect temporary stores. The grading trace also rejects output writes that a program later restores.

\subsection{Write or inspect}
Perform the described inspection or experiment without changing the submitted interface.

\subsection{Expected observation}
The checksum error returns \texttt{v1} zero and leaves the complete output-store history empty.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which program violates failure preservation?

\begin{itemize}
\item \textbf{A} One that never writes the output.
\item \textbf{B} One that writes a field then restores it before returning an error.
\item \textbf{C} One that keeps tentative fields in temporary registers.
\end{itemize}
