\section{Step 5 Require the supported version}\label{packet-s05}

Only after the identifier passes, test the version byte at offset two. This function supports version one. Returning a distinct error lets a caller distinguish recognizable data in an unsupported format from an unrelated identifier.

\subsection{Write or inspect}
Append these instructions in the \texttt{version} region. Keep the scaffold labels and return stub.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -3
    lbu $t7, 2($a0)
    li $t9, 1
    bne $t7, $t9, packet_return
    nop
\end{minted}

\subsection{Expected observation}
Changing byte two to two reports -3 after a complete fixed header is available.
