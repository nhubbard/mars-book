\section{Step 19 Test incomplete prefixes}\label{packet-s19}

Present each prefix of a valid packet by changing only the available count, not by deleting the mapped suffix. This distinguishes the logical boundary from physical allocation. Counts zero through seven must not establish header errors. A complete valid header with a missing trailer still needs more input.

\subsection{Write or inspect}
Perform the described inspection or experiment without changing the submitted interface.

\subsection{Expected observation}
The default packet reports -1 for every count below twelve, with no record writes.
