\section{Step 7 Assemble the unsigned length}\label{packet-s07}

Load the high length byte from offset four, shift it left eight positions, then combine the low byte from offset five with OR. Both loads use zero extension. These values are numbers, so word operations suffice; no address is narrowed.

\subsection{Write or inspect}
Append these instructions in the \texttt{length} region. Keep the scaffold labels and return stub.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    lbu $t0, 4($a0)
    sll $t0, $t0, 8
    lbu $t7, 5($a0)
    or $t0, $t0, $t7
\end{minted}

\subsection{Expected observation}
Bytes 00 03 produce three. Bytes 01 00 produce 256 and will fail the next semantic check.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What value do length bytes 01 00 encode?

\begin{itemize}
\item \textbf{A} One.
\item \textbf{B} 256.
\item \textbf{C} 65536.
\end{itemize}
