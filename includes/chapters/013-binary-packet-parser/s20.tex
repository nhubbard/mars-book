\section{Step 20 Combine header defects deliberately}\label{packet-s20}

Create a full header with both a wrong magic and wrong version, then repair only the magic. Record the two statuses and explain the transition using the priority table. Repeat with a reserved flag and an excessive length. Keep the caller count at least eight for these header tests.

\subsection{Expected observation}
The first pair yields -2, then -3. Fixing an earlier defect can reveal a later one without changing its bytes.
