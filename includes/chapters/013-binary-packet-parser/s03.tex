\section{Step 3 Reject a short fixed header}\label{packet-s03}

Initialize the failure payload pointer to zero and select the need-more status. Compare the unsigned available count with eight before this implementation performs any input load. A nonzero comparison result branches to the supplied return stub. The count domain is nonnegative and at most 256.

\subsection{Write or inspect}
Append these instructions in the \texttt{bounds} region. Keep the scaffold labels and return stub.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -1
    move $v1, $zero
    sltiu $t9, $a1, 8
    bne $t9, $zero, packet_return
    nop
\end{minted}

\subsection{Expected observation}
With \texttt{a1} equal to seven, the function returns -1 with \texttt{v1} equal to zero and leaves both records unchanged.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
What must \texttt{v1} contain on failure?

\begin{itemize}
  \item \textbf{A} Zero.
  \item \textbf{B} The input pointer.
  \item \textbf{C} The partially decoded sequence.
\end{itemize}
