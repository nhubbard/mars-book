\section{Step 8 Apply the payload limit}\label{packet-s08}

Select bad length and test whether the decoded value is less than 65. The strict comparison accepts zero through 64. Reject larger lengths before testing body availability, as required by the error priority.

\subsection{Write or inspect}
Append these instructions in the \texttt{limit} region. Keep the scaffold labels and return stub.

\Needspace{7\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -5
    sltiu $t9, $t0, 65
    beq $t9, $zero, packet_return
    nop
\end{minted}

\subsection{Expected observation}
A complete header claiming 65 payload bytes reports -5 even when only eight input bytes are available.
