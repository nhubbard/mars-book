\section{Step 6 Reject reserved flag bits}\label{packet-s06}

Load the flags into \texttt{t1} so the accepted value survives until record publication. Mask with hexadecimal fe, which retains bits one through seven and clears the permitted bit zero. Any nonzero residue reports bad flags.

\subsection{Write or inspect}
Append these instructions in the \texttt{flags} region. Keep the scaffold labels and return stub.

\Needspace{8\baselineskip}
\MARSCodeLabel{MIPS assembly}
\begin{minted}[samepage=true]{mars-idea}
    li $v0, -4
    lbu $t1, 3($a0)
    andi $t9, $t1, 0xfe
    bne $t9, $zero, packet_return
    nop
\end{minted}

\subsection{Expected observation}
Flags zero and one pass; two, three, and 255 fail. The record is still untouched at this stage.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which mask tests the reserved bits?

\begin{itemize}
  \item \textbf{A} 0x01.
  \item \textbf{B} 0x00.
  \item \textbf{C} 0xfe.
\end{itemize}
