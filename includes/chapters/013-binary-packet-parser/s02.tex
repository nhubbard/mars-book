\section{Step 2 Identify the call interface}\label{packet-s02}

Inspect main before editing the function. It passes the packet address in \texttt{a0}, the available count in \texttt{a1}, and record\_a in \texttt{a2}. The function must also work when a grader supplies a different byte offset or record\_b. Temporary registers contain no promised inputs.

\subsection{Write or inspect}
Perform the described inspection or experiment without changing the submitted interface.

\subsection{Expected observation}
At function entry the arguments describe addresses and a length. They do not contain the first header word or a predecoded length.

\Needspace{11\baselineskip}
\subsection{Check your understanding}
Which value controls the permitted input interval?

\begin{itemize}
  \item \textbf{A} The entire mapped data segment.
  \item \textbf{B} The declared payload length before validation.
  \item \textbf{C} The caller supplied available count.
\end{itemize}
