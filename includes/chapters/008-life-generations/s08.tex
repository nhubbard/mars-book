\section{Step 8 Observe initialized generation
zero}\label{008-life-generations-s08-step-8-observe-initialized-generation-zero}

Generation zero is already a complete board, even though no rule
evaluation has occurred. A zero-step request will render this state and
exit.

\subsection{Write or
inspect}\label{008-life-generations-s08-write-or-inspect}

Inspect the default oscillator in \texttt{board\_a} before rendering.

\subsection{Expected
observation}\label{008-life-generations-s08-expected-observation}

The default live cells are (2,3), (3,3), and (4,3).

\subsection{Check your
understanding}\label{008-life-generations-s08-check-your-understanding}

Which board is current before any swap?

\begin{itemize}
\tightlist
\item
  \textbf{A} \texttt{board\_a}.
\item
  \textbf{B} \texttt{board\_b}.
\item
  \textbf{C} Neither; the seed allocation is writable current state.
\end{itemize}
