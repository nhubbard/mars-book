\section{Step 25 Check zero steps and buffer
  parity}\label{008-life-generations-s25-step-25-check-zero-steps-and-buffer-parity}

Generation zero is in \texttt{board\_a}. Each swap changes which
allocation is current, so even generations return to \texttt{board\_a}
and odd generations use \texttt{board\_b}. The other board retains the
previous complete generation after the first step.

\subsection{Write or
  inspect}\label{008-life-generations-s25-write-or-inspect}

Predict the current board for requested counts zero through four.

\subsection{Expected
  observation}\label{008-life-generations-s25-expected-observation}

Counts 0,2,4 use \texttt{board\_a}; counts 1,3 use \texttt{board\_b}.

\subsection{Check your
  understanding}\label{008-life-generations-s25-check-your-understanding}

What should the unused destination contain at generation zero?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} It must already be generation one.
  \item
        \textbf{B} Its interior is scratch and may still be arbitrary; its
        halo remains zero.
  \item
        \textbf{C} It must be an alias of the seed.
\end{itemize}
