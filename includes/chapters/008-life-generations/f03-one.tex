    \small
    \begin{enumerate}
      \item The condition \texttt{\$s3 == 1} selects the second visit to this source line. Before reaching it, the program completed the destination sweep, swapped the pointers, incremented the working counter, rendered the new current board and published its number.
      \item \texttt{\$s0}=\texttt{0x100101b0} now selects B as current; \texttt{\$s1}=\texttt{0x10010148} selects A as the next destination. A still contains generation zero. The sweep read that complete source without changing it.
      \item The new live cells are $(3,2)$, $(3,3)$ and $(3,4)$. Both end cells of the old horizontal line die; the center survives, and the cells above and below it are born. These decisions all used generation zero, rather than partially updated neighbors.
      \item The first four bytes, \texttt{01 00 00 00}, publish generation one. At \texttt{buffers\_swapped}, the working counter was already one but these bytes and the framebuffer still represented generation zero. They agree only after rendering and publication finish.
    \end{enumerate}
