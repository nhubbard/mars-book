\section{Publish a boundary that another program can
  inspect}\label{008-life-generations-p05-publish-a-boundary-that-another-program-can-inspect}

The \texttt{generation\_ready} label is a public interface for this
exercise. At entry, the current board, full frame, and generation word
must describe the same completed state. The grader and future guided
lesson can stop there without knowing the neighbor-loop labels or the
student\textquotesingle s scratch-register choices.

This label is not an instruction or a hardware transaction. The
preceding stores publish the data, and reaching the label identifies the
intended observation boundary. The working generation register can
already have advanced at a private intermediate label while the old
frame remains visible. Such a state is valid inside the computation but
is not ready for publication.

The initial ready boundary is generation zero. A request for zero steps
still copies the seed and renders it. A request for two produces three
complete observations: zero, one, and two. The exit test belongs at this
boundary so initialization is not confused with the first evolution
step.
