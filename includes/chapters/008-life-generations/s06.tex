\section{Step 6 Copy one binary
byte}\label{008-life-generations-s06-step-6-copy-one-binary-byte}

\texttt{lbu} reads one unsigned seed byte. \texttt{sb} stores it into
the working interior. Advancing both byte cursors by one prepares the
next column without changing the input allocation.

\subsection{Write or
inspect}\label{008-life-generations-s06-write-or-inspect}

Append the per-cell copy body.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    lbu $t4, 0($t0)
    sb $t4, 0($t1)
    daddiu $t0, $t0, 1
    daddiu $t1, $t1, 1
\end{minted}

\subsection{Expected
observation}\label{008-life-generations-s06-expected-observation}

Only the first interior byte has been copied at this partial stage.

\subsection{Check your
understanding}\label{008-life-generations-s06-check-your-understanding}

Does \texttt{lbu} create a live link to the seed byte?

\begin{itemize}
\tightlist
\item
  \textbf{A} Yes, later stores update the register automatically.
\item
  \textbf{B} Only if the byte is one.
\item
  \textbf{C} No; it copies the current byte value into a register.
\end{itemize}
