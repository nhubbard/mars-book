\section{Step 16 Store the next state into the other
  board}\label{008-life-generations-s16-step-16-store-the-next-state-into-the-other-board}

The destination pointer identifies the same cell in the next generation.
\texttt{sb} writes one binary state and leaves the source intact.

\subsection{Write or
  inspect}\label{008-life-generations-s16-write-or-inspect}

Append the destination store.

\MARSCodeLabel{MIPS assembly}
\begin{minted}{mars-idea}
    sb $t4, 0($t7)
cell_written:
\end{minted}

\subsection{Expected
  observation}\label{008-life-generations-s16-expected-observation}

The first next-state cell is complete; the rest of the destination may
still contain old data.

\subsection{Check your
  understanding}\label{008-life-generations-s16-check-your-understanding}

Is this partial destination ready to render as a generation?

\begin{itemize}
  \tightlist
  \item
        \textbf{A} Yes, because one cell is correct.
  \item
        \textbf{B} No; all 64 next-state cells must be complete first.
  \item
        \textbf{C} Only if the first cell is dead.
\end{itemize}
